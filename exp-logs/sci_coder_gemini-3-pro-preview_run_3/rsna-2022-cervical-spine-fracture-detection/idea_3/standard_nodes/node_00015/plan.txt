Implementation Strategy:
1.  **Configuration & Setup**: Initialize the environment using `library.config` and `library.utils`. Override `Config.EPOCHS` to 5 to ensure the "fast baseline" requirement is met within the time limit.
2.  **Data Preparation**: Load training and validation metadata. Initialize `CervicalSpineDataset` with appropriate `albumentations` transforms. Use `load_cached_data=True` to leverage pre-computed `.npy` volumes.
3.  **Model Initialization**: Instantiate the `AnatomicallyGuidedResNet` and move it to the GPU. Set up the `HierarchicalCompoundLoss` criterion, `AdamW` optimizer, and `CosineAnnealingLR` scheduler.
4.  **Training Loop**: Execute the training loop for the specified epochs. Inside the loop, use `library.engine.train_one_epoch` for training and `library.engine.validate` for monitoring performance. Save the model with the best validation metric.
5.  **Final Evaluation**: Load the best saved model. Perform a full validation pass to compute the `Final Validation Metric`.
6.  **Failure Analysis**: Run a custom inference pass on the validation set to extract per-study error magnitudes. Calculate the correlation between these errors and the number of slices (depth) of the scan to identify if scan complexity affects performance.
7.  **Submission**: Check if the validation metric is below the threshold (0.1307335607). If so, generate predictions for the test set using `test_metadata.csv`, format them according to `sample_submission.csv`, and save to `submission.csv`.
