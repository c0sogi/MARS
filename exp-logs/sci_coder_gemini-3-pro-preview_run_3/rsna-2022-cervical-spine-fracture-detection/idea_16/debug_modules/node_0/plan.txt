This script demonstrates the end-to-end workflow for the Cervical Spine Fracture Detection task using the provided library files.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to run in "Debug Mode". This reduces the number of slices per scan (from 64 to 8), batch size, and dataset size to ensure the script completes quickly (within minutes) while still exercising all code paths.
2.  **Data Loading**: We verify the `CervicalDataset` and `DataLoader` by loading a small subset of the training metadata. We assert that the output tensor shapes match the expected `(Batch, Slices, Channels, Height, Width)` format required by the MIL model.
3.  **Model Execution**: We instantiate the `FractureMILModel`, perform a forward pass with dummy data, and verify the output shape `(Batch, 8 classes)`.
4.  **Training Loop**: We simulate a single epoch of training and validation using `train_one_epoch` and `validate_one_epoch` to ensure the optimization step and loss calculation (Weighted Multi-Label Log Loss) function correctly.
5.  **Metric Verification**: We independently test the `calculate_weighted_loss_metric` function with synthetic perfect and imperfect predictions to confirm it behaves as expected (lower loss for better predictions).
