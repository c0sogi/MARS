This script demonstrates the end-to-end usage of the provided RSNA Cervical Spine Fracture Detection library. It covers configuration customization for rapid prototyping, utility verification, dataset loading, model instantiation, and a complete training loop execution.

The strategy includes:
1.  **Configuration Override**: Adjusting `Config` parameters (reducing image size, sequence length, and epochs) to ensure the demo runs quickly within the time limit.
2.  **Utility Testing**: Verifying core functions like `load_dicom`, `load_case_data`, and the custom `weighted_loss_metric` with assertions.
3.  **Dataset & DataLoader Verification**: Instantiating the dataset and iterating through a batch to confirm tensor shapes and data integrity.
4.  **Model Forward Pass**: initializing the `CervicalFractureModel` and running a dummy forward pass to verify architecture compatibility with the input data.
5.  **Training Loop**: Executing `run_training(debug=True)` to demonstrate the full training pipeline, including caching, training, validation, and checkpointing.
