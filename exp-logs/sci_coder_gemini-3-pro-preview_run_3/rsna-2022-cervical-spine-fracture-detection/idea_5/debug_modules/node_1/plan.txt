The issue arises because the `DataLoader` encounters inconsistent tensor shapes during batch creation. This happens because the `runfile.py` script overrides the `Config` parameters (changing `SEQ_LEN` and `IMAGE_SIZE`) but the `load_case_data` function loads stale cache files from a previous run that were generated with different dimensions. To fix this, I will modify `load_case_data` in `library/utils.py` to validate that the shape of the loaded cached data matches the current `Config` expectations. If the shapes mismatch, the cached data will be ignored and recomputed. This ensures that data constraints are consistently applied at the ingestion point (Cite debug_lesson_1).
