This script demonstrates the end-to-end workflow using the provided library files. It performs the following steps:

1.  **Configuration Override**: Monkey-patches the `Config` class to use a minimal dataset and reduced hyperparameters (batch size, epochs) for rapid execution within the time limit.
2.  **Environment Setup**: Disables `tqdm` progress bars to comply with output requirements and sets random seeds for reproducibility.
3.  **Data Loading**: Uses `get_dataloaders` in debug mode to load a small subset of the data.
4.  **Model Verification**: Manually inspects a batch from the DataLoader to verify input shapes for both the Locator and Filler tasks.
5.  **Training**: Initializes the `Trainer` and runs the training loop (Locator phase followed by Filler phase).
6.  **Inference**: Initializes the `Predictor`, generates predictions on the test set, and saves the submission file.
7.  **Validation**: Asserts that the submission file exists and follows the correct format.
