The following script demonstrates the end-to-end usage of the provided "Locate-and-Fill" library. It performs the following steps:
1.  **Configuration Override**: Adjusts the `Config` class to use a minimal subset of data (debug mode) and reduced hyperparameters (1 epoch, small batch size) to ensure the script executes quickly (within minutes).
2.  **Data Loading**: Demonstrates how to initialize dataloaders using `get_dataloaders` and validates the structure and shape of the batches.
3.  **Model Instantiation**: Initializes the `LocatorNetwork` and `FillerNetwork` and verifies their forward passes produce tensors with the expected shapes.
4.  **Training**: Uses the `Trainer` class to train both models on the small debug dataset and verifies that checkpoints are saved.
5.  **Inference**: Uses the `InferencePipeline` class to load the trained models, generate predictions on the test set, and create a submission file. It then validates the format of the generated CSV.
