To improve the model's performance, I will implement a strategy focusing on **Progressive Resizing** (Cite solution_lesson_node_00007) and advanced data augmentation, while removing the detrimental class-balancing stage (Cite solution_lesson_node_00002).

**Strategy Outline:**

1.  **Remove Stage 3**: The previous run demonstrated that Stage 3 (Class-Balanced Sampling) increased the Top-1 Error from 22.89% to 23.19%. Since our metric is global accuracy (micro-average) and the test set likely follows the natural long-tail distribution, forcing class balance hurts the overall performance.
2.  **Enhance Regularization with Mixup/Cutmix**: I will integrate `Mixup` and `Cutmix` augmentations. These are powerful regularizers that improve generalization and robustness, especially for fine-grained classification.
3.  **Extend Training Epochs**: To accommodate the stronger regularization from Mixup and maximize the benefits of Progressive Resizing, I will increase the training epochs for both Stage 1 (Representation Learning) and Stage 2 (High-Res Adaptation).
    *   Stage 1: 3 -> 5 epochs.
    *   Stage 2: 2 -> 5 epochs.
4.  **Update Threshold**: The submission logic will be updated to strictly follow the requirement of generating predictions only if the error is below 19.45%.

**Implementation Details:**
-   **Config**: Add `MIXUP_CONFIG`, enable `use_mixup` for stages, increase epochs, and remove Stage 3 config.
-   **Engine**: Integrate `timm.data.Mixup` and `timm.loss.SoftTargetCrossEntropy` into the training loop.
-   **Runfile**: Remove Stage 3 execution and update the submission threshold.

def train_one_epoch(
    model, loader, optimizer, criterion, device, scaler, mixup_fn=None
):
    """
    Trains the model for one epoch using Mixed Precision.
    """
    model.train()
    running_loss = 0.0
    correct_predictions = 0
    total_samples = 0

    for images, targets, _ in loader:
        images = images.to(device)
        targets = targets.to(device)

        if mixup_fn is not None:
            images, targets = mixup_fn(images, targets)

        optimizer.zero_grad()

        with torch.cuda.amp.autocast():
            outputs = model(images)
            loss = criterion(outputs, targets)

        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()

        running_loss += loss.item() * images.size(0)

        # Calculate accuracy (approximate if mixup is used)
        # If mixup is used, targets are soft, so we can't strictly compute acc here easily
        # We just use argmax of output vs argmax of target (if soft) or target (if hard)
        _, predicted = torch.max(outputs, 1)
        
        if mixup_fn is not None:
            # Recover hard label for accuracy calculation
            _, targets_hard = torch.max(targets, 1)
            correct_predictions += (predicted == targets_hard).sum().item()
        else:
            correct_predictions += (predicted == targets).sum().item()
            
        total_samples += images.size(0)

    avg_loss = running_loss / total_samples
    avg_acc = correct_predictions / total_samples

    return avg_loss, avg_acc
