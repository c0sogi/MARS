Based on the analysis of the previous attempts and the lessons learned, I propose a solution centered on **ConvNeXt-Base** utilizing a **Decoupled Regularization and Resolution (DRR)** training pipeline.

### Model
I propose replacing the EfficientNetV2 architecture with **ConvNeXt-Base**.
*   **Structural Innovation:** While EfficientNetV2 (MBConv) is optimized for parameter efficiency and speed, ConvNeXt adopts a modern, isotropic-like architecture inspired by Vision Transformers (ViTs) but implemented purely with convolutions (7x7 kernels). This design provides a larger receptive field and higher capacity, which is critical for **Fine-Grained Visual Classification (FGVC)** where context and subtle texture differences distinguish species.
*   **Head:** A single linear classification layer with 1,010 outputs.
*   **Initialization:** The model will be initialized with weights pre-trained on ImageNet-21k (via `timm`), providing a richer semantic starting point than ImageNet-1k, which is beneficial given the 1,010 classes.

### Data
I will implement a **Two-Phase Resolution Strategy**, building on the success of progressive resizing (Cite solution_lesson_node_00007) while correcting the regularization strategy.
*   **Preprocessing:**
    *   **Phase 1 (Representation Learning):** Input size **224x224**.
    *   **Phase 2 (Fine-Grained Refinement):** Input size **384x384**.
*   **Augmentation Strategy:**
    *   **Phase 1:** Heavy regularization using **Mixup** and **Cutmix**.
    *   **Phase 2:** Lighter regularization using only **RandAugment** and **Random Erasing**.
    *   **Rationale:** Previous attempts with Mixup failed because they were applied under strict time constraints (Cite solution_lesson_node_00009). By decoupling the regularization, we use Mixup in Phase 1 (where we can afford longer training) to learn robust, generalizable features, and remove it in Phase 2 to allow the model to resolve the fine-grained details necessary for species identification without the label noise introduced by Mixup.

### Training
The training process will be significantly extended to utilize the available 24-hour budget, addressing the convergence issues observed previously.

*   **Optimizer:** **AdamW** with a Cosine Annealing schedule.
*   **Loss Functions:**
    *   **Phase 1:** **Soft Target Cross-Entropy**. This is required to handle the probabilistic labels generated by Mixup/Cutmix.
    *   **Phase 2:** Standard **Cross-Entropy** with Label Smoothing (0.1).
*   **Sampling:** **Instance-Balanced Sampling** (standard shuffling) will be used throughout. We explicitly reject Inverse Frequency Weighting (Cite solution_lesson_node_00002) and Class-Balanced Sampling (Cite solution_lesson_node_00007) as both were shown to degrade the global Top-1 accuracy by sacrificing performance on head classes.
*   **Schedule:**
    *   **Phase 1 (224px):** Train for **20-30 epochs**. This extended duration ensures the model converges despite the difficulty added by Mixup/Cutmix.
    *   **Phase 2 (384px):** Fine-tune for **10 epochs** with a lower learning rate. This leverages the "FixRes" effect, adapting the robust features to the higher resolution.

### Evaluation
*   **Inference:** Predictions will be generated using the final model at **384x384** resolution.
*   **TTA:** Test Time Augmentation (Horizontal Flip) will be applied.
*   **Submission:** The model will predict the class with the highest softmax probability. The submission file will include the top-5 sorted predictions.
