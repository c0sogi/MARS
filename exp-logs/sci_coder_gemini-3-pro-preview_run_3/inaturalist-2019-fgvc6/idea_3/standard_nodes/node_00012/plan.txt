The previous implementation failed with a `torch.OutOfMemoryError` because the configuration assumed access to the full 40GB of an A100 GPU (using a batch size of 64 for `convnext_base`), whereas the runtime environment only provided ~16GB of effective VRAM. Additionally, the training loop used standard single-precision (FP32), which consumes more memory.

To fix this, I will:
1.  **Reduce Batch Sizes**: Update `library/config.py` to lower the batch sizes for Phase 1 (64 → 32), Phase 2 (32 → 16), and Inference (64 → 32) to fit within the 16GB limit.
2.  **Implement Mixed Precision Training**: Update `library/engine.py` to use `torch.amp.autocast` and `GradScaler` to reduce memory usage and accelerate training.
3.  **Integrate Scaler**: Update `runfile.py` to initialize the `GradScaler` and pass it to the training function.

These changes directly apply the guidance from **debug_lesson_2** ("Verify Effective VRAM Capacity and Implement Mixed Precision Training").
