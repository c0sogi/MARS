The `NameError: name 'SR' is not defined` arises because, in Python 3, list comprehensions create their own scope. Variables defined within a class body (like `SR`) are not visible to the inner scope of list comprehensions defined in the same class. To fix this, I will define `SR` at the module level (global scope) so it is accessible everywhere, including inside the list comprehension. I will then update the `Config` class to reference this global constant.
