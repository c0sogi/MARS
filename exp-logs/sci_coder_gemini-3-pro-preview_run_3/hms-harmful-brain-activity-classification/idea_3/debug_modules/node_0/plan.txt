This script demonstrates the end-to-end pipeline for the EEG Harmful Brain Activity Detection task using the provided library. It performs the following steps:

1.  **Configuration Override**: Adjusts `Config` parameters (epochs, batch size, directories) to ensure the demonstration runs quickly and uses a separate working directory.
2.  **Data Pipeline Verification**: Loads a small subset of training data, verifies the shape of the generated spectrograms and targets, and checks for data integrity.
3.  **Model Verification**: Instantiates the `EEGNet` model, performs a forward pass with a dummy batch, and asserts that the output dimensions and probability constraints (Softmax) are correct.
4.  **Training Execution**: Runs the training loop for 1 epoch on a small subset of data (`debug_subset_size=50`) to generate a valid model checkpoint.
5.  **Inference Execution**: Runs the inference pipeline on a subset of the test data using the trained model.
6.  **Submission Validation**: Verifies that the generated submission file follows the required format and constraints (probabilities sum to 1).
