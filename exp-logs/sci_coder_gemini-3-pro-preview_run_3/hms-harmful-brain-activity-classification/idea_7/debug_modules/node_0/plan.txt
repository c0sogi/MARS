This script demonstrates the end-to-end pipeline for the EEG classification task using the provided library files. It overrides the default configuration to run in a "debug" mode with a small subset of data and limited epochs for rapid execution. The script performs the following steps:

1.  **Configuration Setup**: Modifies `Config` to use a temporary working directory and reduces training parameters (epochs, batch size) for speed.
2.  **Data Loading**: Loads the metadata, slices a small subset (e.g., 50 samples) for training and validation, and initializes the `DataLoader`s. This triggers the caching mechanism which processes raw EEG/Spectrogram Parquet files into memory-mapped Numpy arrays.
3.  **Model Initialization**: Instantiates the `DualScaleSpectrogramNet` and verifies the input/output dimensions with a dummy batch.
4.  **Training Loop**: Manually executes a training loop for a few epochs using `train_one_epoch` and `validate`, printing loss and KL divergence metrics.
5.  **Inference & Submission**: Generates predictions on a subset of the test data and creates a valid `submission.csv` file.
6.  **Validation**: Includes assertions throughout to ensure data shapes, model outputs, and file generation are correct.
