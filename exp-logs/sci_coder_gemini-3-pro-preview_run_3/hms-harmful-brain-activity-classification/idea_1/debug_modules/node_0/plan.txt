The following script demonstrates the end-to-end usage of the provided EEG seizure detection library.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode, reduce `EPOCHS` to 2, and set a small `BATCH_SIZE`. This ensures the script runs quickly on a tiny subset of the data without modifying the source files.
2.  **Component Verification**:
    *   **Utilities**: Verify the `AverageMeter` logic.
    *   **Data Pipeline**: Initialize dataloaders, fetch a single batch, and assert correct tensor shapes (Batch, Time, Channels) and data integrity (no NaNs).
    *   **Model**: Instantiate the `BiGRUModel`, perform a forward pass with the fetched batch, and verify output dimensions.
    *   **Training**: Execute `train_model()` to ensure the training loop, loss calculation, backpropagation, and checkpoint saving mechanisms function correctly.
    *   **Inference**: Run `generate_submission()` to load the saved checkpoint, predict on the test set, and verify that the output CSV follows the required format (probabilities summing to 1.0).
3.  **Validation**: Strict assertions are placed at every step to guarantee correctness. Any failure will raise an `AssertionError`.
