Based on the lessons learned from the previous experiments, I propose the **Attentive Dual-Scale Fusion Network with Gated Context**. This solution builds upon the successful dual-stream architecture of Idea 7 but introduces structural innovations in the input adaptation and feature fusion stages to better preserve spatial integrity and model the hierarchical relationship between context and morphology.

# Model
The architecture is a two-stream Convolutional Neural Network that processes orthogonal temporal scales, leveraging pretrained backbones for stability while introducing attention mechanisms to refine feature extraction and combination.

1.  **Stream A: Fine-Grained Morphological Encoder (50s Window)**
    *   **Input:** Generated Mel-Spectrograms from the 50-second EEG clip with shape `(Frequency, Time, Depth=19)`.
    *   **Innovation 1: Channel-Wise Attention Adapter:** Before the standard `1x1 Convolution` that projects the 19 channels to 3 (for the backbone), we insert a **Squeeze-and-Excitation (SE) Block** operating on the 19 input channels.
        *   **Rationale:** A static 1x1 convolution learns a fixed linear combination of electrodes. However, brain activity like seizures can be focal (local to specific electrodes). The SE block allows the model to *dynamically* re-weight the importance of each electrode channel for every sample based on the global signal content, preserving spatial integrity and relevance before the dimension reduction **Cite {solution_lesson_node_00006}**.
    *   **Backbone:** **EfficientNet-B2** (Pretrained on ImageNet). This extracts detailed texture and frequency patterns from the channel-weighted spectrograms **Cite {solution_lesson_node_00018}**.

2.  **Stream B: Long-Term Context Encoder (10m Window)**
    *   **Input:** The provided Kaggle Spectrograms covering the 10-minute window with shape `(Frequency, Time, Depth=4)`.
    *   **Backbone:** **EfficientNet-B0** (Pretrained on ImageNet). This captures slow-moving trends (e.g., GPDs) that provide orthogonal information to the short-term window **Cite {solution_lesson_node_00015}**.

3.  **Fusion Head:**
    *   **Innovation 2: Gated Context Mechanism:** Instead of simply concatenating the feature vectors from Stream A ($f_A$) and Stream B ($f_B$), we employ a gating logic. $f_B$ is passed through a dense layer with a Sigmoid activation to produce a gate vector $g$. The final fused representation is $f_{fused} = f_A \otimes g$ (element-wise multiplication).
        *   **Rationale:** This explicitly models the expert annotation process where the long-term context *modulates* the interpretation of the short-term morphology (e.g., "If the 10m context shows generalized slowing, interpret the 50s spikes differently").

# Data
*   **Stream A Preprocessing (Dynamic Generation):**
    *   Load the 50-second raw EEG from `train_eegs`.
    *   Compute the **Short-Time Fourier Transform (STFT)** and convert to **Mel-Scale Spectrograms** (e.g., 128 bins).
    *   Apply `log(S + epsilon)` and normalize to ImageNet statistics.
    *   **Stacking:** Stack the 19 EEG channels along the **depth axis** to form the `(128, Time, 19)` input tensor. This enables the SE-Adapter to operate on distinct channels **Cite {solution_lesson_node_00006}**.
*   **Stream B Preprocessing (Static Loading):**
    *   Load the 10-minute spectrogram from `train_spectrograms`.
    *   Apply `log` transformation and replace NaNs with the global mean.
    *   Resize spatial dimensions to `(256, 256)` and stack the 4 anatomical regions (LL, RL, LP, RP) along the depth axis.
*   **Augmentation:**
    *   Apply **SpecAugment** (Frequency and Time Masking) to both streams independently. This is critical to prevent the powerful backbones from memorizing noise **Cite {solution_lesson_node_00001}**.
    *   Apply **MixUp** to the training batches.

# Training
*   **Loss Function:** **Kullback-Leibler (KL) Divergence**.
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler.
*   **Strategy:** Since both streams utilize **Pretrained Backbones** (EfficientNet-B2 and B0), we can use a **single, consistent learning rate** (e.g., `3e-4`) for the entire network. This avoids the optimization instability observed when mixing scratch-trained and pretrained models **Cite {solution_lesson_node_00016}**.

# Evaluation
*   **Inference Pipeline:**
    1.  Iterate through `test.csv`.
    2.  Load the 50s EEG, generate the 19-channel Mel-Spectrogram, and pass through Stream A (Attention Adapter -> EfficientNet-B2).
    3.  Load the 10m Spectrogram, reshape to 4-channel depth, and pass through Stream B (EfficientNet-B0).
    4.  Apply the Gated Fusion to the outputs and predict the probability distribution via the final Softmax layer.
