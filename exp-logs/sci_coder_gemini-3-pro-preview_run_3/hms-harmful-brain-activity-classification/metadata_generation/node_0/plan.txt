The implementation strategy is as follows:

1.  **Setup and Loading**: Define input/output paths and constants. Load `train.csv` and `test.csv` from the `./input` directory.
2.  **Path Construction**: Create new columns in the dataframes (`eeg_path` and `spec_path`) containing relative paths to the `.parquet` files (e.g., `train_eegs/{id}.parquet`), ensuring compliance with the requirement to store paths relative to `./input`.
3.  **Target Normalization**: Calculate probability distributions for the 6 target classes (seizure, lpd, gpd, lrda, grda, other) by normalizing the raw vote counts in `train.csv`. These normalized columns (ending in `_prob`) will be used for training with the KL Divergence metric.
4.  **Data Splitting**: Use `GroupShuffleSplit` on the training data, grouping by `patient_id`. This ensures that all recordings from a specific patient end up in either the training set or the validation set, preventing data leakage. The split ratio is fixed at 80% training and 20% validation with a random state of 42.
5.  **Saving Metadata**: Save the processed dataframes to `./metadata/train.csv`, `./metadata/val.csv`, and `./metadata/test.csv`.
6.  **Validation**: Immediately reload the saved metadata to perform the required checks:
    *   Print summary statistics (shapes, unique patients, class distributions).
    *   Verify file existence by checking a random sample of 1000 paths against the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    *   Assert that the intersection of patient IDs in train and validation sets is empty to verify the group split.
