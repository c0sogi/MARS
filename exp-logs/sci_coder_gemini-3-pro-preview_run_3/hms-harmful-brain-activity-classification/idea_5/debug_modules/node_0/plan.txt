This script demonstrates the end-to-end usage of the provided library files for the EEG seizure detection task. It performs the following steps:

1.  **Configuration Setup**: Creates a temporary working directory and overrides default configuration paths to use a small subset of the metadata. This ensures the data processing step in `HMSDataset` runs quickly (processing only ~20 samples instead of 80,000).
2.  **Dataset Verification**: Instantiates the `HMSDataset` with the subset metadata, verifies that data caching works, and asserts that the yielded tensors (EEG, Spectrogram, and Targets) have the correct shapes and data types.
3.  **Model Verification**: Instantiates the `HybridModel`, performs a forward pass with dummy data matching the dataset dimensions, and verifies the output shape (Batch Size, Num Classes).
4.  **Training Loop**: Executes the `train()` function for a single epoch. This validates the data loading, model forward/backward passes, loss calculation (`KLDivLossWithLogits`), and checkpoint saving mechanisms.
5.  **Inference**: Runs the `predict()` function using the trained model checkpoint on the test subset, generating a submission file and verifying its format.
