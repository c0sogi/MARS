Based on the rigorous analysis of the "Lessons Learned" and the progression of "Previous Ideas," I propose the **Structural-Kinematic Decoupled-Gated Network (SKD-GN)**.

This solution represents a structural synthesis that explicitly enables **Spatial Structure Learning** and **Robustness to Sensor Jitter**, strategies that were theoretically sound but failed in previous attempts due to engineering bottlenecks (Parsing Failures in Idea 13, Execution Failures in Idea 48). By integrating **Explicit Bone Vectors** and **Gaussian Noise Injection** into the highly successful **Decoupled-Norm Gating** architecture (Idea 47), we create a model that captures the full spatiotemporal dynamics of the skeleton while maintaining the strict signal-to-noise hierarchy required for stability.

# Model
The architecture is a **Three-Stage Cascaded Network** designed to leverage explicit structural features within a robust, noise-aware framework.

1.  **Stage 1: Structural-Kinematic Decoupled-Gated Encoder**
    *   **Input:** An **Early Fusion** vector consisting of two streams:
        *   **Skeleton Stream:** A rich, physically consistent feature set comprising **Position** (Centered), **Bone Vectors** (Structural), **Velocity** (Temporal), and **Acceleration** (Dynamic).
            *   **Structural Innovation (Explicit Bone Vectors):** We explicitly calculate the vectors between connected parent-child joints (e.g., $P_{wrist} - P_{elbow}$). Unlike raw positions, bone vectors provide **Pose-Invariant Structure** explicit to the graph topology. Previously, this feature caused pipeline crashes (Cite solution_lesson_node_00045); we enable it now via robust parsing.
            *   **Raw Magnitude Retention:** We retain all features in **Raw Millimeters**. Bone vectors share the same magnitude scale as Positions (~1000), fitting perfectly into the hierarchy (Position/Bones $\gg$ Velocity $\gg$ Acceleration) required to filter noise (Cite solution_lesson_node_00085).
        *   **Audio Stream:** MFCC features.
    *   **Decoupled-Norm Input Gating:** We retain the split-path gating mechanism to handle the magnitude disparity between Skeleton (~1000) and Audio (~100):
        *   *Path A (Gate Generation):* $X_{norm} = LayerNorm(X_{raw})$. Used to generate the attention mask via a Sigmoid activation. This prevents the saturation/vanishing gradients caused by raw inputs (Cite solution_lesson_node_00096).
        *   *Path B (Signal Retention):* The original $X_{raw}$ is retained.
        *   *Fusion:* $\tilde{X} = X_{raw} \odot \sigma(Linear(X_{norm}))$. This allows dynamic noise suppression without altering the physical scale of the valid signal (Cite solution_lesson_node_00132).
    *   **Backbone:** A **2-Layer Bi-directional GRU (Bi-GRU)** with **96 units per direction** (192 total). This "Goldilocks" capacity avoids the bottlenecks of lightweight encoders (Cite solution_lesson_node_00066) and the instability of high-capacity models (Cite solution_lesson_node_00110).
    *   **Regularization:** **Dropout (p=0.4)** is applied between GRU layers (Cite solution_lesson_node_00091).
    *   **Output:** Initial frame-wise class probabilities ($P_1$).

2.  **Stage 2: RF-Aligned Monotonic Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_1$) from Stage 1 (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Gated Dilated Temporal Convolutional Layers** using **Standard Convolutions** (Cite solution_lesson_node_00065).
    *   **Dilation Schedule:** **Monotonically Increasing** $[1, 2, 4, 8, 16]$.
        *   *Rationale:* This yields a receptive field of **63 frames**, matching the 64-frame training window almost perfectly ($63 < 64$). This maximizes context without reading invalid zero-padding (Cite solution_lesson_node_00127, solution_lesson_node_00057).
    *   **Causality:** **Centered Padding** (Non-Causal) to leverage future context (Cite solution_lesson_node_00078).
    *   **Output:** Refined class probabilities ($P_2$).

3.  **Stage 3: Independent RF-Aligned Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights** (Cite solution_lesson_node_00054).
    *   **Output:** Final class probabilities ($P_3$).

# Data
The data pipeline incorporates critical engineering fixes for robustness and advanced kinematic derivation.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files, dynamically handling struct vs. cell array vs. primitive types. This is the critical fix that allows us to finally ingest the **Bone Vector** features without crashing (Cite solution_lesson_node_00045).

2.  **Noise-Robust Kinematic Derivation (Structural Innovation):**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Center:** Apply **Root-Relative Centering** (subtracting Hip Center) (Cite solution_lesson_node_00102).
    *   **Augment 1 (Geometric):** Apply random 3D rotations (Y-axis) and scaling.
    *   **Augment 2 (Injection):** Inject **Gaussian Noise** ($\sigma=0.01$) to the position data *before* derivation. This forces the model to learn kinematic features robust to sensor jitter, a strategy that previously failed due to execution errors (Cite solution_lesson_node_00133).
    *   **Derive:** Calculate **Bone Vectors**, **Velocity**, and **Acceleration** using **Central Differences** (`np.gradient`) on the noisy, augmented positions (Cite solution_lesson_node_00127).

3.  **Sampling Strategy:**
    *   **Windowing:** **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** **Moderate Stride** (32 frames) (Cite solution_lesson_node_00053).
    *   **Cache Invalidation:** Explicitly update the experiment ID to force re-computation of the dataset with the new features (Cite solution_lesson_node_00133).

# Training
The training strategy employs robust loss formulations, explicitly rejecting Label Smoothing.

1.  **Cascaded Loss Function:**
    *   $L_{total} = L(P_1) + L(P_2) + L(P_3)$ (Deep Supervision) (Cite solution_lesson_node_00025).
    *   **Weighted Cross-Entropy:** We strictly use **Class Weighting** (weight 0.2 for background). We explicitly **reject Label Smoothing** (Cite solution_lesson_node_00137).
    *   **Log-Space Smoothing Loss:** Truncated MSE on log-probabilities.
    *   **Calibration:** **Low Weight** ($\lambda=0.15$) and **Low Threshold** (1.0) to prevent under-segmentation (Cite solution_lesson_node_00111).

2.  **Optimizer:**
    *   **Adam** optimizer with **Weight Decay** (L2) (Cite solution_lesson_node_00055).

# Evaluation
1.  **Inference:** **Full Sequence Inference** (Batch Size=1) to preserve global temporal context (Cite solution_lesson_node_00079).
2.  **Model Selection:** Select best checkpoint based on **Levenshtein Distance** on full sequences (Cite solution_lesson_node_00075).
3.  **Decoding:**
    *   Apply `argmax` to $P_3$.
    *   Perform **Run-Length Encoding**.
    *   **Min Duration Filter:** Remove segments shorter than **5 frames** (Cite solution_lesson_node_00071).
