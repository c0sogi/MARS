The issue is that `scipy.io.loadmat` returns a Python dictionary, not an object with attributes, so `hasattr(mat, "Video")` evaluates to `False` and `mat.Video` raises an `AttributeError` (or would, if the check didn't cause an early return). This causes the parser to silently return `None` for every file, resulting in an empty dataset and the subsequent `ValueError` in the `DataLoader`. Additionally, when using `squeeze_me=True`, the extracted "Video" struct is often wrapped in a 0-d NumPy array, which must be unwrapped using `.item()` to access its fields.

To fix this, I will modify `library/data_loader.py` to access the "Video" key using dictionary syntax (Cite debug_lesson_2) and explicitly unwrap the result if it is a 0-d array (Cite debug_lesson_16).
