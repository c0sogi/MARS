Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules from the `library` package. Set the random seed for reproducibility.
2.  **Configuration Overrides**: Modify the global `config` variables to create a lightweight execution environment. This includes setting a new working directory, reducing the dataset size (`DEBUG_SUBSET_SIZE`), decreasing the number of epochs, and adjusting batch sizes to ensure the script runs quickly (under 1 hour).
3.  **Utility Verification**: Explicitly test the helper functions in `utils.py`, such as Levenshtein distance calculation and sequence decoding, using assertions to verify correctness.
4.  **Model Verification**: Instantiate the `KC_IRN` model from `model.py`. Pass a dummy tensor through it to verify that the forward pass works and returns the expected output shapes (multi-stage predictions).
5.  **Data Loader Verification**: Initialize the data loaders using `data_loader.py` with the reduced subset. Fetch a single batch to verify the shape of the input features (RGB+Depth+Audio) and target labels.
6.  **Training & Inference Pipeline**: Execute the full training and inference workflow using `train.train_model()`. This will train the model on the small subset, validate it, and generate predictions for the test set.
7.  **Result Validation**: Check for the existence of the generated artifacts (model checkpoint, logs, submission file) and verify the format of the submission file.
