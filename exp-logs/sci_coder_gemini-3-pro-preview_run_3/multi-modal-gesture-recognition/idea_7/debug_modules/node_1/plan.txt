The issue is that `scipy.io.loadmat` returns a dictionary, but the code in `extract_skeleton_data` attempts to access the top-level `Video` variable using attribute syntax (`mat_data.Video`) instead of dictionary syntax (`mat_data['Video']`). This raises an `AttributeError`, which is caught by the `try-except` block, causing the function to return empty data for every file. Consequently, the dataset becomes empty, leading to a `ValueError` in the `DataLoader`.

I will fix this by changing the access method to use dictionary keys (Cite debug_lesson_2). I will also correct the fallback logic in the exception handler to use proper dictionary access.
