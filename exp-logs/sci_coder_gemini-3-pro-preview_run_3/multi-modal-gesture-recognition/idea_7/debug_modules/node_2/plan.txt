The error is caused by unconditionally appending a comma when formatting the submission line, even when the predicted sequence of gestures is empty. This results in lines like `SampleID,`, which causes the validation script to fail when it attempts to parse the empty string after the comma as an integer. To fix this, I will modify `library/predict.py` and `library/train.py` to check if the sequence is non-empty before appending the comma and labels, ensuring that lines with no predictions contain only the `SampleID`.
