The execution failure `AttributeError: module 'library.config' has no attribute 'MEDIAN_WINDOW'` indicates that the `library/utils.py` module depends on a configuration variable `MEDIAN_WINDOW` that is missing from `library/config.py`. This is a synchronization issue between the central configuration and dependent modules (Cite debug_lesson_6). To fix this, I will define `MEDIAN_WINDOW` in `library/config.py` with a default value of 7, which is a standard kernel size for median filtering in gesture recognition tasks.
