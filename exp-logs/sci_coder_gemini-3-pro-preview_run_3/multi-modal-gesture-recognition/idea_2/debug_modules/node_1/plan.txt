The issue is that `scipy.io.loadmat` returns a Python dictionary, where keys correspond to MATLAB variable names. The current implementation of `extract_skeleton_features` attempts to access the `Video` variable using attribute syntax (`mat_data.Video`), which fails and causes the function to return `None` for all samples. The fix is to access the `Video` structure using dictionary key syntax (`mat_data["Video"]`).
