To address the limitations of the previous RNN-based approach—specifically the reliance on heuristic post-processing to fix "jittery" predictions—I propose a **Multi-Stage Temporal Convolutional Network (MS-TCN)**. This architecture introduces a structural innovation by replacing the manual smoothing step with a learned temporal refinement stage, allowing the model to optimize segmentation boundaries and consistency directly from the data.

# Model
The architecture consists of two stacked stages of **Dilated Temporal Convolutional Networks (TCNs)**.
*   **Stage 1 (Prediction Network):** This network takes the frame-wise feature vectors as input. It consists of a series of residual layers with dilated convolutions. The dilation factors increase exponentially (e.g., 1, 2, 4, 8, 16) with each layer, allowing the network to exponentially expand its receptive field and capture long-range temporal dependencies without losing resolution. This stage outputs a probability distribution over the 21 classes for each frame.
*   **Stage 2 (Refinement Network):** This network takes the **output probabilities** of Stage 1 (rather than the raw features) as input. It shares the same dilated residual architecture. Its purpose is to refine the initial predictions by looking at the sequence of class probabilities, effectively learning to correct isolated errors and smooth transitions based on the global context of the gesture sequence. This replaces the manual median filter used previously with a learned smoothing mechanism.

# Data
We will retain the successful feature engineering pipeline established in previous lessons.
*   **Inputs:** The input vector for each frame will be the concatenation of **Normalized 3D Skeleton Coordinates**, **Skeleton Velocity Derivatives**, and **Audio MFCCs**. The inclusion of explicit velocity features is preserved as it significantly boosts dynamic modeling capabilities (Cite solution_lesson_node_00005).
*   **Labels:** We continue to use **dense frame-wise labels**, where every frame is assigned a class ID (0-20). This dense supervision signal is critical for stabilizing the training of sequence models on this dataset (Cite solution_lesson_node_00002).

# Training
The training procedure is designed to enforce both accuracy and temporal smoothness.
*   **Loss Function:** We will use a **Multi-Stage Loss**. The total loss is the sum of the losses for both stages.
    *   **Cross-Entropy Loss:** Applied to the output of both Stage 1 and Stage 2 to ensure both stages learn to classify gestures.
    *   **Smoothing Loss (Truncated MSE):** We will add a regularization term that penalizes the difference in log-probabilities between adjacent frames (e.g., $\sum | \log(p_t) - \log(p_{t-1}) |$). This encourages the model to produce stable, continuous segments, reducing the "jitter" observed in the RNN approach (Cite solution_lesson_node_00002).
*   **Optimizer:** Adam optimizer will be used.
*   **Strategy:** Both stages are trained end-to-end. The refinement stage learns to correct the mistakes of the prediction stage.

# Evaluation
*   **Inference:** The test sequences are passed through the full MS-TCN. The final prediction is taken from the output of **Stage 2**.
*   **Decoding:** We apply `argmax` to the Stage 2 probabilities to get the class for each frame. Because the Refinement Network explicitly learns to output smooth segments, we can reduce the reliance on aggressive post-processing. We will perform a simple **run-length encoding** to collapse consecutive identical labels into a list of gesture IDs, removing the background class (0) and any extremely short segments (e.g., < 5 frames) as a final safety check.
