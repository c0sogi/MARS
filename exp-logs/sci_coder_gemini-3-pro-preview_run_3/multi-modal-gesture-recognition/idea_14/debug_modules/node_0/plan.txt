The following script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition.

**Implementation Strategy:**
1.  **Configuration Setup**: We modify the global `Config` to use a temporary working directory (`./working/demo_execution`) and reduce training hyperparameters (2 epochs, batch size 4) to ensure rapid execution.
2.  **Mini-Dataset Creation**: Instead of processing the entire dataset, we create "mini" versions of the training, validation, and test metadata CSVs containing only a few samples. This verifies the data loading pipeline without incurring the time cost of processing the full dataset.
3.  **Component Verification**:
    *   **Model**: We instantiate the `RSKARN` model and pass a dummy tensor to verify the shape of the outputs from all three refinement stages.
    *   **Loss**: We compute the `CascadedLoss` on the dummy outputs to ensure the loss function (CrossEntropy + Smoothing) operates correctly.
    *   **Dataset**: We initialize the `GestureDataset` with the mini-metadata, triggering the feature extraction and caching mechanism. We verify the shape of the returned tensors.
4.  **Training Loop**: We execute the `Trainer.fit()` method. This runs the full training cycle (forward pass, backward pass, optimizer step, validation) on the mini-dataset, saving the best model.
5.  **Inference & Metrics**: We use the trained model to generate predictions on the mini-test set using the `InferenceEngine`. We also verify the `calculate_score` function (Levenshtein distance metric) with a known synthetic example.
