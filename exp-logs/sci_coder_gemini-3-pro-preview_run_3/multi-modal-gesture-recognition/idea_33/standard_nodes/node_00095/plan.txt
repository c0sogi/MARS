Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Patching**: To satisfy the "fast baseline" requirement, I will monkey-patch the `NUM_EPOCHS` in the `library.trainer` module to a lower value (15) before starting training. This ensures the execution completes well within the time limit.
2.  **Training**: I will instantiate the `ModelTrainer` from `library.trainer` and execute the `train()` method. This handles the training loop, deep supervision loss calculation, and saving the best model based on validation performance.
3.  **Validation & Metric Calculation**: After training, I will reload the best saved model (`best_model.pth`) and perform a dedicated inference pass on the validation set. I will manually aggregate the sliding window predictions to reconstruct full sequences, calculate the Levenshtein distance for each sample, and compute the final global metric. This allows me to print the exact `Final Validation Metric` required.
4.  **Failure Analysis**: During the validation pass, I will collect metadata for each sample (sequence duration, number of gestures, and average kinematic energy). I will then compute and print the Pearson correlation between the error (Levenshtein distance) and these features to identify systematic failure modes (e.g., does the model fail on longer sequences?).
5.  **Submission**: I will compare the final validation metric against the threshold (0.2251). If the model performs sufficiently well, I will instantiate the `SequencePredictor` to generate the `submission.csv` file for the test set.
