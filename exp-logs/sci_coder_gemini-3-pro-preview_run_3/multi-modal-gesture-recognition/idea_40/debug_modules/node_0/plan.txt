    *   We utilize `process_dataset` to load a small cache of training data.
    *   We instantiate the `GestureDataset` and inspect the shape of the features and labels returned by `__getitem__` to ensure they match the expected dimensions (Window Size x Feature Dim).

    *   We initialize the `Trainer` class.

    *   We decode the probability outputs into gesture labels using `decode_predictions`.
