Implementation Strategy:
1.  **Configuration Setup**: Initialize random seeds and override `Config` parameters (directories, batch size, epochs) to ensure the script runs quickly and uses a temporary workspace.
2.  **Data Subsetting**: Create a temporary metadata directory. Read the original metadata CSVs (`train.csv`, `val.csv`, `test.csv`), select a small subset of samples (e.g., 5-10 sequences), and save them to the temporary directory. This forces the data loader to process only a fraction of the data.
3.  **Component Validation**:
    *   **Model**: Instantiate the `GHCKRN` model and perform a forward pass with dummy tensors to verify shape compatibility.
    *   **Loss**: Instantiate `CascadedLoss` and compute loss on dummy outputs to ensure the logic holds.
    *   **Utils**: Verify the Levenshtein distance calculation with a simple known example.
4.  **Pipeline Execution**:
    *   Call `get_dataloaders()` which will now read from the subset metadata.
    *   Initialize the `Trainer` class.
    *   Run `trainer.fit()` for a minimal number of epochs (e.g., 1 or 2).
    *   Run `trainer.generate_submission()` to produce the output CSV.
5.  **Output Verification**: Check that the submission file exists and contains valid rows matching the expected format.
