Furthermore, when `squeeze_me=True` is used, the "Video" struct is loaded as a 0-d NumPy array, which must be explicitly unwrapped using `.item()` before its fields (like `Frames`) can be accessed (Cite debug_lesson_16). The fix involves accessing "Video" via dictionary lookup and unwrapping the resulting object if it is a 0-d array.
