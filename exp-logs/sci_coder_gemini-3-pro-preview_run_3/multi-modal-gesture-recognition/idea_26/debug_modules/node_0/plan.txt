This script demonstrates the usage of the provided HC-NCSN (High-Capacity Non-Causal Sawtooth Network) library components. It performs the following steps:

1.  **Setup & Configuration**: Patches the global `Config` to use a temporary working directory and reduces hyperparameters (epochs, batch size) for a rapid demonstration.
2.  **Data Preparation**: Creates subset metadata files (CSV) from the original metadata to run the pipeline on a small fraction of the data (10 samples).
3.  **Data Loading**: Uses `get_data_loaders` to process the raw multimodal data (Skeleton + Audio) from the subset and create PyTorch DataLoaders. It verifies the shape of the generated batches.
4.  **Model Verification**: Instantiates the `HCNCSN` model and performs a dummy forward pass to verify input/output tensor shapes.
5.  **Training Loop**: Instantiates the `Trainer` class and runs the `fit` method. This demonstrates the training process, including loss calculation (CrossEntropy + Smoothing) and validation (Levenshtein distance).
6.  **Inference**: Uses the trained model to generate predictions on the test subset via `generate_submission` and verifies the output file format.
7.  **Utility Testing**: Validates the logic of helper functions like `levenshtein_distance`.
