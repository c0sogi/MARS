Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override `NUM_EPOCHS` to 30 and `BATCH_SIZE` to 32 to ensure the training completes quickly within the "Fast Baseline" constraints while still allowing convergence on the small dataset.
2.  **Data Loading**: Use `get_data_loaders(load_cached_data=True)` to retrieve the data loaders. Crucially, strictly distinguish between the training loader (windowed, for optimization) and the validation loader. We will use `val_metric_loader` (full sequences) for the validation phase in `trainer.fit` because the `Trainer.validate` method expects full sequence batches (tuples of 3 items) to compute the Levenshtein metric correctly.
3.  **Model Training**: Initialize the `Trainer` and execute `trainer.fit(train_loader, val_metric_loader)`. This handles the training loop, deep supervision loss calculation, and model checkpointing based on the Levenshtein metric.
4.  **Final Validation**: After training, explicitly call `trainer.validate(val_metric_loader)` to compute the final performance metric on the hold-out set. Print this metric in the required format.
5.  **Failure Analysis**: Iterate through the validation set using the trained model to collect error statistics. Calculate the Levenshtein distance for each sample and compute the Pearson correlation between the error and metadata features (sequence length, number of gestures). Print these correlations to identify error patterns.
6.  **Submission Generation**: Check if the final validation metric is below the threshold of 0.2251. If satisfied, call `trainer.generate_submission` to create `submission.csv` for the test set.
