The following script demonstrates the usage of the provided library modules for the gesture recognition task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `config` parameters to run in `DEBUG` mode with a tiny subset of data (5 samples), reduced batch size, and only 1 epoch. This ensures the demonstration completes quickly.
2.  **Utility Verification**: We explicitly test the metric calculation (`levenshtein_distance`) and post-processing logic (`process_predictions`) with synthetic data to ensure correctness.
3.  **Data Loading**: We utilize `data_loader.get_dataloaders()` to load the data pipeline. We verify the shape of the generated batches (Features: `Batch x Window x 193`, Targets: `Batch x Window`) and the data types.
4.  **Model Architecture**: We instantiate the `HSGKN` model, perform a forward pass with the real batch of data loaded previously, and verify the Deep Supervision output structure (stages 1, 2, and 3) and tensor dimensions.
5.  **Training & Inference Loop**: We instantiate the `Trainer` class and execute a full (but miniaturized) cycle: `fit()` for training/validation and `predict()` for generating submission files.
6.  **Validation**: We check for the existence of the generated model checkpoint and submission file to confirm the pipeline finished successfully.
