Based on the comprehensive analysis of the "Lessons Learned" and the progression of "Previous Ideas," I propose the **Hierarchically-Scaled Gated-Kinematic Network (HSG-KN)**.

This solution synthesizes the most effective architectural components (High-Capacity Encoder, Monotonic MS-TCN) with a rigorous data engineering strategy that explicitly resolves the conflict between **Feature Magnitude Alignment** (Lesson 00082) and **Signal-to-Noise Hierarchy** (Lesson 00085). It also incorporates the mandatory **Polymorphic Data Ingestion** (Lesson 00045) and **Input Gating** (Lesson 00058) to ensure robustness against sensor noise and parsing failures.

# Model
The architecture is a **Three-Stage Cascaded Network** designed to maximize feature extraction capacity while ensuring stable, context-aware temporal refinement.

1.  **Stage 1: Gated High-Capacity Kinematic Encoder**
    *   **Input:** An **Early Fusion** vector consisting of Audio MFCCs and Hierarchically Scaled Kinematic features (Position, Velocity, Acceleration). We prioritize Early Fusion to capture joint statistics immediately (Cite solution_lesson_node_00021).
    *   **Feature-Wise Input Gating:** Before entering the recurrent backbone, the input vector $X_t$ is passed through a learnable gating layer: $\tilde{X}_t = X_t \odot \sigma(W_{gate} X_t + b)$. This allows the model to dynamically suppress noisy sensor channels (e.g., jittery joints or silent audio) at a frame-wise level before they corrupt the recurrent state (Cite solution_lesson_node_00058).
    *   **Backbone:** A **Bi-directional GRU (Bi-GRU)** with a hidden dimension of **128 units per direction** (256 total). We explicitly restore this high capacity to prevent the underfitting observed when the encoder width was reduced, ensuring sufficient dimensionality to disentangle multi-modal patterns (Cite solution_lesson_node_00066).
    *   **Output:** Initial frame-wise class probabilities ($P_1$) over 21 classes (Softmax).

2.  **Stage 2: Monotonic Non-Causal Gated Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_1$) from Stage 1. We enforce a strict Information Bottleneck to prevent overfitting (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Gated Dilated Temporal Convolutional Layers** ($\tanh \times \sigma$) (Cite solution_lesson_node_00032). We use **Standard Convolutions**, avoiding the performance degradation of Depthwise Separable Convolutions (Cite solution_lesson_node_00065).
    *   **Dilation Schedule:** We employ a **Monotonically Increasing Schedule**: $[1, 2, 4, 8, 16]$.
        *   *Monotonicity:* We reject Sawtooth schedules as Monotonic schedules have proven superior for segmentation tasks (Cite solution_lesson_node_00080).
        *   *Receptive Field:* With a kernel size of 3, this schedule yields a receptive field of 63 frames. This fits perfectly within the 64-frame training window ($63 < 64$), maximizing context without reading invalid padding values (Cite solution_lesson_node_00057).
    *   **Causality:** We use **Centered Padding** (Non-Causal) to leverage future context, correcting the failure of Causal TCNs in offline settings (Cite solution_lesson_node_00078).
    *   **Output:** Refined class probabilities ($P_2$).

3.  **Stage 3: Independent Iterative Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights**. We strictly avoid recursive weight sharing to allow the stage to specialize in fine-grained boundary polishing (Cite solution_lesson_node_00054).
    *   **Output:** Final class probabilities ($P_3$).

# Data
The data pipeline incorporates critical engineering fixes for robustness and a novel scaling strategy to preserve physical consistency.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files. It explicitly checks the data type of the `Skeleton` field (struct array vs. cell array vs. primitive) and handles each case dynamically. This prevents the "silent failure" (zero-filling) that crippled previous attempts (Cite solution_lesson_node_00045).

2.  **Kinematically Consistent Augmentation:**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Augment:** Apply random 3D rotations (Y-axis) and scaling to $P_{raw}$.
    *   **Derive:** Calculate **Velocity** ($V_t$) and **Acceleration** ($A_t$) from the *augmented* positions. This ensures physical validity (Cite solution_lesson_node_00029).

3.  **Hierarchical Scaling (Structural Innovation):**
    *   Instead of independent Z-score normalization (which destroys the SNR hierarchy, Cite solution_lesson_node_00085), we apply a **Global Linear Scaling** to all skeleton features. We convert units from millimeters to meters (multiply by 0.001).
    *   *Rationale:* This brings the skeletal values (Position ~1.0, Velocity ~0.1) into a magnitude range comparable to Audio MFCCs (~10-100), preventing the audio from dominating the gradients (Cite solution_lesson_node_00082), while strictly preserving the natural hierarchy (Position $\gg$ Velocity $\gg$ Acceleration) required to filter high-frequency noise.

4.  **Sampling Strategy:**
    *   **Windowing:** Generate training samples using **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** Use a **Moderate Stride** (e.g., 32 frames) to avoid the overfitting caused by dense sampling (Cite solution_lesson_node_00053).

# Training
The training strategy prioritizes stability and smoothness using Deep Supervision.

1.  **Cascaded Loss Function:**
    *   $L_{total} = L(P_1) + L(P_2) + L(P_3)$ (Deep Supervision) (Cite solution_lesson_node_00025).
    *   **Weighted Cross-Entropy:** Applied with a weight of **0.2** for the "background" class (Cite solution_lesson_node_00010). We strictly avoid Focal Loss (Cite solution_lesson_node_00034).
    *   **Log-Space Smoothing Loss:** A Truncated MSE loss applied to the log-probabilities of adjacent frames for $P_2$ and $P_3$.
    *   **Threshold:** We use a **Low Truncation Threshold** (e.g., 1.0) to strictly enforce smoothness (Cite solution_lesson_node_00055).

2.  **Optimizer:**
    *   Use the **Adam** optimizer. We avoid AdamW to ensure stable convergence of the recurrent backbone (Cite solution_lesson_node_00026).

3.  **Validation:**
    *   Perform model selection based on the **Levenshtein Distance** computed on **Full Sequences** (reconstructed via sliding windows), ensuring alignment with the final objective (Cite solution_lesson_node_00052, solution_lesson_node_00075).

# Evaluation
1.  **Inference:** Process test sequences using **Sliding Window Inference** with 50% overlap. The probability outputs from overlapping windows are averaged to perform temporal ensembling (Cite solution_lesson_node_00042).
2.  **Prediction:** Extract the final predictions from **Stage 3**.
3.  **Decoding:**
    *   Apply `argmax` to the averaged probabilities.
    *   Perform **Run-Length Encoding (RLE)**.
    *   **Min Duration Filter:** Explicitly remove segments shorter than **5 frames**. This is a critical post-processing step to align the output with physical gesture constraints (Cite solution_lesson_node_00071). We explicitly discard Median Filtering (Cite solution_lesson_node_00036).
