This script demonstrates the end-to-end usage of the provided library modules for the gesture recognition task. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to define a temporary working directory and reduce runtime parameters (epochs, batch size) for a quick demonstration.
2.  **Data Processing**: Uses `DataProcessor` to load and process a small subset (10 samples) of the training data, verifying the shape and integrity of the extracted features (Skeleton Kinematics + Audio MFCC).
3.  **Model Instantiation**: Initializes the `VIARN` model and performs a forward pass with dummy data to verify the architecture and output shapes of the multi-stage refinement network.
4.  **Loss Calculation**: Computes the `CascadedLoss` (Weighted NLL + Truncated MSE) on the dummy outputs to ensure the loss function logic is correct.
5.  **Training Loop**: Instantiates the `Trainer` and runs a short training session (2 epochs) on the data subset. It verifies that the training completes and a model checkpoint is saved.
6.  **Inference**: Uses the `InferenceEngine` to load the saved model, predict gestures for a subset of the test data, and generate a submission CSV file.
