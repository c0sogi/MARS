Based on the comprehensive analysis of the "Lessons Learned" and the progression of "Previous Ideas," I propose the **Adaptive-Scale High-Capacity Kinematic Network (ASH-KN)**.

This solution represents a rigorous synthesis of the most effective strategies identified throughout the development process. It explicitly resolves the **"Input Engineering Trilemma"** (Magnitude vs. Hierarchy vs. Gating) identified in Lessons 00082, 00085, and 00096 by introducing a **Learnable Affine Scaling Interface**. This allows the model to automatically align feature magnitudes without destroying the signal-to-noise hierarchy or causing gating saturation. It combines this with the **High-Capacity Encoder** (Lesson 00066) and **Monotonic Non-Causal Refinement** (Lesson 00080), underpinned by the mandatory **Polymorphic Data Ingestion** (Lesson 00045) and **Physically Consistent Inference** (Lesson 00071).

# Model
The architecture is a **Three-Stage Cascaded Network** designed to robustly ingest raw multi-modal data, extract high-capacity features, and enforce stable temporal consistency.

1.  **Stage 1: Adaptive-Scale High-Capacity Encoder**
    *   **Input:** An **Early Fusion** vector consisting of Audio MFCCs and **Raw** Kinematically Consistent Skeleton features (Position in mm, Velocity, Acceleration). We explicitly **retain Raw Features** to preserve the natural signal hierarchy (Position $\gg$ Acceleration) (Cite solution_lesson_node_00085).
    *   **Structural Innovation (Learnable Affine Scaling):** Instead of fixed Z-score normalization (which destroys hierarchy) or Input Gating (which saturates on raw values, Cite solution_lesson_node_00096), we introduce a **Modality-Specific Affine Scaling Layer**.
        *   *Mechanism:* $Y = X \odot W_{scale} + B_{shift}$, where $W$ and $B$ are learnable parameters initialized to Identity/Zeros.
        *   *Benefit:* This allows the network to learn optimal scaling factors via gradient descent, aligning the magnitude of Millimeters (~1000) and MFCCs (~100) to a common range (Cite solution_lesson_node_00082) without enforcing destructive unit variance on noisy channels.
    *   **Backbone:** A **Bi-directional GRU (Bi-GRU)** with a hidden dimension of **128 units per direction** (256 total). We explicitly restore this high capacity to prevent the underfitting observed in lightweight iterations (Cite solution_lesson_node_00066).
    *   **Regularization:** We strictly enforce **Dropout (p=0.5)** within the encoder layers. This addresses the catastrophic overfitting observed in previous high-capacity attempts (Cite solution_lesson_node_00091).
    *   **Output:** Initial frame-wise class probabilities ($P_1$) over 21 classes (Softmax).

2.  **Stage 2: Monotonic Non-Causal Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_1$) from Stage 1. We enforce a strict Information Bottleneck (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Dilated Temporal Convolutional Layers** with Gated Activations ($\tanh \times \sigma$). We use **Standard Convolutions** (Cite solution_lesson_node_00065).
    *   **Dilation Schedule:** We employ a **Monotonically Increasing Schedule**: $[1, 2, 4, 8, 16]$.
        *   *Monotonicity:* We reject Sawtooth schedules as Monotonic schedules have proven superior for segmentation (Cite solution_lesson_node_00080).
        *   *Receptive Field:* This schedule yields a receptive field of 63 frames, fitting perfectly within the 64-frame training window without reading invalid padding (Cite solution_lesson_node_00057).
    *   **Causality:** We use **Centered Padding** (Non-Causal) to leverage future context, correcting the failure of Causal TCNs in offline settings (Cite solution_lesson_node_00078).
    *   **Regularization:** We apply **Dropout (p=0.3)** after every convolutional block (Cite solution_lesson_node_00091).
    *   **Output:** Refined class probabilities ($P_2$).

3.  **Stage 3: Independent Iterative Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights**. We strictly avoid recursive weight sharing to allow the stage to specialize in fine-grained boundary polishing (Cite solution_lesson_node_00054).
    *   **Output:** Final class probabilities ($P_3$).

# Data
The data pipeline incorporates critical engineering fixes for robustness and strict physical consistency rules.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files. It explicitly checks the data type of the `Skeleton` field (struct array vs. cell array vs. primitive) and handles each case dynamically. This prevents the "silent failure" (zero-filling) that crippled previous attempts (Cite solution_lesson_node_00045).

2.  **Kinematically Consistent Augmentation:**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Augment:** Apply random 3D rotations (Y-axis) and scaling to $P_{raw}$.
    *   **Derive:** Calculate **Velocity** ($V_t$) and **Acceleration** ($A_t$) from the *augmented* positions. This ensures physical validity (Cite solution_lesson_node_00029).
    *   **Fusion:** Concatenate $P_{aug}$, $V_t$, $A_t$, and Audio MFCCs. We avoid explicit spatial features (bone vectors) to minimize input dimensionality (Cite solution_lesson_node_00048).

3.  **Sampling Strategy:**
    *   **Windowing:** Generate training samples using **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** Use a **Moderate Stride** (e.g., 32 frames) to avoid the overfitting caused by dense sampling (Cite solution_lesson_node_00053).

# Training
The training strategy prioritizes stability and smoothness using Deep Supervision.

1.  **Cascaded Loss Function:**
    *   $L_{total} = L(P_1) + L(P_2) + L(P_3)$ (Deep Supervision) (Cite solution_lesson_node_00025).
    *   **Weighted Cross-Entropy:** Applied with a weight of **0.2** for the "background" class (Cite solution_lesson_node_00010). We strictly avoid Focal Loss (Cite solution_lesson_node_00034).
    *   **Log-Space Smoothing Loss:** A Truncated MSE loss applied to the log-probabilities of adjacent frames for $P_2$ and $P_3$.
    *   **Threshold:** We use a **Low Truncation Threshold** (e.g., 1.0) to strictly enforce smoothness (Cite solution_lesson_node_00055).

2.  **Optimizer:**
    *   Use the **Adam** optimizer. We avoid AdamW to ensure stable convergence of the recurrent backbone (Cite solution_lesson_node_00026).
    *   **Weight Decay:** Apply standard L2 regularization (1e-4) (Cite solution_lesson_node_00055).

3.  **Validation:**
    *   Perform model selection based on the **Levenshtein Distance** computed on **Full Sequences** (reconstructed via sliding windows), ensuring alignment with the final objective (Cite solution_lesson_node_00052, solution_lesson_node_00075).

# Evaluation
1.  **Inference:** Process test sequences using **Sliding Window Inference** with 50% overlap. The probability outputs from overlapping windows are averaged to perform temporal ensembling (Cite solution_lesson_node_00042).
2.  **Prediction:** Extract the final predictions from **Stage 3**.
3.  **Decoding:**
    *   Apply `argmax` to the averaged probabilities.
    *   Perform **Run-Length Encoding (RLE)**.
    *   **Min Duration Filter:** Explicitly remove segments shorter than **5 frames**. This is a critical post-processing step to align the output with physical gesture constraints and prevent metric degradation (Cite solution_lesson_node_00071). We explicitly discard Median Filtering (Cite solution_lesson_node_00036).
