The issue is that `scipy.io.loadmat` returns a dictionary, but the code incorrectly attempts to check for the "Video" key using `hasattr(mat, "Video")`, which returns `False` for dictionaries. This causes the parser to reject every file, resulting in an empty dataset and the subsequent `IndexError`. Additionally, when using `squeeze_me=True`, the "Video" structure may be loaded as a 0-d NumPy array, which must be unwrapped using `.item()` before its attributes (like `Frames`) can be accessed.

I will fix this by accessing "Video" as a dictionary key and unwrapping the result if it is a 0-d array.
