This script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It starts by verifying the core utility functions (Levenshtein distance) and then overrides the default configuration to ensure rapid execution suitable for a demonstration. It instantiates the dataset to verify data loading and shape consistency, initializes the `LSMCN` model to check the forward pass, and finally runs the `Trainer` for a single epoch to simulate the training and inference process, validating the generation of the submission file.
