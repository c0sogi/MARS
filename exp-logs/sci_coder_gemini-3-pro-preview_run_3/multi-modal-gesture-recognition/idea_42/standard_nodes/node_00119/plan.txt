The implementation strategy follows the **Linearly-Scaled Moderate-Capacity Network (LSM-CN)** idea. We will override the default epoch count to 25 to create a fast baseline. The script initializes the `Trainer`, runs the training loop, and then performs a detailed validation pass. This validation pass computes the required Levenshtein distance metric and gathers statistics for failure analysis (correlating error with sequence length and gesture count). Finally, based on the validation score threshold (< 0.2251), it conditionally generates the submission file for the test set.
