This script demonstrates the end-to-end usage of the provided RSK-ARN gesture recognition library. It performs the following steps:
1.  **Configuration**: Overrides default `Config` parameters to enable a fast "debug" mode (fewer epochs, smaller batch size, subset of data) and sets up a separate working directory for the demo.
2.  **Utility Verification**: Validates the logic of helper functions like Run-Length Encoding (`rle_encode`) and Levenshtein distance calculation.
3.  **Data Loading**: Initializes the `GestureDataset` and `DataLoader` classes, verifying that data is correctly loaded, augmented, and batched with the expected shapes.
4.  **Model Initialization**: Instantiates the `RSKARN` model, performs a dummy forward pass, and asserts that the output shapes for all refinement stages are correct.
5.  **Training Loop**: Runs the `Trainer` for a single epoch to demonstrate the training process, loss calculation (Cascaded Cross-Entropy + Temporal Smoothing), and checkpoint saving.
6.  **Inference**: Executes the full inference pipeline using the trained model, including sliding window aggregation and submission file generation.
