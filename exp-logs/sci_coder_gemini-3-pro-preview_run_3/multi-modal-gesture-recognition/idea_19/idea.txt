Based on the comprehensive analysis of the "Lessons Learned" and the progression of "Previous Ideas," I propose the **Auxiliary-Supervised Kinematic Refinement Network (ASK-RN)**.

This solution represents a structural evolution of the high-performing "Kinematically-Consistent Iterative Refinement" architecture (Idea 7). It introduces a **Multi-Task Learning (MTL)** framework to the encoder to explicitly learn gesture boundaries, but crucially, it avoids the "Bottleneck Collapse" observed in Idea 11/Lesson 00044 by **selectively blocking** the auxiliary boundary predictions from entering the refinement stages. This allows the encoder to learn richer, boundary-aware features via auxiliary supervision without corrupting the strict information bottleneck required for stable refinement. Additionally, it incorporates the mandatory **Polymorphic Data Ingestion** fix (Lesson 00045).

# Model
The architecture is a **Three-Stage Cascaded Network** with a Multi-Task Encoder and Selective Forwarding.

1.  **Stage 1: Multi-Task Kinematic Encoder**
    *   **Input:** An **Early Fusion** vector consisting of Audio MFCCs and Kinematically Consistent Skeleton features (Position, Velocity, Acceleration) (Cite solution_lesson_node_00021).
    *   **Backbone:** A **Bi-directional GRU (Bi-GRU)**. This remains the encoder of choice due to its superior sample efficiency on this small dataset (Cite solution_lesson_node_00002).
    *   **Dual Heads (Structural Innovation):** The encoder projects its hidden states to two distinct output heads:
        1.  **Classification Head:** Outputs probability distribution over 21 classes ($P_{cls}$).
        2.  **Boundary Head:** Outputs a binary probability indicating a gesture transition ($P_{bnd}$).
    *   **Selective Bottleneck:** Crucially, **only** the $P_{cls}$ vector is passed to the subsequent refinement stages. The $P_{bnd}$ output is used **solely** for calculating the auxiliary loss during training. This prevents the "Auxiliary Task Collapse" where the refinement network learns to rely on degenerate boundary predictions (Cite solution_lesson_node_00044).

2.  **Stage 2: Independent Gated Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_{cls}$) from Stage 1. We avoid passing dense features (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Gated Dilated Temporal Convolutional Layers** ($\tanh \times \sigma$). The gating mechanism effectively controls information flow, allowing the model to sharpen transitions (Cite solution_lesson_node_00032).
    *   **Receptive Field:** We use a dilation schedule of $[1, 2, 4, 8, 16]$, ensuring the receptive field is large but remains within the bounds of the 64-frame window to avoid edge artifacts (Cite solution_lesson_node_00057).
    *   **Attention:** We explicitly **exclude** Global Temporal Pooling (SE-Blocks) to preserve local temporal resolution (Cite solution_lesson_node_00058).

3.  **Stage 3: Iterative Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights** (Cite solution_lesson_node_00054).
    *   **Function:** Further polishes the segmentation boundaries using the Deep Supervision paradigm (Cite solution_lesson_node_00025).

# Data
The data pipeline incorporates the critical engineering fix for robustness and strict physical consistency rules.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files. It explicitly checks the data type of the `Skeleton` field (struct array vs. cell array vs. primitive) and handles each case dynamically. This prevents the "silent failure" (zero-filling) that crippled previous attempts (Cite solution_lesson_node_00045).

2.  **Kinematically Consistent Augmentation:**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Augment:** Apply random 3D rotations (Y-axis) and scaling to $P_{raw}$.
    *   **Derive:** Calculate **Velocity** ($V_t$) and **Acceleration** ($A_t$) from the *augmented* positions. This ensures physical validity (Cite solution_lesson_node_00029).
    *   **Fusion:** Concatenate $P_{aug}$, $V_t$, $A_t$, and Audio MFCCs.

3.  **Boundary Label Generation:**
    *   Generate binary targets for the Auxiliary Boundary Head. Frames within a small radius ($\pm 1$ frame) of a ground-truth segment change are labeled as 1, others as 0.

4.  **Sampling:**
    *   **Windowing:** Generate training samples using **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** Use a **Moderate Stride** (e.g., 32 frames) to avoid the overfitting caused by dense sampling (Cite solution_lesson_node_00053).

# Training
The training strategy employs Deep Supervision with Multi-Task Regularization.

1.  **Loss Function:**
    *   $L_{total} = L_{cls}(S1) + L_{cls}(S2) + L_{cls}(S3) + \lambda_{bnd} L_{bnd}(S1) + L_{smooth}(S2, S3)$.
    *   **Weighted Cross-Entropy ($L_{cls}$):** Applied with a weight of **0.2** for the "background" class (Cite solution_lesson_node_00010).
    *   **Binary Cross-Entropy ($L_{bnd}$):** Applied to the auxiliary boundary head of Stage 1.
    *   **Log-Space Smoothing ($L_{smooth}$):** Truncated MSE loss applied to $P_{cls}$ of refinement stages with a **low threshold** (1.0) (Cite solution_lesson_node_00055).

2.  **Optimizer:**
    *   Use the **Adam** optimizer. We avoid AdamW to ensure stable convergence of the recurrent backbone (Cite solution_lesson_node_00026).

# Evaluation
1.  **Inference:** Process test sequences using **Sliding Window Inference** with 50% overlap. The probability outputs from overlapping windows are averaged to perform temporal ensembling (Cite solution_lesson_node_00042).
2.  **Prediction:** Extract the final predictions from **Stage 3**.
3.  **Decoding:**
    *   Apply `argmax` to the averaged probabilities.
    *   Perform **Run-Length Encoding (RLE)** to collapse consecutive identical labels.
    *   **No Heuristic Filtering:** We explicitly discard post-hoc median filtering, relying on the model's learned smoothness (Cite solution_lesson_node_00036).
