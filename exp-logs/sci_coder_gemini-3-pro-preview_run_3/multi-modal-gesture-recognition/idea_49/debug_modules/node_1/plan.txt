The execution failure `AssertionError: Dataset is empty` is caused by incorrect handling of the data structure returned by `scipy.io.loadmat`. The function returns a Python dictionary, but the code attempts to access the top-level `Video` key using dot notation (`mat.Video`) and checks for its existence with `hasattr(mat, "Video")`. Since dictionaries do not support attribute access for keys, `hasattr` returns `False`, causing the code to default `num_frames` to 0 and skip every sample. Additionally, when `squeeze_me=True` is used, the `Video` struct may be wrapped in a 0-d NumPy array, requiring explicit unwrapping via `.item()` to access its fields (`NumFrames`, `Frames`).
