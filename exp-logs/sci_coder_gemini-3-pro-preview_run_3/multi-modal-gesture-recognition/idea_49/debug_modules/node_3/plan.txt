The issue is caused by the `verbose` parameter in `torch.optim.lr_scheduler.ReduceLROnPlateau`, which has been deprecated and removed in the installed version of PyTorch (2.8.0+cu129). This causes a `TypeError` during the initialization of the scheduler. To fix this, I will remove the `verbose=True` argument from the `ReduceLROnPlateau` constructor in both `library/train.py` and `library/config.py`.

```diff
library/train.py
<<<<<<< SEARCH
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(
        optimizer, mode="min", factor=0.5, patience=2, verbose=True
    )
=======
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(
        optimizer, mode="min", factor=0.5, patience=2
    )
>>>>>>> REPLACE
```
