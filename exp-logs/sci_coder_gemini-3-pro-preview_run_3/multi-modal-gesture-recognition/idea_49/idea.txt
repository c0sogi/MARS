Based on the comprehensive analysis of the "Lessons Learned" and the failures of recent experiments (specifically the "Zombie" execution failure in Idea 48 and the loss function collapse in Idea 37), I propose the **Stochastic-Regularized Decoupled-Gated Network (SR-DGN)**.

This solution is a structural synthesis that optimizes the current state-of-the-art architecture (Idea 47) by successfully integrating the **Structural Regularization** (Stochastic Depth) and **Data Robustness** (Input Noise) strategies that previously failed due to engineering errors. Crucially, it explicitly rejects the **Label Smoothing** technique that caused catastrophic failure in imbalanced settings (Lesson 00137), reverting to the proven **Class Weighting** strategy.

# Model
The architecture is a **Three-Stage Cascaded Network** designed to maximize regularization and noise robustness without compromising the signal hierarchy.

1.  **Stage 1: Decoupled-Norm Gated Encoder**
    *   **Input:** An **Early Fusion** vector consisting of two streams:
        *   **Skeleton Stream:** Kinematically Consistent features (Position, Velocity, Acceleration) derived via **Central Differences** (Cite solution_lesson_node_00127). We explicitly **retain Raw Millimeters** to preserve the signal-to-noise hierarchy (Position $\gg$ Acceleration) (Cite solution_lesson_node_00085).
        *   **Audio Stream:** MFCC features.
    *   **Decoupled-Norm Input Gating:** We retain the successful split-path gating mechanism to handle magnitude differences:
        *   *Path A (Gate Generation):* $X_{norm} = LayerNorm(X_{raw})$. Used to generate the attention mask via a Sigmoid activation. Normalization here prevents gating saturation (Cite solution_lesson_node_00096).
        *   *Path B (Signal Retention):* The original $X_{raw}$ is retained to preserve physical magnitude.
        *   *Fusion:* $\tilde{X} = X_{raw} \odot \sigma(Linear(X_{norm}))$. This allows dynamic noise suppression without altering the physical scale of the valid signal (Cite solution_lesson_node_00132).
    *   **Backbone:** A **2-Layer Bi-directional GRU (Bi-GRU)** with **96 units per direction**. This capacity avoids both underfitting (Cite solution_lesson_node_00066) and overfitting (Cite solution_lesson_node_00110).
    *   **Regularization:** **Dropout (p=0.4)** is applied between GRU layers (Cite solution_lesson_node_00091).
    *   **Output:** Initial frame-wise class probabilities ($P_1$).

2.  **Stage 2: Stochastic-Depth Monotonic Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_1$) from Stage 1 (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Gated Dilated Temporal Convolutional Layers** using **Standard Convolutions** (Cite solution_lesson_node_00065).
    *   **Structural Innovation (Stochastic Depth):** We implement **Stochastic Depth (DropPath)** within the residual blocks of the TCN. During training, we randomly drop entire residual branches with probability $p_{drop}=0.2$, forcing the signal to propagate through the identity connection.
        *   *Rationale:* This effectively trains an implicit ensemble of shallower networks, acting as a powerful structural regularizer for small datasets where deep TCNs tend to overfit (Cite solution_lesson_node_00053). This corrects the execution failure of Idea 48 (Cite solution_lesson_node_00133).
    *   **Dilation Schedule:** **Monotonically Increasing** $[1, 2, 4, 8, 16]$. This yields a receptive field of 63 frames, matching the 64-frame window (Cite solution_lesson_node_00127).
    *   **Causality:** **Centered Padding** (Non-Causal) (Cite solution_lesson_node_00078).
    *   **Output:** Refined class probabilities ($P_2$).

3.  **Stage 3: Independent Stochastic-Depth Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights** (Cite solution_lesson_node_00054).
    *   **Output:** Final class probabilities ($P_3$).

# Data
The data pipeline incorporates critical engineering fixes for robustness and strict cache invalidation.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files to prevent silent failures (Cite solution_lesson_node_00045).

2.  **Noise-Robust Kinematic Derivation:**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Center:** Apply **Root-Relative Centering** (Cite solution_lesson_node_00102).
    *   **Augment 1 (Geometric):** Apply random 3D rotations (Y-axis) and scaling.
    *   **Augment 2 (Injection):** Inject **Gaussian Noise** ($\sigma=0.01$) to the position data *before* derivation. This forces the model to learn kinematic features robust to sensor jitter (Cite solution_lesson_node_00133).
    *   **Derive:** Calculate **Velocity** and **Acceleration** using **Central Differences** (`np.gradient`) on the noisy, augmented positions (Cite solution_lesson_node_00127).

3.  **Sampling Strategy:**
    *   **Windowing:** **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** **Moderate Stride** (32 frames) (Cite solution_lesson_node_00053).

# Training
The training strategy employs robust loss formulations, explicitly rejecting Label Smoothing.

1.  **Cascaded Loss Function:**
    *   $L_{total} = L(P_1) + L(P_2) + L(P_3)$ (Deep Supervision) (Cite solution_lesson_node_00025).
    *   **Weighted Cross-Entropy:** We strictly use **Class Weighting** (weight 0.2 for background). We explicitly **reject Label Smoothing**, as it causes collapse to the majority class in this imbalanced task (Cite solution_lesson_node_00137).
    *   **Log-Space Smoothing Loss:** Truncated MSE on log-probabilities.
    *   **Calibration:** **Low Weight** ($\lambda=0.15$) and **Low Threshold** (1.0) (Cite solution_lesson_node_00111).

2.  **Optimizer:**
    *   **Adam** optimizer with **Weight Decay** (L2) (Cite solution_lesson_node_00055).

# Evaluation
1.  **Inference:** **Full Sequence Inference** (Batch Size=1) to preserve global temporal context (Cite solution_lesson_node_00079).
2.  **Model Selection:** Select best checkpoint based on **Levenshtein Distance** on full sequences (Cite solution_lesson_node_00075).
3.  **Decoding:**
    *   Apply `argmax` to $P_3$.
    *   Perform **Run-Length Encoding**.
    *   **Min Duration Filter:** Remove segments shorter than **5 frames** (Cite solution_lesson_node_00071).
