Implementation strategy:
1.  **Setup and Configuration**: Import necessary standard libraries and the provided custom library modules (`config`, `utils`, `data_loader`, `model`, `train`, `inference`). Set random seeds for reproducibility.
2.  **Training**: Execute `train.train_model()` to train the PG-HCKN model. I will use the default configuration (50 epochs) as the dataset is small enough for this to complete quickly on an A100 GPU. This function returns the best validation score (Levenshtein distance metric).
3.  **Validation Reporting**: Print the `Final Validation Metric` exactly as required using the score returned from the training phase.
4.  **Failure Analysis**: Implement a function `perform_failure_analysis` that:
    *   Loads the trained model and the validation dataset.
    *   Runs inference on the validation set using the sliding window reconstruction logic (similar to the inference module but adapted for validation data).
    *   Computes the Levenshtein distance error for each sample against the ground truth.
    *   Calculates and prints the Pearson correlation between the error and metadata features (Sequence Length and Number of Gestures) to identify failure modes.
5.  **Submission Generation**: Check if the best validation score is below the threshold of `0.2251`. If satisfied, call `inference.generate_submission()` to create the `submission.csv` file for the test set.
