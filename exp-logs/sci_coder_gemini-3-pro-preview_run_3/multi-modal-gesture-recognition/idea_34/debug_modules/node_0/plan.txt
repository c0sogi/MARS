This script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition.

**Implementation Strategy:**
1.  **Configuration Overrides**: To ensure the demonstration runs quickly and efficiently, we create "mini" versions of the metadata files (train, val, test) containing only 5 samples each. We then override the paths in the `library.config` module to point to these mini datasets. We also reduce the batch size and redirect the cache directory to a temporary location.
2.  **Utility Verification**: We assert the correctness of helper functions like `levenshtein_distance` and `run_length_encoding` with known inputs.
3.  **Model Verification**: We instantiate the `PG_HCKN` model and perform a forward pass with dummy data to verify the input/output tensor shapes.
4.  **Training Pipeline**: We execute the `train_model` function for a few epochs using the mini-dataset. This validates the data loading, loss computation, backpropagation, and model checkpointing mechanisms.
5.  **Inference Pipeline**: We run `generate_submission` using the trained model and the mini test set, verifying that the output CSV is generated correctly.
