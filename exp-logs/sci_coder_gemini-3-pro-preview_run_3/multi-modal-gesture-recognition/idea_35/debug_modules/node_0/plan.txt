The following script demonstrates the end-to-end usage of the provided gesture recognition library. It performs the following steps:

1.  **Setup**: Configures a lightweight demonstration environment in `./working/demo_env` to ensure the main training artifacts are not overwritten and execution is fast.
2.  **Data Preparation**: Creates "mini" metadata files by sampling a few rows from the original metadata, allowing for rapid dataset processing and training.
3.  **Utility Verification**: Validates the core metric (Levenshtein distance) and post-processing logic (RLE, filtering) using assertions.
4.  **Dataset & DataLoader**: Instantiates the `GestureDataset`, processes the mini-subset (parsing `.mat` skeletons and audio), and verifies the output tensor shapes.
5.  **Model Architecture**: Initializes the `RHCKN` model with reduced capacity for speed and verifies the forward pass and deep supervision outputs.
6.  **Training Loop**: Runs a short training session (2 epochs) using the `Trainer` class to demonstrate the optimization process and model checkpointing.
7.  **Inference**: Uses the `SlidingWindowPredictor` to generate predictions on the mini-test set and verifies the submission file format.
