1.  **Increase Training Window Size & Stride**: I will increase `WINDOW_SIZE` from 64 to **256** and `STRIDE` to **64**.
    *   **Reasoning**: The current TCN receptive field (~62 frames) is dangerously close to the training window size (64), causing the model to rely on boundary padding artifacts (Cite Lesson 00057). Increasing the window size to 256 ensures the receptive field is a small fraction of the input, allowing the model to learn valid temporal dependencies.
    *   **Reasoning**: A larger stride (64) prevents excessive redundancy in the training data (Cite Lesson 00053).

2.  **Enable Full Sequence Inference**: I will modify the validation and test pipelines to process **full sequences** (Batch Size = 1) instead of sliding windows.
    *   **Reasoning**: The failure analysis showed a high correlation (0.59) between error rate and sequence duration, indicating that the independent sliding window approach severed the temporal context required by the Bi-GRU encoder (Cite Lesson 00079). Processing full sequences preserves the global state and eliminates boundary artifacts.

3.  **Refine Data Loading**: I will update `GestureDataset` to support a `return_full_sequence` mode, which bypasses windowing and padding for validation/test sets, ensuring the model sees the exact variable-length sequence during inference.
