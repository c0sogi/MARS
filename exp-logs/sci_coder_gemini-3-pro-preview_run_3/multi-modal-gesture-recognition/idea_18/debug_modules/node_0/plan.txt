Implementation Strategy:
1.  **Environment Setup**: Create a temporary working directory (`./working/demo_env`) to simulate the project structure. This ensures we can test the `Trainer` class which expects a specific directory layout (`metadata/` folder inside the base directory).
2.  **Data Subsetting**: Read the provided full metadata files (`./metadata/train.csv`, etc.), select a small subset (e.g., 5 samples), and save them to the temporary environment. This drastically reduces data loading and training time for demonstration purposes.
3.  **Library Component Verification**:
    *   **Utils**: Verify Levenshtein distance calculation and sequence decoding logic (RLE and background filtering).
    *   **Data Loader**: Instantiate `GestureDataset` with the subset metadata. Verify the shape of the produced tensors (Window Size x Input Dim) and data types.
    *   **Model**: Instantiate the `AKCIRN` model. Perform a forward pass with dummy data to verify tensor shapes at each stage (Stage 1, 2, and 3 outputs). Verify the `CascadedSmoothLoss` calculation.
    *   **Trainer**: Initialize the `Trainer` with the temporary base directory. Run a full cycle (`load_data`, `setup_model`, `train`, `generate_submission`) for 1 epoch. This verifies the integration of all components.
    *   **Inference**: Execute the standalone `run_inference` function using the model trained in the previous step to verify the inference pipeline.
4.  **Cleanup**: (Optional) The working directory is left for inspection, but the script is designed to be idempotent.
