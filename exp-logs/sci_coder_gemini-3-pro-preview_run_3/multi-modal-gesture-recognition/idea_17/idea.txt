Based on the comprehensive analysis of the "Lessons Learned" and the failure of recent high-capacity models (Idea 16) due to overfitting, I propose the **Recurrently-Shared Kinematic Refinement Network (RS-KRN)**.

This solution structurally evolves the high-performing "Kinematically-Consistent Iterative Refinement" architecture (Idea 7) by introducing **Weight-Shared Iterative Refinement**. This innovation explicitly addresses the conflict between the need for deep iterative refinement (Lesson 00025) and the catastrophic overfitting caused by over-parameterization on this small dataset (Lesson 00053). It also incorporates the critical **Polymorphic Data Ingestion** fix (Lesson 00045).

# Model
The architecture is a **Recursive Multi-Stage Network** that decouples the depth of the refinement process from the number of learnable parameters.

1.  **Stage 1: Kinematic Sequence Encoder**
    *   **Input:** An **Early Fusion** vector combining Audio MFCCs with Kinematically Consistent Skeleton features (Position, Velocity, Acceleration). We prioritize Early Fusion to capture joint statistics (Cite solution_lesson_node_00021).
    *   **Backbone:** A **Bi-directional GRU (Bi-GRU)**. This remains the encoder of choice due to its superior sample efficiency compared to Transformers for this specific task (Cite solution_lesson_node_00002).
    *   **Output:** Initial frame-wise class probabilities ($P_0$) over 21 classes.

2.  **Stage 2+: Recurrently-Shared Refinement Module**
    *   **Structural Innovation:** Instead of stacking distinct TCN models for each refinement stage (which linearly increases parameter count), we instantiate a **single** Deep Gated Dilated TCN module and apply it recurrently.
    *   **Mechanism:**
        *   Iteration 1: $P_1 = \text{Refine}(P_0)$
        *   Iteration 2: $P_2 = \text{Refine}(P_1)$
    *   **Architecture:** The shared module is a stack of **Gated Dilated Convolutional Layers** ($\tanh \times \sigma$) (Cite solution_lesson_node_00032).
    *   **Receptive Field:** Because the parameters are shared, we can afford to make this single module deeper (e.g., dilations up to 32) to maximize the temporal receptive field (Cite solution_lesson_node_00048) without triggering the overfitting observed in Idea 16 (Cite solution_lesson_node_00053).
    *   **Bottleneck:** The module takes only class probabilities as input, maintaining a strict information bottleneck (Cite solution_lesson_node_00020).

# Data
The data pipeline incorporates a critical engineering fix for robustness and optimizes sampling density.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files. It explicitly checks the data type of the `Skeleton` field (struct array vs. cell array vs. primitive) and handles each case dynamically. This prevents the "silent failure" mode where valid samples were replaced with zeros (Cite solution_lesson_node_00045).

2.  **Kinematically Consistent Augmentation:**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Augment:** Apply random 3D rotations (Y-axis) and scaling to $P_{raw}$ to generate Augmented Positions ($P_{aug}$). This is done *before* derivation (Cite solution_lesson_node_00029).
    *   **Derive:** Calculate **Velocity** ($V_t$) and **Acceleration** ($A_t$) from $P_{aug}$.
    *   **Fusion:** Concatenate $P_{aug}$, $V_t$, $A_t$, and Audio MFCCs. We explicitly exclude redundant spatial features (bone vectors) to minimize input dimensionality (Cite solution_lesson_node_00048).

3.  **Sampling Strategy:**
    *   **Windowing:** Generate training samples using **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** Use a moderate stride (e.g., 32 frames) rather than a dense stride (e.g., 8 frames). This prevents the dataset from being dominated by highly correlated, redundant examples, which was a primary driver of overfitting in Idea 16 (Cite solution_lesson_node_00053).

# Training
The training strategy employs Deep Supervision on the recurrent outputs.

1.  **Recursive Cascaded Loss:**
    *   The total loss is the sum of losses from the Encoder and each Refinement iteration: $L_{total} = L(P_0) + L(P_1) + L(P_2)$.
    *   **Weighted Cross-Entropy:** Applied with a weight of **0.2** for the "background" class (Cite solution_lesson_node_00010). We avoid Focal Loss (Cite solution_lesson_node_00034).
    *   **Log-Space Smoothing Loss:** A Truncated MSE loss applied to the log-probabilities of adjacent frames for all refinement outputs ($P_1, P_2$) (Cite solution_lesson_node_00015).

2.  **Optimizer:**
    *   Use the **Adam** optimizer. We avoid AdamW to ensure stable convergence of the recurrent backbone (Cite solution_lesson_node_00026).

3.  **Validation:**
    *   Perform validation on **Full Reconstructed Sequences**, not on sliding windows, to ensure the metric correlates with the actual task performance (Cite solution_lesson_node_00052).

# Evaluation
1.  **Inference:** Process test sequences using **Sliding Window Inference** with 50% overlap. The probability outputs from overlapping windows are averaged to perform temporal ensembling (Cite solution_lesson_node_00042).
2.  **Prediction:** Extract the final predictions from the last refinement iteration ($P_2$).
3.  **Decoding:**
    *   Apply `argmax` to the averaged probabilities.
    *   Perform **Run-Length Encoding (RLE)** to collapse consecutive identical labels.
    *   **No Heuristic Filtering:** We explicitly discard post-hoc median filtering, relying on the model's learned smoothness (Cite solution_lesson_node_00036).
