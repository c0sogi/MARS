Implementation strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library components. Override `Config` class attributes to define a temporary working directory (`./working/demo_run_script`) and enable debug mode (`DEBUG=True`) with a small subset size to ensure rapid execution. Set random seeds for reproducibility.
2.  **Data Preparation**: Create mini-subsets of the metadata CSVs (`train.csv`, `val.csv`, `test.csv`) containing only a few rows. Save these to the working directory and update the `Config` paths to point to them. This ensures the `InferenceEngine` and `DataLoader` process only a tiny fraction of the data.
3.  **Data Loading**: Instantiate the DataLoaders using `get_dataloaders`. Fetch a single batch from the training loader to verify the shape of the input features (Batch, Window, InputDim) and labels.
4.  **Model Initialization**: Instantiate the `RLK_RN` model. Perform a forward pass with the fetched batch to verify the output structure (list of 3 tensors) and dimensions.
5.  **Training Loop**: Initialize the `Trainer` with the model and loaders. Run `trainer.fit()` for a minimal number of epochs (e.g., 2) to demonstrate the training process and checkpoint saving. Verify that `best_model.pth` is created.
6.  **Inference and Submission**: Initialize the `InferenceEngine` loading the weights from the just-trained model. Run `generate_submission` to process the mini test set and generate a CSV. Verify the existence and line count of the submission file.
