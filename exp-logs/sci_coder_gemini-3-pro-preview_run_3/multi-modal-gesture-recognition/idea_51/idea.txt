Based on the rigorous analysis of the "Lessons Learned" and the failures of recent experiments (specifically the **Refinement Capacity Bottleneck** in Idea 50/Lesson 00142 and the **Execution Failure** in Idea 48/Lesson 00133), I propose the **Structural-Kinematic Attentive Gated Network (SKA-GN)**.

This solution is a structural synthesis that optimizes the state-of-the-art **Decoupled-Norm Gated** architecture (Idea 47) by integrating **Explicit Spatial Structure** (Bone Vectors) and **Global Context Attention** (SE-Blocks). Crucially, it corrects the capacity reduction mistake of Idea 50 by maintaining a **High-Capacity Refinement Stage**, and it ensures robustness via **Gaussian Noise Injection** underpinned by a **Polymorphic Data Pipeline**.

# Model
The architecture is a **Three-Stage Cascaded Network** designed to leverage explicit structural features, global temporal context, and robust signal processing.

1.  **Stage 1: Structural-Kinematic Decoupled-Gated Encoder**
    *   **Input:** An **Early Fusion** vector consisting of two streams:
        *   **Skeleton Stream:** A rich, physically consistent feature set comprising **Position** (Centered), **Bone Vectors** (Structural), **Velocity** (Temporal), and **Acceleration** (Dynamic).
            *   **Structural Innovation (Explicit Bone Vectors):** We explicitly calculate vectors between connected joints (e.g., $P_{wrist} - P_{elbow}$). Unlike raw positions, bone vectors provide **Pose-Invariant Structure**. We enable this via robust parsing (Cite solution_lesson_node_00045).
            *   **Raw Magnitude Retention:** We retain all features in **Raw Millimeters**. Bone vectors share the same magnitude scale as Positions (~1000), preserving the **Signal-to-Noise Hierarchy** (Position $\gg$ Acceleration) required to filter noise (Cite solution_lesson_node_00085).
        *   **Audio Stream:** MFCC features.
    *   **Decoupled-Norm Input Gating:** We retain the split-path gating mechanism to handle magnitude disparities without saturation:
        *   *Path A (Gate):* $X_{norm} = LayerNorm(X_{raw})$. Generates the attention mask.
        *   *Path B (Signal):* $X_{raw}$. Retains physical magnitude.
        *   *Fusion:* $\tilde{X} = X_{raw} \odot \sigma(Linear(X_{norm}))$. This allows dynamic noise suppression without altering the physical scale (Cite solution_lesson_node_00132).
    *   **Backbone:** A **2-Layer Bi-directional GRU (Bi-GRU)** with **96 units per direction** (192 total). This "Goldilocks" capacity avoids underfitting (Cite solution_lesson_node_00066) and overfitting (Cite solution_lesson_node_00110).
    *   **Regularization:** **Dropout (p=0.4)** between GRU layers (Cite solution_lesson_node_00091).
    *   **Output:** Initial frame-wise class probabilities ($P_1$).

2.  **Stage 2: Attentive High-Capacity Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_1$) from Stage 1 (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Gated Dilated Temporal Convolutional Layers** ($\tanh \times \sigma$) using **Standard Convolutions** (Cite solution_lesson_node_00065).
    *   **Structural Innovation (Global Context Attention):** We inject a **Squeeze-and-Excitation (SE) Block** after the gated activation in each residual layer.
        *   *Rationale:* While Gated TCNs capture local transitions, they lack global awareness. SE-Blocks perform global average pooling over the temporal window to recalibrate channel weights, allowing the model to suppress spurious activations based on the full sequence context (Cite solution_lesson_node_00141).
    *   **Capacity Correction:** We explicitly maintain a channel dimension of **192** (matching the encoder). This corrects the bottleneck error in Idea 50 (64 channels), ensuring the refinement stage has sufficient capacity to model complex dependencies (Cite solution_lesson_node_00142).
    *   **Dilation Schedule:** **Monotonically Increasing** $[1, 2, 4, 8, 16]$ (RF=63), aligned to the 64-frame window (Cite solution_lesson_node_00127).
    *   **Causality:** **Centered Padding** (Non-Causal) (Cite solution_lesson_node_00078).
    *   **Output:** Refined class probabilities ($P_2$).

3.  **Stage 3: Independent Attentive Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights** (Cite solution_lesson_node_00054).
    *   **Output:** Final class probabilities ($P_3$).

# Data
The data pipeline incorporates critical engineering fixes for robustness and noise tolerance.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files to prevent silent failures when loading Bone Vectors (Cite solution_lesson_node_00045).

2.  **Noise-Robust Kinematic Derivation:**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Center:** Apply **Root-Relative Centering** (Cite solution_lesson_node_00102).
    *   **Augment:** Apply random 3D rotations (Y-axis) and scaling.
    *   **Injection:** Inject **Gaussian Noise** ($\sigma=0.01$) to positions *before* derivation. This forces the model to learn robust kinematic features (Cite solution_lesson_node_00133).
    *   **Derive:** Calculate **Bone Vectors**, **Velocity**, and **Acceleration** using **Central Differences** (`np.gradient`) on the noisy positions (Cite solution_lesson_node_00127).

3.  **Sampling Strategy:**
    *   **Windowing:** **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** **Moderate Stride** (32 frames) (Cite solution_lesson_node_00053).
    *   **Cache Invalidation:** Explicitly update the experiment ID to force re-computation (Cite solution_lesson_node_00133).

# Training
The training strategy employs robust loss formulations.

1.  **Cascaded Loss Function:**
    *   $L_{total} = L(P_1) + L(P_2) + L(P_3)$ (Deep Supervision) (Cite solution_lesson_node_00025).
    *   **Weighted Cross-Entropy:** We strictly use **Class Weighting** (0.2 for background). We explicitly **reject Label Smoothing** (Cite solution_lesson_node_00137).
    *   **Log-Space Smoothing Loss:** Truncated MSE on log-probabilities.
    *   **Calibration:** **Low Weight** ($\lambda=0.15$) and **Low Threshold** (1.0) (Cite solution_lesson_node_00111).

2.  **Optimizer:**
    *   **Adam** optimizer with **Weight Decay** (L2) (Cite solution_lesson_node_00055).

# Evaluation
1.  **Inference:** **Full Sequence Inference** (Batch Size=1) (Cite solution_lesson_node_00079).
2.  **Model Selection:** Select best checkpoint based on **Levenshtein Distance** on full sequences (Cite solution_lesson_node_00075).
3.  **Decoding:**
    *   Apply `argmax` to $P_3$.
    *   Perform **Run-Length Encoding**.
    *   **Min Duration Filter:** Remove segments shorter than **5 frames** (Cite solution_lesson_node_00071).
