# Optimized Strategy: Coordinate Attention Stabilized Deep Residual Network (CA-ResDnCNN)

## Model
I propose the **Coordinate Attention Stabilized Deep Residual Network (CA-ResDnCNN)**. This architecture synthesizes the high-throughput backbone of linear residual stacks with a structural innovation designed specifically for the spatial characteristics of text.

*   **Backbone Architecture**: The network will consist of a deep stack (e.g., 20-30 blocks) of **Residual Blocks**.
    *   **Linear Residual Stack**: We will utilize the "Linear Residual Stack" design (Conv-BN-ReLU-Conv-BN) rather than Dense Connectivity. This ensures high computational throughput, allowing for more training iterations within the runtime limit compared to memory-heavy architectures like RDN **Cite {solution_lesson_node_00018}**.
    *   **Resolution Preservation**: The network will contain **no pooling or downsampling layers**, ensuring that all operations occur at the original spatial resolution to preserve fine text strokes **Cite {solution_lesson_node_00009}**.
    *   **Dense Convolutions**: All convolutions will use standard $3 \times 3$ filters (stride 1, dilation 1). We explicitly reject dilated convolutions to maintain the dense, local receptive fields required to distinguish fine noise from text structure **Cite {solution_lesson_node_00011}**.
*   **Structural Innovation (Coordinate Attention)**: Within each residual block, I will integrate a **Coordinate Attention (CA)** module. Unlike standard Squeeze-and-Excitation (SE) which pools features globally (losing spatial information), CA factorizes channel attention into two parallel 1D feature encoding processes (horizontal and vertical). This allows the network to capture long-range dependencies along one spatial direction while preserving precise positional information along the other. This is particularly effective for **text denoising**, where the signal is highly structured in horizontal lines and vertical strokes.
*   **Stabilized Initialization**: I will implement **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer in every residual block will be initialized to **zero**. This forces the deep network to behave as an identity function at the start of training, preventing the variance explosion that causes deep regression networks to diverge **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network will be architected to predict the **noise residual** $\mathcal{R}(x)$ rather than the clean image. The final output is $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

## Data
*   **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
*   **High-Density Patch Extraction**:
    *   I will extract patches of size $50 \times 50$ using a **small stride** (e.g., 10 pixels).
    *   **Rationale**: Previous attempts failed because they increased model capacity without increasing data density **Cite {solution_lesson_node_00013}**. With the generous **24-hour computational budget** (unlike the short runs in previous lessons), we can now afford to process this massive dataset of overlapping patches, ensuring the deep model is fully saturated with training examples.
*   **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to enforce rotation invariance.

## Training
*   **Loss Function**: Minimize the **Mean Squared Error (MSE)** between the predicted noise residual and the ground truth noise.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** learning rate scheduler.
*   **Curriculum Strategy**: To address the efficiency concerns raised in **Cite {solution_lesson_node_00020}**, I will employ a **Two-Stage Curriculum**:
    1.  **Convergence Phase**: Train on a lower-density subset (e.g., stride 20) for the first few hours. This ensures the optimizer quickly finds a good global minimum without being bogged down by the massive dataset size.
    2.  **Refinement Phase**: Fine-tune on the full high-density dataset (stride 10) for the remaining time. This allows the model to refine its weights using the maximum amount of spatial data once it has already stabilized.

## Evaluation
*   **Inference**: **Geometric Self-Ensemble (Test-Time Augmentation)**.
    *   Generate 8 versions of each test image (original + flips/rotations).
    *   Predict the noise map for each version, inverse-transform them to the original orientation, and compute the average. This robustly reduces variance and improves RMSE.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Averaged Predicted Noise}$.
*   **Submission**: Clip output values to $[0, 1]$ and flatten to the required `image_row_col` format.
