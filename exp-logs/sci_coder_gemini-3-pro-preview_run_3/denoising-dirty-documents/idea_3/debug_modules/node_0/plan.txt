The following script demonstrates the end-to-end usage of the provided library components for the Denoising task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to ensure the demonstration runs quickly (fewer epochs, larger stride for fewer patches, smaller batch size).
2.  **Utility Verification**: Validates the correctness of image normalization, denormalization, and RMSE calculation functions.
3.  **Data Loading**: Demonstrates how to load training and validation data using `get_dataloaders` with a debug limit.
4.  **Model Initialization**: Instantiates the `DRDN` model and verifies the forward pass on a dummy tensor.
5.  **Training Loop**: Runs the `Trainer` to train the model on a small subset of data, verifying that the training process completes and saves a checkpoint.
6.  **Inference & Submission**: Generates predictions for the test set using the trained model and verifies the format of the output submission file.
