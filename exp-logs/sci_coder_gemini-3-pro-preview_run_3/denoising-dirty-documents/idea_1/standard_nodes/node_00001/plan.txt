Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment by importing necessary libraries and the provided modules (`config`, `utils`, `data_loader`, `model`). Set the random seed for reproducibility.
2.  **Training**: Load the training data using `data_loader.extract_patch_data`, which leverages the metadata and caching mechanism. Instantiate the `LearnedLinearFilter` model with hyperparameters from `config` and train it using the extracted patch data.
3.  **Validation**: Iterate through the validation dataset defined in `metadata/val.csv`. For each image, perform inference using the trained model, calculate the squared error against the ground truth, and accumulate statistics. Compute the global Root Mean Squared Error (RMSE) and print it in the required format (`Final Validation Metric: <value>`).
4.  **Failure Analysis**: During the validation loop, collect pixel-level data (input intensity vs. absolute error). Calculate the Pearson correlation coefficient between these variables to identify if the model struggles with specific intensity ranges (e.g., dark text vs. bright background).
5.  **Inference & Submission**: Process the test dataset defined in `metadata/test.csv`. Generate denoised predictions for all test images. Use the provided `utils.format_submission` function to convert these predictions into the specified CSV format and save the file to `submission/submission.csv`.
