To establish a highly efficient and robust baseline, I propose a **Learned Linear Convolutional Filter (Linear Patch-Based Regressor)**. This approach assumes that the clean intensity of a pixel can be estimated as a linear combination of its neighboring noisy pixels. It effectively learns an optimal "blur" or "sharpening" kernel specific to the dataset's noise pattern, rather than relying on generic filters like Gaussian or Median blurring.

### Model
The model is a **Linear Regression** algorithm applied to local image patches.
*   **Architecture**: The model consists of a single set of learnable weights $W$ (of size $k \times k$) and a bias term $b$.
*   **Mechanism**: For every pixel in a noisy image, the model looks at a small surrounding window (e.g., $5 \times 5$ pixels). It flattens this window into a feature vector and computes the dot product with the learned weights, adding the bias to predict the clean center pixel's intensity.
*   **Conceptual Equivalent**: In computer vision terms, this is equivalent to learning a single **custom convolution kernel** that minimizes the reconstruction error. It differs from the MLP (Model 4) by lacking hidden layers and non-linear activation functions, ensuring the optimization problem is convex and extremely fast.

### Data
1.  **Preprocessing**:
    *   Normalize all pixel intensities in the training (noisy and clean) and test images to the range $[0, 1]$.
    *   Pad the boundaries of the training images (e.g., with reflection or zeros) to allow the sliding window to process edge pixels.
2.  **Feature Construction**:
    *   Extract overlapping patches of size $k \times k$ (e.g., $5 \times 5$) from the noisy training images.
    *   Flatten each patch into a 1D feature vector of length $k^2$.
    *   Extract the corresponding center pixel values from the clean training images to serve as the target labels.
3.  **Sampling**:
    *   Since the total number of pixels is large, randomly sample a subset of patches (e.g., 100,000 to 500,000 samples) to construct the training matrix. This ensures the linear solver remains memory-efficient without sacrificing the statistical significance of the learned weights.

### Training
*   **Algorithm**: Use **Ridge Regression** (Linear Regression with L2 regularization). The regularization term is crucial to prevent the model from overfitting to specific noise artifacts and to ensure the learned filter is smooth.
*   **Procedure**:
    *   Fit the model on the sampled feature vectors and targets to minimize the Mean Squared Error (MSE).
    *   The training process will output a coefficient vector (the flattened kernel) and an intercept (bias).
    *   Because this is a linear system, the solution can be computed analytically (using the Normal Equation) or via efficient solvers like Cholesky decomposition, taking only seconds to complete.

### Evaluation
1.  **Inference**:
    *   Reshape the learned coefficients into a $k \times k$ kernel.
    *   Apply this kernel to each test image using a standard **2D convolution** operation (e.g., `cv2.filter2D` or `scipy.signal.convolve2d`).
    *   Add the learned bias term to the convolved output.
2.  **Post-processing**:
    *   Clip the resulting pixel intensities to the valid range $[0, 1]$ to ensure no predictions fall outside the grayscale limits.
3.  **Submission**:
    *   Flatten the processed test images into the required pixel-row format (`image_row_col`) and save to the submission file.
