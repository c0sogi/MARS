# Optimized Strategy: Coordinate Attention Stabilized Deep Residual Network (CA-ResDnCNN) with Curriculum Training

Based on the synthesis of previous failures and empirical lessons, I propose a strategy that combines a high-throughput deep residual backbone with a text-specific attention mechanism, stabilized by specific initialization techniques and trained via a density-curriculum pipeline.

### Model
I propose the **Coordinate Attention Stabilized Deep Residual Network (CA-ResDnCNN)**. This architecture is designed to capture the anisotropic structural properties of text (horizontal lines and vertical strokes) while maintaining the computational efficiency required for deep convergence.

*   **Backbone Architecture**: The network consists of a deep stack (e.g., 20-30 blocks) of **Residual Blocks**.
    *   **Linear Residual Stack**: We utilize the "Linear Residual Stack" design (Conv-BN-ReLU-Conv-BN) rather than Dense Connectivity. This ensures high computational throughput (samples/second), allowing for significantly more training iterations within the runtime limit compared to memory-heavy architectures like RDN **Cite {solution_lesson_node_00018}**.
    *   **Resolution Preservation**: The network contains **no pooling or downsampling layers**. All operations occur at the original spatial resolution to preserve the fine, high-frequency details of text strokes that are destroyed by bottleneck architectures **Cite {solution_lesson_node_00009}**.
    *   **Dense Convolutions**: All convolutions utilize standard $3 \times 3$ filters (stride 1, dilation 1). We explicitly reject dilated convolutions to maintain the dense, local pixel correlations required to distinguish fine noise from text structure **Cite {solution_lesson_node_00011}**.
*   **Structural Innovation (Coordinate Attention)**: Within each residual block, I integrate a **Coordinate Attention (CA)** module. Unlike standard Squeeze-and-Excitation (SE) which pools features globally (losing spatial information), CA factorizes channel attention into two parallel 1D feature encoding processes (horizontal and vertical). This allows the network to capture long-range dependencies along one spatial direction while preserving precise positional information along the other. This is fundamentally optimized for **text denoising**, where the signal is highly structured in horizontal lines and vertical strokes.
*   **Stabilized Initialization**: I implement **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer in every residual block is initialized to **zero**. This forces the deep network to behave as an identity function at the start of training, preventing the variance explosion that caused previous deep regression networks to diverge **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network is architected to predict the **noise residual** $\mathcal{R}(x)$ rather than the clean image. The final output is $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

### Data
I propose a **Curriculum-Based High-Density Patching** strategy. This directly addresses the conflict between the need for high data density to support model capacity **Cite {solution_lesson_node_00013}** and the need for fast epochs to ensure convergence **Cite {solution_lesson_node_00020}**.

1.  **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
2.  **Curriculum Datasets**:
    *   **Dataset A (Sparse/Fast)**: Extract patches of size $50 \times 50$ with a **large stride** (e.g., 20 pixels). This creates a smaller dataset for rapid initial convergence.
    *   **Dataset B (Dense/Refined)**: Extract patches of size $50 \times 50$ with a **very small stride** (e.g., 5-10 pixels). This creates a massive dataset (orders of magnitude larger) to fully saturate the deep model's capacity.
3.  **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to both datasets.

### Training
*   **Loss Function**: Minimize the **Mean Squared Error (MSE)** between the predicted noise residual and the ground truth noise.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** learning rate scheduler.
*   **Two-Stage Curriculum Procedure**:
    *   **Stage 1 (Convergence)**: Train the CA-ResDnCNN on **Dataset A** for the first few hours. This allows the optimizer to quickly find a robust global minimum without being bottlenecked by the massive epoch time of dense data **Cite {solution_lesson_node_00020}**.
    *   **Stage 2 (Refinement)**: Fine-tune the model on **Dataset B** for the remainder of the 24-hour budget. This exposes the stabilized model to the maximum amount of spatial data, satisfying the density requirements for deep networks **Cite {solution_lesson_node_00013}**.

### Evaluation
*   **Inference Strategy**: **Geometric Self-Ensemble (Test-Time Augmentation)**.
    *   Generate 8 versions of each test image (original + flips/rotations).
    *   Predict the noise map for each version using the trained model.
    *   Inverse-transform the predicted noise maps to the original orientation and compute the average. This robustly reduces variance and improves RMSE.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Averaged Predicted Noise}$.
*   **Submission**: Clip the output pixel intensities to $[0, 1]$ and flatten the image data into the required `image_row_col` format.
