Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: The script initializes the environment by setting reproducible seeds using `utils.seed_everything`. It imports necessary modules from the provided `library` package.
2.  **Fast Baseline Training**: It calls `train.train_model` with `num_epochs=15` to ensure the execution fits within the "fast baseline" time constraint (under 2 hours) while still allowing the model to converge reasonably well on the A100 GPU. It utilizes cached data (`load_cached_data=True`) to save preprocessing time.
3.  **Validation & Metric Calculation**:
    *   The script loads the best model checkpoint saved during training.
    *   It re-loads the validation dataset using `data_loader.prepare_data`.
    *   It runs inference on the full validation set in `eval` mode with `torch.no_grad()` for optimized speed and memory usage.
    *   It calculates the Root Mean Squared Error (RMSE) between the predicted noise residuals and the actual noise targets (which is mathematically equivalent to the RMSE between cleaned and ground-truth images).
    *   It prints the `Final Validation Metric` with full precision.
4.  **Failure Analysis**:
    *   The script computes the absolute error for each pixel in the validation set.
    *   It calculates the Pearson correlation coefficient between the input pixel intensity and the error magnitude to identify if errors are correlated with brightness.
5.  **Conditional Submission**:
    *   It compares the calculated RMSE against the strict threshold of `0.011577641381826402`.
    *   If the metric is lower (better), it calls `predict.generate_submission` to generate and save the `submission.csv` file.
