To demonstrate the usage of the provided library files, I have implemented a self-contained Python script. This script executes the following strategy:

1.  **Configuration Management**: It overrides the default file paths in `library.config` to use a temporary directory (`./working/demo_execution`). This ensures that the demo runs in isolation, does not overwrite existing large cache files, and executes quickly by processing only a small subset of data.
2.  **Component Verification**: The script systematically instantiates and tests the core components:
    *   **Utils**: Verifies image normalization and RMSE calculation logic.
    *   **Network**: Instantiates the `SE_ZI_ResDnCNN` model on the CPU and performs a forward pass to verify input/output shapes.
    *   **Data Loader**: Extracts patches from a tiny subset of images (`max_samples=2`) to verify the data processing and caching pipeline.
    *   **Training**: Runs a single epoch of the training loop using the subset of data to confirm that the model trains and saves checkpoints correctly.
    *   **Inference**: Generates predictions for a mini-batch of test images to verify the submission file generation and formatting.
