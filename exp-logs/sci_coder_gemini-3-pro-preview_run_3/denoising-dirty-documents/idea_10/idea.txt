# Optimized Strategy: SE-Gated Zero-Initialized Residual Denoising Network (SE-ZI-ResDnCNN)

Based on the failure analysis of the previous ideas, I propose a strategy that combines the high-throughput backbone of linear residual stacks with the stability of zero-initialization, while introducing **Squeeze-and-Excitation (SE) Attention** as a structural innovation to enhance feature selectivity.

### Model
I propose the **SE-Gated Zero-Initialized Residual Denoising Network (SE-ZI-ResDnCNN)**. This architecture is designed to maximize representational capacity and training stability while maintaining the computational throughput required for convergence.

*   **Backbone Architecture**: The network consists of a deep stack (e.g., 20 to 30 blocks) of **SE-Residual Blocks**.
    *   **Linear Residual Stack**: We strictly adhere to the "Linear Residual Stack" design (ResNet-style) rather than Dense Connectivity (RDN). This avoids the memory-intensive concatenation operations that bottlenecked the RDN, ensuring high training throughput **Cite {solution_lesson_node_00018}**.
    *   **Structural Innovation (SE-Gate)**: Inside each residual block, we insert a **Squeeze-and-Excitation (SE) Block** after the second Batch Normalization layer and before the residual addition. The SE block uses global average pooling to recalibrate channel-wise feature responses. This allows the network to explicitly model inter-dependencies between channels, helping it to distinguish between the statistical profiles of noise and text structure more effectively than standard convolutions alone.
    *   **Resolution Preservation**: The network contains **no pooling or downsampling layers**, operating entirely at the original spatial resolution to preserve fine text strokes **Cite {solution_lesson_node_00009}**.
    *   **Dense Convolutions**: All convolutions utilize standard $3 \times 3$ filters (stride 1, dilation 1), prioritizing dense local pixel correlations over dilated receptive fields **Cite {solution_lesson_node_00011}**.
*   **Stabilized Initialization**: We employ **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer (and the SE scaling factor) in every residual block is initialized to **zero**. This forces the deep network to behave as an identity function at initialization, preventing the variance accumulation that caused the previous deep ResNet to explode **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network predicts the **noise residual** $\mathcal{R}(x)$ rather than the clean image, with the final output being $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

### Data
*   **Preprocessing**: Normalize all image pixel intensities to $[0, 1]$.
*   **High-Density Patch Extraction with Long-Duration Training**:
    *   We will extract patches of size $50 \times 50$ using a **small stride** (e.g., 10 pixels).
    *   **Strategic Correction**: Previous attempts with high-density patching failed because the training time was truncated to 5 epochs **Cite {solution_lesson_node_00020}**. However, since we have a **24-hour computational budget** (significantly longer than the ~30 minutes used previously), we can afford the computational cost of this dense dataset. We will leverage the full runtime to train this high-density configuration for sufficient iterations to ensure convergence, satisfying the requirement to match model capacity with data density **Cite {solution_lesson_node_00013}**.
*   **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations.

### Training
*   **Loss Function**: Minimize **Mean Squared Error (MSE)** between the predicted noise and ground truth noise.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** learning rate scheduler.
*   **Procedure**: Train for a high number of epochs (e.g., 200+) to fully exploit the 24-hour limit. The Zero-Gamma initialization allows us to use a high initial learning rate without divergence, while the SE blocks accelerate feature learning.

### Evaluation
*   **Inference Strategy**: **Geometric Self-Ensemble (Test-Time Augmentation)**.
    *   Generate 8 versions of each test image (original + flips/rotations).
    *   Predict the noise map for each version, inverse-transform them to the original orientation, and compute the mean.
    *   This averages out random model variance, providing a robust improvement in RMSE over single-pass inference.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Averaged Predicted Noise}$.
*   **Submission**: Clip output values to $[0, 1]$ and flatten to the required format.
