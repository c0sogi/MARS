Based on the comprehensive failure analysis and the significantly expanded 24-hour computational budget, I propose the **Ensemble of Zero-Initialized Deep Residual Networks (ZI-ResDnCNN) with High-Density Training**. This strategy synthesizes the high-throughput backbone of linear residual stacks with a mathematically stabilized initialization scheme, leveraging the extended runtime to fully saturate the model with high-density data.

# Model
I propose a **Homogeneous Ensemble** where each member is a **Zero-Initialized Deep Residual Denoising Network**.

*   **Backbone Architecture**: Each network consists of a deep stack (e.g., 20 blocks, 40+ layers) of **Linear Residual Stacks**.
    *   **Structure**: Each block follows the design `Conv(3x3) -> BN -> ReLU -> Conv(3x3) -> BN`, with an element-wise addition of the input to the output. We strictly adhere to this linear topology rather than Dense Connectivity (RDN) to maximize computational throughput (samples/second), ensuring efficient training of deep models **Cite {solution_lesson_node_00018}**.
    *   **Inductive Bias**: We utilize standard dense $3 \times 3$ convolutions (stride 1, dilation 1). We explicitly reject dilated convolutions (which miss local pixel correlations **Cite {solution_lesson_node_00011}**) and attention mechanisms (which add overhead without aiding local denoising **Cite {solution_lesson_node_00025}**).
    *   **Resolution Preservation**: The network contains **no pooling or downsampling layers**, operating entirely at the original spatial resolution to preserve fine text strokes **Cite {solution_lesson_node_00009}**.
*   **Structural Innovation (Zero-Gamma Initialization)**: To enable the training of this deep regression network without the signal explosion observed in previous attempts, I implement **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer in *every* residual block is initialized to **zero**.
    *   **Mechanism**: This forces each residual block to behave mathematically as an identity function ($y = x + 0$) at the start of training. This prevents the linear accumulation of variance that destroys deep regression models, allowing the network to start stable and incrementally learn the noise residuals **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network is architected to predict the **noise residual** $\mathcal{R}(x)$ rather than the clean image. The final output is $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

# Data
I propose a **High-Density Data Strategy** that is strictly matched to the model's capacity and the available 24-hour runtime.

*   **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
*   **High-Density Patch Extraction**:
    *   Extract patches of size $50 \times 50$ using a **very small stride** (e.g., 6 to 8 pixels).
    *   **Strategic Resolution**: Previous attempts failed because they increased model capacity without increasing data density **Cite {solution_lesson_node_00013}**, or they used dense data but truncated training due to short time limits **Cite {solution_lesson_node_00020}**. With the **24-hour budget**, we can now afford to process this massive dataset (millions of patches) to full convergence, ensuring the deep model is fully saturated with training examples.
*   **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to enforce rotation invariance.

# Training
*   **Ensemble Strategy**: Train **$K=5$ independent instances** of the ZI-ResDnCNN using different random seeds.
    *   **Rationale**: **Cite {solution_lesson_node_00029}** warned against ensembling under-trained models when time is short. However, with 24 hours, we have sufficient time to train *each* ensemble member to full convergence (approx. 3-4 hours per model). This allows us to reap the variance-reduction benefits of ensembling without the downside of underfitting.
*   **Loss Function**: Minimize **Mean Squared Error (MSE)** between predicted and true noise.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** learning rate scheduler. The Zero-Gamma initialization allows for a higher initial learning rate, accelerating convergence.

# Evaluation
*   **Dual-Level Inference**:
    1.  **Geometric Self-Ensemble (Test-Time Augmentation)**: For each of the $K$ models, generate predictions for 8 geometric transformations (flips/rotations) of the test image, inverse-transform the outputs, and average them.
    2.  **Ensemble Averaging**: Compute the final prediction by averaging the TTA outputs of all $K$ ensemble members.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Ensemble Predicted Noise}$.
*   **Submission**: Clip pixel intensities to $[0, 1]$ and flatten to the `image_row_col` format.
