This script demonstrates the end-to-end usage of the provided library for the image denoising task. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` class to set up a lightweight demonstration environment (reduced epochs, larger stride for fewer patches, smaller batch size, and a temporary working directory).
2.  **Utility Verification**: Validates the correctness of the RMSE calculation function.
3.  **Data Pipeline Execution**: Runs the data preparation pipeline to extract patches from the training images using the modified configuration, verifying the shapes of the resulting data.
4.  **Model Initialization**: Instantiates the `ResDnCNN` model and verifies a forward pass with a dummy batch.
5.  **Training Loop**: Executes a single epoch of training to demonstrate the training process and ensure the model checkpoint is saved.
6.  **Inference & Submission**: Runs the inference pipeline on a subset of the test data, generating a submission file and verifying its format.
