Based on the comprehensive analysis of previous failures and empirical lessons, I propose the **High-Capacity Zero-Initialized Deep Residual Ensemble (HC-ZI-ResDnCNN)**. This strategy leverages the extended 24-hour computational budget to resolve the conflict between model capacity and data density that plagued previous attempts.

# Model
I propose a **Homogeneous Ensemble** where each member is a **High-Capacity Deep Residual Denoising Network**.

*   **Backbone Architecture**: Each network consists of a deep stack (e.g., 30 blocks, 60+ layers) of **Linear Residual Stacks** (Conv-BN-ReLU-Conv-BN).
    *   **Throughput Optimization**: We strictly adhere to this linear topology rather than Dense Connectivity (RDN) or Attention mechanisms. This maximizes computational throughput (samples/second), allowing us to train a high-capacity model to convergence within the time limit **Cite {solution_lesson_node_00018}**.
    *   **Inductive Bias**: We utilize standard dense $3 \times 3$ convolutions, explicitly rejecting dilated convolutions (which miss local pixel correlations **Cite {solution_lesson_node_00011}**) and attention mechanisms (which add overhead without aiding local denoising **Cite {solution_lesson_node_00025}**).
    *   **Resolution Preservation**: The network contains **no pooling or downsampling layers**, operating entirely at the original spatial resolution to preserve fine text strokes **Cite {solution_lesson_node_00009}**.
    *   **Increased Capacity**: Unlike previous iterations, we will increase the network width (e.g., 96 filters per layer). This higher capacity is now viable because we will explicitly match it with high-density data, addressing the underfitting/overfitting trade-off observed in **Cite {solution_lesson_node_00013}**.
*   **Structural Innovation (Zero-Gamma Identity Path)**: To enable the training of this significantly deeper and wider network without signal explosion, I implement **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer in *every* residual block is initialized to **zero**. This forces each block to behave mathematically as an identity function at initialization, preventing variance accumulation and allowing the deep network to learn residuals incrementally **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network predicts the **noise residual** $\mathcal{R}(x)$, with the final output being $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

# Data
I propose a **High-Density Data Strategy** that is strictly matched to the model's increased capacity and the available 24-hour runtime.

*   **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
*   **High-Density Patch Extraction**:
    *   Extract patches of size $50 \times 50$ using a **very small stride** (e.g., 8 or 10 pixels).
    *   **Strategic Resolution**: Previous attempts failed because they increased model capacity without increasing data density **Cite {solution_lesson_node_00013}**, or they used dense data but truncated training due to short time limits **Cite {solution_lesson_node_00020}**. With the **24-hour budget**, we can now afford to process this massive dataset (millions of patches) to full convergence, ensuring the wide/deep model is fully saturated with training examples.
*   **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to enforce rotation invariance.

# Training
*   **Ensemble Strategy**: Train **$K=5$ independent instances** of the HC-ZI-ResDnCNN using different random seeds.
    *   **Rationale**: **Cite {solution_lesson_node_00029}** warned against ensembling under-trained models when time is short. However, with 24 hours, we have sufficient time to train *each* ensemble member to full convergence (approx. 4 hours per model). This allows us to reap the variance-reduction benefits of ensembling without the downside of underfitting.
*   **Loss Function**: Minimize **Mean Squared Error (MSE)** between predicted and true noise.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** learning rate scheduler. The Zero-Gamma initialization allows for a stable start even with deep networks.
*   **Stability**: Apply **Gradient Clipping** to further ensure stability during the initial training phase of the wide network **Cite {solution_lesson_node_00017}**.

# Evaluation
*   **Dual-Level Inference**:
    1.  **Geometric Self-Ensemble (TTA)**: For each of the $K$ models, generate predictions for 8 geometric transformations (flips/rotations) of the test image, inverse-transform the outputs, and average them.
    2.  **Ensemble Averaging**: Compute the final prediction by averaging the TTA outputs of all $K$ ensemble members.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Ensemble Predicted Noise}$.
*   **Submission**: Clip pixel intensities to $[0, 1]$ and flatten to the `image_row_col` format.
