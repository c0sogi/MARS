The following script demonstrates the end-to-end usage of the provided library for the image denoising task. It performs the following steps:

1.  **Configuration Override**: Modifies the global configuration in `library.config` to use a temporary working directory and lightweight hyperparameters (fewer epochs, smaller model, sparse data sampling) to ensure the demo runs quickly.
2.  **Utility Verification**: Validates the image loading and RMSE calculation functions from `library.utils`.
3.  **Dataset Preparation**: Generates a small training and validation dataset using `library.dataset`, verifying the shape and integrity of the patches.
4.  **Model Instantiation**: Initializes the Residual Dense Network (RDN) from `library.model` with reduced complexity and verifies the forward pass dimensions.
5.  **Training Loop**: Executes a short training run using `library.train`, producing a trained model file.
6.  **Inference & Submission**: Generates predictions on a subset of the test data using `library.predict` and verifies the format of the output submission file.
