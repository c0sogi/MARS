The issue is that the `calculate_rmse` function in `library/utils.py` returns a NumPy scalar (specifically from `np.sqrt`), which is then propagated to the `validate` function and subsequently saved in the model checkpoint under the "loss" key. When `torch.load` attempts to load this checkpoint with the default `weights_only=True` setting, it fails because NumPy scalars are not in the default allowlist of safe globals. To fix this, I will explicitly cast the result of the RMSE calculation to a native Python `float` before returning it. Cite debug_lesson_1.
