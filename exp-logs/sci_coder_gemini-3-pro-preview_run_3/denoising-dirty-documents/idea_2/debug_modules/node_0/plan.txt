The following implementation demonstrates the end-to-end usage of the provided library modules for the image denoising task.

### Implementation Strategy

1.  **Configuration Setup**: We first import the `Config` class and override specific hyperparameters (epochs, batch size, debug sample size) to ensure the script runs quickly (within minutes) while still executing all logical paths.
2.  **Component Validation**:
    *   **Dataset**: We explicitly call `load_data` to verify metadata parsing and image loading. We then instantiate `DenoisingDataset` to verify that data augmentation (random cropping) and tensor conversion work correctly.
    *   **Model**: We instantiate the `UNet` architecture and perform a forward pass with a dummy tensor to confirm that the input/output dimensions are preserved.
    *   **Metrics**: We validate the `calculate_rmse` function with known inputs.
3.  **Training Pipeline**: We execute `run_training` from `library.train`. This function orchestrates the data loading, model initialization, training loop, validation, and checkpoint saving.
4.  **Inference Pipeline**: We execute `run_inference` from `library.predict`. This loads the saved checkpoint, performs inference on the test set, and generates the submission CSV.
5.  **Output Verification**: Finally, we inspect the generated submission file to ensure it adheres to the required format (correct columns and row counts based on the processed test data).
