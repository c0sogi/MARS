The implementation strategy is as follows:

1.  **Setup & Configuration**: Import necessary modules from the provided library. Override the default number of training epochs to a lower value (20) to ensure the script executes quickly as a "fast baseline" while still learning from the 92 training images.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. This will train the U-Net model, perform validation during training, and save the best model checkpoint based on validation RMSE.
3.  **Validation & Failure Analysis**:
    *   Load the best saved model checkpoint.
    *   Load the hold-out validation dataset using `library.dataset.get_dataloaders`.
    *   Iterate through the validation set to generate predictions.
    *   Compute the **Final Validation Metric** (Global RMSE) over all pixels in the validation set and print it in the required format.
    *   Perform failure analysis by calculating the Mean Absolute Error (MAE) for each validation image.
    *   Compute and print the Pearson correlation between the error magnitude (MAE) and input image statistics (Mean Intensity and Standard Deviation) to identify error patterns.
4.  **Submission**:
    *   Compare the Final Validation Metric against the provided threshold (0.016654925420880318).
    *   If the metric is lower than the threshold, trigger the inference pipeline using `library.predict.run_inference` to generate the submission file for the test set.
