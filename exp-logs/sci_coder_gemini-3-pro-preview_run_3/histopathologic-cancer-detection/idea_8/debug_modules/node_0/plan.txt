The following script demonstrates the complete pipeline using the provided library files.

**Strategy:**
1.  **Configuration Override**: We dynamically modify `Config` parameters (epochs, batch size, working directory) and subset the data to ensure the demonstration runs quickly (under 5 minutes) while exercising all code paths.
2.  **Data Loading**: We verify the `load_metadata` function and `PathologyDataset` class, ensuring data shapes and types are correct.
3.  **Model Training (Base Models)**: We iterate through the architectures defined in `Config.MODEL_ARCHS`. For each, we initialize the model using `get_model`, train it for one epoch on a small subset using `train_one_epoch`, evaluate it using `evaluate`, and generate test predictions using `predict_tta`.
4.  **Meta-Learner**: We construct an Out-Of-Fold (OOF) DataFrame from the validation predictions and train the XGBoost meta-learner using `train_xgboost_meta_learner`.
5.  **Inference**: We use the trained meta-learner to generate final predictions on the test set via `inference_meta_learner`.
6.  **Verification**: Throughout the script, assertions verify shapes, file outputs, and logic integrity.
