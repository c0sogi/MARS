### Implementation Strategy

The solution implements a **Heterogeneous Stacking Ensemble** orchestrated within a strict time limit.

1.  **Configuration & Constraints**: To adhere to the "fast baseline" requirement and 2-hour runtime limit, the script overrides the default configuration to use a **stratified subset of 25,000 training samples** and reduces training to **5 epochs** per fold. This ensures the 10 models (2 architectures $\times$ 5 folds) can be trained and validated quickly on the A100 GPU.
2.  **Level-0 Training (Base Models)**:
    *   Iterates through two architectures: `convnext_tiny` and `tf_efficientnetv2_s`.
    *   Uses **5-Fold Cross-Validation** on the subsampled training data.
    *   Trains each model with AdamW optimizer and Cosine Annealing scheduler.
    *   Generates **Out-Of-Fold (OOF)** predictions using Test Time Augmentation (TTA) to serve as features for the meta-learner.
3.  **Level-1 Training (Meta-Learner)**:
    *   Aggregates the OOF predictions from both architectures.
    *   Trains a **Logistic Regression** meta-learner to learn the optimal combination of the base models.
4.  **Validation & Inference**:
    *   Evaluates the full ensemble on the **hold-out validation set** (loaded from `./metadata/val.csv`). Predictions for each architecture are obtained by averaging the outputs of its 5 fold models.
    *   Computes the **Final Validation Metric (AUC)**.
5.  **Failure Analysis**:
    *   Analyzes prediction errors on the validation set.
    *   Computes the correlation between error magnitude and basic image statistics (brightness, contrast) to identify potential failure modes.
6.  **Submission**:
    *   If the Final Validation AUC exceeds the strict threshold (`0.99336`), the pipeline proceeds to generate predictions for the test set and saves `submission.csv`.
