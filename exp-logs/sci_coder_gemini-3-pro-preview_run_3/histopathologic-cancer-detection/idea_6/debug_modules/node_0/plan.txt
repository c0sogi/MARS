This script demonstrates the end-to-end usage of the provided library files for the tumor detection task. It performs the following steps:
1.  **Configuration**: Overrides default configuration settings (directories, epochs, batch size) to ensure the demo runs quickly and does not interfere with production outputs.
2.  **Data Loading**: Loads metadata, creates a small subset for demonstration, and initializes the `PathologyDataset` and `DataLoader`. It verifies the data shapes and transform pipeline.
3.  **Model Initialization**: Instantiates a `convnext_tiny` model (without pre-trained weights for speed) and verifies the output shape.
4.  **Training & Validation**: Runs a single epoch of training and validation on the data subset using the provided engine functions, verifying that the loss is a valid float.
5.  **Inference**: Demonstrates Test Time Augmentation (TTA) inference on the validation subset.
6.  **Stacking Ensemble**: Simulates Out-Of-Fold (OOF) predictions to train a meta-learner (Logistic Regression) and generates ensemble predictions.
7.  **Submission**: Creates a sample submission file using the `create_submission` utility.
