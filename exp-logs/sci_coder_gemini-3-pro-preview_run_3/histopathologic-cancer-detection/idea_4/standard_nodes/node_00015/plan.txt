My implementation strategy for the `runfile.py` script is as follows:

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class, set random seeds for reproducibility, and detect the computation device (GPU). I will define a reduced number of epochs (`FAST_EPOCHS = 2`) to ensure the entire pipeline (training 10 models + validation + potential submission) completes within the 2-hour time limit while still using the full dataset for maximum performance.

2.  **Training Loop**: Implement a nested loop iterating through the 2 model architectures (`ConvNeXt-Tiny`, `EfficientNetV2-Small`) and 5 cross-validation folds. For each combination, I will call `run_fold_training` with the reduced epoch count. This ensures we create the full heterogeneous ensemble required by the strategy.

3.  **OOF Validation**: To compute a valid metric on the hold-out validation set (`metadata/val.csv`) without data leakage, I will perform Out-Of-Fold (OOF) prediction. I will iterate through each fold, load the validation data for that fold, and use the models trained on the *other* folds (i.e., the models assigned to that fold) to generate predictions. These predictions will be aggregated and filtered to match the specific IDs in the hold-out set.

4.  **Metric Calculation**: Calculate the Area Under the ROC Curve (AUC) using the aggregated OOF predictions and the ground truth labels from the hold-out set. I will print this in the required format: `Final Validation Metric: <value>`.

5.  **Failure Analysis**: Compute the absolute error for the validation predictions. I will then sample a subset of images (to save time), extract basic features (brightness, contrast), and calculate the Pearson correlation between these features and the model error to identify potential failure modes.

6.  **Submission**: Check if the calculated validation AUC exceeds the threshold (`0.9933607469455475`). If it does, I will call `generate_submission` to create the final `submission.csv` using the ensemble of all trained models.
