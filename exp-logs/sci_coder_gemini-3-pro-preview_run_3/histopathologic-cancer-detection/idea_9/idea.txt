Based on the progression of experiments and the lessons learned, I propose a **Converged Heterogeneous Stacking Strategy with Non-Linear Meta-Learning**. This approach structurally evolves the solution from a linear combination of models to a non-linear meta-learning pipeline, while strictly enforcing the convergence protocols that previous heterogeneous attempts failed to meet.

# Model
I propose a **Two-Stage Stacking Architecture** designed to leverage complementary inductive biases and learn complex interactions between model predictions.

1.  **Level-0 Base Learners (Heterogeneous):**
    *   **ConvNeXt-Tiny:** Retained as the primary backbone. Its hierarchical, Transformer-inspired design (7x7 kernels, LayerNorm) has empirically proven to be the strongest individual performer on this dataset (Cite solution_lesson_node_00013).
    *   **DenseNet-121:** Introduced as the secondary backbone. Unlike the residual summation of ResNets or the stage-wise design of ConvNeXt, DenseNet uses dense concatenation connectivity. This architecture is historically effective in medical imaging for preserving feature reuse and gradient flow, providing a distinct feature extraction pathway.
    *   **Structure:** We will implement **5-Fold Cross-Validation** for *both* architectures. This results in 10 independent models (2 architectures × 5 folds), ensuring 100% data utilization and generating robust Out-Of-Fold (OOF) predictions (Cite solution_lesson_node_00013).

2.  **Level-1 Meta-Learner:**
    *   **XGBoost Classifier:** Instead of the linear Logistic Regression or simple averaging used in previous ideas, we will employ a Gradient Boosted Decision Tree (XGBoost) as the meta-learner.
    *   **Rationale:** Previous attempts using naive averaging failed because they could not account for the specific strengths and weaknesses of disparate models (Cite solution_lesson_node_00015). A non-linear meta-learner can learn conditional logic (e.g., "Trust ConvNeXt more when DenseNet is uncertain") to optimize the final probability calibration.

# Data
-   **Preprocessing (Cropping):** We will strictly apply a **Center Crop of 64x64 pixels**. This isolates the labeled 32x32px Region of Interest (ROI) while preserving the optimal 16px context buffer, maximizing the Signal-to-Noise Ratio (Cite solution_lesson_node_00001).
-   **Augmentation:** We will employ the proven geometric suite: **RandomRotate90**, HorizontalFlip, and VerticalFlip. This forces the model to learn the rotational invariance inherent in histopathology images (Cite solution_lesson_node_00002).

# Training
-   **Convergence Strategy:** We will train every fold of every base model for **30 Epochs**. Previous analysis showed that loss was still decreasing at epoch 20 (Cite solution_lesson_node_00014). Extending the schedule ensures we extract the maximum discriminative power from the backbones, directly preventing the under-training failure observed in previous heterogeneous attempts (Cite solution_lesson_node_00008).
-   **Scheduler:** We will utilize **Cosine Annealing** for the full duration, avoiding Early Stopping. This ensures the model benefits from the fine-grained weight updates at the end of the cycle (Cite solution_lesson_node_00022).
-   **Optimization:**
    -   **Batch Size:** We will maximize the batch size (saturating the A100 VRAM) to ensure stable Batch Normalization statistics and gradient updates (Cite solution_lesson_node_00010).
    -   **Safety:** We will explicitly disable `drop_last` or ensure `len(dataset) >= batch_size` to prevent the silent data-subsetting failures observed in previous attempts (Cite solution_lesson_node_00018).
-   **Checkpointing:** We will utilize **TTA-Integrated Checkpointing**. Model weights will be saved based on the validation AUC calculated using Test Time Augmentation, ensuring the saved state is explicitly optimized for the inference strategy (Cite solution_lesson_node_00006).

# Evaluation
1.  **OOF Generation:** We will generate Out-Of-Fold predictions for the training set using **4-view Test Time Augmentation (TTA)**. Using TTA for the meta-learner's training data reduces noise and aligns the training distribution with the test distribution (Cite solution_lesson_node_00005).
2.  **Meta-Training:** The XGBoost model will be trained on these TTA-enhanced OOF probabilities to map the base model outputs to the ground truth labels.
3.  **Inference:** For the test set, we will generate TTA-averaged predictions from all 10 base models. These probabilities will be fed into the trained XGBoost model to produce the final submission score. This prioritizes the "OOF Strategy" to maximize the final leaderboard performance (Cite solution_lesson_node_00020).
