The implementation strategy focuses on orchestrating a robust Heterogeneous Ensemble Pipeline within the strict time and performance constraints.

1.  **Configuration & Setup**: We will override the default `Config` to set `NUM_EPOCHS` to 2. This ensures the training of three distinct backbones (ResNet18, EfficientNetV2-S, ConvNeXt-Tiny) completes well within the 2-hour limit while leveraging the A100 GPU for rapid convergence on the full dataset.
2.  **Training Phase**: We will iterate through each model architecture. For each, we initialize the model with ImageNet pretrained weights, train for 2 epochs using the full training set, and perform validation with Test Time Augmentation (TTA) at the end of each epoch. The model state with the highest TTA-Validation AUC will be saved.
3.  **Ensemble Validation**: Once all models are trained, we will load their best states and perform inference on the validation set. The predictions will be averaged (soft voting) to compute the final ensemble AUC. This metric determines if we proceed to submission.
4.  **Failure Analysis**: We will analyze the ensemble's performance on the validation set by calculating the absolute error for each sample. We will then extract image meta-features (brightness, contrast, channel means, sharpness) for the validation images and compute their correlation with the error magnitude to identify potential weak points.
5.  **Submission**: If the ensemble validation AUC exceeds the threshold (0.9892525043540494), we will generate predictions for the test set using the full ensemble with TTA and save the submission file.
