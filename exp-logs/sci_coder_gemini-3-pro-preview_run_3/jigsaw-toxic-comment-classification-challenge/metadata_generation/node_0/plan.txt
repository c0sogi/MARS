The implementation strategy is as follows:

1.  **Data Loading**: The script uses `pandas` to load the raw `train.csv` and `test.csv` files from the `./input` directory.
2.  **Metadata Structure**: Instead of duplicating the text data (which would violate the "no copy" rule and waste space), the metadata files will store the `id`, the relative path to the source file (`source_file`), and the row index (`source_row_index`) in that source file. This allows efficient retrieval of the original text by downstream loaders.
3.  **Stratification**: To ensure the validation set represents the multi-label distribution of the training data, a stratification key is created by concatenating the six binary labels into a string (e.g., "010010"). The data is split 80:20 using `sklearn.model_selection.train_test_split` with this key. Rare combinations are handled gracefully by falling back to a random split if strict stratification is impossible.
4.  **Output**: Three CSV files (`train_metadata.csv`, `val_metadata.csv`, `test_metadata.csv`) are saved to the `./metadata` directory. These files contain the linkage information and the ground-truth labels (for train/val).
5.  **Validation**: The script reloads the generated metadata to perform the required checks:
    *   **Summary Statistics**: Prints shapes and label distributions.
    *   **File Path Check**: Verifies that the `source_file` references (e.g., `train.csv`) exist in `./input`.
    *   **Stratification Check**: Asserts that the label distributions in the training and validation sets are statistically similar (within a small tolerance).
