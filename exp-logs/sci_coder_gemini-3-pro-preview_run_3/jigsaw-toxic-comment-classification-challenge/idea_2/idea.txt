# Proposed Solution: Hybrid Semantic-Keyword Ensemble (RoBERTa + NBSVM)

## Model
I propose a **Hybrid Ensemble Architecture** that fuses two distinct modeling paradigms to capture both deep semantic context and precise keyword signals.
1.  **Contextual Backbone (Deep Learning):** A pre-trained **RoBERTa** (Robustly Optimized BERT Pretraining Approach) model will serve as the primary feature extractor. Unlike the previous n-gram models, RoBERTa utilizes self-attention mechanisms to understand syntax, negation, and long-range dependencies, addressing the "bag-of-words" limitations where word order is ignored. A linear classification head attached to the `[CLS]` token embedding will output the 6 multi-label probabilities.
2.  **Keyword Expert (Linear Baseline):** The **NBSVM (Naive Bayes - Support Vector Machine)** model will be retained as a secondary component. This model has proven empirically robust and efficient at detecting explicit toxicity via specific token occurrences (Cite solution_lesson_node_00001). By keeping this, we ensure the system remains sensitive to rare, highly toxic slang or obfuscated words that might be lost in the sub-word tokenization or truncation of the Transformer.

## Data
The data pipeline will be split to serve the specific needs of each model component:
1.  **Transformer Pipeline:** Raw text will be processed using the RoBERTa tokenizer. We will apply a fixed maximum sequence length (e.g., 128 or 256 tokens) to manage GPU memory usage, truncating longer comments while preserving the initial segment where the intent is often established.
2.  **NBSVM Pipeline:** We will generate sparse TF-IDF matrices for word n-grams (1-2) and character n-grams (2-6). Crucially, we will maintain strict vocabulary pruning (e.g., `min_df` $\ge$ 3) to filter out the "long tail" of noisy features that degraded performance in previous high-dimensional experiments (Cite solution_lesson_node_00002).

## Training
The training process will treat the two components as independent learners to maximize error diversity:
1.  **RoBERTa Fine-tuning:** The Transformer will be fine-tuned on the GPU using **Binary Cross-Entropy with Logits Loss** (BCEWithLogitsLoss). We will employ the **AdamW** optimizer with a linear learning rate warmup and decay schedule to stabilize the adaptation of the pre-trained weights to the toxicity domain.
2.  **NBSVM Fitting:** We will compute the Naive Bayes log-count ratios for each class and use them to scale the TF-IDF features element-wise. A Logistic Regression classifier will then be trained on these scaled features, using strong regularization (low `C`) to prevent overfitting to sparse artifacts (Cite solution_lesson_node_00002).

## Evaluation
1.  **Inference:** Both the fine-tuned RoBERTa model and the fitted NBSVM model will generate probability predictions for the test set independently.
2.  **Ensembling:** The final predictions will be computed via a **weighted average** of the two probability vectors (e.g., $P_{final} = \alpha \cdot P_{RoBERTa} + (1-\alpha) \cdot P_{NBSVM}$). This strategy combines the high-variance, high-capacity semantic understanding of the neural network with the high-bias, stable keyword detection of the linear model.
