The `FileNotFoundError` occurs because the validation subset in `runfile.py` is created by naively slicing the first 50 rows (`val_full.iloc[:50]`). Due to the high class imbalance, this small subset lacks positive samples for rare classes (like 'threat'), causing the `roc_auc_score` to return `NaN` (undefined for single-class targets). Consequently, the model saving condition `if val_auc > best_auc` in `training_engine.py` evaluates to `False` (since `NaN > 0.0` is False), preventing the creation of the `best_roberta_model.bin` checkpoint. The script then crashes when attempting to load this missing file for inference.

The fix is to stratify the validation subset in `runfile.py` to ensure it contains at least two positive samples for each class, similar to how the training subset is constructed. This guarantees valid AUC calculation and ensures the model checkpoint is saved (Cite debug_lesson_3).
