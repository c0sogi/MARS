The following script demonstrates the end-to-end usage of the provided 3D object detection library. It covers data preparation, model instantiation, training, and inference.

### Implementation Strategy
1.  **Environment Setup**: We import the necessary modules from the provided library files (`library.*`).
2.  **Configuration Override**: To ensure the demo runs quickly, we override the `Config` class attributes. We create small subsets of the training and test metadata (10 samples and 4 samples, respectively) and point the configuration to these files. We also reduce batch sizes and voxel limits.
3.  **Data Verification**: We instantiate the `LidarDataset` with the subset and verify that the `DataLoader` yields batches with the correct tensor shapes (voxels, coordinates, ground truth boxes).
4.  **Model Verification**: We instantiate the `TwoStagePointPillars` model. We run a forward pass in `train` mode to check loss calculation and in `test` mode to check prediction formats.
5.  **Training & Inference**: We run a single training epoch using `train_one_epoch` and then generate a submission file using `generate_submission` on the test subset, verifying the final output file structure.
