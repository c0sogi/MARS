This script demonstrates the end-to-end usage of the provided 3D object detection library. It performs the following steps:
1.  **Configuration**: Overrides default `Config` parameters to define a temporary working directory, reduce epochs, and disable time-consuming augmentation (GT Sampling) for a quick demonstration.
2.  **Dataset Verification**: Instantiates the `NuScenesLidarDataset`, loads a small batch of data, and verifies the structure and shapes of the generated voxels, coordinates, and targets.
3.  **Model & Loss Verification**: Instantiates the `TemporalPointPillars` model and `DetectionLoss`. It performs a forward pass with the sample batch, calculates the loss, and asserts the output shapes and loss validity.
4.  **Training**: Uses the `Trainer` class to train the model for one epoch on a small subset of the training data.
5.  **Inference**: Uses the `InferenceEngine` to generate predictions on a subset of the test data using the trained model, producing a submission CSV file.
