The `AssertionError` in `runfile.py` indicates a mismatch between the expected heatmap resolution (512x512) and the actual model output (256x256). This occurs because the current backbone configuration uses `BACKBONE_LAYER_STRIDES = [2, 2, 2]`, resulting in a cumulative downsampling factor of 8, while the upsampling path only recovers a factor of 4 (max upsample stride 4), yielding a net stride of 2. To fix this and ensure the output resolution matches the input grid (net stride 1), I will change `BACKBONE_LAYER_STRIDES` to `[1, 2, 2]`. This ensures the cumulative downsampling (1, 2, 4) aligns with the upsampling strides (1, 2, 4) (Cite debug_lesson_3).
