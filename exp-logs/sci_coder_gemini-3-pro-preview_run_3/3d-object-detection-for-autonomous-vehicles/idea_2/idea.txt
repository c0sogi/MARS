To establish a highly efficient and lightweight baseline that contrasts with the deep learning approach of Idea 1, I propose a **Two-Stage Geometric Clustering and Gradient Boosting Pipeline**. This approach corresponds to **Model 4** in the provided architectures. It relies on unsupervised geometric algorithms for object proposal and efficient tree-based learning for classification, avoiding the heavy computational cost of neural network backpropagation and voxelization.

### Model
The architecture operates in a purely feed-forward manner using geometric signal processing followed by structured learning:

1.  **Stage 1: Unsupervised Proposal Generation**
    *   **Ground Plane Removal**: The raw point cloud is processed using a RANSAC (Random Sample Consensus) algorithm to robustly fit a plane to the ground points. Points falling within a distance threshold of this plane are removed, isolating potential obstacles.
    *   **Euclidean Clustering**: The remaining non-ground points undergo Euclidean Clustering (using an algorithm like DBSCAN). This groups spatially adjacent points into discrete clusters, where each cluster represents a candidate object (a "proposal").
    *   **Geometric Bounding**: For each cluster, an initial oriented bounding box is calculated using Principal Component Analysis (PCA). The eigenvectors of the cluster's covariance matrix determine the object's primary axes (orientation), and the min/max projections along these axes determine the dimensions.

2.  **Stage 2: Feature Extraction**
    *   Instead of learning features via convolutions, we compute a fixed-length vector of explicit geometric descriptors for each cluster:
        *   **Shape Descriptors**: Eigenvalues of the covariance matrix ($\lambda_1, \lambda_2, \lambda_3$) to calculate linearity, planarity, and sphericity (helping distinguish linear bicycles from planar walls or spherical bushes).
        *   **Spatial Descriptors**: Volume, bounding box dimensions ($l, w, h$), and center coordinates ($x, y, z$).
        *   **Statistical Descriptors**: Point count, point density, and maximum/mean intensity values.

3.  **Stage 3: Classification and Regression Heads**
    *   **Classifier**: A **LightGBM** (Gradient Boosting Machine) classifier takes the feature vector and predicts the object class (e.g., `Car`, `Pedestrian`, `Background`). The output probability serves as the detection `confidence`.
    *   **Regressor**: A separate LightGBM regressor predicts the **residuals** (corrections) needed to transform the initial PCA-derived bounding box into the tight ground-truth box. This corrects errors where PCA might loosely fit a car or misalign the yaw.

### Data
1.  **Training Set Construction**:
    *   Iterate through the `train_metadata.csv`. For each sample, perform Ground Removal and Clustering to generate proposals.
    *   Match these proposals to the Ground Truth bounding boxes using Intersection over Union (IoU).
    *   **Positive Samples**: Clusters with IoU > 0.4 with a GT box. The target is the GT class and the geometric residuals (e.g., $\Delta x, \Delta y, \Delta yaw$).
    *   **Negative Samples**: Clusters with IoU < 0.4 (or 0.1). The target class is `Background`.
    *   Compile these into a tabular dataset where rows are object candidates and columns are the engineered features.

2.  **Test Set Preparation**:
    *   Process `test_metadata.csv` identically (Ground Removal + Clustering) to generate the table of candidate features for inference.

### Training
1.  **Algorithm**: Use **LightGBM**, which is optimized for speed and handles tabular data efficiently.
2.  **Strategy**:
    *   **Classification**: Train on the full tabular dataset (Positives + Negatives) using **Multi-class Log Loss**. This teaches the model to reject background clutter (rocks, walls) and classify valid objects.
    *   **Regression**: Filter the dataset to include *only* Positive samples. Train using **Mean Squared Error (MSE)** or **L1 Loss** to learn the offsets for center, dimensions, and yaw.
3.  **Optimization**: Use a validation split (grouped by `scene_token`) to employ **Early Stopping**, halting training when validation metric plateaus. This prevents overfitting and ensures the training completes in minutes rather than hours.

### Evaluation
1.  **Inference**:
    *   Load the test point clouds and generate candidate clusters.
    *   Extract the geometric feature vectors.
    *   Pass vectors through the LightGBM Classifier. Discard any candidates classified as `Background` or with `confidence` below a low threshold (e.g., 0.1).
2.  **Refinement**:
    *   Pass the surviving candidates through the LightGBM Regressor to obtain residuals.
    *   Apply the residuals to the original PCA bounding boxes to obtain the final refined coordinates ($x, y, z, w, l, h, yaw$).
3.  **Formatting**:
    *   Format the refined boxes into the submission string: `confidence x y z w l h yaw class_name`.
    *   (Optional) Apply a simple 3D Non-Maximum Suppression (NMS) if multiple clusters overlap significantly, though Euclidean clustering naturally separates objects.
