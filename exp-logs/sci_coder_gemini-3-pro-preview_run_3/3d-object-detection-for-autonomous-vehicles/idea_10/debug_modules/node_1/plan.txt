The `KeyError: 'class_name'` arises because `GTDatabaseSampler.build_database` creates a DataFrame from an empty list `all_db_infos` without specifying columns, resulting in a DataFrame with no schema (Cite debug_lesson_6). When the code subsequently attempts to group by "class_name", it fails. Furthermore, if the database is empty, the associated points file might not be created or might be empty, which would cause `np.memmap` to raise a `ValueError` or `FileNotFoundError` (Cite debug_lesson_8).

I will fix this by:
1.  Enforcing the DataFrame schema in `build_database` even when no objects are found.
2.  Ensuring the points file is created (even if empty) in `build_database`.
3.  Adding a file size check before calling `np.memmap` in `__init__` to handle empty databases gracefully.
