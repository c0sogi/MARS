To establish a robust and highly efficient baseline, I propose a **Frozen Siamese Transformer with Linear Readout**. This approach synthesizes the semantic power of Transformers (Model 1), the interaction modeling of Siamese networks (Model 2), and the computational efficiency of Ridge Regression (Model 5).

# Model
The architecture consists of a fixed (frozen) pre-trained Transformer encoder followed by a shallow linear regression block.
1.  **Encoder Backbone:** Utilize a lightweight, pre-trained Sentence Transformer (e.g., `all-MiniLM-L6-v2`) designed for semantic similarity tasks. This model is small, fast, and optimized for generating meaningful sentence embeddings without requiring fine-tuning.
2.  **Siamese Feature Extraction:**
    *   **Question Embedding ($u$):** The `question_title` and `question_body` are concatenated and passed through the encoder to produce a dense vector $u$.
    *   **Answer Embedding ($v$):** The `answer` text is passed through the same encoder to produce a dense vector $v$.
3.  **Interaction Layer:** To capture the relationship between the question and the answer (crucial for labels like `answer_relevance`), we construct a combined feature vector $X$ by concatenating the embeddings and their interactions: $X = [u, v, |u - v|, u * v]$, where $|u-v|$ is the element-wise absolute difference and $u*v$ is the element-wise product.
4.  **Prediction Head:** The feature vector $X$ is fed into a Multi-Output Ridge Regression model. This linear layer learns to map the semantic features and their interactions to the 30 target probabilities.

# Data
1.  **Text Aggregation:** For the question side, concatenate `question_title` and `question_body` with a whitespace separator. Treat `answer` as the second input.
2.  **Cleaning:** Perform minimal preprocessing: fill missing values with empty strings and strip leading/trailing whitespace. The pre-trained Transformer handles tokenization, casing, and punctuation natively.
3.  **Feature Generation:** Run the pre-trained Transformer in inference-only mode on the training and validation sets to generate the fixed embeddings ($u$ and $v$) and compute the interaction terms ($|u-v|$, $u*v$). These pre-computed vectors serve as the input for the regressor.

# Training
1.  **Strategy:** This approach avoids computationally expensive backpropagation through the Transformer. Training is restricted to the Ridge Regression layer, which has a closed-form solution (or highly optimized iterative solvers).
2.  **Loss Function:** Ridge Regression minimizes the Mean Squared Error (MSE) with L2 regularization. While the competition metric is Spearman's correlation, MSE is a stable and effective proxy for regression tasks on bounded [0,1] targets.
3.  **Optimization:** Use `RidgeCV` (Ridge Regression with built-in Cross-Validation) to automatically select the optimal regularization strength ($\alpha$) for the linear layer. This eliminates the need for manual hyperparameter tuning loops.

# Evaluation
1.  **Inference:** For each row in the test set, generate embeddings $u$ and $v$ using the frozen Transformer.
2.  **Prediction:** Compute the interaction features and pass the resulting vector $X$ through the trained Ridge Regression model to obtain the 30 target scores.
3.  **Post-processing:** Clip the predicted values to the range [0, 1] to ensure valid probability outputs before saving to the submission file.
