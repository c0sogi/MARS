The following implementation orchestrates the end-to-end workflow for the Frozen Siamese Transformer with Linear Readout. It leverages the provided library modules for data loading, feature extraction (using a pre-trained Sentence Transformer), model training (Ridge Regression), and evaluation.

The script performs the following steps:
1.  **Initialization**: Sets random seeds for reproducibility and loads the train, validation, and test datasets.
2.  **Feature Extraction**: Uses the `EmbeddingPipeline` to generate semantic embeddings for questions and answers. It computes interaction features (concatenation, difference, product) to capture the relationship between the question and answer. Caching is enabled to speed up execution.
3.  **Model Training**: Trains a Multi-Output Ridge Regression model (`LinearHead`) on the training features.
4.  **Validation**: Evaluates the model on the hold-out validation set using the mean column-wise Spearman's correlation coefficient.
5.  **Failure Analysis**: Calculates the Mean Absolute Error (MAE) for the validation set and correlates these errors with input text lengths to identify potential weaknesses (e.g., does the model struggle with long/short texts?).
6.  **Submission**: Generates predictions for the test set, ensures they are within the [0, 1] range, and saves the formatted submission file.
