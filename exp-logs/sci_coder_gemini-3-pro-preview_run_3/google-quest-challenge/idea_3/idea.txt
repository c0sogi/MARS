Based on the analysis of the previous experiments and the derived lessons, I propose the **Contextualized Cross-Encoder with Segment-Aware Feature Extraction**.

This strategy introduces a structural innovation by shifting from a Siamese (Bi-Encoder) architecture to a **Cross-Encoder** architecture. While the Siamese approach (Idea 2) is efficient, it relies on "late interaction" (combining independent embeddings via heuristic math), which limits its ability to model complex dependencies between Question and Answer. A Cross-Encoder processes the Question and Answer jointly, allowing the self-attention mechanism to learn deep, token-level interactions ("early interaction"). To address the challenge of predicting single-source targets (e.g., `question_well_written`) with a joint model, I propose a novel feature extraction scheme that pools the Question and Answer segments separately from the joint context.

### Model
1.  **Backbone (Cross-Encoder):** Utilize the `sentence-transformers/all-mpnet-base-v2` model. Unlike the previous Siamese configuration, the input will be a single sequence containing both the Question and the Answer separated by special tokens. This allows the model to leverage full cross-attention.
2.  **Segment-Aware Feature Extraction:** Instead of relying solely on the `[CLS]` token, we will extract a rich set of features from the fine-tuned backbone to feed the downstream regressor:
    *   **Joint Representation ($h_{CLS}$):** The embedding of the `[CLS]` token, capturing the global relationship and interaction between the Question and Answer.
    *   **Contextualized Question ($h_{Q}$):** The mean-pooled embedding of the tokens corresponding to the Question segment.
    *   **Contextualized Answer ($h_{A}$):** The mean-pooled embedding of the tokens corresponding to the Answer segment.
    *   **Interaction Term ($h_{diff}$):** The element-wise absolute difference $|h_{Q} - h_{A}|$.
    *   **Feature Vector:** The final feature vector for the regression head is the concatenation $[h_{CLS}, h_{Q}, h_{A}, h_{diff}]$. This preserves the explicit interaction modeling strategy that proved critical in the baseline (Cite solution_lesson_node_00001).
3.  **Regression Head:** A **Ridge Regression** model (using `RidgeCV`) trained on the extracted feature vectors. This retains the "Fine-Tune then Ridge" pattern, which empirically outperforms standard MLP heads for ranking metrics (Cite solution_lesson_node_00004).

### Data
1.  **Input Formatting:** Concatenate the text as: `[CLS] Question_Title + Question_Body [SEP] Answer [SEP]`.
2.  **Preprocessing:** Tokenize the inputs using the MPNet tokenizer with a maximum length of 512 tokens. Maintain a mapping of token indices to identify the "Question" span and "Answer" span for the segment-aware pooling step.
3.  **Caching:** After fine-tuning, run the model in inference mode to generate and save the feature vectors ($[h_{CLS}, h_{Q}, h_{A}, h_{diff}]$) to disk. This ensures pipeline integrity and allows for rapid iteration on the Ridge head (Cite solution_lesson_node_00003).

### Training
1.  **Stage 1: End-to-End Fine-Tuning:**
    *   Train the Cross-Encoder backbone with a temporary linear head on the 30 target labels.
    *   **Loss:** `BCEWithLogitsLoss`.
    *   **Epochs:** Train for **6 epochs** to ensure the backbone representation fully converges (Cite solution_lesson_node_00006).
    *   **Batch Size:** Use a physical batch size of 8 with gradient accumulation steps set to 2 (effective batch size 16). This prioritizes update frequency over gradient stability, which is beneficial for this small dataset (Cite solution_lesson_node_00007).
    *   **Optimizer:** `AdamW` with a learning rate of 2e-5 and linear warmup.
2.  **Stage 2: Ridge Regression:**
    *   Load the cached feature vectors from Stage 1.
    *   Train a multi-output `RidgeCV` model to map the high-dimensional features to the 30 target probabilities.

### Evaluation
1.  **Inference:** Pass the test set pairs through the fine-tuned Cross-Encoder.
2.  **Extraction:** Compute the segment-aware features ($h_{CLS}, h_{Q}, h_{A}$) and the interaction term ($h_{diff}$) for each test sample.
3.  **Prediction:** Feed the concatenated vector into the trained Ridge Regression model.
4.  **Post-processing:** Clip predictions to the [0, 1] range.
