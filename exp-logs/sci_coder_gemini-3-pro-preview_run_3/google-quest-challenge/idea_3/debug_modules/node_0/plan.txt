### Implementation Strategy

1.  **Environment Setup**: We will initialize the random seeds and ensure the working directory (`./working/idea_3`) exists as defined in the library configuration.
2.  **Data Subsetting (Optimization)**: To ensure the script runs quickly (within minutes), we will manually load the large metadata CSVs, sample a tiny subset (e.g., 20 rows for training, 10 for validation/test), and save them as Parquet files in the working directory. The `load_data` function in the library is designed to prefer these cached files over the full metadata, effectively forcing the pipeline to use our small subset.
3.  **Configuration Overrides**: We will monkey-patch the `TrainConfig` class to reduce the number of epochs to 1, reduce the batch size, and simplify the Ridge Regression alphas. This ensures the training and inference loops complete almost instantly.
4.  **Component Verification**:
    *   **Dataset**: Instantiate `QuestDataset` and verify the output shapes of tensors produced by `__getitem__`.
    *   **Model**: Instantiate `SegmentAwareCrossEncoder`, perform a forward pass with dummy data, and verify the shapes of the returned logits and features.
    *   **Training Engine**: Execute `run_backbone_training`. This will fine-tune the backbone on the small subset and save the model weights.
    *   **Feature Extraction**: Execute `run_feature_extraction` to generate embeddings using the fine-tuned model. We will verify the shapes of the saved numpy arrays.
    *   **Ridge Head**: Execute `train_ridge_and_predict` to train the final regression layer and generate a submission file. We will verify the submission file's format and content.
5.  **Assertions**: At every step, we use `assert` statements to validate shapes, data types, and file existence, ensuring the logic is correct.
