3.  **Pipeline Execution**:

    *   **Phase 2 (Fine-Tuning)**: Train the model on the first fold using the DAPT-adapted weights.
    *   **Phase 3 (Feature Extraction & Ridge Regression)**: Extract topology-aware features (Question/Answer embeddings) and train the Ridge Regression heads for Fold 0.
4.  **Ensemble Simulation**: To demonstrate the stacking logic without doubling the runtime, I will simulate the existence of Fold 1 by duplicating the artifacts (predictions/targets) generated from Fold 0.
5.  **Meta-Stacking**: Run the `MetaStacker` to aggregate predictions from the simulated folds and generate the final submission file.
6.  **Validation**: Throughout the script, I will use `assert` statements to verify file creation, data shapes, and value ranges (e.g., probabilities in [0, 1]).
