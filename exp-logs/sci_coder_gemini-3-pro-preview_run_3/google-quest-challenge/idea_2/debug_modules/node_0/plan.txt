### Implementation Strategy

1.  **Setup & Verification**: Import necessary modules from the provided library files. Set the random seed for reproducibility.
2.  **Component Demonstration**: Manually instantiate the `StackExchangeDataset` and `SiameseNetwork` with a small dummy dataset to verify their initialization logic and forward pass dimensions before running the full pipeline.
3.  **Stage 1 (Fine-Tuning)**: Execute `train_stage_1` with `debug=True`. This trains the Siamese Network on a small subset (100 rows) for a few epochs, ensuring the code runs quickly while generating the necessary model artifacts (`mpnet_finetuned_state.pth`).
4.  **Feature Extraction**: Execute `cache_features` with `debug=False`. We use the full dataset here because the subsequent Ridge Regression stage expects alignment with the full metadata files (which are read from disk). Since we have an A100 GPU, extracting features for ~6000 rows will be very fast.
5.  **Stage 2 (Refinement)**: Execute `train_ridge_head`. This trains the Ridge Regression model on the extracted features and generates an initial submission.
6.  **Inference**: Execute `predict_and_submit` with `debug=False`. This runs the full inference pipeline, ensuring the final `submission.csv` is generated and correctly formatted.
7.  **Final Validation**: Load the generated submission file, verify its shape matches the test set size (608 rows), and check that predictions are within the [0, 1] range.
