To address the `torch.OutOfMemoryError` encountered during training, I will implement a three-part strategy to reduce GPU memory usage:

1.  **Reduce Batch Size**: In `library/config.py`, I will decrease `BATCH_SIZE` from 16 to 4. To maintain the same effective batch size for convergence stability, I will increase `GRADIENT_ACCUMULATION_STEPS` from 1 to 4.
2.  **Enable Mixed Precision Training**: In `library/trainer.py`, I will integrate `torch.cuda.amp.GradScaler` and `autocast`. This allows the model to perform operations in half-precision (float16) where appropriate, significantly lowering memory footprint and speeding up training on the A100 GPU.
3.  **Optimize Feature Extraction**: In `library/feature_caching.py`, I will wrap the inference calls in `autocast` to ensure memory efficiency during the feature extraction phase as well.
