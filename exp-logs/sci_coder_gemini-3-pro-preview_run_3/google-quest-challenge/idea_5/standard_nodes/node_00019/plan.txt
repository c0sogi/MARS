2.  **Extended Convergence**: I will increase the number of fine-tuning epochs from 5 to 6 for both MPNet and DeBERTa streams. The previous run indicated MPNet was still improving at epoch 5, suggesting potential underfitting (Cite Lesson 00006).
3.  **Feature Normalization**: I will integrate a `StandardScaler` into the Ridge Regression pipeline. Since the Ridge head is trained on high-dimensional embedding features (concatenation of CLS and segment means), standardizing these features ensures the linear solver (RidgeCV) can find a more optimal hyperplane (Cite Lesson 00004).
