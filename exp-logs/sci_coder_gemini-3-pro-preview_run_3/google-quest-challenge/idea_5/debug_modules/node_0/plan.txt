This script demonstrates the usage of the provided library modules for the StackExchange Question-Answer labeling task. It performs the following steps:

1.  **Data Preparation**: Creates a small "demo" dataset by sampling the original metadata files to ensure the script runs quickly.
2.  **Dataset & DataLoader**: Demonstrates how to instantiate the `StackExchangeDataset` and wrap it in a `DataLoader`, verifying the output shapes and mask generation logic.
3.  **Modeling**: Instantiates the `SegmentAwareCrossEncoder`, performs a forward pass, and verifies the shapes of the output logits and extracted features.
4.  **Training Engine**: Runs a single training epoch and a validation step using the `engine` module functions to demonstrate the training loop mechanics.
5.  **Feature Extraction**: Uses the model to extract embeddings from the text data.
6.  **Ridge Regression Head**: Trains a Ridge regression model on the extracted features and generates predictions, ensuring they fall within the valid [0, 1] range.
7.  **Metrics**: Verifies the Spearman correlation metric calculation.
