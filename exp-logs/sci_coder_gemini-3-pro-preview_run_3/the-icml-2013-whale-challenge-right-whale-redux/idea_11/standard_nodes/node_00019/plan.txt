The `torch.OutOfMemoryError` indicates that the GPU ran out of memory while trying to train the Dual-Stream EfficientNet model with a batch size of 64. The model consists of two EfficientNetV2-M backbones, which are memory-intensive.

To resolve this, I will:
1.  **Reduce Batch Size**: In `library/config.py`, decrease `BATCH_SIZE` from 64 to 16 to significantly lower the memory footprint.
2.  **Enable Mixed Precision**: In `library/trainer.py`, implement Automatic Mixed Precision (AMP) using `torch.cuda.amp.autocast` and `GradScaler`. This reduces memory usage by storing activations in half-precision and speeds up training on the A100 GPU.
