The `RuntimeError: Unknown model (convnext_tiny.fb_in1k)` occurs because the specific model identifier `convnext_tiny.fb_in1k` is not present in the registry of the installed `timm` library version (1.0.20). While this identifier exists in some versions to denote Facebook's original ImageNet-1k weights, it is not universally available.

To fix this, I will update the `BACKBONE` configuration in `library/config.py` to use the standard, version-agnostic identifier `convnext_tiny`. This ensures the model can be instantiated by `timm.create_model`, which will automatically select the default pretrained weights when `pretrained=True` is set. This approach follows the principle of using standard resource identifiers rather than guessing specific variant tags (Cite debug_lesson_1).
