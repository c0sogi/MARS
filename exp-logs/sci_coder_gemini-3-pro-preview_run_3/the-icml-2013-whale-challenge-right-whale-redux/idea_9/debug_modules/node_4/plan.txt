The `RuntimeError: Unknown model (convnext_small)` occurs because `convnext_small` is not a valid model identifier in the installed version of `timm` (1.0.20). While `convnext_small` describes the architecture, `timm` requires a specific variant tag (e.g., indicating the weight source and training dataset) to locate the model in its registry. As per **Debug Lesson 1**, guessing "generic" names often fails; we must use the precise identifier expected by the library. The standard identifier for ConvNeXt Small with ImageNet-1k weights from Meta (Facebook) is `convnext_small.fb_in1k`.

I will update `library/config.py` to use `convnext_small.fb_in1k` instead of the invalid `convnext_small`. Cite debug_lesson_1.
