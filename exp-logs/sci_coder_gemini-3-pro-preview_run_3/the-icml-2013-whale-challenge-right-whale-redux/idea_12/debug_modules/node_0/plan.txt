This script demonstrates the end-to-end usage of the provided Right Whale Detection library. It performs the following steps:
1.  **Configuration & Setup**: Sets reproducible seeds and defines a lightweight configuration for rapid execution (using a smaller backbone and fewer epochs).
2.  **Data Processing**: Loads a small subset of the training data using `library.dataset.process_data`, verifying that caching and data loading work correctly.
3.  **Component Verification**:
    *   **Transforms**: Validates that spectrogram generation and augmentation (SpecAugment) produce tensors of the correct shape.
    *   **Dataset**: Verifies that the `WhaleDataset` correctly formats inputs (3-channel expansion) and targets.
    *   **Model**: Instantiates `WhaleEfficientNet` with a smaller backbone (`tf_efficientnet_b0`) for speed and checks forward pass dimensions.
    *   **Loss**: Computes `WeightedBCELoss` on dummy data to ensure stability.
4.  **Training Loop**: Uses the `Trainer` class to overfit a small batch of data for 2 epochs, ensuring the training pipeline (forward pass, backward pass, optimizer step) functions without error.
5.  **Inference**: Runs predictions on the validation set and calculates the ROC AUC score.
