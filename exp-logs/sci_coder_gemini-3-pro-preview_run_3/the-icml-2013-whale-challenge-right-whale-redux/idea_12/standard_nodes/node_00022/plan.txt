The implementation strategy follows the Multi-Stage Noisy Student pipeline described in the idea. 

1.  **Setup & Data Loading**: We initialize the environment and load the training, validation, and test datasets using the provided `process_data` function. This leverages the caching mechanism to speed up subsequent runs.
2.  **Stage 1: Teacher Training**: We train the first `WhaleEfficientNet` (Teacher) on the labeled training data. We use the `Trainer` class with the provided configuration (including Mixup and Weighted BCE Loss). The best model state based on validation AUC is saved.
3.  **Stage 2: Pseudo-Labeling**: We load the best Teacher model and generate soft probability predictions for the entire unlabeled test set. We then construct a combined dataset where the training data retains its hard labels (0 or 1) and the test data uses the generated soft probabilities as targets.
4.  **Stage 3: Student Training**: We initialize a fresh `WhaleEfficientNet` (Student) and train it on this combined dataset. This allows the model to learn from a larger, more diverse distribution.
5.  **Validation & Analysis**: We evaluate the final Student model on the hold-out validation set. We calculate the required AUC metric and perform failure analysis by correlating prediction errors with input signal statistics (mean and standard deviation of the spectrograms) to identify potential systematic weaknesses.
6.  **Submission**: If the validation AUC exceeds the specified threshold, we generate predictions for the test set using the Student model and save the submission file in the required CSV format.
