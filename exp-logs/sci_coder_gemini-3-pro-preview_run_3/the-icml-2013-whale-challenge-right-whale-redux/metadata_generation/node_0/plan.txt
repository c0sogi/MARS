The strategy involves scanning the `./input/train2` and `./input/test2` directories to identify audio files. For the training data, labels will be derived from the filenames based on the suffix (`_1.aif` for whale calls, `_0.aif` for noise). The training data will then be split into training and validation sets using a stratified 80:20 split with a fixed random seed. Metadata CSV files containing relative file paths and labels will be generated and saved to the `./metadata` directory. Finally, the script will reload these files to perform validation checks, ensuring file paths resolve correctly and the data split distribution is accurate.
