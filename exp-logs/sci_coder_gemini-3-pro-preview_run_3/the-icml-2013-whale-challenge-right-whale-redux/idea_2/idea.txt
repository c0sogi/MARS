# Strategy: Deep Residual Learning with Channel Attention (SE-ResNet)

Building on the success of the 2D CNN approach, I propose a structural evolution from a simple "Shallow CNN" to a **Residual Network integrated with Squeeze-and-Excitation (SE) Attention**. This addresses the need for a more expressive feature extractor capable of modeling complex spectral dependencies while retaining the robust training pipeline established in previous lessons.

## Model
The core innovation is the transition from a plain feed-forward convolutional stack to a **Residual Architecture with Channel Attention**.
*   **Backbone:** The model will utilize a stack of **SE-Residual Blocks**. Unlike the previous simple convolutional blocks, these blocks employ skip connections (identity shortcuts) that allow gradients to flow through the network more effectively, enabling the training of a significantly deeper model (e.g., comparable to ResNet-18 or ResNet-34) without degradation.
*   **Attention Mechanism:** Within each residual block, an **Squeeze-and-Excitation (SE) module** is inserted. This component performs "Squeezing" (Global Average Pooling to aggregate spatial context) and "Excitation" (a lightweight fully connected bottleneck to predict channel-wise importance weights). This structurally allows the network to dynamically recalibrate the importance of different feature maps (frequency bands), effectively suppressing background noise channels and emphasizing whale call patterns.
*   **Head:** The backbone output is fed into a Global Average Pooling layer followed by a single fully connected layer with a Sigmoid activation.

## Data
*   **Input Representation:** Continue to transform raw 1D audio waveforms into **2D Log-Mel Spectrograms**. This representation has proven superior for event detection by exposing time-frequency textures to the CNN (Cite solution_lesson_node_00001).
*   **Resolution:** Maintain the standard spectrogram resolution (approx. 64-128 Mel bands) rather than increasing it. This ensures the input signal remains compact enough to align with the model's receptive field, avoiding the performance degradation observed with high-resolution inputs (Cite solution_lesson_node_00002).

## Training
*   **Loss Function:** Utilize **Binary Cross-Entropy (BCE) with Inverse Class Frequency Weighting**. This directly addresses the ~9:1 class imbalance by penalizing the model more heavily for missing the minority whale calls (Cite solution_lesson_node_00001).
*   **Augmentation Strategy:**
    *   **SpecAugment:** Apply random time and frequency masking to the spectrograms during training. This acts as a critical regularizer, forcing the model to learn robust partial features rather than memorizing noise artifacts (Cite solution_lesson_node_00003).
    *   **Mixup with Mixed Losses:** Implement Mixup augmentation to smooth the decision boundary. Crucially, use the **Mixed Losses** strategy—calculating the weighted loss for each sample in the mix pair separately and then combining the scalar losses—rather than mixing the labels or weights. This ensures the minority class gradients are not diluted (Cite solution_lesson_node_00005).
*   **Optimization:** Use the Adam optimizer combined with a **Cosine Annealing Learning Rate Scheduler**. This schedule allows for an initial high learning rate to escape local minima, followed by a gradual decay to refine the weights, which has been shown to stabilize validation loss (Cite solution_lesson_node_00003).

## Evaluation
*   **Inference:** Preprocess test recordings into Log-Mel Spectrograms using the same parameters as the training set.
*   **Prediction:** Perform a forward pass through the SE-ResNet model. The final sigmoid output will serve as the predicted probability of a right whale call.
