The implementation strategy involves the following steps:
1.  **Setup and Configuration**: Import the necessary modules and the provided library. Override `Config.EPOCHS` to 12. This ensures the model trains long enough to achieve the high AUC threshold (>0.9837) while remaining a "fast baseline" that executes quickly on the provided A100 GPU. Set the random seed for reproducibility.
2.  **Training**: Initialize the `Trainer` class with `debug=False` to utilize the full training dataset. Execute the training loop using `trainer.fit()`, which handles the training process, validation monitoring, and saving the best model checkpoint.
3.  **Validation and Analysis**: After training, switch the model to evaluation mode. Iterate through the validation `DataLoader` to collect predictions, ground truth labels, and input feature statistics (mean and standard deviation of the spectrograms). This is done without gradient computation (`torch.no_grad`) for efficiency.
4.  **Metric Calculation**: Compute the ROC AUC score on the collected validation data and print it in the specific format required: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute and print the Pearson correlation between the error magnitude and the input feature statistics (spectrogram mean and std) to identify potential sources of systematic error.
6.  **Submission**: Compare the final validation AUC against the strict threshold (0.9836981714333874). If the metric exceeds the threshold, call `trainer.predict()` to generate predictions on the test set and save the `submission.csv` file.
