The `RuntimeError: Unknown model (convnext_tiny.fb_in1k)` occurs because the model identifier `convnext_tiny.fb_in1k` is not recognized by the installed version of the `timm` library. As noted in **debug_lesson_1**, libraries like `timm` use strict registries for model names, and guessing or using outdated identifiers causes failures. I will fix this by updating the `BACKBONE` configuration in `library/config.py` to `convnext_tiny`, which is the standard, valid identifier for this architecture in `timm`.
