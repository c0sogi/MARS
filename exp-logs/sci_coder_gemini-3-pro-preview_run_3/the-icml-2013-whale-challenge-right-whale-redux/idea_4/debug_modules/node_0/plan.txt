Implementation Strategy:
1.  **Environment Setup**: Import necessary standard libraries and the provided library modules (`config`, `utils`, `data`, `model`, `losses`, `train`). Set the random seed for reproducibility.
2.  **Data Subsetting**: To ensure the demonstration runs quickly, load the full metadata files from `./metadata`, sample a small subset (e.g., 20 training samples, 10 validation samples, 10 test samples), and save these subsets to the `./working` directory.
3.  **Configuration Override**: Modify the `Config` class attributes at runtime to point to the new subset metadata files, reduce the number of epochs (2), decrease the batch size (4), and set a temporary cache directory. This ensures the training loop executes rapidly without processing the entire dataset.
4.  **Component Validation**:
    *   **Data Processing**: Test `process_audio_file` on a single real audio file to verify it returns a spectrogram of the correct shape `(1, 224, 224)`.
    *   **Model Architecture**: Instantiate `WhaleClassifier`, pass a dummy input tensor, and verify the output logits shape `(Batch_Size, 1)`.
    *   **Loss Function**: Instantiate `WeightedBCELoss` and `MixupLoss`, compute loss on dummy predictions and targets, and verify the loss is a scalar tensor.
5.  **Full Pipeline Execution**: Run the `run_training` function using the modified configuration. This tests the data loading, model training, validation, checkpoint saving, and inference pipeline end-to-end.
6.  **Result Verification**: Assert that the `best_model.pth` checkpoint and `submission.csv` file are generated and that the submission file contains the correct number of rows.
