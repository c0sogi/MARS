The implementation strategy is as follows:

1.  **Setup and Imports**: Import necessary modules from the standard library (`os`, `pandas`, `numpy`, `torch`, `scipy`, `sklearn`) and the provided solution library (`library`).
2.  **Reproducibility**: Initialize the random number generators using `seed_everything` with the defined seed to ensure consistent results.
3.  **Training**: Execute the training pipeline using `run_training`. We will use the default 15 epochs which is sufficient for this small dataset and ensures a fast runtime (approx. 10-15 minutes on GPU). We enable `load_cached_data` to speed up data loading.
4.  **Validation**:
    *   Load the trained model from the checkpoint.
    *   Load the validation dataset using the metadata.
    *   Run inference in evaluation mode (`model.eval()`, `torch.no_grad()`) to obtain probabilities.
    *   Calculate the Area Under the ROC Curve (AUC) using `sklearn.metrics.roc_auc_score`.
    *   Print the required metric string: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the absolute error magnitude (`|target - prediction|`) for each validation sample.
    *   Load the validation metadata to extract meta-features (specifically, the number of slices for each MRI modality: FLAIR, T1w, T1wCE, T2w).
    *   Calculate and print the Pearson correlation between the error magnitude and these meta-features to identify if the model struggles with patients having fewer or more slices.
6.  **Submission**:
    *   Compare the final validation AUC against the threshold `0.6978181818181817`.
    *   If the model performs well enough, call `generate_submission` to create the `submission.csv` file for the test set.
