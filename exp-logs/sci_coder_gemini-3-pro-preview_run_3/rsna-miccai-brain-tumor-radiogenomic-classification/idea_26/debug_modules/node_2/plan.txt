The issue is that `roc_auc_score` returns `nan` instead of raising a `ValueError` when provided with 2D input arrays `(N, 1)` containing only a single class (e.g., all positives in a small validation batch). This `nan` return value causes the model checkpointing logic (`if val_auc > best_auc`) to fail silently, leading to the `AssertionError` because no model file is saved. To fix this, we must flatten the target and probability arrays to 1D shapes `(N,)` before passing them to the metric function. This forces the library to use binary classification logic, which correctly raises a `ValueError` when only one class is present, allowing the existing exception handler to assign a fallback value of 0.5.
