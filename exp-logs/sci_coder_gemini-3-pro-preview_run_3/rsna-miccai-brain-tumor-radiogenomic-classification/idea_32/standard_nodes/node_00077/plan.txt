The implementation strategy is as follows:

1.  **Setup and Initialization**: Initialize the environment by setting random seeds for reproducibility and defining the compute device (GPU/CPU).
2.  **Model Training**: Execute the training pipeline using the provided `train_model` function. We will run for 10 epochs to ensure a fast but effective baseline, utilizing the caching mechanism to speed up data loading.
3.  **Validation Inference**: Load the best model saved during training and the validation dataset. Perform inference to generate predictions and calculate the Area Under the ROC Curve (AUC).
4.  **Metric Reporting**: Print the final validation AUC in the required format (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: Compute the absolute error for each validation sample. Correlate these errors with metadata features (slice counts per modality) extracted from the validation metadata file to identify potential sources of poor performance (e.g., insufficient slices).
6.  **Submission Generation**: Compare the validation AUC against the specified threshold (0.6978...). If the model performs sufficiently well, load the test dataset, generate predictions, and save them to `submission/submission.csv` in the correct format.
