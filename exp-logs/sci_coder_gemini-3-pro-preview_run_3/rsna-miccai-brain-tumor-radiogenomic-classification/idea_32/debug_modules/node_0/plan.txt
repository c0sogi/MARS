This script demonstrates the end-to-end usage of the provided machine learning library for Glioblastoma subtype prediction. It covers data loading, preprocessing, model instantiation, training, and inference.

### Implementation Strategy
1.  **Setup & Configuration**: We import the necessary modules and set the random seed for reproducibility. We define small constants (e.g., `DEMO_SAMPLES=8`, `DEMO_EPOCHS=2`) to ensure the script executes quickly within the provided environment.
2.  **Data Processing Verification**: We utilize `load_processed_data` with `max_samples` to load a small subset of the training data. We verify the shape and integrity of the resulting tensors (checking for correct channel dimensions and absence of NaNs).
3.  **Model Verification**: We instantiate the `HRLNNet` model and perform a forward pass with a dummy tensor to confirm the architecture produces the correct output shape.
4.  **Training Loop**: We execute the `train_model` function from the library, passing in the subset parameters. This demonstrates the training pipeline, including loss calculation, backpropagation, and model checkpointing. We verify that the best model is saved to disk.
5.  **Inference & Submission**: We load the trained model and processing a subset of the test data. We generate predictions, verify they are valid probabilities (0-1), and construct a sample submission DataFrame.
