The CUDA Out of Memory error is caused by an excessively large effective batch size ($8 \times 32 = 256$ images) which exceeds the available GPU memory. To fix this, I will reduce `BATCH_SIZE` to 2 and `NUM_SLICES` to 22 in `library/config.py`. Since changing `NUM_SLICES` alters the shape of the data, I will also implement a validation check in `library/dataset.py` to verify that cached data matches the current configuration, forcing regeneration if a mismatch is detected (Cite `debug_lesson_1`).
