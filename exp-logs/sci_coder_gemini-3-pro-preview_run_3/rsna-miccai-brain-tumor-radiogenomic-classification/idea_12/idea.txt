Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Slice-Grouped Volumetric Fusion Network**.

This solution structurally evolves the "2.5D Stacking" approach. It specifically resolves the tension between the need for **high volumetric information density** (Cite solution_lesson_node_00012) and the **instability/overfitting** associated with high-channel inputs (Cite solution_lesson_node_00013, Cite solution_lesson_node_00034). By introducing a **Slice-Grouped Stem**, we enforce "Early Fusion" of modalities (Cite solution_lesson_node_00018) while maintaining a constrained parameter space.

# Model
The architecture is a **2.5D Convolutional Neural Network** featuring a specialized **Slice-Grouped Stem** designed to process spatially registered multi-modal slices efficiently.

1.  **Input:** The model accepts a tensor of shape $(B, 128, 256, 256)$. This represents **32 spatial slices** for each of the 4 modalities ($32 \times 4 = 128$), maximizing volumetric coverage (Cite solution_lesson_node_00012).
2.  **Slice-Grouped Stem:**
    *   **Layer 1 (Intra-Slice Multi-Modal Learning):** `Conv2d(in_channels=128, out_channels=64, kernel_size=3, padding=1, groups=32, bias=False)`.
        *   **Mechanism:** By setting `groups=32`, the convolution is split into 32 parallel paths. Since the input channels are stacked in an **interleaved** order (see Data section), each group processes exactly **4 channels** corresponding to the 4 modalities of a single slice depth.
        *   **Benefit:** This enforces **Early Fusion** (Cite solution_lesson_node_00018) by allowing the kernel to learn pixel-level correlations between FLAIR, T1w, T1wCE, and T2w for each slice individually. Simultaneously, it drastically reduces parameters compared to a standard convolution, preventing overfitting (Cite solution_lesson_node_00013).
    *   **Layer 2 (Inter-Slice Aggregation):** `Conv2d(in_channels=64, out_channels=64, kernel_size=1, bias=False)`.
        *   **Mechanism:** This pointwise convolution mixes the features across the Z-axis (depth), integrating the information from different slices before entering the backbone.
    *   **Normalization & Activation:** Both layers are followed by `BatchNorm2d` and `ReLU`.
    *   **Initialization:** Crucially, these layers must be initialized using **Kaiming/He Normal** initialization to ensure the high-dimensional input is projected into a statistically stable feature space, preventing gradient explosion (Cite solution_lesson_node_00034).
3.  **Backbone:** An **EfficientNet-B0** instantiated via the `timm` library (Cite solution_lesson_node_00038). It is configured with `in_chans=64` to accept the stem's output, retaining native regularization like DropPath.
4.  **Head:** Global Average Pooling followed by a single fully connected layer (Sigmoid activation).

# Data
1.  **Global Volumetric Normalization:** For each patient, load the full 3D volume and normalize pixel intensities based on the global minimum and maximum of that volume. This preserves inter-slice contrast, ensuring empty slices remain dark and do not introduce noise (Cite solution_lesson_node_00015).
2.  **High-Density Uniform Sampling:** Extract **32 slices** uniformly distributed across the 10%-90% depth range of the MRI volume (Cite solution_lesson_node_00003).
3.  **Interleaved Stacking:** Stack the slices in an **interleaved** pattern: `[Slice0_FLAIR, Slice0_T1w, Slice0_T1wCE, Slice0_T2w, Slice1_FLAIR, ...]`.
    *   **Reasoning:** This ordering aligns with the `groups=32` structure of the stem, ensuring each group sees the full multi-modal context for one specific slice. It also maintains a consistent physical stride (Cite solution_lesson_node_00016).
4.  **Library Usage:** Use `pydicom` for robust data loading (Cite solution_lesson_node_00020).

# Training
1.  **Optimizer:** Use **Adam** with a learning rate of `1e-4`.
2.  **Regularization:** Do **not** use Weight Decay (AdamW) or aggressive geometric augmentations, as these suppress signal learning in this dataset (Cite solution_lesson_node_00007). Rely on the parameter efficiency of the Slice-Grouped Stem and `timm`'s native DropPath.
3.  **Loss Function:** **Binary Cross Entropy with Logits Loss**.
4.  **Strategy:** Train end-to-end. The Stem is trained from scratch (He init) while the backbone is fine-tuned.

# Evaluation
For each subject in the test set:
1.  Load metadata and file paths.
2.  Apply **Global Volumetric Normalization** and **High-Density Uniform Sampling** (32 slices).
3.  Construct the **Interleaved** input tensor $(128, 256, 256)$.
4.  Pass through the network. The Slice-Grouped Stem will extract multi-modal features per slice and aggregate them for the backbone to predict `MGMT_value`.
