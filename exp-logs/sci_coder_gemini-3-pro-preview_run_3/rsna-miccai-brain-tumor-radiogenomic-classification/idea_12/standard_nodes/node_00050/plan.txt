This is the implementation strategy for the `runfile.py` script:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds and detecting the compute device (GPU/CPU) using the provided utility functions.
2.  **Data Loading**: Leverage `library.data.get_dataloaders` to load the training, validation, and test datasets. We will enable caching (`load_cached_data=True`) to maximize speed.
3.  **Model Initialization**: Instantiate the `SliceGroupedFusionNet` and move it to the active device.
4.  **Training Loop**: Implement a standard training loop for `NUM_EPOCHS` (10).
    *   Use the Adam optimizer and BCEWithLogitsLoss.
    *   In each epoch, perform training using `train_one_epoch` and validation using `evaluate`.
    *   Track the best validation AUC and save the model checkpoint (`best_model.pth`) whenever performance improves.
5.  **Final Evaluation**:
    *   Load the best saved model checkpoint.
    *   Run a final evaluation on the full validation set to obtain the `Final Validation Metric`.
    *   Print this metric in the exact required format with full precision.
6.  **Failure Analysis**:
    *   Generate predictions for the validation set using the best model.
    *   Calculate the absolute error magnitude for each sample.
    *   Load the validation metadata (`val.parquet`) to extract meta-features (specifically, the number of slices per modality: FLAIR, T1w, T1wCE, T2w).
    *   Compute and print the correlation coefficients between the error magnitude and these features (as well as the target class) to identify systematic failure modes.
7.  **Submission Generation**:
    *   Compare the final validation AUC against the threshold `0.6978181818181817`.
    *   If the metric exceeds the threshold, create the `./submission` directory and generate the submission file using `library.train.generate_submission` on the test loader.
