The implementation strategy involves the following steps:
1.  **Setup & Imports**: Import the required modules and the pre-defined functions from the `library` package. Initialize the environment with a fixed random seed and detect the compute device.
2.  **Training**: Invoke `library.train.train_model` to train the VAMSNet model. We will use 10 epochs and batch size 32 to ensure the process completes quickly while establishing a solid baseline. Caching is enabled to speed up data loading.
3.  **Validation Inference**: Manually load the validation dataset and the trained model weights. Run inference in evaluation mode (without gradients) to obtain raw probabilities for the validation set.
4.  **Metric Calculation**: Compute the Area Under the ROC Curve (AUC) using the validation predictions and ground truth. Print this metric in the strictly required format.
5.  **Failure Analysis**: Compute the absolute error for each validation sample. Load the validation metadata to extract input features (specifically, the number of slices per MRI modality). Calculate and print the correlation between the model's error and these features to identify potential biases.
6.  **Conditional Submission**: Compare the calculated validation AUC against the provided threshold (0.6978...). If the model's performance exceeds this threshold, call `library.predict.generate_submission` to create the final `submission.csv` for the test set.
