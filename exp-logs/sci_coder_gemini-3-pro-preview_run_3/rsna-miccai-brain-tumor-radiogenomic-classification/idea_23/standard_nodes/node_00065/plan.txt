5.  **Validation & Metrics**:
    *   Evaluate the optimized model on the full validation set using `engine.evaluate`.

    *   Generate individual probability predictions for the validation set using `engine.predict`.
    *   Merge these predictions with the validation metadata to align them with patient IDs and target values.
    *   Calculate the absolute error (`|target - probability|`).
    *   Extract meta-features (specifically slice counts per modality) and compute their correlation with the error to identify if data quantity/density affects performance.

7.  **Submission**:
