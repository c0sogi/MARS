The following script demonstrates the end-to-end usage of the provided library modules for the Glioblastoma subtype prediction task.

**Implementation Strategy:**
1.  **Setup & Configuration**: We initialize the environment by setting random seeds for reproducibility. We also define a separate working directory for this demonstration to ensure we don't interfere with existing caches and to keep the execution lightweight.
2.  **Data Preparation**: We load the pre-generated metadata files. To ensure the script executes quickly (within the time limit), we slice these dataframes to create a tiny "demo" dataset (4 samples for training, 4 for validation, 4 for testing).
3.  **Dataset Instantiation**: We utilize the `RMSHDDataset` class to load and process the MRI volumes for our demo subsets. We verify the output shapes of the tensors to ensure the data pipeline (DICOM loading, 3D resizing, normalization) is functioning correctly.
4.  **Model Initialization**: We instantiate the `RMSHDNet` model and perform a dummy forward pass with a batch of data to verify the architecture and tensor dimensions.
5.  **Training Loop**: We set up the training infrastructure (DataLoaders, Optimizer, Loss Function) and run the `library.engine.run_training` function for a minimal number of epochs (2) to demonstrate the training process and early stopping logic.
6.  **Inference & Submission**: We use the trained model to generate predictions on the demo test set using `library.engine.predict`, and format the results into a submission CSV file.
