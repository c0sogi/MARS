This script demonstrates the end-to-end usage of the provided library files for the MGMT promoter methylation prediction task. It performs the following steps:
1.  **Configuration Override**: Modifies the default `Config` to run in a lightweight "demo" mode (reduced epochs, smaller batch size, fewer slices, and a separate working directory).
2.  **Data Subsetting**: Creates a small subset of the original metadata (train/val/test) to ensure the demonstration runs quickly (under 5 minutes).
3.  **Model Verification**: Instantiates the `MGSHDNetwork` and validates the forward pass with dummy data.
4.  **Training Loop**: Executes `run_training` on the subset data to produce a model checkpoint.
5.  **Inference Loop**: Executes `run_inference` to generate a submission file and verifies its format.
