The previous implementation failed due to three interacting issues:
1.  **Stale Artifacts:** The inference pipeline loaded a `best_model.pth` file from a previous, incompatible experiment because the current training run failed to save a new model. This caused a `RuntimeError` due to architecture mismatch (Cite debug_lesson_8).
2.  **Undefined Metrics:** The training loop failed to save a model because `roc_auc_score` returned `nan` (instead of raising `ValueError`) when the validation set contained only one class. This `nan` propagated, preventing the "best model" logic from triggering (Cite debug_lesson_1).
3.  **Cache Loading Failure:** The dataset loader crashed when reading cached patient IDs because `np.load` requires `allow_pickle=True` for object arrays (strings), causing unnecessary reprocessing (Cite debug_lesson_5).

The following changes fix these issues by:
1.  Explicitly deleting any existing model checkpoint at the start of the demo execution to prevent "ghost" bugs.
2.  Sanitizing the validation AUC metric to handle `nan` values by defaulting to 0.5.
3.  Enabling pickle support when loading cached string identifiers.
