The implementation strategy involves the following steps:

1.  **Initialization**: Define paths for input data and output metadata. Initialize the exclusion list for the specific problematic cases mentioned in the task description.
2.  **Data Loading & Cleaning**: Read the `train_labels.csv`. Convert `BraTS21ID` to 5-digit strings to match directory names. Filter out the IDs specified in the exclusion list.
3.  **File Scanning**: Implement a helper function to traverse the directory structure for a given subject. This function will check for the four MRI modalities (FLAIR, T1w, T1wCE, T2w), collect all `.dcm` file paths within them, and store them as relative paths to the `./input` directory.
4.  **Metadata Generation**:
    *   **Train/Val**: Iterate through the cleaned training labels, scan for files, and compile a DataFrame. Split this data into training (80%) and validation (20%) sets using stratified sampling based on the `MGMT_value` target to maintain class distribution.
    *   **Test**: Iterate through the `test` directory, scan for files for each subject, and compile a DataFrame (without labels).
5.  **Persistence**: Save the resulting DataFrames as Parquet files in the `./metadata` directory. Parquet is chosen for its efficiency in handling complex nested data (lists of file paths).
6.  **Verification**:
    *   Load the generated metadata files.
    *   Print summary statistics (counts, distributions).
    *   Perform the required integrity check by sampling 1,000 file paths and verifying their existence on disk. Raise an error if the missing ratio exceeds 0.5.
    *   Verify that the train/validation split is non-overlapping and properly stratified.
