The following script demonstrates the end-to-end usage of the provided machine learning pipeline for glioblastoma subtype prediction. It performs the following steps:

1.  **Setup & Configuration**: It creates a temporary working directory and generates "mini" metadata files containing a small subset (5 samples) of the original data. This ensures the demonstration runs quickly while still processing real DICOM data.
2.  **Runtime Overrides**: It dynamically modifies the `Config` class attributes to point to these mini-datasets and reduces training hyperparameters (1 epoch, small batch size) to satisfy the time constraints.
3.  **Model Verification**: It instantiates the `SSFNet` model and performs a forward pass with dummy tensors to verify the architecture and output shapes match expectations `(Batch, 1)`.
4.  **Training Pipeline**: It executes the `run_training` function, verifying that the training loop completes and produces a saved model checkpoint.
5.  **Inference Pipeline**: It executes the `generate_submission` function using the trained model, verifying that a valid submission CSV is generated with the correct schema.
