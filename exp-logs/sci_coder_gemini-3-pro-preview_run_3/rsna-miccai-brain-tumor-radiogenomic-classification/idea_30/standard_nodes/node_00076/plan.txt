The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the available computation device (GPU/CPU).
2.  **Training**: Execute the training pipeline using the provided `fit()` function from the `library.train` module. This leverages the pre-configured `HRVANet` model and training loop, automatically handling data loading, caching, and model saving.
3.  **Validation**:
    *   Load the best saved model state.
    *   Load the validation dataset using `get_dataloaders`.
    *   Perform inference on the full validation set in evaluation mode (`model.eval()`) with gradient calculation disabled (`torch.no_grad()`) for efficiency.
    *   Compute the Area Under the ROC Curve (AUC) comparing the predicted probabilities against the ground truth labels.
    *   Print the "Final Validation Metric" with full precision as required.
4.  **Failure Analysis**:
    *   Load the validation metadata (`val.parquet`) to access input features.
    *   Calculate the absolute error for each prediction (`|target - prediction|`).
    *   Extract meta-features from the metadata, specifically the number of slices available for each MRI modality (FLAIR, T1w, T1wCE, T2w).
    *   Compute and print the correlation between the prediction error and these meta-features to identify if data quantity/quality impacts performance.
5.  **Submission**:
    *   Compare the calculated Final Validation Metric against the specified threshold (0.6978181818181817).
