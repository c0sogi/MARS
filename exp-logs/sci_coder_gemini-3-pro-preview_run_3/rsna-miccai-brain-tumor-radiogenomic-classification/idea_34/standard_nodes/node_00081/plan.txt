The following implementation orchestrates the GNHR-Net pipeline. It begins by setting a fixed random seed for reproducibility. It then executes the training phase using the `run_training` function from the provided library, which handles the training loop, validation monitoring, and model checkpointing. The script utilizes the cached data loaders to ensure efficiency.

After training, the script re-loads the best model and the validation dataset to perform a mandatory failure analysis. It calculates the final ROC AUC score on the validation set and prints it in the specified format. It also computes correlations between the prediction error and the number of slices per modality to identify potential sources of failure.

Finally, the script checks if the validation AUC exceeds the specified threshold. If the condition is met, it invokes `predict_and_submit` to generate predictions on the test set and save the `submission.csv` file.
