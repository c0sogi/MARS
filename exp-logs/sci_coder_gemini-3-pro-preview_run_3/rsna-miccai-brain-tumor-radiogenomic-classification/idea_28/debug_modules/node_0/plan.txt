The following script demonstrates the usage of the provided library modules (`utils`, `data`, `model`, `train`) to perform the glioblastoma genetic subtype prediction task.

### Strategy Outline
1.  **Setup & Verification**: Initialize the environment with a fixed random seed for reproducibility. Verify the utility function `extract_image_id` works as expected on sample filenames.
2.  **Data Processing (Subset)**: Instead of loading the full dataset (which takes significant time), we load the training metadata and select a small subset (4 patients). We use `generate_dataset_arrays` to process these patients' MRI scans into 3D tensors. This demonstrates the data pipeline logic without the runtime overhead of the full dataset.
3.  **Dataset & DataLoader**: We wrap the processed tensors using the `BraTSDataset` class and create PyTorch `DataLoader` instances for training and validation simulation.
4.  **Model instantiation**: We instantiate the `RFMHDNetwork` (Robust Filename-Sorted Modality-Normalized High-Density Network). We perform a dummy forward pass to verify the input/output shapes match the expected dimensions `(Batch, 1)`.
5.  **Training & Validation Loop**: We manually execute the `train_one_epoch` and `validate` functions from the `library.train` module using the subset dataloaders. This verifies the training logic, loss calculation, and AUC metric computation.
6.  **Inference Simulation**: We demonstrate how to generate predictions on a test batch, mimicking the submission generation process.
