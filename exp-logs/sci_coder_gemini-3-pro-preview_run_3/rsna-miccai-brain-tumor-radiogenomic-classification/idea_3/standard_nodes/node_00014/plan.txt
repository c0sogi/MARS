Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy
1.  **Setup & Imports**: Initialize the environment using `seed_everything` and `get_device` from the provided library. Import necessary data loading, modeling, and training functions to avoid code duplication.
2.  **Configuration**: Define hyperparameters (Batch Size: 16, Epochs: 15, LR: 1e-4) suitable for a fast but effective baseline run on the A100 GPU.
3.  **Data Loading**: Use `get_dataloaders` with `load_cached_data=True` to efficiently load the preprocessed train, validation, and test sets.
4.  **Training Loop**: Implement a standard training loop using `train_one_epoch` and `validate`. Track the validation AUC at each epoch and save the model weights (`best_model.pth`) whenever the AUC improves.
5.  **Final Evaluation**: Load the best saved model and perform a dedicated inference pass on the validation set. This allows us to capture raw probabilities for both metric calculation and failure analysis.
6.  **Metric Reporting**: Calculate and print the `Final Validation Metric` (ROC AUC) using the full precision.
7.  **Failure Analysis**: Compute the absolute error for each validation sample. Load the validation metadata to extract meta-features (specifically, the number of slices per modality) and calculate their Pearson correlation with the model's error. This identifies if data quantity affects performance.
8.  **Conditional Submission**: Compare the final validation AUC against the threshold (0.6832727272727273). If the model performs sufficiently well, generate the submission file using `predict_and_submit`, which employs the Multi-View Ensemble strategy.
