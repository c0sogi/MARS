The solution addresses the "ghost bug" caused by stale artifacts and the undefined metric propagation that prevented a new model from being saved.

1.  **Invalidate Stale Artifacts**: In `runfile.py`, we explicitly remove the `best_model.pth` file (if it exists) during the environment setup. This ensures that if the current training run fails to produce a valid model (e.g., due to metric errors), the inference step will correctly fail with a "File not found" error rather than silently loading an incompatible model from a previous run (Cite debug_lesson_8).
2.  **Flatten Metric Inputs**: In `library/train.py`, we flatten the target and probability arrays before passing them to `roc_auc_score`. This forces Scikit-Learn to treat the input as a binary classification problem (shape `(N,)`) rather than a multi-label problem (shape `(N, 1)`), ensuring that single-class batches raise a `ValueError` (which is caught) instead of returning `nan` (Cite debug_lesson_9).
3.  **Sanitize Metrics**: We also add an explicit check for `np.isnan()` on the returned AUC score to provide a fallback value (0.5), preventing `nan` from propagating into the model saving logic (Cite debug_lesson_1).
