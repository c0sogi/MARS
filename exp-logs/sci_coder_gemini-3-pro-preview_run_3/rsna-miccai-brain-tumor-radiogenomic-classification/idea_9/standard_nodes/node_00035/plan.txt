The implementation strategy involves the following steps:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and defining the compute device (GPU/CPU) using the provided `library` modules.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. We will use the default configuration (15 epochs) which is optimized for the small dataset size (~400 samples) to ensure a fast baseline execution while allowing sufficient convergence.
3.  **Validation & Metrics**: 
    *   Load the best model checkpoint saved during training.
    *   Perform inference on the full validation dataset to obtain predictions.
    *   Calculate the Area Under the ROC Curve (AUC) and print it in the specific format required (`Final Validation Metric: <value>`).
4.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample.
    *   Load the validation metadata to extract input features (specifically, the number of slices per MRI modality).
    *   Calculate and print the correlation between the error magnitude and these features to identify potential sources of systematic failure.
5.  **Submission**:
    *   Compare the final validation AUC against the specified threshold (0.6978...).
    *   If the threshold is met, invoke `library.predict.generate_submission` to create the `submission.csv` file.
