Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility using `library.utils.seed_everything`.
2.  **Training**: Execute the training pipeline using `library.trainer.run_training`. This handles data loading, model initialization, and the training loop with early stopping, saving the best model to `./working/best_model.pth`.
3.  **Validation & Metric Calculation**:
    *   Load the validation dataset using `library.data_loader.get_datasets`.
    *   Load the best trained model state.
    *   Perform inference on the validation set in evaluation mode (`torch.no_grad()`) to obtain probabilities.
    *   Calculate the Area Under the ROC Curve (AUC) comparing predictions to ground truth labels.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error (`|predicted_prob - true_label|`) for each validation sample.
    *   Extract simple aggregate features from the preprocessed validation input tensors (e.g., Mean Signal Intensity, Signal Standard Deviation) to represent input characteristics.
    *   Compute and print the Pearson correlation between these input features and the prediction error to identify potential sources of bias or failure.
5.  **Submission Generation**:
    *   Compare the calculated validation AUC against the threshold (`0.6978181818181817`).
    *   If the model performance exceeds the threshold, invoke `library.inference.generate_submission` to create the final `submission.csv` for the test set.
