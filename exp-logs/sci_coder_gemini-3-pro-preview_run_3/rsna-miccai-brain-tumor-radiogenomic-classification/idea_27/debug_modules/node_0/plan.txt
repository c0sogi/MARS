Implementation Strategy:
1.  **Configuration & Setup**: Initialize the environment by setting random seeds for reproducibility. Crucially, modify the `DEBUG_SAMPLE_SIZE` in the `library.config` and `library.data_loader` modules to a small number (e.g., 5). This ensures that the data loading and processing steps run on a tiny subset of the data, allowing the script to complete quickly within the demonstration timeframe.
2.  **Data Loading Demonstration**: Use `library.data_loader.get_datasets` to load the training, validation, and test datasets. Verify the integrity of the loaded data by checking the shapes of the input tensors (should be `(N, 128, 224, 224)`) and the labels.
3.  **Model Instantiation & Verification**: Instantiate the `MNSHDNetwork` from `library.model_arch`. Perform a forward pass with a dummy tensor of the correct shape to verify that the model architecture is valid and produces outputs of shape `(Batch_Size, 1)`.
4.  **Training Loop Demonstration**: Instead of running the full `run_training` function (which has hardcoded epochs), manually construct a minimal training loop. Initialize the optimizer and loss function, then call `library.trainer.train_one_epoch` and `library.trainer.validate` for a single epoch. This demonstrates how to use the training utilities while adhering to the time constraints. Save the resulting model weights to the path expected by the inference module.
5.  **Inference Demonstration**: Call `library.inference.generate_submission` to generate predictions using the model saved in the previous step. Verify that the submission CSV is created and contains the expected number of rows and columns.
