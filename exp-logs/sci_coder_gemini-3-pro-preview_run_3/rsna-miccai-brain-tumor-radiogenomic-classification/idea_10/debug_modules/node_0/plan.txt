This script demonstrates the end-to-end usage of the provided library modules for the Glioblastoma MGMT promoter methylation prediction task.

The strategy is as follows:
1.  **Setup & Configuration**: Initialize the environment using `library.utils`, setting random seeds for reproducibility and determining the available computation device (CPU/GPU).
2.  **Data Processing Demonstration**: Instead of loading the entire dataset (which would take time), we load the metadata, select a small subset (2 samples), and use `library.dataset.process_data` to process these MRI volumes from DICOM files into 3D tensors. We then instantiate the `BraTSDataset`.
3.  **Model Initialization**: We instantiate the `MGMTNet` model from `library.model` and verify its architecture by passing a dummy input tensor and checking the output shape.
4.  **Training Loop Demonstration**: We utilize the `train_one_epoch` and `validate` functions from `library.train` to simulate a single training step and evaluation pass using the mini-dataset created in step 2. This verifies the loss calculation and backpropagation pipeline.
5.  **Inference**: We demonstrate how to generate predictions using the trained model on the processed data.
