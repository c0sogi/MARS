The implementation strategy involves the following steps:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds and detecting the computation device (GPU).
2.  **Training**: Execute the training pipeline using the provided `run_training` function from `library.train`. This handles data loading (with caching), model initialization (`MGMTNet`), and the training loop with early stopping. We will use the full training set (418 samples) as it is small enough for rapid training, ensuring we maximize performance to meet the AUC threshold.
3.  **Validation Inference**: Load the best model checkpoint saved during training. Perform inference on the validation dataset to compute the final AUC score and collect predictions for failure analysis.
4.  **Failure Analysis**: Calculate the absolute error for each validation sample. Correlate these errors with metadata features (specifically the number of slices per MRI modality) to identify potential sources of systematic error.
5.  **Submission Generation**: Compare the final validation AUC against the required threshold (0.6978...). If the model performs sufficiently well, generate predictions for the test set and save them to `submission/submission.csv` in the specified format.
