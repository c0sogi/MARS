This script implements the end-to-end pipeline for the S3HD Network. It initializes the environment, loads the data (utilizing caching where available), trains the model using the provided `Trainer` class, and evaluates the best model on the validation set. It then performs a failure analysis by correlating prediction errors with metadata features (specifically slice counts per modality) to identify potential systematic issues. Finally, if the validation AUC exceeds the specified threshold, it generates the submission file for the test set.
