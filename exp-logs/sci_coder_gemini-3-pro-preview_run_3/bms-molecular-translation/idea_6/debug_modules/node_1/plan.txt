The issue is a `RuntimeError` during data loading caused by the variable lengths of the tokenized InChI sequences. The default PyTorch `collate_fn` attempts to stack tensors in a batch, but fails when they have different dimensions (sequence lengths). To fix this, we need to implement a custom collate function that pads the sequences to the maximum length in the batch using `pad_sequence`.

Here are the changes to `runfile.py`:

1.  Import `pad_sequence` from `torch.nn.utils.rnn`.
2.  Define `custom_collate_fn` to handle image stacking and sequence padding.
3.  Update the `DataLoader` initializations to use this custom collate function.

def custom_collate_fn(batch):
    """
    Custom collate function to handle variable-length sequences.
    Pads sequences to the maximum length in the batch.
    """
    batch_out = {}

    # 1. Stack images (always present)
    images = [item["image"] for item in batch]
    batch_out["image"] = torch.stack(images)

    # 2. Pad sequences if present (Train/Val)
    if "sequence" in batch[0]:
        sequences = [item["sequence"] for item in batch]
        # Pad with 0 (index of <PAD> in Tokenizer)
        batch_out["sequence"] = pad_sequence(sequences, batch_first=True, padding_value=0)

    # 3. Stack atom counts if present (Train/Val)
    if "atom_counts" in batch[0]:
        atom_counts = [item["atom_counts"] for item in batch]
        batch_out["atom_counts"] = torch.stack(atom_counts)

    # 4. Collect original text if present (Train/Val)
    if "original_text" in batch[0]:
        batch_out["original_text"] = [item["original_text"] for item in batch]

    # 5. Collect image_id if present (Test)
    if "image_id" in batch[0]:
        batch_out["image_id"] = [item["image_id"] for item in batch]

    return batch_out
