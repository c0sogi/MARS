Here is the implementation strategy for the `runfile.py` script:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and defining hyperparameters (batch size, learning rate, image size) suitable for a fast baseline run on the available hardware (NVIDIA A100).
2.  **Data Preparation**:
    *   Initialize the `Tokenizer` using the provided library.
    *   Create `ChemicalDataset` instances for training, validation, and testing using the pre-generated metadata.
    *   **Optimization**: Subsample the training dataset (e.g., to 50,000 samples) to ensure the training phase completes quickly within the time limit, while keeping the validation set intact as required.
    *   Create PyTorch DataLoaders with appropriate batch sizes and worker counts.
3.  **Model Initialization**: Instantiate the `FormulaConditionedModel` (ResNet encoder + MLP formula predictor + GRU decoder) and move it to the GPU. Set up the AdamW optimizer and a learning rate scheduler.
4.  **Training Loop**: Use the provided `Trainer` class to train the model. The trainer handles the forward pass, multi-task loss calculation (CrossEntropy for text + MSE for formula), backpropagation, and validation monitoring.
5.  **Validation and Failure Analysis**:
    *   Load the best checkpoint saved during training.
    *   Run inference on the **entire** validation set to compute the final Levenshtein distance metric.
    *   Perform failure analysis by correlating the error (Levenshtein distance) with input features (image width, height, aspect ratio, and target sequence length) to identify error sources.
6.  **Submission Generation**:
    *   Run inference on the test set using the trained model.
    *   Construct the submission DataFrame with `image_id` and predicted `InChI` strings.
    *   Save the result to `./submission/submission.csv`.
