Outline of Implementation Strategy:
1.  **Configuration**: Modify `Config` to enable `DEBUG` mode (training on a subset of 10,000 samples) and reduce `NUM_EPOCHS` to 2 for a fast baseline. Increase `BATCH_SIZE` to 256 to leverage the A100 GPU.
2.  **Training**: Execute the training pipeline using `library.trainer.train()`. This handles vocabulary building, data loading, and the training loop with checkpointing.
3.  **Validation & Analysis**:
    *   Reload the validation dataset and model.
    *   Perform batched inference on the validation set to generate predictions.
    *   Calculate and print the **Final Validation Metric** (Mean Levenshtein Distance).
    *   Perform failure analysis by correlating prediction errors with ground truth sequence lengths.
4.  **Submission**:
    *   Disable `DEBUG` mode to target the full test set.
    *   Invoke `library.inference.generate_submission()` to create the final `submission.csv` using the trained model.
