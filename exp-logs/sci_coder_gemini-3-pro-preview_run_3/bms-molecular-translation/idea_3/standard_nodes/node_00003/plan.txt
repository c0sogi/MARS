Implementation Strategy:
1.  **Configuration & Setup**: Override default `Config` parameters to ensure the run completes quickly (enable `DEBUG` mode with a larger sample size of 5000, reduce `EPOCHS` to 2). Set random seeds and detect the computing device (GPU).
2.  **Data Loading**: Initialize the tokenizer and data loaders for training, validation, and testing using `get_dataloaders`.
3.  **Model Initialization**: Instantiate the `DecoderOnlyTransformer` model, optimizer (AdamW), scheduler (linear warmup), and loss function (CrossEntropyLoss).
4.  **Training Loop**: Implement the training loop iterating through epochs. Inside the loop, execute `train_one_epoch` (imported from `library.train`) and a custom validation step to monitor performance. Save the best model checkpoint based on validation loss.
5.  **Validation & Failure Analysis**:
    *   Load the best saved model.
    *   Run inference on the full validation set (or the debug subset) to generate predictions.
    *   Calculate the Levenshtein distance for each sample and the mean metric.
    *   Print the `Final Validation Metric`.
    *   Extract metadata (specifically InChI length) for the validation samples.
    *   Compute and print the Pearson correlation between the Levenshtein error and the InChI length to identify error patterns.
6.  **Test Inference & Submission**: Run inference on the test dataset using the best model. Collect predictions, format them into a DataFrame matching the sample submission, and save the result to `submission.csv`.
