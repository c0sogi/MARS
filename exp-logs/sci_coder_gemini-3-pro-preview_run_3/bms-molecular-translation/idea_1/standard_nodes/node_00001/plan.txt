The following script orchestrates the training, validation, failure analysis, and submission generation for the InChI prediction task.

**Implementation Strategy:**
1.  **Setup & Configuration**: The script imports necessary components from the provided library. It overrides `Config` parameters to create a "fast baseline" suitable for the 2-hour limit. Specifically, it sets `NUM_EPOCHS` to 1 and enables `DEBUG` mode with a larger `DEBUG_SIZE` (50,000) for training to ensure timely completion while seeing enough data.
2.  **Training**: It executes the training loop using `train_model`. The model uses a MobileNetV3 encoder and LSTM decoder with teacher forcing.
3.  **Validation**: Post-training, the script manually loads the **entire** validation metadata (bypassing the debug truncation used in training) to perform a rigorous evaluation. It computes the Levenshtein distance on the full hold-out set using greedy decoding.
4.  **Failure Analysis**: It calculates the Levenshtein distance for each prediction and computes the Pearson correlation between this error and the length of the ground truth InChI string. This helps identify if sequence length is a systematic failure mode.
5.  **Submission**: Finally, it calls the `generate_submission` function with `debug=False` to generate predictions for the complete test set and save the results to the required CSV format.
