The implementation strategy involves creating a single Python script that acts as a driver for the provided library modules.

1.  **Environment Setup**: We will import the `Config` class and override specific hyperparameters (like `DEBUG_SIZE`, `BATCH_SIZE`, and `NUM_EPOCHS`) to ensure the code runs rapidly on a tiny subset of the data.
2.  **Component Verification**:
    *   **Tokenizer**: We will instantiate the `InchiTokenizer`, convert a sample InChI string to a sequence of indices, and decode it back to text to verify the round-trip integrity.
    *   **Data Loading**: We will call `get_dataloaders` in debug mode and inspect the shapes of the returned image and caption tensors to ensure they match the configuration (Batch Size, Image Size, Sequence Length).
    *   **Model**: We will instantiate the `ShowAndTell` model and perform a forward pass with a dummy batch to confirm the output dimensions of the logits.
3.  **Training Simulation**: We will execute the `train_model` function for a single epoch. This function integrates the data loaders, model, loss function, optimizer, and validation loop. We will verify that it completes without error and produces a model object.
4.  **Inference Simulation**: We will call `generate_submission` using the trained model to predict InChI strings for the test set (in debug mode). We will verify that a submission CSV file is generated in the correct output directory.
