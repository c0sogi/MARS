The solution involves creating a Python script that generates metadata for training, validation, and testing. The script will load the provided labels and submission files, parse the `contact_id` to extract grouping information (`game_play`), and generate file paths for the associated video files. It will then perform a Group Shuffle Split on the training data to create a validation set that respects the integrity of individual plays (i.e., all time steps for a single play remain in the same split). Finally, the script will save these metadata files and perform rigorous validation checks on the file paths and data splits.
