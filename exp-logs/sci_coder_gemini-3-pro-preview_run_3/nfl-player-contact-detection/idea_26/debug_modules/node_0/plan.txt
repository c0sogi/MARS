The following script demonstrates the end-to-end execution of the provided machine learning pipeline for the NFL Contact Detection task. It optimizes for speed by reducing the dataset size and model complexity (number of estimators), ensuring the demonstration runs quickly while validating the core logic.

The script performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory, enables debug sampling (processing only 5,000 training rows), and reduces XGBoost estimators to 10 for rapid training.
2.  **Pipeline Instantiation**: Initializes the `Pipeline` class which orchestrates data loading, feature engineering, and modeling.
3.  **Training Execution**: Runs the training pipeline (`run_training`). This involves:
    *   Loading and merging tracking/metadata.
    *   Computing features for Stream A (Player-Player) and Stream B (Player-Ground).
    *   Training the Dual-Stream GBDT models.
    *   Optimizing thresholds based on validation MCC.
4.  **Model Validation**: Asserts that the models were successfully instantiated and trained.
5.  **Inference Execution**: Runs the inference pipeline (`run_inference`) on the test set to generate predictions.
6.  **Submission Validation**: Verifies that the output `submission.csv` exists, follows the correct schema, and contains valid binary predictions.
