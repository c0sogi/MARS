The implementation strategy involves the following steps:

1.  **Initialization**: Set random seeds for reproducibility using the provided `seed_everything` utility.
2.  **Data Loading**: Use the `DataManager` class to load and preprocess training and validation datasets for both Stream A (Player-Player) and Stream B (Player-Ground). This leverages the pre-computed metadata and tracking data processing logic.
3.  **Model Training**: Instantiate the `DualStreamPredictor`. Train XGBoost models for both streams independently. The trainer handles feature usage, early stopping, and internal threshold optimization for individual streams.
4.  **Global Optimization**: Use the `ThresholdOptimizer` to refine the decision thresholds on the validation set and compute the global Matthews Correlation Coefficient (MCC).
5.  **Validation & Failure Analysis**:
    -   Print the required `Final Validation Metric`.
    -   Perform failure analysis by calculating the correlation between prediction errors and input features on the validation set to identify weak points.
6.  **Inference & Submission**:
    -   Check if the validation MCC exceeds the required threshold (0.6533).
    -   If successful, load test data for both streams.
    -   Generate predictions using the trained models.
    -   Combine predictions from both streams into the final submission format and save it to `./submission/submission.csv`.
