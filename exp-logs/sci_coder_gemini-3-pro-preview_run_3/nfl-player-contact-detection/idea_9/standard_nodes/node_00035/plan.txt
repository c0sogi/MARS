The implementation strategy follows the "Asymmetric Modality-Selective Dual-Stream GBDT" design. First, the script initializes the environment and seeds for reproducibility. It then executes the training pipeline using `run_training`, overriding the number of estimators to 800 to ensure the process completes quickly while leveraging the GPU-accelerated XGBoost backend.

For validation, the script loads the pre-computed validation features and generates predictions for both Stream A (Player-Player) and Stream B (Player-Ground) using the stream-specific models and their optimized thresholds. These predictions are aggregated to compute the global Matthews Correlation Coefficient (MCC) on the entire hold-out set. Simultaneously, a failure analysis is performed by calculating the correlation between the model's error residuals and the input features, identifying the variables most associated with incorrect predictions.

Finally, the script checks if the validation MCC exceeds the strict threshold of 0.6565613438092561. If the condition is met, it triggers the `run_inference` pipeline to generate the final `submission.csv` for the test set; otherwise, it skips submission generation.
