The error `KeyError: 'Column not found: accel_p1'` arises because the configuration expects feature names `accel_p1` and `accel_p2`, whereas the data pipeline produces `acceleration_p1` and `acceleration_p2`. This discrepancy occurs because the raw tracking data column `acceleration` is automatically renamed by the `.add_suffix()` method used in the pipeline (Cite debug_lesson_25). To resolve this, I will update the `STREAM_A_FEATURES` list in `library/config.py` to use the correct column names `acceleration_p1` and `acceleration_p2`.
