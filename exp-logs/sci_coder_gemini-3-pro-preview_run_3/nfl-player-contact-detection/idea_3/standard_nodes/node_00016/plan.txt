Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility and initialize the logger using the provided utility functions.
2.  **Data Loading**: Use the `DatasetManager` to load training, validation, and test datasets. The manager handles caching, so subsequent runs will be faster.
3.  **Model Training**: Initialize the `XGBWrapper` model (which uses GPU-accelerated XGBoost). Train the model on the training set with the validation set used for early stopping to prevent overfitting and reduce runtime.
4.  **Validation & Optimization**:
    *   Generate probability predictions for the validation set.
    *   Use the `optimize_threshold` function to find the decision boundary that maximizes the Matthews Correlation Coefficient (MCC).
    *   Report the **Final Validation Metric** with full precision.
5.  **Failure Analysis**:
    *   Compute the absolute prediction error on the validation set.
    *   Calculate the Pearson correlation between the error and each input feature to identify which features correlate most with model failure.
    *   Print the top features associated with high error.
6.  **Submission**:
    *   Check if the validation MCC exceeds the required threshold (0.6190873081343531).
    *   If successful, predict on the test set, apply the optimized threshold, and generate the `submission.csv` file in the required format.
