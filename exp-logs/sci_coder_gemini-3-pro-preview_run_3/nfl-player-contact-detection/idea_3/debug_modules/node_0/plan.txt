Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment by setting a fixed random seed and configuring a logger. Define a dedicated working directory (`./working/demo_run`) to isolate generated files and cache.
2.  **Data Subsetting**: To ensure the script runs quickly, create smaller subsets of the training, validation, and test metadata files. We will filter by `game_play` to preserve the temporal structure required for lag feature generation.
3.  **Config Overrides**: Dynamically update the `Config` class attributes to point to the newly created data subsets and the dedicated working directory. drastically reduce the XGBoost `n_estimators` to ensure rapid training for demonstration purposes.
4.  **Data Pipeline Execution**: Instantiate the `DatasetManager` to load and process the data. We force `load_cached_data=False` to ensure the new subsets are processed from scratch.
5.  **Model Training**: Initialize the `XGBWrapper`, train it on the subsetted data, and verify that the model artifact is saved.
6.  **Evaluation**: Perform inference on the validation set, optimize the decision threshold based on the Matthews Correlation Coefficient (MCC), and validate the metric is within expected bounds.
7.  **Inference & Submission**: Generate predictions for the test set using the optimized threshold, format the results into a submission DataFrame, save it to the specified output path, and verify the file structure.
