This directly addresses the lesson's finding that "width of the temporal receptive field is often more critical than the density."
2.  **Remove Visual Smoothing:** I will remove the rolling mean and max aggregations for visual features (IoU, Distance). The lesson indicated that smoothing these "sharp" signals blurs the precise moment of impact, leading to performance degradation. I will rely on the instantaneous values (and their implicit inclusion in the model via the tracking context).

    def _add_lags(
        self, df: pd.DataFrame, cols: List[str], group_cols: List[str], window: int
    ) -> pd.DataFrame:
        """
        Adds flattened lag features to the dataframe using vectorized shifts.
        """
        df_res = df.copy()
        # Ensure sort order
        df_res = df_res.sort_values(by=group_cols + ["step"])

        grouped = df_res.groupby(group_cols)

        # Generate lags from -window to +window
        shifts = range(-window, window + 1)

        for col in cols:
            for s in shifts:
                col_name = f"{col}_lag_{s}"
                # shift(s): positive s shifts data down (t takes value of t-s).
                # We want lag_s to represent t+s.
                # If s=-1 (past), we want value at t-1. shift(1) gives value of t-1 at t.
                # If s=1 (future), we want value at t+1. shift(-1) gives value of t+1 at t.
                # So we use shift(-s).
                df_res[col_name] = grouped[col].shift(-s)

        return df_res
