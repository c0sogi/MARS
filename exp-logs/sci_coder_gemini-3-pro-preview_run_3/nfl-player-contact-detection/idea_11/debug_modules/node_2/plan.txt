XGBoost enforces consistency between training and validation data formats, raising a `ValueError` when it detects feature names in the validation set but not in the training set.

If it is, I will use `.iloc` to slice it using the selected indices, thereby preserving the DataFrame structure and feature names. This ensures that both training and validation datasets passed to XGBoost retain their feature names, satisfying the consistency requirement.
