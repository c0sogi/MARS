The `XGBoostError` occurred because the training dataset for Stream B contained only negative samples (homogenous data) or was empty due to the undersampling logic. When `n_pos` is 0, the current undersampling implementation sets `n_neg_keep` to 0, resulting in an empty dataset. Furthermore, training on a dataset with only zeros causes XGBoost to calculate a `base_score` of 0, which is undefined for the logistic loss function.

To fix this, I will modify `library/model_wrapper.py` to:
1.  Update `_undersample` to retain negative samples even when no positive samples are present, ensuring the model receives data.
2.  Explicitly set `base_score` to 0.5 in `fit_stream` to prevent the crash on homogenous data, as recommended in **debug_lesson_20** (Cite debug_lesson_20).
