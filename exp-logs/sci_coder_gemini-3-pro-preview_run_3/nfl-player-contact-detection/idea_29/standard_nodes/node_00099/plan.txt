    -   **Rationale**: The previous solution lacked explicit relative orientation features, which are critical for distinguishing between incidental proximity and actual engagement (Cite Lesson 00074).
    -   **Change**: I will add `orientation_cos_sim` and `direction_cos_sim` to the Stream A feature set. These capture the alignment between players (e.g., facing each other vs. running parallel).

2.  **Stream B (Impact) Optimization**:
    -   **Rationale**: The failure analysis of the previous run showed that prediction errors were highly correlated with absolute `x_position` and `orientation`. This indicates the model is overfitting to spatial biases (e.g., specific locations on the field) rather than learning the invariant dynamics of a fall. Lesson 00075 demonstrates that stripping away absolute coordinates improves generalization for intrinsic events like ground impacts.
    -   **Change**: I will remove `x_position`, `y_position`, `direction`, and `orientation` from the Stream B feature set, forcing the model to rely on translation-invariant kinematic features (Speed, Acceleration, Surge, Sway, Jerk).
