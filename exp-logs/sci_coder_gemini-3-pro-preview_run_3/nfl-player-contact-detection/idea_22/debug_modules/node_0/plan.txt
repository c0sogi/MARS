This script demonstrates the end-to-end usage of the provided machine learning pipeline for predicting contact events in football footage. It covers data loading, feature engineering, model training, and inference using the Dual-Stream architecture (Stream A for player interactions, Stream B for ground impacts).

To ensure rapid execution within the demonstration constraints, the script:
1.  Enables `DEBUG` mode to process a small subset of the data (approx. 5-8 plays).
2.  Overrides XGBoost hyperparameters to use a minimal number of estimators (2 trees), ensuring the training phase completes almost instantly while still exercising the code paths.
3.  Validates the outputs of each stage (Data Loader, Feature Engine, Trainer, Predictor) using assertions.
