Implementation Strategy
The optimization strategy addresses the performance regression in the previous solution (Idea 20) by correcting data sampling flaws and restoring high-value kinematic features identified in prior lessons.

1.  **Correct Data Sampling (Cite solution_lesson_node_00060):** The previous solution uniformly subsampled the training set to 200k rows before class balancing, discarding ~95% of the positive samples. I will remove this `slice_data` step in `runfile.py` and pass the full dataset to the trainer, relying on the existing `undersample_training_data` function to perform targeted majority undersampling (keeping 100% of positives).
2.  **Restore Alignment Features in Stream A (Cite solution_lesson_node_00027, solution_lesson_node_00051):** I will re-introduce `cos_orient_dir` (Pose-Motion Alignment) and `cos_sim_orient` (Orientation Similarity) to the Player-Player stream. These explicit relational scalars are more robust for interaction detection than raw coordinates alone.
3.  **Enrich Stream B with Sensor Kinematics (Cite solution_lesson_node_00027, solution_lesson_node_00034):** I will add `jerk` (derivative of acceleration) and `angular_velocity` (derivative of orientation) to the Player-Ground stream. These features are critical for detecting the physical instability associated with ground impacts.
4.  **Regularize Stream B (Cite solution_lesson_node_00062):** I will reduce the `max_depth` for Stream B from 12 to 8 to prevent the overfitting observed when using deep trees with noisy kinematic derivatives.
