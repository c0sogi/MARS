The previous solution relied on vector projections (`surge`/`sway`), which failed to capture the scalar intensity of convergence as effectively as the explicit closure rate.

3.  **Regularizing Stream B (Cite solution_lesson_node_00062):** The Player-Ground model suffered from overfitting due to excessive tree depth (`max_depth=12`) combined with noisy derivative features. I will reduce `max_depth` to 6 in `config.py` to enforce better generalization for this lower-signal stream.

def subsample_dataset(X, y, ids, max_samples, seed):
    """
    Subsamples the dataset to max_samples to ensure fast training.
    """
    if len(X) <= max_samples:
        return X, y, ids

    print(f"Subsampling dataset from {len(X)} to {max_samples} samples...")
    np.random.seed(seed)
    indices = np.random.choice(len(X), max_samples, replace=False)

    # X is a DataFrame, y and ids are numpy arrays
    X_sub = X.iloc[indices].reset_index(drop=True)
    y_sub = y[indices]
    ids_sub = ids[indices]

    return X_sub, y_sub, ids_sub
