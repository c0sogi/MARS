This script demonstrates the end-to-end usage of the provided NFL Contact Detection library. It performs the following steps:

1.  **Configuration Overrides**: Modifies the global `Config` to use lightweight XGBoost hyperparameters (fewer trees, shallower depth) for rapid execution.
2.  **Data Subsampling**: Implements a monkey-patch for `DataLoader.load_metadata` to load only a small subset of games (3 plays). This ensures the feature engineering pipeline—which relies on temporal lags—remains valid while significantly reducing runtime.
3.  **Feature Engineering**: Instantiates `FeatureEngineer` to generate features for Stream A (Player-Player) and Stream B (Player-Ground) for training, validation, and test sets. It verifies the structure and content of the generated feature matrices.
4.  **Model Training**: Uses `DualStreamGBDT` to train the two XGBoost models on the processed features. It validates that models are successfully trained and thresholds are optimized.
5.  **Inference & Submission**: Generates predictions on the test set and creates a submission file, verifying the final output format and consistency with the sample submission.
