Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Dual-Polarity Spatial-Channel Attention CNN (DPSCA-CNN)**.

This solution represents a structural evolution of the **Isomorphic Dual-Polarity Hierarchical CNN** (Idea 47). It identifies that while the "Dual-Polarity" concept (capturing both Peaks and Shadows) was successfully applied to the *readout* layer (Cite solution_lesson_node_00134), the *backbone* itself still relies on standard convolutions that treat all spatial pixels equally, leaving it vulnerable to speckle noise.

Previous attempts to regularize spatial features using **DropBlock** failed because the masking was too coarse (Cite solution_lesson_node_00126). This solution replaces "hard" masking with **"Soft" Dual-Polarity Spatial Attention**. By extending the Dual-Polarity philosophy to the attention mechanism, we explicitly highlight pixels that exhibit strong **Signal-to-Shadow Contrast** (both bright peaks and deep voids) while suppressing low-contrast speckle noise *before* downsampling, integrated into the robust **Plain CNN** backbone.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **DPSCA Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout to preserve negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).

*   **Structural Innovation (Dual-Polarity Spatial-Channel Attention):**
    We replace the standard SE module with a **DPSCA Module**, applied sequentially (Channel $\to$ Spatial).
    1.  **Channel Attention (Hybrid):** We use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, robust to local noise spikes (Cite solution_lesson_node_00104).
    2.  **Spatial Attention (Dual-Polarity):**
        *   **Objective:** Highlight pixels that are physically significant (Icebergs or Shadows) and suppress background clutter.
        *   **Mechanism:** Instead of the standard CBAM approach (Max+Avg pooling across channels), we apply **Channel-wise Max Pooling** (extracting the strongest positive activation per pixel) and **Channel-wise Min Pooling** (extracting the strongest negative activation per pixel).
        *   **Fusion:** These two spatial maps are concatenated and passed through a **7x7 Convolution** $\to$ **Sigmoid** to generate a spatial attention mask.
        *   **Rationale:** This extends the "Dual-Polarity" insight (Cite solution_lesson_node_00134) to the spatial domain. It forces the network to focus on regions with high dynamic range (Signal-to-Shadow contrast) and ignore "flat" noisy regions, effectively acting as a learned, physics-aware denoiser.

*   **Readout (Isomorphic Dual-Polarity):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Projection:** We compress channels (128 $\to$ 64) via 1x1 Conv.
    *   **Pooling:** We apply both **Global Max Pooling** and **Global Min Pooling** to each stage.
    *   **Result:** A 256-dimensional vector that captures multi-scale peaks and shadows without parameter explosion (Cite solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing fusion (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
