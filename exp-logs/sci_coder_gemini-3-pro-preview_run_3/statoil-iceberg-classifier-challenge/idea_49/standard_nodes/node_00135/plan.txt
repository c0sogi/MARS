2.  **Training**: Execute a 5-fold cross-validation loop using `run_fold`. This trains 5 independent models and saves their checkpoints.
3.  **Validation**: Manually load the specific hold-out validation set defined in `metadata/val.csv`. This ensures we evaluate on the exact set required by the prompt, rather than the internal CV splits.
4.  **Ensemble Inference**: Run inference on this hold-out set using an ensemble of the 5 trained models (averaging predictions).
5.  **Metric Calculation**: Compute the Log Loss on the hold-out set and print it in the exact required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute correlations between this error and input features (Incidence Angle, Band Means/Stds) to identify sources of systematic error.
7.  **Submission**: Check if the validation metric is below the strict threshold (0.17174082291273365). If successful, call `predict_test` to generate the final `submission.csv` for the test set.
