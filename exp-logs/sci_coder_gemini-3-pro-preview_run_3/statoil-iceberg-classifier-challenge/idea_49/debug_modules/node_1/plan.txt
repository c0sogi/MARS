The error arises because the `runfile.py` script performs a cleanup operation (`shutil.rmtree`) in the `if __name__ == "__main__":` block, which deletes the directory structure created earlier by `Config.setup()`. Consequently, when the training loop attempts to save a checkpoint, the `checkpoints` directory no longer exists, causing a `RuntimeError`. The fix is to call `Config.setup()` again immediately after the cleanup to ensure the required directory structure is recreated before `run_demo()` executes.
