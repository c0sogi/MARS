Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the following solution. This approach introduces a structural innovation to better utilize the critical "incidence angle" metadata while strictly adhering to the architectural constraints (width, depth, pooling) proven to work for this specific signal data.

# Solution: Angle-Calibrated Residual Network (AC-ResNet)

### Model
The architecture is a **Shallow Residual Network** that integrates **Conditional Batch Normalization (CBN)** to dynamically calibrate feature maps based on the radar incidence angle.

*   **Backbone:** The network consists of an initial convolutional stem followed by three stages of Residual Blocks.
    *   **Width Constraint:** The channel dimensions are strictly constrained to **64 $\to$ 64 $\to$ 128**. We explicitly avoid expanding to 256+ channels to prevent the overfitting and information bottlenecks observed with wide networks on this small dataset (Cite solution_lesson_node_00026).
*   **Structural Innovation (Angle Calibration):** Instead of standard Batch Normalization, the residual blocks employ **Conditional Batch Normalization (CBN)**.
    *   A lightweight Multi-Layer Perceptron (MLP) takes the scalar `inc_angle` as input and predicts the affine parameters (scale $\gamma$ and shift $\beta$) for the normalization layers.
    *   Mathematically, the normalized feature map $x$ is transformed as $y = \gamma(\text{angle}) \cdot \hat{x} + \beta(\text{angle})$. This allows the network to learn "angle-invariant" feature representations by dynamically adjusting the intensity distribution of the radar signals, which physically vary with incidence angle (Cite solution_lesson_node_00012).
*   **Pooling Strategy:** The final feature maps are processed using **Global Max Pooling**. This is retained to preserve the sparse, high-intensity peak signals characteristic of icebergs, avoiding the signal dilution caused by Average Pooling (Cite solution_lesson_node_00007).
*   **Classification Head:** The pooled 128-dimensional vector is passed through a Dense layer (512 units) $\rightarrow$ ReLU $\rightarrow$ **Dropout** $\rightarrow$ Output. Dropout is applied *after* the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).

### Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. No upscaling is performed, as training on native resolution has proven superior to adapting pre-trained ImageNet models (Cite solution_lesson_node_00009).
*   **Augmentation:** Data augmentation is applied using the optimized **`torchvision.transforms`** library (RandomHorizontalFlip, RandomVerticalFlip) (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** The Adam optimizer is used with a **constant learning rate** (e.g., 1e-3) (Cite solution_lesson_node_00019).
*   **Regularization:** Crucially, **L2 Regularization (Weight Decay)** is enforced, and the loss function is **`BCEWithLogitsLoss`** (combining Sigmoid and BCELoss in a numerically stable block). This addresses the instability and overfitting observed when training without weight decay on this noisy dataset (Cite solution_lesson_node_00036).

### Evaluation
*   **Inference:** Predictions are generated using **Test-Time Augmentation (TTA)**. For each test image, the model predicts probabilities for the original and flipped versions, averaging the results.
*   **Ensembling:** The final submission probability for each ID is the average of the TTA predictions from all **5 models** trained in the Cross-Validation loop.
