The implementation strategy follows the requirements to establish a fast baseline, evaluate it strictly, and generate a submission if performance criteria are met.

1.  **Configuration Override**: The script begins by modifying the `Config` class to reduce `NUM_EPOCHS` to 20. This ensures the training completes quickly (within the 2-hour limit) while still allowing the Angle-Calibrated ResNet to converge on this small dataset. `MAX_SAMPLES` is kept as `None` to utilize the full dataset, which is small enough (1604 samples) to process rapidly.
2.  **Training Orchestration**: It iterates through the 5 folds defined in the configuration, calling the provided `run_fold` function for each. This trains the ensemble of models using the pre-defined architecture and training loop.
3.  **Validation Evaluation**: To strictly adhere to the requirement of using the hold-out validation set from `./metadata`, the script loads `val.csv`. It then retrieves the corresponding processed image data from the cache by matching IDs. A dedicated `DataLoader` is created for this subset. The script performs inference using the ensemble of all 5 trained models (averaging their predictions) with Test-Time Augmentation (TTA). The final Log Loss is computed and printed in the required format.
4.  **Failure Analysis**: The script calculates the absolute error for each validation sample. It then computes correlations between this error magnitude and key features (incidence angle, Band 1 mean, Band 2 mean) to identify potential weaknesses, printing the results.
5.  **Submission**: Finally, the calculated validation metric is compared against the strict threshold (0.18145903282502943). If the model performs sufficiently well, `create_submission` is called to generate the final `submission.csv` for the test set.
