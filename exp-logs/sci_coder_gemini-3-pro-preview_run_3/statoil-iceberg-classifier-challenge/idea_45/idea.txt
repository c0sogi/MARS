Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Bottlenecked Dual-Polarity Hierarchical CNN (BDPH-CNN)**.

This solution represents a structural synthesis of the most effective components identified to date, explicitly resolving the conflict between the physical need to capture "Shadow" information (Lesson 102) and the strict capacity constraints of the classifier head (Lesson 124). It combines the robust **Plain CNN** backbone (Lesson 46) with **Hybrid Squeeze-and-Excitation** (Lesson 106/104) and a novel **Bottlenecked Dual-Polarity Readout** that captures multi-scale peaks and shadows without parameter explosion.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, parameter-efficient feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).
    *   **Attention:** Within the SE Module, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes (Cite solution_lesson_node_00104).

*   **Structural Innovation (Bottlenecked Dual-Polarity Readout):**
    *   **Objective:** Capture both **Peaks** (Icebergs) and **Shadows** (Signal Voids) from multiple scales (Stage 3 and 4) without exploding the dense layer size (Cite solution_lesson_node_00124).
    *   **Mechanism:**
        1.  **Projection:** At the output of **Stage 3** (9x9) and **Stage 4** (4x4), we apply a **1x1 Convolution** to compress the channel dimension from 128 to **32**. This learnable bottleneck forces the network to select the most discriminative features for pooling.
        2.  **Dual-Polarity Pooling:** On these compressed maps, we apply both **Global Max Pooling** (capturing positive peaks) and **Global Min Pooling** (implemented as `GlobalMax(-x)`, capturing negative shadows preserved by LeakyReLU).
        3.  **Aggregation:** The resulting vector is a concatenation of 4 components: $Stage3_{max} (32) + Stage3_{min} (32) + Stage4_{max} (32) + Stage4_{min} (32)$.
    *   **Result:** The total image feature vector size is **128**. This is identical to the baseline single-scale Max Pooling model, but it semantically encodes multi-scale contrast (Signal-to-Shadow) information (Cite solution_lesson_node_00102, solution_lesson_node_00035).

*   **Feature Fusion (Raw Scale):** The 128-dim feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).

*   **Classification Head:** A single hidden layer: `Linear(129 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Linear(256 -> 1)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In). We explicitly avoid manual fixed scales or `fan_out` modes (Cite solution_lesson_node_00064, solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00027).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from the adaptive gradient updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
