Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Hierarchically Calibrated Isomorphic CNN (HCI-CNN)**.

This solution represents a structural synthesis of the most effective components identified to date (Plain CNN backbone, Hybrid SE, Isomorphic Dual-Polarity Readout) while introducing a novel **Hierarchical Calibration** mechanism. This explicitly addresses the "Interaction" bottleneck (Cite solution_lesson_node_00155) by modeling the physics of radar acquisition: the incidence angle affects texture features (Stage 3, governed by scattering physics) differently than it affects geometric features (Stage 4, governed by shadow length geometry). By applying independent **FiLM (Feature-wise Linear Modulation)** calibrations to each hierarchical level *before* fusion, we enforce a physics-consistent prior without increasing the classifier's capacity or destabilizing the backbone.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, geometry-aware feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Standard SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** We use **Standard SE** with **Global Average Pooling** (Cite solution_lesson_node_00104) and **ReLU** in the bottleneck (Cite solution_lesson_node_00158) with reduction ratio $r=16$ (Cite solution_lesson_node_00146).

*   **Readout (Corrected Decoupled Isomorphic):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Decoupled Projections:** We use **separate** 1x1 Convolutional layers for Stage 3 (`Proj3`) and Stage 4 (`Proj4`) to learn depth-specific transformations (Cite solution_lesson_node_00144).
    *   **Isomorphic Dual-Polarity:**
        *   **Stage 3:** `Proj3(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling** $\to$ Vector $V_3$ (128 dims).
        *   **Stage 4:** `Proj4(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling** $\to$ Vector $V_4$ (128 dims).
    *   **Constraint:** Max and Min pooling share the *same* projection within a stage (Cite solution_lesson_node_00142).

*   **Structural Innovation (Hierarchical Calibration):**
    *   Instead of concatenating the incidence angle globally, we use it to independently modulate the vectors $V_3$ and $V_4$.
    *   **Angle Encoder:** `Linear(1 -> 32) -> LeakyReLU`.
    *   **Calibrator 3:** `Linear(32 -> 256)` $\to$ Split into Scale $\gamma_3$ and Shift $\beta_3$ (each 128 dims).
    *   **Calibrator 4:** `Linear(32 -> 256)` $\to$ Split into Scale $\gamma_4$ and Shift $\beta_4$ (each 128 dims).
    *   **Modulation:**
        *   $V_3' = V_3 \odot \text{Sigmoid}(\gamma_3) + \beta_3$
        *   $V_4' = V_4 \odot \text{Sigmoid}(\gamma_4) + \beta_4$
    *   **Rationale:** This allows the network to learn that incidence angle affects mid-level texture (clutter gain) differently than high-level geometry (shadow length), providing a non-linear interaction (Cite solution_lesson_node_00155) while keeping the final feature vector size constant.

*   **Classification Head:**
    *   **Fusion:** $V_{final} = \text{Concat}(V_3', V_4')$ (Total 256 dims).
    *   **Prediction:** `Dropout(0.5)` $\to$ `Linear(256 -> 1)` $\to$ `Output`.
    *   This strictly respects the capacity constraints of the baseline (Cite solution_lesson_node_00124).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:** Imputation of missing incidence angles is performed using the median calculated **only on the training fold indices** and applied to the validation fold (Cite solution_lesson_node_00147).

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the raw scalar input (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
