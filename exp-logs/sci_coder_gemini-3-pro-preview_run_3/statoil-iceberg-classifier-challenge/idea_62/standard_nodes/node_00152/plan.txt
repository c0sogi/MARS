Implementation strategy:
1.  **Environment Setup**: Import the provided library modules (`config`, `utils`, `data_loader`, `model`, `train`, `predict`). Override the `Config` class attributes to point to the correct `./working` directory and reduce `NUM_EPOCHS` to 25 to satisfy the "fast baseline" requirement while ensuring convergence on the small dataset.
2.  **Training**: Execute the full 5-fold cross-validation pipeline using `library.train.run_cross_validation()`. This will train models and save checkpoints to `./working/checkpoints`.
3.  **Validation & Metric**: Perform an Out-Of-Fold (OOF) validation loop. Iterate through each fold, load the corresponding best checkpoint, and generate predictions for the validation set. Aggregate these predictions to calculate the global **Log Loss** metric.
4.  **Failure Analysis**: During the OOF loop, extract input features (incidence angle, image mean, image standard deviation). Calculate the absolute error between predictions and targets. Compute and print the Pearson correlation between the error magnitude and these features to identify systematic failure modes.
5.  **Submission**: Compare the calculated final validation metric against the threshold (`0.17174082291273365`). If the metric is lower (better), call `library.predict.generate_submission()` to create the submission file in `./working/submission/submission.csv`.
