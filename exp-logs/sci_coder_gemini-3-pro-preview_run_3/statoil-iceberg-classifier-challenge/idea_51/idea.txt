Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Dual-Polarity Downsampling CNN (DPD-CNN)**.

This solution represents a fundamental structural evolution of the **Isomorphic Dual-Polarity Hierarchical CNN** (Idea 47). It identifies and resolves a critical bottleneck in the previous best architecture: while the **Readout** was modified to capture "Shadow" (signal void) information (Cite solution_lesson_node_00134), the **Backbone** still relied on standard **Max-Pooling** for downsampling. Standard Max-Pooling inherently biases signal propagation towards positive values, destroying the deep shadow features (negative values preserved by LeakyReLU) generated in early layers before they can reach the final readout.

This solution introduces **Dual-Polarity Downsampling (DPD)** modules within the backbone to explicitly propagate both **Peaks** (Icebergs) and **Shadows** (Signal Voids) through the depth of the network, ensuring the final readout receives high-fidelity features from both ends of the dynamic range.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for preserving the full dynamic range of SAR signals.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ **DPD Module** (Stages 1-3) or **Readout** (Stage 4).
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104).

*   **Structural Innovation (Dual-Polarity Downsampling):**
    *   We replace standard `MaxPool2d` in Stages 1, 2, and 3 with **DPD Modules**.
    *   **Mechanism:**
        1.  **Parallel Pooling:** The input feature map is processed by both **MaxPool2d** (extracting peaks) and **MinPool2d** (extracting shadows, implemented as `Max(-x)`).
        2.  **Concatenation:** The outputs are concatenated along the channel dimension.
        3.  **Fusion:** A **1x1 Convolution** (followed by BN and LeakyReLU) projects the concatenated channels back to the target width (e.g., $128+128 \to 128$).
    *   **Rationale:** This ensures that shadow features are not discarded during downsampling, allowing the network to build deep, hierarchical representations of signal voids alongside signal peaks (Cite solution_lesson_node_00134).

*   **Readout (Isomorphic Dual-Polarity):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Projection:** Compress channels (128 $\to$ 64) via 1x1 Conv.
    *   **Pooling:** Apply both **Global Max Pooling** and **Global Min Pooling**.
    *   **Result:** A 256-dimensional vector ($64_{max}+64_{min}$ from two stages) that strictly respects the capacity constraints of the baseline (Cite solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017, solution_lesson_node_00040).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing fusion (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
