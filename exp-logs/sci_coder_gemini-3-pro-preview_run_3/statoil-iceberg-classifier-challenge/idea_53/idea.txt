Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Decoupled Isomorphic Dual-Polarity CNN (DIDP-CNN)**.

This solution represents a precision structural evolution of the **Isomorphic Dual-Polarity Hierarchical CNN** (Idea 47). It addresses a subtle but critical representational bottleneck: while Idea 47 successfully captured both "Peaks" and "Shadows" within a strict parameter budget, it forced both feature types to share the *same* low-dimensional projection (subspace). Since bright backscatter (icebergs) and deep signal voids (shadows) are physically distinct phenomena, forcing them to share a compressed 64-channel bottleneck likely causes feature interference.

This solution introduces **Decoupled Feature Projections**: it creates independent, learnable subspaces for Positive (Peak) and Negative (Shadow) features at each hierarchical level, strictly maintaining the successful 256-dimensional readout size of the baseline. This allows the model to specialize filters for "bright spots" and "dark spots" independently, integrated into the robust **Plain CNN** backbone.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, interference-free feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104).

*   **Structural Innovation (Decoupled Isomorphic Readout):**
    *   **Objective:** Capture Peaks and Shadows from Stages 3 and 4 without forcing them to share a bottleneck, while keeping the total feature vector size at **256**.
    *   **Mechanism:**
        *   **Stage 3 Branching:**
            1.  **Peak Projection:** `Conv1x1(128 -> 64)` $\to$ **Global Max Pooling**.
            2.  **Shadow Projection:** `Conv1x1(128 -> 64)` $\to$ **Global Min Pooling** (implemented as `Max(-x)`).
            *   *Note:* Unlike Idea 47, these are *separate* convolution layers, allowing the network to learn distinct filters for peaks vs. shadows.
        *   **Stage 4 Branching:**
            1.  **Peak Projection:** `Conv1x1(128 -> 64)` $\to$ **Global Max Pooling**.
            2.  **Shadow Projection:** `Conv1x1(128 -> 64)` $\to$ **Global Min Pooling**.
    *   **Aggregation:** The four vectors are concatenated: $64_{peak3} + 64_{shadow3} + 64_{peak4} + 64_{shadow4} = 256$.
    *   **Rationale:** This maintains the exact capacity of the baseline (256 dense inputs) (Cite solution_lesson_node_00124) but provides **orthogonal subspaces** for the two physical signal types, preventing feature interference (Cite solution_lesson_node_00102).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing fusion (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
