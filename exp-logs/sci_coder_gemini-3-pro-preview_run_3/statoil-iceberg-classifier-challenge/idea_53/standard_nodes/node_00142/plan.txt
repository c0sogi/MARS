The following is the implementation strategy for the `runfile.py` script:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and setting up the directory structure using the provided `Config` class. To ensure the script runs as a "fast baseline" within the time limit, we will dynamically override `Config.NUM_EPOCHS` to a lower value (25 epochs) and `Config.PATIENCE` (8 epochs).

2.  **Data Loading**: Utilize the `process_data` function from `library.data` to load and preprocess the dataset (loading from cache if available). This provides normalized image tensors and imputed incidence angles.

3.  **Training & Validation (Cross-Validation)**:
    *   Iterate through 5 folds using `StratifiedKFold` (replicated locally to ensure index alignment).
    *   For each fold, instantiate the `DIDPCNN` model, `AdamW` optimizer, and `BCEWithLogitsLoss`.
    *   Train the model using the `Trainer` class, saving the checkpoint with the best validation loss.
    *   After training, load the best checkpoint and perform inference on the validation set to generate Out-Of-Fold (OOF) predictions.

4.  **Metric Calculation**: Compute the Log Loss on the aggregated OOF predictions against the ground truth labels. This value is printed exactly as required: `Final Validation Metric: <value>`.

5.  **Failure Analysis**: Calculate the absolute error for each training sample. Compute and print the Pearson correlation between this error magnitude and key features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify sources of model failure.

6.  **Submission Generation**: Compare the final validation metric against the threshold (0.17174082291273365). If the model performs well enough:
    *   Load the test set using `get_test_loader`.
    *   Iterate through the saved checkpoints for all 5 folds.
    *   Generate predictions for the test set, averaging the probabilities across all folds.
    *   Save the final dataframe to `./submission/submission.csv`.
