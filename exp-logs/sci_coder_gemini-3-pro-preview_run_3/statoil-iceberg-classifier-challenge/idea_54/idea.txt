Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Statistical-Attentive Isomorphic CNN (SAI-CNN)**.

This solution represents a structural evolution of the **Isomorphic Dual-Polarity Hierarchical CNN** (Idea 47). It identifies a limitation in the current attention mechanism: while **Global Average Pooling** (used in Hybrid SE) is robust to noise (Cite solution_lesson_node_00104), it only captures the *mean intensity* of a feature map. In SAR imagery, the **texture** (speckle statistics) is a fundamental discriminator between clutter (water) and targets (icebergs/ships). Two channels could have the same mean but vastly different variances (e.g., uniform noise vs. sparse peaks).

This solution introduces **Statistical Squeeze-and-Excitation (Stat-SE)**, which fuses **Global Average Pooling** and **Global Standard Deviation Pooling** in the attention squeeze step. This allows the network to explicitly model the dispersion/texture of the signal, enabling it to suppress clutter-dominant channels even if they have high mean intensity. This is integrated into the robust **Plain CNN** backbone with the successful **Isomorphic Dual-Polarity Readout**.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for texture-aware, physics-informed feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Stat-SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).

*   **Structural Innovation (Statistical Squeeze-and-Excitation):**
    *   We replace the standard SE module with a **Stat-SE Module**.
    *   **Statistical Squeeze:** We compute two statistics for each channel:
        1.  **Global Average:** $\mu_c = \frac{1}{HW}\sum x_{ij}$ (Mean Intensity).
        2.  **Global Standard Deviation:** $\sigma_c = \sqrt{\frac{1}{HW}\sum (x_{ij} - \mu_c)^2}$ (Texture/Dispersion).
    *   **Fusion:** These statistics are concatenated ($2 \times Channels$) and passed to the Excitation MLP.
    *   **Rationale:** By providing the network with the standard deviation, it can distinguish between "flat" high-return regions (e.g., calm water at low incidence) and "textured" high-return regions (e.g., icebergs or rough sea clutter), refining the channel recalibration process beyond simple intensity gating.

*   **Readout (Isomorphic Dual-Polarity):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Projection:** We apply a **Shared 1x1 Convolution** to compress channels from 128 to **64** (Cite solution_lesson_node_00142).
    *   **Dual-Polarity Pooling:** On these compressed maps, we apply both **Global Max Pooling** (Peaks) and **Global Min Pooling** (Shadows, implemented as `Max(-x)`).
    *   **Result:** A 256-dimensional vector ($64_{max}+64_{min}$ from two stages) that captures the **Signal-to-Shadow Contrast** while strictly respecting the capacity constraints of the baseline (Cite solution_lesson_node_00134, solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057, solution_lesson_node_00141).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017, solution_lesson_node_00040).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the raw scalar input (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
