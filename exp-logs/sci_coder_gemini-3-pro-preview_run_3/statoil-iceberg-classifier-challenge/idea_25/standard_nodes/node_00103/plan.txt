Implementation strategy:
1.  **Setup & Configuration**: Import necessary standard libraries and the provided `library` modules. To satisfy the "fast baseline" requirement, I will monkey-patch `library.train.NUM_EPOCHS` to reduce the training duration (e.g., 30 epochs instead of 75), while maintaining the integrity of the 5-fold cross-validation.
2.  **Data Loading**: Use `library.data_loader.process_data` to load the full training dataset and cached arrays. This allows access to the raw data for manual StratifiedKFold splitting, ensuring I can correctly map Out-Of-Fold (OOF) predictions back to their original indices.
3.  **Cross-Validation Loop**: Iterate through 5 folds. For each fold:
    *   Retrieve the specific train/val DataLoaders using `library.data_loader.get_loaders`.
    *   Train the model using `library.train.train_fold`.
    *   Load the best saved checkpoint for that fold.
    *   Perform inference on the validation set to generate OOF predictions.
    *   Perform inference on the test set and accumulate these probabilities for the final ensemble.
4.  **Validation & Metric**: Aggregate the OOF predictions into a single array aligned with the training targets. Compute the Log Loss metric. Print it in the exact required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Compute the absolute error for each training sample. Create a DataFrame combining errors with metadata (incidence angle) and image statistics (mean, max, std). Calculate and print the correlation between the error magnitude and these features to identify failure modes.
6.  **Submission**: Check if the validation metric is below the specified threshold (`0.1812...`). If so, average the accumulated test predictions, construct the submission DataFrame, and save it to `submission.csv`.
