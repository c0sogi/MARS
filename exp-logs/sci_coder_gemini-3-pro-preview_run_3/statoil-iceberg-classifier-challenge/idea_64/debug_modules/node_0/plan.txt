The following script demonstrates the usage of the provided library files to solve the iceberg classification task. It performs three main steps:
1.  **Data Processing Verification**: It manually triggers the data loading and processing pipeline using a temporary cache directory to verify that the raw JSON data is correctly converted into numpy arrays with the expected shapes (Channels, Height, Width).
2.  **Model Logic Verification**: It instantiates the `MSICNN` model and performs a forward pass with dummy data on the GPU (if available). It asserts that the model outputs the correct tensor shapes for both training mode (Multi-Sample Dropout enabled) and evaluation mode.
3.  **Integration Test**: It executes the full training loop using `run_training` with reduced hyperparameters (1 epoch) to ensure the entire pipeline—from data loading to submission generation—functions correctly without errors.
