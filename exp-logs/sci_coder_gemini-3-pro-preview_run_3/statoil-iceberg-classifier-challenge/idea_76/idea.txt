Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Asymmetric Texture-Shadow Isomorphic CNN (ATSI-CNN)**.

This solution represents a structural synthesis designed to capture the complete physical signature of icebergs—**Peak Intensity**, **Surface Texture**, and **Shadow Depth**—while strictly adhering to the parameter constraints that ensure generalization on this small dataset. It resolves the conflict between **Lesson 163** (Texture requires spatial diversity) and **Lesson 124** (Classifier capacity must be limited) by allocating specific statistical pooling operations to the network stages where they are most physically relevant, integrated into the robust **Plain CNN** backbone.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, parameter-efficient feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Standard SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).
    *   **Attention:** We use **Standard SE** with **Global Average Pooling** (Cite solution_lesson_node_00104) and **ReLU** in the bottleneck (Cite solution_lesson_node_00158) with a reduction ratio of $r=16$ (Cite solution_lesson_node_00146).

*   **Structural Innovation (Asymmetric Isomorphic Readout):**
    *   We extract features from **Stage 3** and **Stage 4** using **Decoupled Projections** (separate 1x1 convolutions mapping 128 $\to$ 64 channels) (Cite solution_lesson_node_00144).
    *   **Stage 3 (Texture Focus):** On the Stage 3 projection ($9 \times 9$ spatial grid), we apply **Global Max Pooling** (Peaks) and **Global MAD Pooling** (Texture).
        *   *Rationale:* **Mean Absolute Deviation (MAD)** captures signal roughness (Ice vs. Water) robustly (Cite solution_lesson_node_00143). We apply it at Stage 3 because statistical estimation requires a sufficient sample size ($9 \times 9 = 81$ pixels), which is lost in deeper layers.
    *   **Stage 4 (Shadow Focus):** On the Stage 4 projection ($4 \times 4$ spatial grid), we apply **Global Max Pooling** (Peaks) and **Global Min Pooling** (Shadows).
        *   *Rationale:* **Min Pooling** (implemented as `Max(-x)`) captures signal voids (Cite solution_lesson_node_00134). We apply it at Stage 4 to capture high-level object geometry (the "dark side" of the target) preserved by LeakyReLU.
    *   **Result:** The final vector is $64_{S3\_Max} + 64_{S3\_MAD} + 64_{S4\_Max} + 64_{S4\_Min}$. Total size is **256**. This captures the full physical signature without exceeding the capacity limit of the baseline (Cite solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Linear(256 -> 1)` $\to$ `Output`.
    *   We include the non-linear hidden layer to allow interaction between image features and the angle (Cite solution_lesson_node_00155).
    *   Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:** Imputation of missing incidence angles is performed using the median calculated **only on the training fold indices** and applied to the validation fold (Cite solution_lesson_node_00147).

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from the adaptive gradient updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
