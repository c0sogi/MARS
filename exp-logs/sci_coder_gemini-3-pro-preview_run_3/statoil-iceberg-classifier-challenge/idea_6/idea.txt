Based on the analysis of previous experiments and the specific lessons learned, I propose the following optimized solution. This strategy explicitly addresses the finding that while the "Micro-ResNet" architecture (Idea 5) was individually superior to the "Simple CNN" (Idea 4), it failed to achieve the top score because it lacked the variance reduction of an ensemble (Cite solution_lesson_node_00027). Therefore, this solution combines the advanced architecture with the robust training regime of the current best baseline.

# Solution: Ensembled SE-MicroResNet with Test-Time Augmentation

### Model
The architecture is a **Custom Micro-Residual Network with Squeeze-and-Excitation (SE) Attention**, designed to maximize feature extraction capability while strictly controlling model capacity.

*   **Backbone:** The network begins with a convolutional stem followed by three stages of **Residual Blocks**. Each block follows a standard `Conv-BN-ReLU-Conv-BN` structure with a residual skip connection.
    *   **Attention Mechanism:** An **SE Block** is integrated within each residual unit. This module performs global average pooling on the residual branch, passes the signal through a bottleneck MLP, and uses the sigmoid output to recalibrate the channel-wise feature maps. This allows the model to dynamically emphasize informative channels (e.g., the synthetic band vs. noise) (Cite solution_lesson_node_00027).
    *   **Width Constraint:** The channel width is strictly capped. The stages progress as **64 $\to$ 128 $\to$ 128**. We explicitly avoid expanding to 256 or 512 channels to prevent the overfitting observed when aggressive width expansion was applied to this small dataset (Cite solution_lesson_node_00026).
*   **Pooling Strategy:** The final feature maps are processed using **Global Max Pooling**. This is retained to preserve the sparse, high-intensity peak signals characteristic of icebergs, avoiding the signal dilution caused by Average Pooling (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The flattened 128-dimensional vector is concatenated with the scalar **incidence angle**.
*   **Classification Head:** The fused vector is passed through a Dense layer (512 units) followed by ReLU. **Dropout** is applied *after* this activation (not on the input vector) to regularize the learned representation without destroying the compact signal (Cite solution_lesson_node_00017). The final layer is a single Dense unit with Sigmoid activation.

### Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. No upscaling is performed, as training a custom model on native resolution has proven superior to adapting pre-trained ImageNet models (Cite solution_lesson_node_00009).
*   **Augmentation:** Data augmentation is applied using the optimized **`torchvision.transforms`** library (RandomHorizontalFlip, RandomVerticalFlip) to ensure stability and reproducibility (Cite solution_lesson_node_00013).

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation**. This is essential to reduce variance and produce a robust estimator given the small sample size (Cite solution_lesson_node_00016).
*   **Initialization:** The network is trained **from scratch** with all layers trainable. No layers are frozen, as freezing random weights prevents feature learning (Cite solution_lesson_node_00012).
*   **Optimization:** The Adam optimizer is used with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers (decay), relying on the implicit regularization of the constant step size to prevent the model from overfitting to noise in the later stages of training (Cite solution_lesson_node_00019).
*   **Loss Function:** Binary Cross-Entropy (Log Loss).

### Evaluation
*   **Inference:** Predictions are generated using **Test-Time Augmentation (TTA)**. For each test image, the model predicts probabilities for the original, horizontally flipped, and vertically flipped versions, averaging the results.
*   **Ensembling:** The final submission probability for each ID is the average of the TTA predictions from all **5 models** trained in the Cross-Validation loop. This combines the superior bias reduction of the SE-ResNet architecture with the variance reduction of the ensemble (Cite solution_lesson_node_00027).
