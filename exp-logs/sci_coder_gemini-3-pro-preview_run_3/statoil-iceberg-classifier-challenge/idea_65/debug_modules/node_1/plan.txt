The issue is caused by Python's default argument evaluation behavior. In `library/data.py`, the `get_data_loaders` function defines `batch_size=Config.BATCH_SIZE` as a default argument. This value is evaluated and bound when the module is imported (at which point `Config.BATCH_SIZE` is 32). When `runfile.py` subsequently updates `Config.BATCH_SIZE` to 8 at runtime, the function continues to use the stale default value of 32, causing the tensor shape mismatch assertion to fail. To fix this, I will modify `get_data_loaders` (and `get_test_loader` for consistency) to default `batch_size` to `None` and assign it from `Config.BATCH_SIZE` dynamically within the function body.
