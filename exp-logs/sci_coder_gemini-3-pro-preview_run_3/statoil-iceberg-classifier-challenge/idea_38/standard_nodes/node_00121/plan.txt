The issue is that the code attempts to load a NumPy array containing string objects (`id_test.npy`) without explicitly enabling pickling. To fix this, I will update the `np.load` call for the test IDs in `library/dataset.py` to include `allow_pickle=True`. Cite debug_lesson_2.
