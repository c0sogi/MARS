Implementation strategy:
1.  **Configuration Override**: Import the `Config` class and modify its attributes to enable `DEBUG` mode, reduce `EPOCHS` to 1, and set a small `BATCH_SIZE`. This ensures the script runs quickly within the time limit.
2.  **Cache Path Redirection**: Update `Config.CACHE_PATHS` to point to the existing `./working/cache` directory. This avoids the time-consuming process of parsing the raw JSON files and leverages the pre-processed NumPy arrays.
3.  **Data Loading Verification**: Use `get_data_loaders` to load the dataset (fold 0). Retrieve a single batch of data to verify the shapes of images, angles, and labels using assertions.
4.  **Model Verification**: Instantiate the `SDHAResNet` model. Perform a forward pass with the retrieved batch to confirm the model architecture is valid and produces outputs of the expected shape.
5.  **Training Loop Execution**: Execute `train_fold(0)` to demonstrate the training pipeline. This will train the model for one epoch (due to the config override) and save a checkpoint.
6.  **Inference and Submission**: Load the trained model checkpoint. Iterate through the `test_loader` to generate predictions. Create a `demo_submission.csv` file to demonstrate the submission format.
