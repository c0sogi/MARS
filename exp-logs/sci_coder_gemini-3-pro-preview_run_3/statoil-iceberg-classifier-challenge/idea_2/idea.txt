Based on the lessons learned, I propose a solution that shifts from training custom shallow CNNs to leveraging **Transfer Learning** with a deep, pretrained backbone. This addresses the limitations of small dataset size by utilizing feature extractors learned from large-scale data (ImageNet), while strictly adhering to the architectural constraints identified in the previous experiments (specifically regarding pooling and channel depth).

# Solution: VGG16 Transfer Learning with Global Max Pooling

### Model
The architecture adopts the **VGG16** network (pretrained on ImageNet) as the feature extraction backbone. This represents a structural innovation over the previous custom 4-layer CNNs, introducing significantly deeper processing (13 convolutional layers) to capture complex textural hierarchies in the radar data.
*   **Backbone:** The VGG16 convolutional base is used, discarding the original fully connected classifier.
*   **Pooling Strategy:** The output of the final convolutional block is processed using **Global Max Pooling**. This is chosen explicitly to preserve the strong, sparse signal of icebergs and avoid the signal dilution observed with Average Pooling (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The flattened 512-dimensional feature vector from the pooling layer is concatenated with the scalar **incidence angle**.
*   **Classification Head:** The fused vector passes through two Dense layers (e.g., 512 units -> 256 units) before the final Sigmoid output. The width of these layers is kept high to avoid the information bottleneck observed when reducing channel width too aggressively (Cite solution_lesson_node_00006). Dropout is applied to these layers to regularize the model.

### Data
*   **Channel Composition:** The input is formed by stacking the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) to create a 3-channel image. This synthetic channel has been proven to enrich the feature representation (Cite solution_lesson_node_00005).
*   **Resizing:** The original 75x75 images are **upscaled to 224x224**. This is necessary to match the receptive field and spatial reduction characteristics of the VGG16 backbone (which reduces spatial dimensions by a factor of 32, turning 224x224 into 7x7 feature maps, whereas 75x75 would be reduced to a negligible 2x2).
*   **Preprocessing:** Pixel values are scaled to match the input statistics expected by the pretrained VGG16 model (typically normalization using ImageNet mean and std).
*   **Augmentation:** Random horizontal and vertical flips are applied during training to improve generalization (Cite solution_lesson_node_00005).

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation**. This is crucial for the small dataset size (approx. 1600 samples) to ensure the stability of the solution and produce robust out-of-fold predictions.
*   **Fine-tuning:** Initially, the convolutional backbone is frozen, and only the new dense head is trained. Optionally, the final convolutional block can be unfrozen for fine-tuning with a lower learning rate in later epochs.
*   **Optimization:** The Adam optimizer is used with the Log Loss function.
*   **Imputation:** Missing incidence angle values are imputed with the median of the training set.

### Evaluation
*   **Ensembling:** The final prediction for each test image is the average of the probabilities output by the 5 models trained during the Cross-Validation process. This reduces the variance of the predictions and generally improves the Log Loss score.
