Implementation strategy:
1.  **Setup and Data Loading**: Import necessary modules and set the random seed. Load the full processed dataset using `load_and_process_data`. Load the raw `train.json` to map image IDs to array indices.
2.  **Dataset Splitting**: Load `train.csv` and `val.csv` from the metadata directory. Use the ID mapping to split the full training data into a training subset (for model fitting) and a hold-out validation subset (for final evaluation).
3.  **Training**: Execute a 5-fold cross-validation loop on the *training subset* only. Use the provided `run_fold` function, limiting epochs to 20 to ensure a fast baseline. Collect the trained models (loaded from best checkpoints).
4.  **Validation**: Perform inference on the *hold-out validation subset* using an ensemble of the 5 trained models. Calculate the Log Loss metric and print it in the required format.
5.  **Failure Analysis**: Calculate the absolute prediction errors on the validation set. Compute and print the Pearson correlation between these errors and the incidence angle, as well as the image signal intensity (Band 1 mean).
6.  **Submission**: Compare the validation metric against the specified threshold. If the model performs well enough, generate predictions for the test set using the ensemble, format the submission dataframe, and save it to `submission.csv`.
