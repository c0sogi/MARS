The following script implements the complete 5-Fold Cross-Validation pipeline for the Iceberg Classifier using the **MAD-ResNet** architecture.

**Implementation Strategy:**
1.  **Setup & Data Loading**: Initializes the environment with fixed seeds and loads the pre-processed dataset (train, val, test) using the provided library functions. It merges the training and validation sets to perform a full stratified 5-fold cross-validation.
2.  **Cross-Validation Loop**: Iterates through 5 folds. For each fold:
    *   Splits data into training and validation subsets.
    *   Initializes the `MADResNet` model, Adam optimizer, and BCE loss.
    *   Trains for the configured number of epochs (60), saving the best checkpoint based on validation loss.
    *   Loads the best checkpoint to generate Out-Of-Fold (OOF) predictions for the validation subset and accumulates predictions for the test set.
3.  **Validation & Metric**: Computes the overall Log Loss using the aggregated OOF predictions and the true labels. This metric is printed in the required format.
4.  **Failure Analysis**: Calculates the absolute prediction error for each sample and computes Pearson correlations between this error and input features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify systematic weaknesses.
5.  **Submission**: Checks if the validation metric meets the strict threshold (< 0.1812). If successful, averages the test predictions across all folds and generates the `submission.csv` file in the specified format.
