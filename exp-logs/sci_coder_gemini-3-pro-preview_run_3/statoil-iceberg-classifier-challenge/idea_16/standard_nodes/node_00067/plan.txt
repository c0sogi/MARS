The implementation strategy follows the Spatially-Regularized Selective SE-CNN design. The script `runfile.py` orchestrates the entire pipeline:

1.  **Setup & Data Loading**: It initializes the environment with fixed seeds for reproducibility and loads the pre-processed dataset (images and incidence angles) using the provided `data_loader` module. It utilizes the cached `.npy` files to save time.
2.  **5-Fold Cross-Validation**: It iterates through 5 folds using `StratifiedKFold`. For each fold:
    *   It creates training and validation DataLoaders.
    *   It instantiates the `SpatiallyRegularizedSECNN` model and moves it to the GPU.
    *   It trains the model using the `trainer` module, which handles the optimization loop, backpropagation, and checkpointing based on validation loss.
    *   It re-loads the best checkpoint for the fold to generate Out-Of-Fold (OOF) predictions on the validation set.
3.  **Validation & Failure Analysis**:
    *   It aggregates OOF predictions to calculate the global Log Loss metric on the entire training set.
    *   It performs failure analysis by calculating the absolute error for each sample and correlating this error with input features (incidence angle, image mean/std) to identify weakness drivers.
4.  **Submission**:
    *   It checks if the final validation metric meets the specified threshold (< 0.181459).
    *   If successful, it performs inference on the test set using an ensemble of the 5 trained models (averaging their probabilities).
    *   It saves the final submission file to `./submission/submission.csv`.
