The following script demonstrates how to utilize the provided library files to train and evaluate the iceberg classification model.

**Strategy:**
1.  **Configuration Override**: We monkey-patch the `Config` class to set up a lightweight demonstration environment (reduced epochs, fewer folds, and a dedicated working directory) to ensure the script runs quickly (under 5 minutes).
2.  **Data Loading**: We use `get_data` to load and process the JSON files into numpy arrays, validating the shapes and integrity of the data.
3.  **Component Verification**: We explicitly verify the `get_fold_loaders` (for training/validation splits) and `get_test_loader` (for inference) to ensure data shapes and preprocessing (scaling/imputation) are correct.
4.  **Model Logic**: We instantiate the `ACICNN` model, perform a dummy forward pass to check tensor shapes, and run a single training/validation step to confirm the optimization loop works.
5.  **Full Pipeline Execution**: Finally, we trigger the main `train_model` function from `library.train`. This runs the full cross-validation loop (restricted to 2 folds by our config) and generates a submission file, which we then validate.
