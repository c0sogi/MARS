The implementation strategy involves the following steps:

1.  **Environment Setup**: Initialize the random seed and detect the compute device (GPU/CPU) using the provided `library.utils`.
2.  **Data Loading**: Load the training, validation, and test datasets using `library.data_loader.get_loaders` with `load_cached_data=True`. This utilizes the pre-split data defined in the metadata.
3.  **Model Training**: Execute the training loop for a single fold (Fold 0) using `library.train.run_fold`. Given the small dataset size (~1600 images) and the "fast baseline" requirement, the training is capped at 30 epochs with early stopping.
4.  **Validation & Metric Calculation**:
    *   Load the best trained model.
    *   Perform inference on the full validation set to obtain probabilities and ground truth labels.
    *   Compute the **Log Loss** metric using `sklearn.metrics.log_loss` to evaluate performance against the competition metric.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample (`|y_true - y_pred|`).
    *   Compute the Pearson correlation coefficient between the prediction error and the **incidence angle**. This identifies if the model struggles with specific radar angles.
    *   Print the correlation results.
6.  **Submission Generation**:
    *   Compare the final validation log loss against the threshold `0.1806015565870406`.
    *   If the model performs well enough, generate the submission file using `library.predict.generate_submission`. Since only one model was trained (due to the fixed train/val split in metadata), `num_folds` is set to 1.
