This script demonstrates the end-to-end usage of the provided machine learning library for the ship vs. iceberg classification task. It performs the following steps:

1.  **Configuration Overrides**: Patches the imported modules to use a temporary directory and reduced hyperparameters (1 epoch, 2 folds) to ensure the script executes quickly (under 1 hour).
2.  **Component Verification**:
    *   **Utils**: Verifies the `AverageMeter` class.
    *   **Model**: Instantiates the `CDICNN` model, performs a forward pass with dummy data, and asserts the output shape is correct.
    *   **Data**: Initializes the `IcebergDataset` and `DataLoader` with a small subset of data to verify the data pipeline and batch shapes.
3.  **Training Pipeline Execution**: Runs the full training loop using `run_training` with a debug sample size. This triggers data loading, model training, validation, checkpointing, and submission generation.
4.  **Result Validation**: explicitly checks that the submission file and model checkpoints were generated successfully.
