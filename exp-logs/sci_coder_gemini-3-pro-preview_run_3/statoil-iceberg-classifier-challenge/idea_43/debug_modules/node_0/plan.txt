This script demonstrates the end-to-end usage of the provided machine learning library for the iceberg classification task. It performs the following steps:

1.  **Utilities Verification**: Initializes the random seed for reproducibility and detects the available computation device (CPU or GPU).
2.  **Model Architecture Test**: Instantiates the `CAFPCNN` model, creates dummy input tensors matching the expected dimensions, and performs a forward pass to verify the output shape and logic.
3.  **Data Pipeline Test**: Initializes the data loaders, fetches a single batch of training data, and asserts that the image dimensions (including the generated 3rd channel) and label shapes are correct.
4.  **Training Integration Test**: Executes a minimal training run using `fit_fold` with a single epoch and reduced batch size. This validates the integration of the data loader, model, optimizer, and loss function, ensuring the training loop runs without errors and produces a model checkpoint.
