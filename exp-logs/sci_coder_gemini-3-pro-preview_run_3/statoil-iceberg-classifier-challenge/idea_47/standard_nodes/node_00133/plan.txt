Implementation strategy:
1.  **Environment & Data**: Initialize the environment with fixed seeds and detect the computation device (GPU). Load the pre-processed data using the provided `process_data` function.
2.  **Data Splitting**: Explicitly separate the dataset into a **Cross-Validation Set** (sourced from `train.csv`) and a **Hold-Out Validation Set** (sourced from `val.csv`) using the metadata. This ensures the "Final Validation Metric" is calculated on strictly unseen data, preventing leakage.
3.  **Training (5-Fold CV)**: Implement a 5-Fold Stratified Cross-Validation loop on the CV set. Inside the loop, instantiate the `IDPH_CNN` model and use the `Trainer` class to train for a limited number of epochs (35) to ensure a fast baseline execution while retaining sufficient convergence. Save the best model for each fold.
4.  **Validation Assessment**: Load the 5 trained models and perform ensemble inference on the Hold-Out Validation Set. Calculate the Log Loss to report the "Final Validation Metric".
5.  **Failure Analysis**: Compute the absolute prediction error for the validation set. Calculate statistical features (mean, std) for the image bands on-the-fly and compute their Pearson correlation with the error to identify systematic weaknesses.
6.  **Submission**: If the validation metric meets the specified threshold (< 0.1806), perform ensemble inference on the Test Set and generate the `submission.csv` file.
