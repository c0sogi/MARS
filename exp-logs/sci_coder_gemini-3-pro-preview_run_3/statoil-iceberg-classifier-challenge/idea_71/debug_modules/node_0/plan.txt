The following script demonstrates the usage of the provided library files to train the `RTICNN` model for iceberg classification. It performs the following steps:

1.  **Configuration Patching**: Overrides default hyperparameters (epochs, folds) to ensure the demonstration runs quickly (1 epoch, 2 folds).
2.  **Data Loading Verification**: Uses `library.data_loader` to load and process the JSON data into numpy arrays, validating shapes and data types.
3.  **Model Verification**: Instantiates the `RTICNN` model, runs a forward pass with dummy data, and asserts output shapes to confirm architecture correctness.
4.  **Training Pipeline Execution**: Runs the full cross-validation training loop using `library.train.run_training_process`, which handles training, validation, and prediction.
5.  **Submission Verification**: Checks the generated submission file for correct formatting and row counts.
