### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed for reproducibility using `library.utils.set_seed`.
2.  **Data Loading**: Use `library.data_loader.load_data` to retrieve the training and test datasets. We will verify the structure and shapes of the returned data dictionaries (images, angles, labels).
3.  **Dataset & DataLoader**: Instantiate `library.data_loader.IcebergDataset` with a small subset of the data (to ensure speed). We will use `library.data_loader.get_transforms` to apply the appropriate augmentations.
4.  **Model Initialization**: Initialize the `library.model.StabilizedSECNN` model. We will perform a forward pass with a dummy tensor to verify the architecture's input/output dimensions match the requirements (output shape `[Batch, 1]`).
5.  **Training Loop Demonstration**:
    *   Set up the optimizer (`Adam`) and loss function (`BCEWithLogitsLoss`).
    *   Run a short training loop using `library.trainer.train_one_epoch` for a few epochs on the data subset.
    *   Run a validation step using `library.trainer.validate`.
    *   Assert that the loss is a valid finite number.
6.  **Inference & Submission**:
    *   Generate predictions on a subset of the test data.
    *   Construct a pandas DataFrame in the required format (`id`, `is_iceberg`).
    *   Save the demonstration submission to `./working/demo_submission.csv`.
