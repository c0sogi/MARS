Implementation strategy:
1.  **Setup and Configuration**: Define the working directory (`./working/idea_50`), number of folds (5), and training parameters (50 epochs for a fast but effective baseline). Set the random seed for reproducibility.
2.  **Training Loop**: Iterate through 5 folds using the provided `library.trainer.run_fold` function. This function handles the training of the MPDP-CNN model on the combined train+validation data using Stratified K-Fold splits, saving checkpoints for each fold.
3.  **Validation Data Loading**: Explicitly load the hold-out validation set (`val.csv`) using `library.dataset.get_data` and `library.dataset.IcebergDataset`. Calculate the incidence angle imputation value from the training metadata to ensure consistency.
4.  **Ensemble Inference**: Perform inference on the validation set using the ensemble of the 5 trained models. Average the predictions to get the final ensemble probability.
5.  **Metric Calculation**: Compute the Log Loss on the validation set using the ensemble predictions and the ground truth labels. Print the result in the required format.
6.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute statistical features (mean, std, max) for Band 1 and Band 2 of the validation images. Calculate and print the Pearson correlation between the error magnitude and these input features (including incidence angle) to identify sources of error.
7.  **Submission Generation**: If the validation metric is below the specified threshold (0.17174082291273365), use `library.trainer.generate_submission` to create the final `submission.csv` for the test set.
