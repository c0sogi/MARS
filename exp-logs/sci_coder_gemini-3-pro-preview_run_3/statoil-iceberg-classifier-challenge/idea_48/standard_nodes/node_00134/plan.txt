5.  **Metric & Failure Analysis**:
    *   I will calculate the Log Loss on this specific hold-out subset and print it in the required format.
    *   I will calculate the absolute error for these predictions and compute the Pearson correlation between the error and the `inc_angle` feature.
6.  **Submission Generation**: If the calculated validation metric is below the threshold (0.1806...), I will proceed to generate the submission. This involves loading the test data, running inference with all 5 saved models, averaging the probabilities, and saving the result to `./submission/submission.csv`.
