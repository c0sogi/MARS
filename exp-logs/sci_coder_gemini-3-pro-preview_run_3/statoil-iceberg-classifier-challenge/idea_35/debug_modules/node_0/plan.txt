This script demonstrates the end-to-end usage of the provided library components for the Iceberg Classifier task. It performs the following steps:
1.  **Setup**: Initializes the environment and seeds for reproducibility.
2.  **Data Loading**: Uses `library.dataset.get_loaders` to process the raw JSON data (via pre-generated metadata) and create PyTorch DataLoaders. It verifies the shape and integrity of the loaded batches.
3.  **Model Initialization**: Instantiates the `DPACNN` model from `library.model` and verifies the forward pass with a dummy batch.
4.  **Training**: Runs a short training loop (2 epochs) using `library.trainer.run_fold` to demonstrate the training process and checkpointing mechanism.
5.  **Inference**: Performs inference on a subset of the test data using the trained model to demonstrate prediction generation.
