Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Setup & Reproducibility**: Initialize the environment with a fixed random seed to ensure reproducibility. Define paths for metadata, input, and submission directories.
2.  **Data Loading & Preprocessing**:
    *   Use the provided `process_split` function to load training, hold-out validation, and test datasets from the pre-generated metadata.
    *   Perform imputation on the `inc_angle` feature. Calculate the median angle from the full training set and apply it to fill `NaN` values in training, validation, and test sets, ensuring consistency.
3.  **Cross-Validation Strategy**:
    *   Implement a 5-Fold Cross-Validation loop on the training data (`metadata/train.csv`).
    *   For each fold, split the data into training and local validation subsets.
    *   Instantiate the `DPACNN` model and train it using the `run_fold` function from the provided library. This handles the training loop, optimization (AdamW), and early stopping.
    *   Store the best model from each fold in memory for the ensemble.
4.  **Ensemble Evaluation**:
    *   Load the hold-out validation set (`metadata/val.csv`) which was strictly excluded from the CV process.
    *   Generate probability predictions using each of the 5 trained models.
    *   Average the predictions to form the ensemble output.
    *   Calculate and print the **Final Validation Metric (Log Loss)**.
5.  **Failure Analysis**:
    *   Calculate the absolute error between the ensemble predictions and the ground truth labels on the hold-out set.
    *   Compute summary statistics for the images (mean intensity for Band 1 and Band 2).
    *   Calculate the correlation between the error magnitude and input features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify sources of systematic error.
6.  **Submission Generation**:
    *   Check if the Final Validation Metric is below the specified threshold (`0.1806...`).
    *   If successful, generate predictions for the test set (`metadata/test.csv`) using the 5-model ensemble.
    *   Format the output as a CSV file (`id,is_iceberg`) and save it to `./submission/submission.csv`.
