### Implementation Strategy

1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (e.g., `MAX_SAMPLES`, `NUM_EPOCHS`, `BATCH_SIZE`, `WORKING_DIR`) to ensure the demonstration runs quickly and uses a separate directory for outputs. We will explicitly create the new working directory.
2.  **Data Processing**: We will call `process_and_cache_data` to load the dataset. We will verify the logic by asserting the shapes of the returned numpy arrays (training images, labels, angles, etc.) match the expected dimensions defined in the configuration.
3.  **Data Loading**: We will use `get_cv_loaders` to generate PyTorch DataLoaders for a specific cross-validation fold. We will fetch a single batch to verify that the data shapes (Batch, Channels, Height, Width) and types are correct.
4.  **Model Initialization**: We will instantiate the `IcebergSEResNet` model. We will perform a forward pass using the dummy batch fetched in the previous step to verify that the model architecture produces the correct output shape `(Batch, 1)`.
5.  **Training Loop**: We will execute `fit_fold` for a single fold. This demonstrates the integration of the training loop, validation, loss calculation, and optimizer. We will verify that model checkpoints (`checkpoint.pth`, `model_best.pth`) are successfully created in the working directory.
6.  **Inference and Submission**: We will load the best model from the saved checkpoint using `load_checkpoint`. We will then use `get_test_loader` to prepare the test data, run inference to generate probabilities, and use `save_submission` to create the CSV file. Finally, we will validate the format of the generated submission file.
