Based on the lessons learned from previous experiments, I propose the **Aggressively Downsampled SE-ResNet Ensemble**.

This solution synthesizes the superior feature extraction capability of the **Squeeze-and-Excitation Residual Network** (which was the strongest base learner in Idea 5, Cite solution_lesson_node_00027) with the robust structural constraints of the **Simple CNN** (specifically aggressive spatial reduction to filter noise, Cite solution_lesson_node_00046, and early channel expansion, Cite solution_lesson_node_00050). It explicitly corrects the architectural flaws of previous ResNet attempts (insufficient downsampling, initialization errors) and leverages the proven variance-reduction strategy of cross-validation ensembling.

# Model
The architecture is a **4-Stage Residual Network with Squeeze-and-Excitation (SE) Attention**.

*   **Backbone:** The network consists of an initial convolutional stem followed by **four** residual stages. This depth is explicitly chosen to ensure the spatial resolution is downsampled four times (approx. $75 \to 37 \to 18 \to 9 \to 4$), matching the aggressive noise-filtering properties of the successful Simple CNN (Cite solution_lesson_node_00046). Previous ResNet attempts failed partly because they stopped at $19 \times 19$, leaving too much speckle noise for the global pooling layer.
*   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We explicitly expand to 128 channels immediately in the second stage ("Early Expansion") to preserve low-level texture details (Cite solution_lesson_node_00050), while capping the maximum width at 128 to prevent overfitting (Cite solution_lesson_node_00026).
*   **Block Structure:** Each residual block contains Convolutional layers, Batch Normalization, ReLU, and an **SE Module** (reduction ratio 16). The SE module allows the network to recalibrate channel importance, which was proven to enhance the base learner's performance (Cite solution_lesson_node_00027).
*   **Pooling:** The final $4 \times 4$ (or $5 \times 5$) feature maps are processed using **Global Max Pooling** to capture high-intensity signal peaks (icebergs) (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The flattened vector is concatenated with the scalar **incidence angle** (Late Fusion) (Cite solution_lesson_node_00039).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer** (`Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Output`). We restrict the head depth to limit capacity (Cite solution_lesson_node_00040) and apply Dropout *only* after the activation to preserve feature integrity (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default (Kaiming Uniform)** initialization for all layers (Cite solution_lesson_node_00045).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce variance and maximize the performance of the strong SE-ResNet base learner (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3) to leverage implicit regularization (Cite solution_lesson_node_00019).
*   **Loss Function:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the predictions from the 5 models trained in the Cross-Validation loop.
