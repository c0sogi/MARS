Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup and Configuration**: Initialize the environment using the provided `Config` class. Set random seeds for reproducibility across `numpy` and `torch`. Ensure necessary directories exist.
2.  **Data Loading**: Use the `dataset.get_data` function to load pre-processed training, validation, and test DataLoaders. This leverages the caching mechanism to speed up execution.
3.  **Model Training**: Instantiate the `SimpleFCN` model and the `Trainer`. Execute the training loop using `trainer.fit()`, which handles forward passes, backpropagation, and early stopping based on validation loss.
4.  **Validation Assessment**: After training, evaluate the best model on the validation set to compute the final Log Loss. Print this metric in the required format.
5.  **Failure Analysis**: Perform a detailed error analysis on the validation set.
    *   Generate predictions for validation samples.
    *   Calculate the absolute error magnitude ($|y_{true} - y_{pred}|$) for each sample.
    *   Extract high-level features (e.g., mean/std of Band 1 and Band 2, incidence angle) from the input tensors.
    *   Compute and print the Pearson correlation between these features and the error magnitude to identify potential sources of bias or difficulty.
6.  **Submission Generation**: Use the trained model to generate probabilities for the test set and save the results to `submission.csv` using the `trainer.predict` method.
