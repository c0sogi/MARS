The issue is that the `test_ids` are stored as a NumPy array of strings, which NumPy treats as an object array (`dtype=object`). When loading such arrays using `np.load()`, the `allow_pickle` parameter defaults to `False` in recent NumPy versions for security, causing a `ValueError`. To fix this, we need to explicitly set `allow_pickle=True` when loading the cached IDs in `library/data_loader.py`.
