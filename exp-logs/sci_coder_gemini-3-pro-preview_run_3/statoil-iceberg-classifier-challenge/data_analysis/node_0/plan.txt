The strategy for the EDA script is as follows:

1.  **Data Loading**: Load the training metadata from `./metadata/train.csv` to identify the specific samples allocated to the training set. Then, load the raw `./input/train.json` file and filter it to include only these training samples. This ensures strictly no data leakage from validation or test sets.

2.  **Target Analysis**: Analyze the `is_iceberg` column to report the class distribution (Ship vs. Iceberg) and check for class imbalance.

3.  **Image Data Analysis**:
    *   Verify the dimensions of the image bands (Band 1 and Band 2) to confirm they are 75x75 flattened vectors (length 5625).
    *   Convert the lists of floats into NumPy arrays to calculate global pixel statistics (mean, std, min, max) for each band. This is crucial for normalization strategies.

4.  **Tabular Data Analysis**:
    *   Analyze the `inc_angle` feature.
    *   Report missing values (NaNs), descriptive statistics (mean, std), and potential outliers.

5.  **Feature Relationships**:
    *   **Feature Engineering**: Create summary features for each image (Mean, Std, Min, Max for Band 1 and Band 2) to relate the high-dimensional image data to the target in a structured way.
    *   **Correlations**: Calculate correlations between these summary features, the incidence angle, and the target.
    *   **Feature Importance**: Train a lightweight Random Forest classifier using the summary features and `inc_angle` (with imputation for missing values) to identify which signal characteristics are most predictive of the target.

6.  **Output**: Format all floating-point numbers to 4 decimal places and organize the results into the requested capitalized sections.
