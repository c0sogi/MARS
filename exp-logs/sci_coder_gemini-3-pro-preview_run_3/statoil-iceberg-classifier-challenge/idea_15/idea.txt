Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Selective Hierarchical SE-CNN (SHSE-CNN)**.

This solution synthesizes the robust structural constraints of the **Simple CNN** (aggressive downsampling, early expansion) with the feature-enhancement capabilities of **Squeeze-and-Excitation (SE)** attention and **Selective Hierarchical Pooling**. It explicitly corrects the flaws of previous iterations: it fixes the channel bottleneck that caused the failure of Selective Pooling in Idea 11 (Cite solution_lesson_node_00050), and it avoids the noise propagation of full Hierarchical Pooling (Cite solution_lesson_node_00035) and the complexity of ResNets (Cite solution_lesson_node_00046).

# Model
The architecture is a **Custom 4-Stage Convolutional Network** augmented with Channel Attention and Multi-Scale Pooling.

*   **Backbone:** The network consists of 4 sequential Convolutional Blocks. We explicitly choose a **Plain CNN** (no residual connections) to enforce aggressive noise filtering via sequential downsampling, which has proven superior to ResNets for this specific noisy dataset (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` $\to$ `BatchNorm` $\to$ `ReLU` $\to$ **SE Module** $\to$ `MaxPool2d`.
    *   **Attention:** The **SE Module** (Squeeze-and-Excitation) is integrated into every block. This allows the network to dynamically recalibrate the importance of the HH, HV, and synthetic channels, a feature proven to enhance the base learner's capability (Cite solution_lesson_node_00027).
    *   **Width Strategy (Early Expansion):** The channel dimensions are strictly configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We explicitly expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050), correcting the bottleneck that caused Idea 11 to fail.
*   **Structural Innovation (Selective Hierarchical Pooling):** We implement a **Partial Feature Pyramid**.
    *   We apply **Global Max Pooling** to the output of **Block 3** (extracting medium-scale features, ~9x9 grid) and **Block 4** (extracting abstract existence features, ~4x4 grid).
    *   We explicitly **exclude** Block 1 and Block 2 from pooling to prevents the propagation of high-frequency speckle noise into the classifier (Cite solution_lesson_node_00035).
    *   **Pooling Type:** Global Max Pooling is used to capture the sparse, high-intensity peak signals characteristic of icebergs (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The pooled vectors from Block 3 (128 dim) and Block 4 (128 dim) are concatenated with the scalar **incidence angle**.
    *   **Scale Alignment:** We explicitly **do not normalize** the incidence angle. Since the raw angle values (~30-45) match the magnitude of the raw radar signal features (dB values ~-45 to +30), we preserve the natural scale alignment to maximize performance (Cite solution_lesson_node_00057).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer**: `Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   Dropout is applied *only* after the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained to avoid computational overhead and artifacts (Cite solution_lesson_node_00009).
*   **Augmentation:** We use the optimized `torchvision.transforms` library for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce variance and maximize the performance of the enhanced base learner (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent the instability and "confident errors" observed in unregularized runs (Cite solution_lesson_node_00036).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform) for all layers (Cite solution_lesson_node_00045).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
