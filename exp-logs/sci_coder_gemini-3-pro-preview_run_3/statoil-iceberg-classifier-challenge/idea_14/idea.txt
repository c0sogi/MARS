Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Hybrid Wide-SE-ResNet with Raw-Scale Fusion**.

This solution synthesizes the superior feature extraction capabilities of the **Squeeze-and-Excitation Residual Network** (identified as a stronger base learner in Cite solution_lesson_node_00027) with the robust structural constraints of the **Simple CNN** (specifically aggressive spatial reduction and early channel expansion). It explicitly corrects the architectural flaws of previous ResNet attempts (insufficient downsampling, width overfitting, and scale mismatch) and leverages the proven variance-reduction strategy of cross-validation ensembling.

# Model
The architecture is a **Custom 4-Stage Residual Network** designed to balance channel-wise attention with strict capacity constraints.

*   **Backbone:** The network consists of an initial convolutional stem followed by four stages of **Residual Blocks**.
    *   **Spatial Reduction:** We enforce **4 Downsampling operations** (via strided convolutions) to reduce the 75x75 input to a ~5x5 feature map. This matches the aggressive noise-filtering profile of the successful Simple CNN, preventing the global pooling layer from picking up speckle noise (Cite solution_lesson_node_00046).
    *   **Width Strategy (Early Expansion):** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We explicitly expand to 128 channels immediately in the second stage to preserve low-level texture details (Cite solution_lesson_node_00050), while strictly capping the maximum width at 128 to prevent the overfitting observed with 256+ channels (Cite solution_lesson_node_00026).
    *   **Attention Mechanism:** Each residual block includes a **Squeeze-and-Excitation (SE)** module (reduction ratio 16). This allows the network to explicitly model the dependencies between the HH and HV bands, which was shown to improve single-model performance (Cite solution_lesson_node_00027).
*   **Pooling Strategy:** The final feature maps are processed using **Global Max Pooling**. This is retained to preserve the sparse, high-intensity peak signals (icebergs) and avoid signal dilution (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The flattened 128-dimensional vector is concatenated with the scalar **incidence angle**.
    *   **Crucial Innovation:** We explicitly **do not normalize** the incidence angle. Since the raw angle values (~30-45) are on the same order of magnitude as the raw radar signal features (dB values ~-40 to +30), we preserve the natural scale alignment to avoid the performance degradation observed with normalization (Cite solution_lesson_node_00057).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer** (`Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Output`). We apply Dropout *only* after the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. We strictly avoid upscaling to prevent computational overhead and artifacts (Cite solution_lesson_node_00009).
*   **Augmentation:** We use the optimized `torchvision.transforms` library for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset and maximize the performance of the strong SE-ResNet base learner (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent the instability and "confident errors" observed in unregularized runs (Cite solution_lesson_node_00036).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform). We explicitly reject manual fixed-scale initialization (Cite solution_lesson_node_00045).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop.
