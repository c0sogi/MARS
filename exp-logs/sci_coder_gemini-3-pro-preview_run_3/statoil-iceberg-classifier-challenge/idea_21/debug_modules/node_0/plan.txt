This script demonstrates the usage of the provided machine learning library for the Ship vs. Iceberg classification task. It covers data loading, model instantiation, a fast training loop using a subset of data (debug mode), and inference setup.

### Strategy
1.  **Setup**: Configure a dedicated cache directory (`./working/demo_usage`) to avoid conflicts with existing runs and ensure a clean demonstration of the data processing pipeline.
2.  **Data Loading**: Use `get_loaders` with `debug=True` to load a small subset (100 samples) of the data. This verifies the caching mechanism, data splitting (Stratified K-Fold), and preprocessing (band reshaping, channel creation) without the overhead of the full dataset.
3.  **Data Verification**: Inspect a single batch from the `DataLoader` to assert that image tensors have the correct shape `(Batch, 3, 75, 75)` and labels/angles are properly formatted.
4.  **Model Usage**: Instantiate the `MSD_SE_CNN` model, move it to the appropriate device (CPU/GPU), and perform a forward pass with the sample batch to verify the architecture and output dimensions.
5.  **Training Pipeline**: Execute `train_kfold` with minimal epochs (1) and the debug subset. This validates the entire training loop—including loss calculation, backpropagation, and validation—very quickly.
6.  **Inference**: Initialize the test data loader using `get_test_loader` and verify it yields images and IDs correctly for submission generation.
