The `RuntimeError` during validation occurs because `runfile.py` attempts to load `model_best.pth`, which currently contains stale data from a previous experiment in a "full checkpoint" format (keys: `epoch`, `state_dict`, etc.), whereas the code expects a raw state dictionary (weights only). The current training loop in `library/train.py` saves the correct raw state dictionary format but writes it to `checkpoint.pth`, leaving the stale `model_best.pth` untouched. To fix this, I will modify `library/train.py` to save the best model directly to `model_best.pth`. This ensures the training process overwrites the stale artifacts with the correct format expected by the validation and prediction scripts. Cite debug_lesson_4.
