The implementation strategy is as follows:
1.  **Setup and Reproducibility**: Initialize the script by setting the random seed using the provided utility to ensure consistent results across runs.
2.  **Training Loop**: Iterate through the 5 folds defined in the configuration. For each fold, invoke the `run_fold` function from the training library. This handles data splitting (via Stratified K-Fold), model training, and checkpoint saving.
3.  **Validation**:
    *   Load the fixed hold-out validation set using the `get_dataloaders` function, which respects the metadata split.
    *   Load the best saved models from all 5 folds.
    *   Perform inference on the validation set using an ensemble approach. For each image, apply Test-Time Augmentation (TTA) by averaging predictions from the original, horizontally flipped, and vertically flipped versions across all 5 models.
    *   Compute the Log Loss metric on these predictions.
4.  **Failure Analysis**: Calculate the Pearson correlation coefficient between the absolute prediction errors and the incidence angles to identify potential biases related to the angle of acquisition.
5.  **Submission**: Check if the calculated validation metric is strictly lower than the specified threshold (0.18145903282502943). If satisfied, call the `generate_submission` function to produce the final `submission.csv` for the test set.
