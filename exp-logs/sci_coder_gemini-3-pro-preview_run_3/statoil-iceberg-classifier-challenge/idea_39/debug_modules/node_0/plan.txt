    *   Set up a standard optimizer (`AdamW`) and loss function (`BCEWithLogitsLoss`).

5.  **Inference & Submission Demonstration**:
    *   Use `library.train.predict_test` to generate probabilities for the mini-dataset.

    *   Validate the generated CSV format (columns and row count).
