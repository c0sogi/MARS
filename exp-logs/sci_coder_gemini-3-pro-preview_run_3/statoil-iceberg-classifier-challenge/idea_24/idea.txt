Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Contrast-Aware Max-Attentive CNN (CAMA-CNN)**.

This solution represents a structural evolution of the robust "Simple CNN" baseline (Idea 4, Idea 20). It synthesizes the stability of the **Plain CNN** backbone (Cite solution_lesson_node_00046) with the signal-preserving properties of **LeakyReLU** (Cite solution_lesson_node_00091). The core structural innovation is the introduction of a **Contrast-Aware Architecture**, utilizing **Max-Squeeze-and-Excitation** and **Dual Global Pooling** to explicitly model the Signal-to-Clutter Ratio (SCR), which is the fundamental physical discriminator for icebergs in SAR imagery.

# Model
The architecture is a **Custom 4-Stage Convolutional Network** designed to detect high-intensity peaks while characterizing the background clutter floor.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly choose this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Max-SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This allows the network to preserve negative values (e.g., radar shadows or normalized dips) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy (Early Expansion):** The channel dimensions are strictly configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050) but cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation 1 (Max-SE Attention):** We replace standard SE (which uses Average Pooling) with a **Max-Squeeze-and-Excitation Module**.
    *   **Rationale:** In SAR imagery, an iceberg is a sparse, high-intensity peak. Average pooling washes out this signal. By using **Global Max Pooling** in the SE squeeze step, the network upweights channels that contain *any* strong peak, aligning the attention mechanism with the "Max Pooling Inductive Bias" proven effective for this dataset (Cite solution_lesson_node_00007).
*   **Structural Innovation 2 (Dual Global Pooling):** At the final layer, we apply both **Global Max Pooling** and **Global Average Pooling** to the feature maps.
    *   **Rationale:** Global Max Pooling captures the target intensity (Iceberg). Global Average Pooling captures the background clutter level (Sea State). By concatenating both ($[Max(x), Avg(x)]$), we allow the dense classifier to learn the **Signal-to-Clutter Ratio (Contrast)**, providing a robust physical basis for classification that Max Pooling alone misses.
*   **Feature Fusion (Raw Scale):** The concatenated vectors ($128_{max} + 128_{avg}$) are fused with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. We use high dropout (0.5) to regularize the increased feature space (Cite solution_lesson_node_00091) and apply it only after activation (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained to avoid artifacts (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent instability (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to ensure convergence under strong regularization (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
