This script demonstrates the usage of the provided library modules for the Iceberg vs Ship classification task. It covers data loading, dataset creation, model instantiation, a single training step, and a full engine execution with minimal parameters for speed.

The implementation strategy is as follows:
1.  **Data Loading**: Use `library.utils.load_data` to load and process the raw JSON data into numpy arrays, validating shapes and types.
2.  **Dataset & DataLoader**: Instantiate `library.dataset.IcebergDataset` with a small subset of data to verify tensor conversion and batch shapes.
3.  **Model Verification**: Initialize `library.model.CAMA_CNN`, pass a dummy batch through it, and verify the output dimensions.
4.  **Training Loop**: Manually execute `library.model.train_one_epoch` and `library.model.validate` on a small batch to ensure the optimization step works without errors.
5.  **Full Engine Run**: Execute `library.engine.run` with reduced hyperparameters (`epochs=1`, `n_folds=2`) to demonstrate the end-to-end pipeline and submission file generation within the time limit.
