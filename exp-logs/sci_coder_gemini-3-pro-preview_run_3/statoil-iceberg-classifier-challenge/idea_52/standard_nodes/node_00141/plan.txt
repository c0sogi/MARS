The orchestration script `runfile.py` implements the full 5-Fold Cross-Validation pipeline using the provided library modules. It loads the cached data, iterates through the folds to train the `MS_IDPH_CNN` model using the `Trainer` class, and aggregates out-of-fold predictions to compute the final Log Loss metric. Following validation, it performs failure analysis by correlating the per-sample Log Loss with input features (incidence angle and band means). Finally, if the validation metric meets the specified threshold, it generates an ensemble prediction on the test set and saves the submission file.
