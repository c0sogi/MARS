Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Ensembled Robust Micro-ResNet (ERM-ResNet)**.

This solution synthesizes the superior feature extraction capabilities of the Residual architecture (demonstrated in Idea 5) with the rigorous regularization and ensembling pipeline of the current best baseline (Idea 4). It explicitly corrects the implementation flaws that caused previous ResNet iterations to fail (e.g., initialization scaling, width overfitting, and TTA degradation).

### Model
The architecture is a **Custom Micro-Residual Network** designed to balance gradient flow with strict capacity constraints.

*   **Backbone:** The network transitions from the "Simple CNN" stack to a **Residual Backbone**. This decision is based on the finding that the single-model ResNet (Idea 5) significantly outperformed the single-model Simple CNN (0.1999 vs. ~0.2440 validation loss), proving it is a stronger base learner (Cite solution_lesson_node_00027).
    *   **Structure:** The network consists of an initial convolutional stem followed by three stages of Residual Blocks. Each block employs a `Conv-BN-ReLU-Dropout2d-Conv-BN` structure with a skip connection.
    *   **Width Constraint:** The channel dimensions are strictly capped at **128** (Stages: 64 $\to$ 128 $\to$ 128). We explicitly avoid expanding to 256 or 512 channels to prevent the overfitting observed in wider variants (Cite solution_lesson_node_00026).
    *   **Structural Regularization:** We incorporate **Spatial Dropout (Dropout2d)** within the residual blocks. Unlike dense dropout, this drops entire feature maps to prevent channel co-adaptation, providing structural regularization suitable for spatial data.
    *   **Exclusion of Attention:** We explicitly **exclude** Squeeze-and-Excitation (SE) blocks. While powerful, previous experiments suggested that attention mechanisms increased the hypothesis space too much for this small dataset, leading to overfitting on noise (Cite solution_lesson_node_00031).
*   **Pooling Strategy:** The final feature maps are processed using **Global Max Pooling**. This is retained to preserve the sparse, high-intensity peak signals (icebergs) and avoid the signal dilution observed with Average Pooling (Cite solution_lesson_node_00007).
*   **Feature Fusion (Late Fusion):** The flattened 128-dimensional vector is concatenated with the scalar **incidence angle**. We utilize Late Fusion rather than Conditional Batch Normalization to minimize parameter overhead (Cite solution_lesson_node_00039).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer** configuration: `Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   Dropout is applied *only* after the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).

### Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. We avoid upscaling to prevent computational overhead and artifacts (Cite solution_lesson_node_00009).
*   **Augmentation:** We use the optimized `torchvision.transforms` library for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset and was the key driver of the baseline's success (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent the instability and "confident errors" observed in unregularized runs (Cite solution_lesson_node_00036).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform). We explicitly reject manual fixed-scale initialization, which was identified as the root cause of failure in previous ResNet attempts (Cite solution_lesson_node_00045).

### Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Previous experiments demonstrated that TTA degrades performance on this directional SAR data (likely due to physics-violating flips of shadow/backscatter features), dragging down the ensemble score (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
