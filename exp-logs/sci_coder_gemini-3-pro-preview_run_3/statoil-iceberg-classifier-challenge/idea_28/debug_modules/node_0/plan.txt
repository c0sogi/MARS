The following is an implementation strategy and the complete Python script to verify the provided library components.

### Implementation Strategy

1.  **Configuration Override**: We will override the default settings in `library.config` to create a fast demonstration environment. This includes setting `NUM_EPOCHS=2`, reducing `NUM_FOLDS`, and redirecting the `WORKING_DIR` to a separate folder (`./working/demo_run`) to ensure clean execution without interfering with other runs. We must also manually update the dependent path variables (like `CACHE_PATH_X_TRAIN`) since they are initialized at import time.
2.  **Data Pipeline Verification**: We will use `library.dataset` to load the data. We will explicitly disable cache loading (`load_cached_data=False`) to demonstrate the raw data processing capability. We will assert the shapes of the batches yielded by the DataLoaders to ensure the image reshaping (75x75) and channel stacking (HH, HV, Avg) are correct.
3.  **Model Instantiation**: We will instantiate the `SHH_SE_CNN` model from `library.model` and move it to the configured device (GPU/CPU). We will perform a dummy forward pass with a batch of data to verify that the model architecture accepts the inputs (images + incidence angles) and produces the expected output shape.
4.  **Training Loop**: We will execute a short training loop using `library.engine.train_one_epoch` and `library.engine.evaluate`. We will integrate `library.engine.EarlyStopping` to handle checkpoint saving.
5.  **Inference and Submission**: After training, we will use `library.utils.load_checkpoint` to reload the best model weights. We will then generate predictions on the test set using `library.dataset.get_test_loader`, format the results into a DataFrame, and save a sample submission file to verify the end-to-end workflow.
