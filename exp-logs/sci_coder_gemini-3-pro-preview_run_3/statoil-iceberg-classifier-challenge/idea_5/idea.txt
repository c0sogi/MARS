# Solution: Custom Micro-ResNet with Channel Constraints

### Model
I propose a structural evolution from the simple stacked CNN to a **Custom Shallow Residual Network (Micro-ResNet)**. This architecture leverages residual connections to enhance gradient flow and feature preservation, allowing the model to learn more robust representations than the plain CNN without increasing the parameter count to the level of unstable Deep/Dense networks (Cite solution_lesson_node_00015).

*   **Backbone:** The network consists of an initial convolutional stem followed by three stages of **Residual Blocks**. Each block employs a standard `Conv-BN-ReLU-Conv-BN` structure with a skip connection adding the input to the output.
    *   **Squeeze-and-Excitation (SE):** To retain the channel-wise attention benefits of the previous best approach, an SE module is integrated within each residual block.
    *   **Width Constraint:** Crucially, the channel width is strictly capped. The stages will progress as **64 $\to$ 128 $\to$ 128** filters. We explicitly avoid expanding to 256 or 512 channels to prevent the overfitting observed when aggressive width expansion was applied to this small dataset (Cite solution_lesson_node_00026).
*   **Pooling Strategy:** The final 128-channel feature maps are processed using **Global Max Pooling**. This is retained to preserve the sparse, high-intensity peak signals characteristic of icebergs, avoiding the signal dilution caused by Average Pooling (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The 128-dimensional pooled vector is concatenated with the scalar **incidence angle**.
*   **Classification Head:** The fused vector is passed through a specific dense block designed to preserve signal integrity: `Dense(512) -> ReLU -> Dropout -> Dense(1) -> Sigmoid`. Note that Dropout is applied *only* after the first dense projection, not on the compact input vector, to avoid destroying the compressed signal (Cite solution_lesson_node_00017).

### Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. No upscaling is performed, as training a custom model on native resolution has proven superior to adapting pre-trained ImageNet models (Cite solution_lesson_node_00009).
*   **Augmentation:** Data augmentation is applied using the optimized **`torchvision.transforms`** library (RandomHorizontalFlip, RandomVerticalFlip) to ensure stability and reproducibility (Cite solution_lesson_node_00013).

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation**. This is essential to reduce variance and produce a robust estimator given the small sample size (Cite solution_lesson_node_00016).
*   **Initialization:** The network is trained **from scratch** with all layers trainable. No layers are frozen, as freezing random weights prevents feature learning (Cite solution_lesson_node_00012).
*   **Optimization:** The Adam optimizer is used with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers (decay), relying on the implicit regularization of the constant step size to prevent the model from overfitting to noise in the later stages of training (Cite solution_lesson_node_00019).
*   **Loss Function:** Binary Cross-Entropy (Log Loss).

### Evaluation
*   **Inference:** Predictions are generated using **Test-Time Augmentation (TTA)**. For each test image, the model predicts probabilities for the original and flipped versions, averaging the results.
*   **Ensembling:** The final submission probability for each ID is the average of the TTA predictions from all **5 models** trained in the Cross-Validation loop (Cite solution_lesson_node_00016).
