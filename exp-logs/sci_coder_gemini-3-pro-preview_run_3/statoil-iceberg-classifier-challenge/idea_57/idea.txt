Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Wide-Attention Isomorphic Dual-Polarity CNN (WA-IDPH-CNN)**.

This solution represents the precise structural synthesis of the most effective components identified to date, explicitly correcting the implementation errors that caused previous "advanced" models (like Idea 53 and Idea 56) to fail. It combines the robust **Plain CNN** backbone (Cite solution_lesson_node_00046) with a **Decoupled Isomorphic Readout** (correcting the projection flaws of Lesson 144/142). Crucially, it introduces **Wide-Attention Squeeze-and-Excitation**, which mitigates the information bottleneck of standard SE modules (Cite solution_lesson_node_00109) without succumbing to the noise sensitivity of Statistical SE (Cite solution_lesson_node_00145).

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed feature extraction without information bottlenecks.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Wide-SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).

*   **Structural Innovation 1 (Wide-Attention Squeeze-and-Excitation):**
    *   We replace the standard SE module (Reduction Ratio $r=16$) with a **Wide-SE Module** (Reduction Ratio $r=2$).
    *   **Squeeze:** We use **Global Average Pooling** (Cite solution_lesson_node_00104).
    *   **Excitation:** The MLP structure is `Linear(128 -> 64)` $\to$ `LeakyReLU` $\to$ `Linear(64 -> 128)` $\to$ `Sigmoid`.
    *   **Rationale:** Standard SE compresses 128 channels to 8, creating a severe information bottleneck that hinders the modeling of complex channel interdependencies. By reducing the compression ratio to 2, we allow the network to learn richer global context (Cite solution_lesson_node_00109) while avoiding the noise sensitivity of higher-order statistics (Cite solution_lesson_node_00145).

*   **Structural Innovation 2 (Decoupled Isomorphic Readout):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Decoupled Projections:** We use **separate** 1x1 Convolutional layers for Stage 3 (`Proj3`) and Stage 4 (`Proj4`). This allows the model to learn depth-specific transformations, correcting the shared-weight flaw of previous attempts (Cite solution_lesson_node_00144).
    *   **Isomorphic Dual-Polarity:**
        *   **Stage 3:** `Proj3(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
        *   **Stage 4:** `Proj4(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
    *   **Coherence:** Within each stage, Max and Min pooling operate on the *same* projected feature map, ensuring they describe the dynamic range of the same latent features (Cite solution_lesson_node_00142).
    *   **Result:** A 256-dimensional vector ($64_{max3}+64_{min3}+64_{max4}+64_{min4}$) that captures Signal-to-Shadow Contrast without parameter explosion (Cite solution_lesson_node_00124, solution_lesson_node_00134).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057, solution_lesson_node_00141).

*   **Classification Head:** A single hidden layer: `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from the adaptive gradient updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
