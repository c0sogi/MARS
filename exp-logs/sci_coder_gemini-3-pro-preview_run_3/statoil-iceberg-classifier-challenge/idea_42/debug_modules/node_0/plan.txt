### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and modify its attributes at runtime to define a specific working directory (`./working/demo_usage`) and enable debug mode. This ensures the demonstration runs quickly on a small subset of data without modifying the provided library files.
2.  **Data Loading Verification**: Use `library.utils.load_dataset` to load training and test data. Verify the data types and shapes of the returned numpy arrays (images, angles, and labels/ids).
3.  **Layer Verification**: Instantiate `MaxBlurPool2d` and `SEModule` from `library.layers`. Pass dummy tensors through them to verify that the output shapes match the expected behavior (e.g., spatial downsampling for pooling, channel preservation for SE).
4.  **Dataset and DataLoader Verification**: Use `library.data.get_dataloaders` to create PyTorch DataLoaders. Fetch a single batch to confirm the tensor shapes for images, angles, and labels are correct and ready for the model.
5.  **Model Architecture Verification**: Instantiate the `AAHACNN` model from `library.model`. Perform a forward pass with dummy data to ensure the model executes without errors and produces an output tensor of shape `(Batch_Size, 1)`.
6.  **Full Training Pipeline Verification**: Execute `library.train.run_kfold` with reduced parameters (`n_folds=2`, `epochs=1`) to simulate a full training and inference cycle.
7.  **Submission Verification**: Check that the submission file is generated in the correct location and adheres to the required CSV format.
