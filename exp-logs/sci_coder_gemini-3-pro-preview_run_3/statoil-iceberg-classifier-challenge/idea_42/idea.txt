Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Anti-Aliased Hybrid-Attentive Plain CNN (AAHA-CNN)**.

This solution represents a structural evolution of the **Plain CNN** backbone (Idea 30). It addresses a fundamental signal processing limitation in the current best architecture: standard Max Pooling violates the Nyquist sampling theorem, introducing **aliasing** and **shift-variance**. In sparse target detection (icebergs), this means a small spatial shift of the input can drastically alter the feature representation, creating instability. By integrating **Anti-Aliased Downsampling (MaxBlurPool)**, this solution robustifies the network against translation and speckle noise while retaining the successful **Hybrid SE** and **Selective Hierarchical** components.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for shift-invariant feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **SE Module** $\to$ **MaxBlurPool**.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout to preserve semantic negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation (Anti-Aliased Downsampling):** We replace standard `MaxPool2d` with **MaxBlurPool**.
    *   **Mechanism:** The operation is decoupled into two steps: (1) Max Pooling with stride 1 (to extract peaks), followed by (2) a fixed low-pass filter (e.g., a 3x3 Gaussian kernel) with stride 2 (to subsample).
    *   **Rationale:** Standard Max Pooling with stride > 1 ignores the sampling theorem, causing aliasing. By smoothing the feature map before subsampling, we improve the network's **shift invariance**, making it robust to small translations of the target and reducing high-frequency speckle artifacts without adding learnable parameters.
*   **Attention (Hybrid SE):** Within the SE Module, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes (Cite solution_lesson_node_00104).
*   **Readout Strategy (Selective Hierarchical Max Pooling):**
    *   We apply **Global Max Pooling** to the output of **Stage 3** (medium-scale) and **Stage 4** (abstract).
    *   We explicitly **exclude** Stage 1 and 2 to filter noise (Cite solution_lesson_node_00035).
    *   **Pooling Type:** We strictly use **Max Pooling** for the readout to capture sparse, high-intensity iceberg peaks (Cite solution_lesson_node_00007, solution_lesson_node_00102).
*   **Feature Fusion (Raw Scale):** The pooled vectors are concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from the adaptive gradient updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019, solution_lesson_node_00030).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
