The following is the implementation of `runfile.py` which orchestrates the 5-Fold Stratified Cross-Validation, training, evaluation, and submission generation using the provided library modules.

**Strategy Outline:**
1.  **Configuration**: Initialize the environment and override `EPOCHS` to 2 to ensure the "fast baseline" requirement is met while maintaining sufficient convergence.
2.  **Data Loading**: Load the metadata CSVs (`train.csv`, `val.csv`, `test.csv`).
3.  **Cross-Validation**: Perform 5-Fold Stratified Split on the training data. For each fold:
    -   Process data using `library.data.process_data` with unique cache prefixes.
    -   Train the `TweetModel` (DeBERTa-v3-Large with Dual Heads) using `library.engine.train_fn`.
    -   Save model weights to the working directory.
4.  **Final Validation**:
    -   Load the hold-out validation set (`val.csv`) and process it as a test set (to preserve neutral rows).
    -   Perform inference using an **ensemble** of the 5 trained models. The predictions are generated by averaging logits and applying the Hybrid Decoding strategy (Start + End + Content Score).
    -   Calculate the Jaccard score against the ground truth.
    -   **Constraint Check**: Only proceed to submission if the score exceeds the threshold (0.7164...).
5.  **Failure Analysis**: Compute and print correlations between prediction error (1 - Jaccard) and input text length (char/word) to identify error patterns.
6.  **Submission**: If the validation score is sufficient, generate predictions for `test.csv` using the ensemble, apply the deterministic rule for neutral tweets, and save the result to `submission.csv` with appropriate quoting.
