The following implementation demonstrates the complete pipeline for the Tweet Sentiment Extraction task using the provided library modules.

**Strategy:**
1.  **Configuration & Setup**: We initialize the `Config` class, overriding defaults to enable `debug` mode and reduce the number of epochs for rapid execution. We also switch the model backbone to `distilroberta-base` to significantly speed up the demonstration compared to the default `deberta-v3-large`.
2.  **Data Preparation**: We load the tokenizer and generate PyTorch DataLoaders for training, validation, and testing using `get_dataloaders` and `get_test_loader`. We verify the integrity of the data batches (shapes and keys) using assertions.
3.  **Model Initialization**: We instantiate the `TweetModel` with the lighter backbone.
4.  **Training & Evaluation**: We execute a single training epoch using `train_fn` and evaluate performance using `eval_fn`, printing the resulting Loss and Jaccard scores.
5.  **Inference**: We generate predictions on the test set, applying the hybrid decoding logic (start/end logits + content mask) manually for the test loop (since `eval_fn` is designed for validation with ground truth).
6.  **Submission**: We format the predictions into a CSV file matching the submission requirements and verify its structure.
