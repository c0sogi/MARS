Implementation strategy:
1.  **Setup & Data**: Initialize the `Config` and set random seeds. Use the provided `prepare_data` function to load the training data, which merges the provided train and validation sets, filters out neutral sentiments (as they are trivial) and impossible targets, and creates 5 stratified folds.
2.  **Training Loop**: Iterate through the 5 folds. For each fold:
    *   Initialize the `TweetDataset` and `DataLoader` for training and validation subsets.
    *   Instantiate the `TweetModel` (DeBERTa-v3 with Weighted Layer Pooling and Multi-Sample Dropout).
    *   Train for 3 epochs using `AdamW` optimizer and a cosine schedule. Implement a custom training loop with `GradScaler` (Mixed Precision) to ensure speed on the A100 GPU.
    *   Save the model weights that achieve the best Jaccard score on the validation fold.
    *   Perform inference on the validation fold (OOF) using the best model to gather predictions for non-neutral samples.
3.  **Global Validation**: Load the official hold-out validation set (`metadata/val.csv`). Compute the final Jaccard metric by comparing the ground truth against the OOF predictions. For neutral samples (which were excluded from training), predict the input text itself. For non-neutral samples, use the model's prediction.
4.  **Failure Analysis**: Calculate the correlation between the error (1 - Jaccard) and the length of the input text to identify if longer tweets are harder to predict.
5.  **Submission**: If the validation metric exceeds the threshold (0.7093), load the test set. Perform inference using an ensemble of all 5 trained models (averaging logits) to ensure robustness. Decode the spans using joint probability maximization. Save the results to `submission.csv` in the required format.
