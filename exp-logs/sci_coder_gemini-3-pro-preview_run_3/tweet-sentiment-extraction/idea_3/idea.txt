Based on the comprehensive analysis of the provided lessons and previous ideas, I propose the following optimized strategy. This solution evolves the successful DeBERTa-v3 baseline by introducing a more sophisticated classification head (Weighted Layer Pooling and Multi-Sample Dropout) to better capture the syntactic boundaries of sentiment spans, while strictly adhering to the data and inference constraints identified as optimal in the lessons.

### Model
**Backbone: DeBERTa-v3-base**
I will utilize the **DeBERTa-v3-base** architecture. Its disentangled attention mechanism—which separates content and relative position embeddings—has proven superior for precise boundary detection compared to absolute position models like RoBERTa Cite {solution_lesson_node_00014}.

**Head: Weighted Layer Pooling & Multi-Sample Dropout**
Instead of a simple linear layer on top of the final hidden state, I will implement a custom head to improve feature extraction:
1.  **Weighted Layer Pooling:** The model will extract the hidden states from the **last four layers** of the encoder. A set of learnable scalar weights will be applied to these layers to compute a weighted average. This allows the model to leverage both the high-level semantic understanding (top layers) and the low-level syntactic information (lower layers) necessary for identifying phrase boundaries.
2.  **Multi-Sample Dropout:** I will re-introduce **Multi-Sample Dropout**, previously attempted in a flawed configuration Cite {solution_lesson_node_00009}. By applying multiple varying dropout masks (e.g., 5) to the pooled output and averaging the resulting logits, this component will act as an internal ensemble. This specifically addresses the overfitting on noisy labels observed in earlier iterations Cite {solution_lesson_node_00007}.

### Data
**Preprocessing & Filtering**
1.  **Neutral Exclusion:** All training rows with "neutral" sentiment will be **excluded**. The model will not be trained on these samples, as they represent a trivial identity mapping that dilutes gradients Cite {solution_lesson_node_00006}.
2.  **Alignment Filtering:** I will filter out training samples where the character-level `selected_text` cannot be cleanly mapped to token offsets (e.g., due to destructive tokenization). This prevents the model from training on "impossible" or misaligned targets Cite {solution_lesson_node_00016}.

**Target Generation**
I will generate targets using a **mask-based overlap approach**. A binary mask corresponding to the character span will be projected onto the token sequence; any token with non-zero overlap will be labeled as part of the target. This is more robust to annotation noise than strict start/end offset matching Cite {solution_lesson_node_00012}.

### Training
**Objective Function**
The model will be trained using **Cross-Entropy Loss with Label Smoothing (0.1)**. This prevents the model from becoming overconfident in the subjective boundaries of the training data, encouraging better generalization Cite {solution_lesson_node_00010}.

**Constraints & Hyperparameters**
To maintain efficiency and prevent overfitting:
-   **Epochs:** Strictly limited to **3 epochs**.
-   **Batch Size:** Set to **32**.
-   **Sequence Length:** Capped at **96 tokens**.
These constraints match the data density and prevent the model from memorizing noise Cite {solution_lesson_node_00007}.

### Evaluation
**Inference Pipeline**
1.  **Deterministic Route:** If the sentiment is "neutral", the pipeline will bypass the model and return the entire `text` string Cite {solution_lesson_node_00006}.
2.  **Probabilistic Route:** For "positive" and "negative" tweets, the model will predict start and end probabilities.
3.  **Joint Decoding:** Instead of independent selection, I will compute the **outer product** of the start and end probability vectors to form a joint probability matrix. I will mask invalid transitions (where `start_index > end_index`) and select the span $(i, j)$ that maximizes the joint probability Cite {solution_lesson_node_00013}.

**Ensembling**
To further stabilize predictions, I will employ a **5-Fold Cross-Validation Ensemble**. The final start and end probabilities will be the average of the outputs from 5 models trained on different stratified folds of the data.
