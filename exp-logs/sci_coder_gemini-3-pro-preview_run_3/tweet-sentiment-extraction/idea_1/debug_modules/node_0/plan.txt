This script demonstrates the end-to-end usage of the provided library files to solve the tweet sentiment extraction task. It performs the following steps:

1.  **Initialization**: Sets the random seed for reproducibility using `library.utils`.
2.  **Data Loading**: Loads the training, validation, and test datasets using `library.data_loader`. It asserts that the data is loaded correctly and contains the necessary columns.
3.  **Utility Verification**: Validates the `jaccard` function from `library.utils` with test cases to ensure the metric calculation is correct.
4.  **Model Training**: Instantiates the `SentimentRelevanceModel` from `library.model` and fits it on the training data. It explicitly disables caching (`load_cached_data=False`) to demonstrate the weight computation process.
5.  **Evaluation**: Evaluates the model on the validation set and asserts that the performance is within a reasonable range.
6.  **Inference**: Generates predictions for the test set and saves them to the submission file.
7.  **Submission Verification**: Checks the generated submission file for correct dimensions, column names, and absence of missing values.
