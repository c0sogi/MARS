This script demonstrates the usage of the provided Sentiment Extraction library components. It performs the following steps:
1.  **Configuration**: Overrides the default `Config` to use a temporary working directory and reduced batch sizes for the demonstration.
2.  **Utility Verification**: Validates the `jaccard` scoring function with known inputs.
3.  **Data Loading**: Uses `get_loaders` to load the training data, then creates a small subset (mini-batch) to ensure the training demonstration runs quickly.
4.  **Model Initialization**: Instantiates the `TweetModel` (DeBERTa-v3-Large backbone).
5.  **Adversarial Weight Perturbation (AWP) Verification**:
    *   Performs a forward and backward pass to populate gradients.
    *   Initializes AWP and performs an attack step.
    *   Asserts that model weights have changed.
    *   Restores weights and asserts they match the original state.
6.  **Training Loop**: Runs `train_fn` on the mini-dataset to demonstrate the training process without executing a full epoch.
7.  **Inference & Decoding**: Simulates model logits and validates the `get_best_start_end_idxs` function to ensure correct span extraction logic.
