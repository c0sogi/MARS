Based on the comprehensive analysis of the provided lessons and the performance trajectory of previous ideas, I propose the following optimized strategy. This solution retains the high-capacity **DeBERTa-v3-Large** backbone and the rigorous data protocols established in the "Current Best Solution," but introduces **Adversarial Weight Perturbation (AWP)** as a structural innovation in the training loop. This addresses the "aleatoric uncertainty" and generalization issues on noisy labels (identified in Lesson {solution_lesson_node_00024}) more effectively than the failed passive regularization (Lesson {solution_lesson_node_00025}) or self-training approaches (Lesson {solution_lesson_node_00031}).

# Model
**Backbone: DeBERTa-v3-Large**
I will utilize the **`microsoft/deberta-v3-large`** architecture. This model is retained because its disentangled attention mechanism provides superior boundary detection capabilities compared to RoBERTa (Cite {solution_lesson_node_00014}), and the "Large" variant offers the necessary capacity to resolve complex sentiment contexts (Cite {solution_lesson_node_00023}).

**Head: Simple Linear Classification**
I will strictly employ a **Simple Linear Head** (outputting Start/End logits) attached to the final hidden layer. I will explicitly reject complex heads like Weighted Layer Pooling or Multi-Task Content Heads, as previous experiments demonstrated that aggregating lower layers or adding auxiliary tasks dilutes the spatial precision required for this task (Cite {solution_lesson_node_00018}, Cite {solution_lesson_node_00027}).

# Data
**Preprocessing (Exploitation)**
1.  **Raw Input Fidelity:** The model will process **raw, unmodified text**. I will avoid whitespace normalization, as this destroys structural cues and degrades performance (Cite {solution_lesson_node_00020}).
2.  **Neutral Exclusion:** Training data will be filtered to exclude "neutral" sentiment rows, as they represent a trivial identity mapping that wastes model capacity (Cite {solution_lesson_node_00006}).
3.  **Alignment Filtering:** Samples where character labels cannot be cleanly mapped to tokens will be discarded to prevent training on noise (Cite {solution_lesson_node_00016}).
4.  **Target Generation:** Targets will be generated using **Mask-Based Overlap**, where any token overlapping the character span is part of the target, providing robustness against annotator noise (Cite {solution_lesson_node_00012}).
5.  **Full Dataset Utilization:** I will perform 5-Fold Cross-Validation on the **entire** labeled dataset, avoiding the use of a fixed hold-out set which was shown to degrade performance by reducing training signal (Cite {solution_lesson_node_00028}).

# Training
**Structural Innovation: Adversarial Weight Perturbation (AWP)**
To address the overfitting to noisy labels without the "blurring" effect of aggressive dropout (Cite {solution_lesson_node_00025}), I will integrate **Adversarial Weight Perturbation (AWP)** into the training loop.
-   **Mechanism:** For each training step, after the standard forward and backward pass, the algorithm will compute an adversarial perturbation $\delta$ (maximizing the loss) and inject it into the model's embeddings. A second forward and backward pass is then performed on these perturbed weights to update the model.
-   **Rationale:** This effectively minimizes the "worst-case" loss in the neighborhood of the current weights, forcing the model to find a flatter minimum in the loss landscape. This improves generalization on the "positive" and "negative" classes where boundary ambiguity is high.

**Standard Parameters:**
-   **Objective:** Cross-Entropy with Label Smoothing (0.1) to prevent overconfidence (Cite {solution_lesson_node_00010}).
-   **Constraints:** 3 Epochs (AWP enabled after Epoch 1 to ensure stable initialization), Batch Size 32, Max Length 96 (Cite {solution_lesson_node_00007}).

# Evaluation
**Inference Pipeline**
1.  **Deterministic Rule:** If sentiment is "neutral", return the entire `text` (Cite {solution_lesson_node_00006}).
2.  **Ensemble Summation Decoding:** For "positive" and "negative" samples, average the logits from all 5 fold-models. Select the span $(i, j)$ that maximizes the **sum of probabilities** ($P_{start}(i) + P_{end}(j)$). This method is empirically superior to joint probability maximization for fuzzy boundaries (Cite {solution_lesson_node_00019}).
