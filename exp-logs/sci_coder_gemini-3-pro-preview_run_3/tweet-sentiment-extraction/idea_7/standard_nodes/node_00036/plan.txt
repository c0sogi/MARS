The strategy involves optimizing the training pipeline by reverting to **Full-Dataset Cross-Validation** (Cite solution_lesson_node_00028) and disabling **Adversarial Weight Perturbation (AWP)** (Cite solution_lesson_node_00035).

1.  **Full-Dataset CV**: The previous solution used a fixed hold-out set, which underutilized the available data (~20% less training data). By training on the full `input/train.csv` using 5-fold CV, we maximize the data available for the model to learn complex patterns.
2.  **Disable AWP & Restore Epochs**: AWP was previously used with reduced epochs (2) to save time, but this degraded performance as AWP requires more iterations to converge. We disable AWP to improve training speed and restore the epoch count to 3 to ensure proper convergence of the DeBERTa-v3-Large model.
3.  **OOF Evaluation**: We replace the hold-out validation logic in `runfile.py` with an Out-Of-Fold (OOF) evaluation loop. This ensures we generate unbiased predictions for the entire training set to calculate a reliable global Jaccard score.
