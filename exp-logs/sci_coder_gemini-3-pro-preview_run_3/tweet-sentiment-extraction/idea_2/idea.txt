To solve the task of extracting sentiment-supporting phrases from tweets, I propose a strategy that evolves the previous RoBERTa-based approach by upgrading the backbone architecture, refining the classification head, and aligning the training objective directly with the evaluation metric.

### Model
**Backbone: DeBERTa-v3 (Decoding-enhanced BERT with Disentangled Attention)**
I will replace the RoBERTa backbone with **DeBERTa-v3**. Unlike RoBERTa, which adds absolute position embeddings to content embeddings, DeBERTa uses a disentangled attention mechanism that represents each word using two vectors: one for content and one for relative position. This structural innovation allows the model to better capture the dependency between the sentiment label (context) and the specific phrase location (span), which is critical for this extraction task.

**Head: Multi-Sample Dropout**
To address the overfitting observed in previous attempts Cite {solution_lesson_node_00007}, I will implement a **Multi-Sample Dropout** head. Instead of a single dropout layer followed by a linear classifier, the model will use multiple dropout masks (e.g., 5) in parallel. The outputs will be averaged before the final prediction. This technique acts as an internal ensemble, smoothing the gradients and improving generalization on the noisy, subjective labels found in this dataset.

### Data
**Preprocessing**
The text will be tokenized using the DeBERTa-v3 tokenizer (SentencePiece), which treats whitespace differently than RoBERTa's BPE, requiring careful offset mapping to ensure the predicted tokens align perfectly with the original character indices for the final quoted string output.

**Stratified Filtering**
I will strictly **exclude all "neutral" samples from the training dataset**. As identified in the lessons, "neutral" tweets have a near-perfect overlap between `text` and `selected_text`. Training the model on this trivial identity mapping wastes capacity and dilutes the gradients for the difficult "positive" and "negative" cases Cite {solution_lesson_node_00006}.

### Training
**Objective: Compound Loss with Soft Jaccard**
Standard Cross-Entropy (CE) loss optimizes for exact start/end index matching, which is too rigid for this task where slightly shifted spans might still yield high Jaccard scores. I will introduce a **Soft Jaccard Loss** component. The total loss will be $L = L_{CE} + \lambda L_{SoftJaccard}$. This differentiable approximation allows the model to directly optimize the competition metric during training.

**Constraints**
To prevent overfitting to annotator noise, I will adhere to the optimal constraints identified previously:
- **Epochs:** Limit training to exactly **3 epochs**.
- **Sequence Length:** Set the maximum sequence length to **96 tokens**, covering the vast majority of tweets without unnecessary padding.
- **Batch Size:** Use a batch size of **32**. Cite {solution_lesson_node_00007}.

### Evaluation
**Inference Strategy**
1.  **Deterministic Rule:** For any test sample with "neutral" sentiment, the model will bypass the neural network and deterministically predict the entire `text`. Cite {solution_lesson_node_00006}.
2.  **Span Prediction:** For "positive" and "negative" samples, the model will predict start and end logits. The final span will be selected by maximizing the sum of start and end probabilities ($P_{start}(i) + P_{end}(j)$) subject to the constraint $i \le j$.
