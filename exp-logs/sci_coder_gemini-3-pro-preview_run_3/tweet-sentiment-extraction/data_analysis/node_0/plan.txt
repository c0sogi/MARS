Here is the implementation strategy and the complete Python script for the Exploratory Data Analysis.

### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries (`pandas`, `numpy`, `collections`, `scipy.stats`) and enforce reproducibility by setting random seeds.
2.  **Data Loading**: Load the training dataset from `./metadata/train.csv`. Perform a quick safety check to ensure no missing values exist in critical columns, although the metadata generation step should have handled this.
3.  **Target Variable Analysis**:
    *   Treat `sentiment` as the primary class label. Calculate and report its distribution and balance ratios.
    *   Treat `selected_text` as the extraction target. Analyze it in the context of the input text in later sections.
4.  **Input Data Analysis (Text Modality)**:
    *   **Lengths**: Calculate character counts and word counts for both the full tweet (`text`) and the target phrase (`selected_text`). Report descriptive statistics (mean, std, min, max).
    *   **Vocabulary**: Tokenize the text (using simple whitespace splitting) to calculate the total vocabulary size and the number of unique words. Identify "hapax legomena" (words appearing only once) as a proxy for rare words/OOV potential.
5.  **Feature/Signal Relationships**:
    *   **Meta-Feature Analysis**: Analyze how `sentiment` influences the length of the `selected_text`.
    *   **Jaccard Similarity**: Since the metric is Jaccard, calculate the Jaccard similarity between the `text` and `selected_text` for each row. Group these results by `sentiment` to uncover structural patterns (e.g., "neutral" tweets often having `selected_text` identical to `text`).
    *   **Correlations**: Calculate the Pearson correlation between the length of the original tweet and the length of the selected text.
6.  **Formatting**: Ensure the output is printed in clear, capitalized sections with floating-point numbers formatted to 4 decimal places.
