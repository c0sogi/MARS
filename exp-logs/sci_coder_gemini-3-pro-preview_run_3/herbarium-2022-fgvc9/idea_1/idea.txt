# Baseline Approach: MobileNetV3-Large Fine-Tuning

## Model
We propose using the **MobileNetV3-Large** architecture, a Convolutional Neural Network specifically designed for efficiency and low latency. Unlike the EfficientNetV2-S (Model 1), which prioritizes scaling accuracy, MobileNetV3 utilizes **depthwise separable convolutions** and **inverted residual blocks** with linear bottlenecks to drastically reduce parameter count and computational cost (FLOPs). It also incorporates lightweight **Squeeze-and-Excitation (SE)** modules to capture channel-wise dependencies with minimal overhead.

The model will be initialized with weights pre-trained on ImageNet-1k. The final classification head, originally designed for 1,000 classes, will be replaced with a single fully connected linear layer projecting the 1,280-dimensional feature vector to the **15,501 species categories**. This approach treats the problem as a flat classification task, ignoring the hierarchical taxonomy to maintain simplicity and establish a raw performance baseline.

## Data
To prioritize training throughput and minimize I/O bottlenecks:
1.  **Preprocessing**: All images will be resized to a fixed resolution of **224x224** pixels. This resolution is standard for pre-trained models and significantly reduces the memory footprint compared to the original high-resolution images.
2.  **Normalization**: Pixel values will be normalized using the standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`).
3.  **Augmentation**: To prevent basic overfitting without incurring the computational cost of heavy augmentations, we will apply only **Random Horizontal Flips** during training. No complex geometric transformations or color jitters will be used.

## Training
The training process focuses on rapid convergence and stability:
1.  **Loss Function**: We will use standard **Cross-Entropy Loss**. Given the relatively balanced nature of the dataset (most classes have ~30-50 images), we will not apply complex re-weighting schemes initially.
2.  **Optimizer**: We will use the **AdamW** optimizer, which decouples weight decay from gradient updates, generally providing better generalization than standard Adam.
3.  **Scheduler**: A **One-Cycle Learning Rate Policy** will be employed. This scheduler rapidly increases the learning rate to a maximum value and then anneals it down, allowing for "super-convergence" (training the model significantly faster than constant or step-decay schedules).
4.  **Mixed Precision**: We will utilize **Automatic Mixed Precision (AMP)** (FP16/FP32). This leverages the A100 GPU's Tensor Cores to speed up arithmetic operations and reduce memory usage, allowing for larger batch sizes.

## Evaluation
For the inference phase on the test set:
1.  **Preprocessing**: Images will be resized to **256x256** and then **Center Cropped** to **224x224**. This deterministic approach ensures that the central subject of the image is captured.
2.  **Prediction**: The model will perform a single forward pass for each image. We will apply an `argmax` operation on the output logits to select the `category_id` with the highest confidence score. No Test Time Augmentation (TTA) or multi-crop averaging will be performed to ensure the inference remains lightweight and fast.
