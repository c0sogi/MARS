The issue is a misuse of `torch.cuda.amp.GradScaler` in the training loop. The code incorrectly calls `scaler.scale(optimizer).step()`, but `scaler.scale()` expects a tensor (the loss) and returns a scaled tensor, not an object that handles the optimizer step. The correct usage is `scaler.step(optimizer)` to unscale the gradients and perform the optimization step. I will fix this in `library/trainer.py` as indicated by the traceback, and also apply the same fix to `library/model.py` where the same bug is present.
