The issue is caused by an API breaking change in `albumentations` version 2.0. The `RandomResizedCrop` transform no longer accepts separate `height` and `width` arguments; instead, it requires a single `size` argument as a tuple `(height, width)`. This mismatch triggers a Pydantic validation error because the mandatory `size` field is missing. I will update the `RandomResizedCrop` instantiation in `library/utils.py` to use `size=(image_size, image_size)`. Cite debug_lesson_3.
