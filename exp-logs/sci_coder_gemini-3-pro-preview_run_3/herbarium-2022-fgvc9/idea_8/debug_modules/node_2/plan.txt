The issue is that the `Trainer` initializes the best F1 score tracker (`self.best_f1`) to `0.0`. In the demo run, the model achieved a validation F1 score of exactly `0.0` in the first epoch. Since the code uses a strict inequality (`if val_f1 > self.best_f1`), the condition `0.0 > 0.0` failed, preventing the model checkpoint from being saved. This caused the subsequent `FileNotFoundError` in the script. To fix this, I will initialize `self.best_f1` to `-1.0` to ensure that an initial score of `0.0` is treated as an improvement and triggers a save. Cite debug_lesson_2.
