This out-of-bounds access triggers the assertion failure on the GPU.

2.  **Update `library/dataset.py`**: Modify `PlantDataset` to use the `species_to_label` map to convert raw IDs to contiguous labels during training.
3.  **Update `runfile.py`**: Modify the submission generation logic to map the model's predicted contiguous labels back to the original `category_id`s using the reverse mapping.
