The error is caused by a breaking change in the `albumentations` library (version 2.0+), where transforms like `RandomResizedCrop` and `CenterCrop` now require a single `size` tuple argument `(height, width)` instead of separate `height` and `width` arguments. The traceback confirms this with a `pydantic` validation error stating `Field required ... size`. To fix this, I will update the instantiation of `A.RandomResizedCrop` and `A.CenterCrop` in `library/dataset.py` to use the `size` parameter, conforming to the new API specification.
