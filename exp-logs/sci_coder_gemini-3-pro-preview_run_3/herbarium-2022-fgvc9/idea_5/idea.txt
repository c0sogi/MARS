# Proposed Strategy: Progressive Hierarchical EfficientNetV2

## Model
We propose a **Hierarchical EfficientNetV2-Small** architecture. This design evolves the flat classification of previous baselines by structurally integrating the taxonomic hierarchy provided in the dataset.
- **Backbone**: We will use **EfficientNetV2-Small**. This backbone provides a stronger feature extractor than the MobileNetV3 used in **Cite solution_lesson_node_00002**, while avoiding the excessive computational weight and convergence difficulties of the ConvNeXt-Tiny attempted in **Cite solution_lesson_node_00012**.
- **Multi-Task Heads**: The model will feature three parallel classification heads branching from the final feature map:
    1.  **Species Head**: 15,501 classes (Primary Task).
    2.  **Genus Head**: ~2,500 classes (Auxiliary Task).
    3.  **Family Head**: ~270 classes (Auxiliary Task).
    This structure forces the model to learn features that are taxonomically consistent, using the easier Family/Genus tasks to stabilize the learning of the fine-grained Species task.

## Data
- **Augmentation**: We will strictly implement **Strong Data Augmentation** (RandomResizedCrop, ShiftScaleRotate, ColorJitter). As demonstrated in **Cite solution_lesson_node_00004**, these invariances are critical for preventing overfitting and achieving high performance in long training runs.
- **Regularization**: We will apply **Label Smoothing (0.1)** to all heads **Cite solution_lesson_node_00004**. Crucially, we will **exclude Mixup and CutMix**. **Cite solution_lesson_node_00012** showed that these heavy regularizers can obscure the training signal and cause convergence failure when training time or model capacity is constrained.
- **Preprocessing**: We will merge the training metadata with the taxonomic information to generate targets for the Family and Genus heads.

## Training
We introduce a **Progressive Resolution Training** strategy. This structural innovation synthesizes the need for high resolution (to see details) with the need for stable, rapid convergence (learned from the failure in **Cite solution_lesson_node_00012**).

1.  **Stage 1: Feature Learning (Low Resolution)**
    -   **Resolution**: **224x224**.
    -   **Duration**: **12 Epochs**.
    -   **Strategy**: Train with a larger batch size to maximize throughput. This phase ensures the model learns robust, generalized features and converges to a good state quickly, adhering to the lesson that extended training duration is key to performance **Cite solution_lesson_node_00004**.
    -   **Optimizer**: AdamW with **OneCycleLR** **Cite solution_lesson_node_00002**.

2.  **Stage 2: Fine-Grained Refinement (High Resolution)**
    -   **Resolution**: **320x320** (or higher as memory permits).
    -   **Duration**: **8 Epochs**.
    -   **Strategy**: Fine-tune the pre-trained weights on higher-resolution inputs. This allows the model to resolve minute details (e.g., leaf venation) required for species-level distinction, which are lost at 224px. By starting from a converged state, we avoid the "cold start" failure observed when training high-resolution models from scratch **Cite solution_lesson_node_00012**.
    -   **Loss**: Weighted Multi-Task Cross-Entropy ($L_{total} = L_{species} + 0.1 L_{genus} + 0.1 L_{family}$).

## Evaluation
-   **Inference**: Predictions will be generated using the **Species Head** at the Stage 2 resolution (**320x320**).
-   **Test Time Augmentation (TTA)**: We will apply **Horizontal Flip TTA** (averaging predictions of the original and flipped image). This simple strategy reduces variance and improves the Macro F1 score on hard-to-classify examples without the computational cost of multi-crop methods.
