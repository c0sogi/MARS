The following script demonstrates the end-to-end workflow of the provided plant classification library. It overrides the default configuration to run in "Debug" mode, ensuring the process completes quickly by using a small subset of the data and training for only a single epoch.

The script performs the following steps:
1.  **Configuration**: Overrides `Config` parameters to set up a temporary working directory (`./working/demo_run`), enable debug mode (sampling 2000 train, 500 val, 500 test images), and reduce epochs to 1.
2.  **Hierarchy Processing**: Verifies the extraction of taxonomic hierarchy (Species -> Genus -> Family) from the metadata, ensuring the mapping DataFrame is correctly structured.
3.  **Data Loading**: Initializes the DataLoaders and validates the shape and types of a single batch of training data (images and hierarchical labels).
4.  **Model Initialization**: Instantiates the `HierarchicalEfficientNet` and performs a forward pass with the sample batch to verify the dimensions of the outputs from the three classification heads.
5.  **Training**: Executes the `fit()` function to train the model for one epoch. It asserts that the training completes and a model checkpoint is saved.
6.  **Inference**: Runs `predict_all()` using the trained checkpoint to generate predictions on the test subset. It verifies the existence and format of the generated `submission.csv`.
