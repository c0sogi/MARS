This script demonstrates the end-to-end usage of the provided library files for the plant classification task. It optimizes for speed by enabling the `DEBUG` mode in the configuration, which drastically reduces the dataset size to 64 samples and limits training to 1 epoch.

The script performs the following steps:
1.  **Configuration Override**: Modifies `Config` attributes to use a temporary working directory, small batch sizes, and disables pretrained weight downloading for speed.
2.  **Hierarchy Loading**: Verifies `load_hierarchy_mappings` correctly processes the metadata JSON and creates a cache.
3.  **Data Pipeline**: Tests `get_dataloaders` to ensure images and hierarchical targets (species, genus, family) are loaded correctly with the expected shapes.
4.  **Model Verification**: Instantiates `HierarchicalEfficientNet` and performs a forward pass to validate output logits for all three tasks.
5.  **Training Loop**: Executes the `fit` function from `library.train` for one epoch, ensuring the training pipeline runs and saves checkpoints.
6.  **Inference & Submission**: Runs `predict_tta` on the test set and generates a submission file using `generate_submission`, asserting the output format is correct.
