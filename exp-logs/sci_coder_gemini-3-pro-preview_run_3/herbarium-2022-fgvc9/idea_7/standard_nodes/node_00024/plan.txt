Implementation strategy:
1.  **Setup**: Import necessary libraries and the provided modules (`library.config`, `library.utils`, `library.data`, `library.model`, `library.train`, `library.inference`). Initialize seeding and logging.

3.  **Data Preparation**: Load the full training metadata, sample the subset, and save it to the working directory. Update `Config.TRAIN_CSV` to point to this subset.
4.  **Stage 1 Training**: Initialize the `HierarchicalEfficientNet` and train for 2 epochs at 224x224 resolution using `train.fit`.
5.  **Stage 2 Training**: Continue training the model for 1 epoch at 384x384 resolution using `train.fit`.
6.  **Validation**: Evaluate the final model on the **full** validation set using `train.validate`. Print the `Final Validation Metric` in the required format.
7.  **Failure Analysis**: Compute predictions on the validation set. Calculate the correlation between prediction error (0/1) and input features (File Size, Class Frequency) using `numpy`. Print these correlations.
8.  **Submission**: Compare the final validation F1 score against the threshold (0.5930838412243743). If the score is higher, execute the inference pipeline to generate `submission.csv`.
