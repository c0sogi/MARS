Based on the lessons learned from previous experiments, I propose the **Content-Adaptive Parametric Trajectory Network (CAP-Net)**.

This solution addresses the primary weaknesses of previous iterations: the failure to effectively model the temporal decay of lung function (Idea 3, **Cite solution_lesson_node_00025**) and the destruction of the strong linear baseline signal by normalization layers (Idea 5, **Cite solution_lesson_node_00017**). It introduces a structural innovation by reframing the regression task: instead of predicting a black-box value for every `Patient_Week`, the network predicts the **parameters of a linear trajectory** ($\alpha, \beta, \gamma$) specific to each patient's disease severity.

### 1. Model
The architecture is a hybrid CNN-MLP that outputs the coefficients of a dynamic affine transformation rather than the target value directly.

*   **Image Branch (Content-Adaptive 2.5D):**
    *   **Input:** Three slices per patient selected via the **Lung-Extent Heuristic** (Apical, Middle, Basal) to ensure anatomical consistency without geometric registration **Cite solution_lesson_node_00015**.
    *   **Backbone:** A shared, frozen **EfficientNet-B0**.
    *   **Feature Extraction:** We extract features *only* from the final convolutional layer (Global Average Pooling). We explicitly reject multi-scale pyramids to prioritize deep semantic signals (lung volume/shape) over low-level textures, which were found to dilute performance in volumetric regression **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated feature vector is projected to a lower dimension (e.g., 128) via a Linear layer to balance modalities **Cite solution_lesson_node_00008**.

*   **Fusion & Parameter Head:**
    *   **Inputs:** The projected image features are concatenated with embedded metadata (`Age`, `Sex`, `SmokingStatus`) and the **Standardized Baseline FVC**.
    *   **Late Fusion:** The `Baseline FVC` is injected directly at this fusion stage (not earlier) to prevent its strong signal from being drowned out by high-dimensional image data **Cite solution_lesson_node_00023**.
    *   **Architecture:** A Multi-Layer Perceptron (MLP) maps this fused vector to 4 scalar outputs: $\alpha$ (Baseline Coefficient), $\beta$ (Intercept Adjustment), $\gamma$ (Slope/Decay Rate), and $\delta$ (Uncertainty Raw).
    *   **Constraints:** This MLP contains **No Batch Normalization** **Cite solution_lesson_node_00010** and **No Dropout** **Cite solution_lesson_node_00007** to preserve the precision of the linear baseline signal and uncertainty calibration.

*   **Trajectory Prediction Logic (The Structural Innovation):**
    *   Instead of feeding `Weeks` into the MLP, we apply the predicted parameters to the temporal variable in a final equation:
        $$ \mu_{pred} = \alpha \cdot \text{Baseline}_{scaled} + \beta + \gamma \cdot \text{Weeks}_{scaled} $$
    *   This enforces a multiplicative interaction between the patient's condition (Image/Meta) and time ($Rate \times Time$), solving the temporal modeling failure observed in additive architectures **Cite solution_lesson_node_00022**. It also allows the model to learn the optimal autoregressive weight $\alpha$ (damping baseline noise) rather than hard-coding a residual **Cite solution_lesson_node_00016**.
    *   **Uncertainty:** $\sigma_{pred} = \text{softplus}(\delta) + 1\text{e-}3$. We do not enforce the 70ml clip here to allow gradient flow **Cite solution_lesson_node_00014**.

### 2. Data
*   **Preprocessing:**
    *   **Slice Selection:** For each patient, identify the slice with the maximum lung area (Anchor). Select two additional slices where the lung area drops to 50% of the maximum (Apical/Basal) **Cite solution_lesson_node_00015**.
    *   **Target Scaling:** The target `FVC` is **Z-score standardized** during training. This is mandatory to resolve the magnitude gap between initialization and targets **Cite solution_lesson_node_00006**.
    *   **Input Scaling:** `Baseline FVC` and `Weeks` are similarly standardized.

### 3. Training
*   **Loss Function:** Modified Laplace Log Likelihood ($L = \frac{|y - \mu|}{\sigma} + \ln(\sigma)$).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Duration:** **35 Epochs**. This extended duration is critical to allow the projection layers to converge and the uncertainty head to calibrate **Cite solution_lesson_node_00009**.
*   **Strategy:** The model learns to predict the *trajectory* of the disease. By decoupling the static severity assessment (MLP) from the temporal projection (Equation), we maximize the use of the limited training data.

### 4. Evaluation
*   **Inference:**
    *   Forward pass to get $\alpha, \beta, \gamma, \delta$.
    *   Calculate $\mu_{scaled}$ and $\sigma_{scaled}$ using the trajectory equation.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target\_dist} + \mu_{target\_dist}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target\_dist}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the metric-required clipping: $\sigma_{final} = \max(\sigma_{final}, 70)$ **Cite solution_lesson_node_00014**.
