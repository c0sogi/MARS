The implementation strategy involves creating a standalone Python script that performs a comprehensive Exploratory Data Analysis (EDA) on the lung fibrosis dataset. The script will first load the training metadata from the pre-generated `./metadata/train.csv` file. It will then analyze the target variable (`FVC`) for distribution properties and normality. For tabular data, it will compute descriptive statistics, check for outliers, and analyze categorical cardinality. For image data, it will sample a subset of patient directories to calculate metadata statistics like slice counts and file sizes, and attempt to use `pydicom` (with a graceful fallback if unavailable) to extract pixel-level statistics. Finally, it will explore feature relationships using correlation matrices and a Random Forest regressor to determine feature importance, ensuring all outputs are formatted clearly with 4 decimal precision.
