6.  **Validation & Failure Analysis**: Load the best model checkpoint. Perform inference on the full validation set. Calculate the official "Modified Laplace Log Likelihood" metric. Compute and print correlations between the absolute prediction error and input features (FVC, Age, Sex, Smoking, Time) to identify failure modes.
7.  **Submission Logic**: Check if the `Final Validation Metric` exceeds the threshold `-6.573619738753321`. If satisfied, generate predictions for the test set, apply the required confidence clipping (70ml), and save the result to `./submission/submission.csv`.
