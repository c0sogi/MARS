Based on the comprehensive analysis of the accumulated lessons, I propose the **Gated Metric-Aligned Residual Network (GMAR-Net)**.

This solution represents a structural evolution of the **Gated Clinical-Residual** (Idea 26) and **Dual-Stream** (Idea 13) architectures. It synthesizes the need for **Over-Parameterized Clinical Anchors** **Cite solution_lesson_node_00060** with a **Learnable Gating Mechanism** to explicitly address the "Capacity Mismatch" **Cite solution_lesson_node_00054** and "Signal Drowning" **Cite solution_lesson_node_00023** observed in previous iterations. Furthermore, it strictly enforces **Metric-Aligned Optimization** **Cite solution_lesson_node_00066** and removes heuristic shortcuts that caused premature convergence **Cite solution_lesson_node_00085**.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Gated Residual Topology** to predict lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for fine-grained texture analysis (e.g., reticulation), avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of heavier models like V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting **Cite solution_lesson_node_00065**.

*   **Stream A: Over-Parameterized Clinical Anchor (The Controller):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`. We exclude `Percent` to prioritize primitive features and avoid redundancy/leakage **Cite solution_lesson_node_00098**, **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory" (Baseline + Decay). We use an MLP to ensure the network has sufficient capacity to robustly map the identity and linear trends into the latent space **Cite solution_lesson_node_00060**.
    *   **Outputs:** This stream produces two vectors:
        1.  **Clinical Latent Vector ($H_{clin}$):** The baseline trajectory embedding.
        2.  **Gating Vector ($G$):** A learned scalar/vector generated via `Sigmoid(Linear(H_{clin}))`.

*   **Stream B: Cascaded Visual Interaction:**
    *   **Input:** Concatenation of [Image Projection, $H_{clin}$]. We cascade the clinical vector here to enable cross-modal interaction **Cite solution_lesson_node_00032**.
    *   **Architecture:** An **MLP** (`Linear(128 -> 64) -> ReLU -> Linear(64 -> 64)`).
    *   **Output:** Visual Latent Vector ($H_{vis}$).

*   **Gated Fusion (Structural Innovation):**
    *   **Aggregation:** $H_{final} = H_{clin} + (G \odot H_{vis})$.
    *   **Rationale:** Instead of simple summation, the clinical stream *gates* the visual residual. This allows the model to dynamically suppress the visual stream (driving $G \to 0$) if the image is noisy or ambiguous, preventing the high-dimensional branch from destabilizing the robust tabular prior **Cite solution_lesson_node_00023**.

*   **Metric-Aligned Head:**
    *   A single Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We explicitly **exclude** the "Time-Shortcut" (concatenating `|t|` at the head). By forcing the time dependency to flow through the deep streams, we prevent premature convergence to simple heuristics **Cite solution_lesson_node_00085**. We use a shared head to ensure uncertainty estimation maintains a direct connection to the clinical priors **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features are mapped to the active range of the network **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin **Cite solution_lesson_node_00036**.
    *   **Normalization:** Target `FVC` is Z-score standardized **Cite solution_lesson_node_00001**. Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   **Correction:** We explicitly include the $\sqrt{2}$ constants found in the competition metric. This corrects the systematic underestimation of uncertainty (approx 30%) observed when using standard NLL **Cite solution_lesson_node_00066**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly maintain a batch size of **32 or higher** to ensure stability of Batch Normalization statistics **Cite solution_lesson_node_00094**.
    *   **Duration:** **50 Epochs** to allow uncertainty calibration **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through GMAR-Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
