To optimize the GMAR-Net performance, I will implement the following changes based on the lessons learned:

1.  **Dynamic Scheduler Horizon (Cite Lesson 00100)**: I will modify `library/train.py` to initialize the `CosineAnnealingLR` scheduler using `Config.EPOCHS` as `T_max`. This fixes the issue in the previous run where the scheduler was configured for 50 epochs but training ran for only 25, preventing the learning rate from decaying to the minimum and hindering convergence.
2.  **Linear Residual Stream (Cite Lesson 00052, 00060)**: I will modify `GMARNet` in `library/model.py` to split the clinical processing into two streams: a non-linear MLP (`clinical_net`) for gating/context and a linear projection (`clinical_residual`) for the residual base. This ensures that the strong autoregressive signal from the standardized Baseline FVC (which may be negative) is not blocked by ReLU activations, allowing the model to robustly learn the identity mapping $FVC_{pred} \approx FVC_{base}$.
3.  **Hyperparameter Tuning**: I will increase `EPOCHS` from 25 to 30 in both `library/config.py` and `runfile.py` to allow the model sufficient time to converge with the corrected scheduler.
