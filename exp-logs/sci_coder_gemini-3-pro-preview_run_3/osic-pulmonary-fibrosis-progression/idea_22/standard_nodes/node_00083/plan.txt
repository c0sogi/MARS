To optimize the solution, I will implement the **Dual-Stream Point-Wise Residual Network (DSPRNet)**, which previously achieved the best performance (Cite solution_lesson_node_00052).

### Strategy
1.  **Architecture Refinement**: Replace the `SPPDSNet` with `DSPRNet`.
    *   **Stream A (Autoregressive)**: Use a direct linear projection of only the dominant autoregressive features (`Baseline FVC` and `Relative Week`) into the latent space. This leverages the "Linear Residual" concept (Cite solution_lesson_node_00052) while ensuring sufficient parameterization (Cite solution_lesson_node_00060).
    *   **Stream B (Deep Interaction)**: Keep the deep path processing the concatenated Image Embeddings and all Tabular features to capture non-linear corrections.
    *   **Fusion**: Sum the outputs of Stream A and Stream B in the latent space (64-dim).
    *   **Heads**: Use shared heads for $\mu$ and $\sigma$ on the fused vector, ensuring the uncertainty estimate has direct access to the strong time/baseline signals provided by Stream A (Cite solution_lesson_node_00055).
2.  **Training Configuration**:
    *   Reduce `EPOCHS` to 25, as previous successful runs converged around epoch 14-20.
    *   Maintain the differential learning rate strategy (Cite solution_lesson_node_00027) and EfficientNet-B2 backbone (Cite solution_lesson_node_00071).

class SPPDSNet(nn.Module):
    """
    Static-Prior Preserving Dual-Stream Network.
    Combines a Clinical Anchor Stream with a Visual Interaction Stream via summation.
    """

    def __init__(self):
        super().__init__()
        self.image_encoder = ImageEncoder()

        # Dimensions from Config
        input_dim = Config.CLINICAL_INPUT_DIM  # 6
        img_dim = Config.IMG_EMBED_DIM  # 64
        hidden_dim = Config.CLINICAL_HIDDEN_DIM  # 128
        out_dim = Config.CLINICAL_OUT_DIM  # 64

        # Stream A: Clinical Anchor (Over-Parameterized MLP)
        # Input: [Base_FVC, Base_Percent, Rel_Week, Age, Sex, Smoke]
        self.stream_a = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU(), nn.Linear(hidden_dim, out_dim)
        )

        # Stream B: Visual Interaction Stream
        # Input: Image Embed (64) + Clinical Features (6)
        self.stream_b = nn.Sequential(
            nn.Linear(input_dim + img_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, out_dim),
        )

        # Heads
        # Fusion output dimension is out_dim (64) due to summation

        # Mean Head: Predicts FVC
        self.head_mu = nn.Linear(out_dim, 1)

        # Uncertainty Head: Predicts Confidence (Sigma)
        # Input: Fusion Vector (64) + Abs(Rel_Time) (1) = 65
        # This "Time-Shortcut" helps model the uncertainty cone
        self.head_sigma = nn.Linear(out_dim + 1, 1)

    def forward(self, image, tabular):
        """
        Args:
            image: Tensor (B, 3, H, W)
            tabular: Tensor (B, 6) -> [Base_FVC, Base_Percent, Rel_Week, Age, Sex, Smoke]
        Returns:
            mu: Predicted FVC (raw/scaled)
            sigma: Predicted Confidence (raw/scaled, positive)
        """
        # 1. Extract Image Embeddings
        img_embed = self.image_encoder(image)  # (B, 64)

        # 2. Stream A: Clinical Anchor
        out_a = self.stream_a(tabular)  # (B, 64)

        # 3. Stream B: Visual Interaction
        # Concatenate image embeddings with clinical features
        combined_input = torch.cat([img_embed, tabular], dim=1)  # (B, 70)
        out_b = self.stream_b(combined_input)  # (B, 64)

        # 4. Latent Fusion (Summation)
        # Residual learning: Visual stream corrects the Clinical Anchor
        h_final = out_a + out_b  # (B, 64)

        # 5. Prediction Heads
        mu = self.head_mu(h_final)

        # Time-Shortcut for Uncertainty
        # Rel_Week is at index 2 of the tabular input
        rel_week = tabular[:, 2:3]  # (B, 1)
        abs_rel_time = torch.abs(rel_week)

        # Concatenate fusion vector with absolute relative time
        sigma_input = torch.cat([h_final, abs_rel_time], dim=1)  # (B, 65)
        raw_sigma = self.head_sigma(sigma_input)

        # Enforce positivity
        sigma = F.softplus(raw_sigma) + Config.SIGMA_MIN_TRAIN

        return mu, sigma

class DSPRNet(nn.Module):
    """
    Dual-Stream Point-Wise Residual Network.
    Cite {lesson_id}: solution_lesson_node_00052
    Combines a Linear Autoregressive Stream with a Deep Visual Interaction Stream via summation in latent space.
    """

    def __init__(self):
        super().__init__()
        self.image_encoder = ImageEncoder()

        # Dimensions
        input_dim = Config.CLINICAL_INPUT_DIM  # 6
        img_dim = Config.IMG_EMBED_DIM  # 64
        hidden_dim = Config.CLINICAL_HIDDEN_DIM  # 128
        out_dim = Config.CLINICAL_OUT_DIM  # 64

        # Stream A: Linear Autoregressive Residual
        # Cite {lesson_id}: solution_lesson_node_00060 (Over-parameterization)
        # Input: [Base_FVC (Scaled), Rel_Week] -> 2 features
        self.stream_a = nn.Linear(2, out_dim)

        # Stream B: Deep Visual Interaction
        # Input: Image Embed (64) + All Clinical Features (6) = 70
        self.stream_b = nn.Sequential(
            nn.Linear(input_dim + img_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, out_dim),
        )

        # Shared Heads
        # Cite {lesson_id}: solution_lesson_node_00055 (Shared path for uncertainty)
        self.head_mu = nn.Linear(out_dim, 1)
        self.head_sigma = nn.Linear(out_dim, 1)

    def forward(self, image, tabular):
        """
        Args:
            image: Tensor (B, 3, H, W)
            tabular: Tensor (B, 6) -> [Base_FVC, Base_Percent, Rel_Week, Age, Sex, Smoke]
        """
        # 1. Extract Image Embeddings
        img_embed = self.image_encoder(image)  # (B, 64)

        # 2. Stream A: Autoregressive
        # Select Base_FVC (idx 0) and Rel_Week (idx 2)
        ar_input = tabular[:, [0, 2]]  # (B, 2)
        out_a = self.stream_a(ar_input)  # (B, 64)

        # 3. Stream B: Visual Interaction
        combined_input = torch.cat([img_embed, tabular], dim=1)  # (B, 70)
        out_b = self.stream_b(combined_input)  # (B, 64)

        # 4. Latent Fusion (Summation)
        # The linear trend (A) is corrected by the deep residual (B)
        h_final = out_a + out_b  # (B, 64)

        # 5. Prediction Heads
        mu = self.head_mu(h_final)
        raw_sigma = self.head_sigma(h_final)

        # Enforce positivity
        sigma = F.softplus(raw_sigma) + Config.SIGMA_MIN_TRAIN

        return mu, sigma
