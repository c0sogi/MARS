### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters (e.g., `EPOCHS = 1`, `NUM_WORKERS = 0`) to ensure the demonstration runs quickly and efficiently within the time limit.
2.  **Utility Verification**: Demonstrate `seed_everything` for reproducibility and validate the `compute_metric` function using synthetic ground truth and prediction data to confirm the mathematical logic of the modified Laplace Log Likelihood.
3.  **Data Pipeline Demonstration**:
    *   Initialize the data loaders using `get_dataloaders`.
    *   Fetch a single batch from the training loader.
    *   Validate the shapes and data types of the yielded tensors (Images, Tabular Features, and Targets) against the expected dimensions defined in `Config`.
4.  **Model Initialization and Forward Pass**:
    *   Instantiate the `ZIOSRNet` model.
    *   Perform a forward pass using the fetched batch.
    *   Verify that the outputs (`mu` and `sigma`) have the correct shapes and that `sigma` values are positive (due to the Softplus activation).
5.  **Training and Evaluation Loop**:
    *   Instantiate the `LaplaceNLLLoss` criterion.
    *   Execute `train_one_epoch` for a single epoch to demonstrate the training loop.
    *   Execute `validate` to demonstrate the evaluation process and metric calculation on the validation set.
6.  **Submission Generation**:
    *   Run `generate_submission` to produce predictions for the test set.
    *   Verify that the submission file is created at the specified path and contains the expected columns.
