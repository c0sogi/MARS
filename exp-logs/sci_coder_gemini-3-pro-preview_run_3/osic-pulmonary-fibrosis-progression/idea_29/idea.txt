Based on the comprehensive analysis of the accumulated lessons, I propose the **Metric-Aligned Over-Parameterized Dual-Stream Network (MAOP-DS Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream Point-Wise Residual** topology **Cite solution_lesson_node_00052** with the critical corrections regarding **Linear Capacity** **Cite solution_lesson_node_00060**, **Metric Alignment** **Cite solution_lesson_node_00066**, and **Batch Stability** **Cite solution_lesson_node_00094**. It explicitly rejects the "Time-Shortcut" **Cite solution_lesson_node_00085** and "Proxy Features" **Cite solution_lesson_node_00069** that caused previous iterations to fail.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology. This design ensures the model preserves the robust clinical trajectory while allowing deep visual features to learn complex residual corrections.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for fine-grained texture analysis (e.g., reticulation), avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of heavier models like V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting **Cite solution_lesson_node_00065**.

*   **Stream A: Over-Parameterized Clinical Anchor:**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prioritize primitive features and avoid proxy leakage **Cite solution_lesson_node_00098**, **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory" (Baseline + Decay). Unlike a simple linear layer, this MLP provides sufficient capacity to robustly map the identity and linear trends into the latent space without optimization bottlenecks **Cite solution_lesson_node_00060**.

*   **Stream B: Visual Interaction Stream:**
    *   **Input:** Concatenation of [Image Projection, `Baseline FVC`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`]. We employ **Early Fusion** here to allow the network to learn cross-modal interactions immediately **Cite solution_lesson_node_00103**, **Cite solution_lesson_node_00032**.
    *   **Architecture:** An **MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream captures non-linear residuals (e.g., "Fibrosis pattern X accelerates decline").

*   **Latent Fusion & Shared Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm **Cite solution_lesson_node_00052**.
    *   **Head:** A single Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We explicitly **exclude** any "Time-Shortcut" (concatenating `|t|` at the head). By forcing the time dependency to flow through the deep streams, we prevent premature convergence to simple heuristics **Cite solution_lesson_node_00085**. We use a shared head to ensure uncertainty estimation maintains a direct connection to the clinical priors **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features are mapped to the active range of the network **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) instead of One-Hot to preserve order and reduce sparsity **Cite solution_lesson_node_00103**.
    *   **Normalization:** Target `FVC` is Z-score standardized **Cite solution_lesson_node_00001**. Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   We explicitly include the $\sqrt{2}$ constants to correct the systematic underestimation of uncertainty (~30%) observed when using standard NLL **Cite solution_lesson_node_00066**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link the scheduler's `T_max` directly to the training epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly maintain a batch size of **32 or higher** (using Gradient Accumulation if necessary) to ensure stability of Batch Normalization statistics **Cite solution_lesson_node_00094**.
    *   **Duration:** **50 Epochs** to allow uncertainty calibration **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through MAOP-DS Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
