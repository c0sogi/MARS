Based on the accumulated lessons, I propose the **Metric-Aligned Cascaded Anchor Network (MACAN)**.

This solution represents a structural evolution of the **Dual-Stream** and **Cascaded** architectures. It resolves the stability issues of previous iterations by strictly enforcing **Metric-Aligned Optimization** `Cite solution_lesson_node_00066` and utilizing a **Cascaded Residual Topology** `Cite solution_lesson_node_00052`. This topology forces the high-dimensional visual stream to act strictly as a conditional modifier to a robust, over-parameterized clinical anchor, preventing the "Signal Drowning" observed in parallel fusion `Cite solution_lesson_node_00023`.

### 1. Model
The architecture is a hybrid CNN-MLP designed to predict lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for texture analysis (e.g., reticulation), avoiding the underfitting of B0 `Cite solution_lesson_node_00071` and the overfitting of heavier models `Cite solution_lesson_node_00054`.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection `Cite solution_lesson_node_00027`.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals `Cite solution_lesson_node_00025`.
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting `Cite solution_lesson_node_00065`.

*   **Stream A: Over-Parameterized Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`. We explicitly **exclude** `Percent` to prevent proxy leakage and rely on robust primitive features `Cite solution_lesson_node_00069`, `Cite solution_lesson_node_00098`.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory" (Baseline + Decay). We use an MLP to ensure the network has sufficient capacity to robustly map the identity and linear trends into the latent space without optimization bottlenecks `Cite solution_lesson_node_00060`.

*   **Stream B: Cascaded Visual Interaction (The Innovation):**
    *   **Input:** Concatenation of [Image Projection (64-dim), **Stream A Output** (64-dim)].
    *   **Topology:** We **cascade** the processed clinical latent vector into the visual stream. This forces the visual stream to learn "Given this expected clinical state, what is the visual correction?", enabling deep cross-modal interactions `Cite solution_lesson_node_00032`.
    *   **Architecture:** An **MLP** (`Linear(128 -> 64) -> ReLU -> Linear(64 -> 64)`).

*   **Residual Fusion & Shared Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm `Cite solution_lesson_node_00052`.
    *   **Head:** A single Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We explicitly **exclude** any "Time-Shortcut" at the head to prevent premature convergence to simple heuristics `Cite solution_lesson_node_00085`. We use a shared head to ensure uncertainty estimation maintains a direct connection to the clinical priors `Cite solution_lesson_node_00055`.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features are mapped to the active range of the network `Cite solution_lesson_node_00090`.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency `Cite solution_lesson_node_00015`.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin `Cite solution_lesson_node_00036`.
    *   **Normalization:** Target `FVC` is Z-score standardized `Cite solution_lesson_node_00001`. Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude `Cite solution_lesson_node_00017`, `Cite solution_lesson_node_00035`.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   We explicitly include the $\sqrt{2}$ constants to correct the systematic underestimation of uncertainty (~30%) observed when using standard NLL `Cite solution_lesson_node_00066`.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow `Cite solution_lesson_node_00014`.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** We link the scheduler's `T_max` directly to the training epochs to ensure the full decay cycle is completed `Cite solution_lesson_node_00100`.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs `Cite solution_lesson_node_00027`.
    *   **Batch Size:** Strictly maintain a batch size of **32** to ensure stability of Batch Normalization statistics `Cite solution_lesson_node_00094`.
    *   **Duration:** **50 Epochs** to allow uncertainty calibration `Cite solution_lesson_node_00011`.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through MACAN to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) `Cite solution_lesson_node_00006`.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file `Cite solution_lesson_node_00014`.
