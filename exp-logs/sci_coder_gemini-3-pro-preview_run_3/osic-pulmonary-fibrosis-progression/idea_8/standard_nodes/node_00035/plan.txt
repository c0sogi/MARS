My implementation strategy focuses on reverting the "New Solution" (Idea 8) back to the higher-performing state described in the lessons by removing the auxiliary objectives and rigid constraints that caused performance degradation.

1.  **Remove Auxiliary MSE Loss (Cite Lesson 00034):** The previous solution introduced an auxiliary MSE loss on the predicted slope (`gamma`) to force it to match the OLS slope. Lesson 00034 explicitly states that this deterministic constraint conflicts with the probabilistic nature of the target (heteroscedastic regression) and degrades performance. I will remove `LAMBDA_MSE` and the corresponding loss calculation.
2.  **Simplify Uncertainty Modeling (Cite Lesson 00034):** The previous solution enforced a rigid linear growth for uncertainty (`sigma(t) = base + growth * |t|`). Lesson 00034 identifies this as a source of error. I will revert to predicting a patient-specific constant uncertainty parameter (`delta`), allowing the model to learn the average uncertainty without imposing a potentially incorrect shape constraint.
3.  **Pipeline Cleanup:** I will remove the computation and loading of OLS slopes (`target_slope`) from the preprocessing and data loading stages, as they are no longer required for the loss function.

def compute_patient_slopes(df):
    """
    Computes the standardized slope (gamma) for each patient using OLS.
    Returns a DataFrame with Patient and Slope.
    """
    # Z-score normalize target and time for slope calculation
    # to match the model's latent space expectations
    df_norm = df.copy()
    df_norm["FVC_scaled"] = (df["FVC"] - STATS["FVC_MEAN"]) / STATS["FVC_STD"]
    df_norm["Weeks_scaled"] = (df["Weeks"] - STATS["WEEKS_MEAN"]) / STATS["WEEKS_STD"]

    slopes = []

        p_data = df_norm[df_norm["Patient"] == p]

    def calculate_trajectory(self, params, tabular, weeks):
        """
        Computes mu(t) and sigma(t) based on model parameters and inputs.

        params: (B, 5) -> [alpha, beta, gamma, delta_base, delta_growth]
        tabular: (B, 7) -> [Base_FVC, ...] (Index 0 is Base_FVC)
        weeks: (B, 1) -> Scaled weeks
        """
        # Extract parameters
        alpha = params[:, 0:1]
        beta = params[:, 1:2]
        gamma = params[:, 2:3]
        delta_base = params[:, 3:4]
        delta_growth = params[:, 4:5]

        # Extract Baseline FVC (scaled) from tabular input
        baseline_fvc = tabular[:, 0:1]

        # 1. Mean Trajectory: mu(t)
        # mu(t) = alpha * Baseline + beta + gamma * Weeks
        mu = alpha * baseline_fvc + beta + gamma * weeks

        # 2. Uncertainty Trajectory: sigma(t)
        # sigma(t) = softplus(delta_base) + softplus(delta_growth) * |Weeks| + epsilon
        # We take absolute value of weeks because uncertainty grows in both past and future directions
        sigma = (
            F.softplus(delta_base)
            + F.softplus(delta_growth) * torch.abs(weeks)
            + UNCERTAINTY_FLOOR
        )

        return mu, sigma

    def criterion(self, params, tabular, weeks, target_fvc, target_slope):
        """
        Computes the composite loss: Laplace NLL + Auxiliary Slope MSE.
        """
        # Calculate trajectory in scaled space
        mu, sigma = self.calculate_trajectory(params, tabular, weeks)

        # 1. Primary Loss: Laplace Negative Log Likelihood
        # Metric definition: Score = - (sqrt(2) * Delta) / sigma - ln(sqrt(2) * sigma)
        # NLL (to minimize) = (sqrt(2) * |y - mu|) / sigma + ln(sqrt(2) * sigma)

        sqrt_2 = torch.sqrt(torch.tensor(2.0, device=self.device))
        absolute_error = torch.abs(target_fvc - mu)

        nll = (sqrt_2 * absolute_error) / sigma + torch.log(sqrt_2 * sigma)
        nll_loss = torch.mean(nll)

        # 2. Auxiliary Loss: MSE on Slope (Gamma)
        # Gamma is index 2 in params
        gamma = params[:, 2:3]
        slope_loss = F.mse_loss(gamma, target_slope)

        # Total Loss
        total_loss = nll_loss + LAMBDA_MSE * slope_loss

        return total_loss, nll_loss.item(), slope_loss.item()
