1.  **Revert Spatial Attention**: I will remove the `SpatialAttention` module from the model architecture. Reverting to simple Global Average Pooling aligns with **Lesson ID: solution_lesson_node_00030**. I will rename the model from `SAPNet` to `ParametricNet` to reflect this.
2.  **Optimize Input Resolution**: I will reduce `IMG_SIZE` from 256 to 224. **Lesson ID: solution_lesson_node_00031** indicated that increasing resolution to 256x256 caused early overfitting. 224x224 is the native resolution for EfficientNet-B0 and provides a better balance of detail and generalization for this dataset size.
3.  **Increase Training Duration**: I will increase the training epochs in `runfile.py` from 20 to 30. **Lesson ID: solution_lesson_node_00009** highlights that frozen-backbone or fine-tuning architectures require more iterations for the projection heads to fully converge.

These changes collectively restore the high-performing "CAP-Net" architecture while ensuring sufficient convergence time.

class SpatialAttention(nn.Module):
    """
    Spatial Attention Block: 1x1 Conv + Sigmoid.
    Weights the feature map spatially to focus on relevant regions (e.g., fibrosis).
    """

    def __init__(self, in_channels):
        super(SpatialAttention, self).__init__()
        self.conv = nn.Conv2d(in_channels, 1, kernel_size=1)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        # x: (B, C, H, W)
        # mask: (B, 1, H, W)
        mask = self.sigmoid(self.conv(x))
        return x * mask
