In low-data regimes (176 training samples), learnable attention mechanisms often overfit or fail to converge effectively. I will remove the `SpatialAttention` class and revert to using `nn.AdaptiveAvgPool2d(1)` directly on the backbone features.

This mismatch meant the learning rate did not decay sufficiently, leaving the model under-converged. I will increase the training epochs in `runfile.py` to 50 to match the scheduler and allow the differential learning rates (fine-tuning) to fully converge.

class SpatialAttention(nn.Module):
    """
    Spatial Attention Block: 1x1 Conv + Sigmoid.
    Weights the feature map spatially to focus on relevant regions (e.g., fibrosis).
    """

    def __init__(self, in_channels):
        super(SpatialAttention, self).__init__()
        self.conv = nn.Conv2d(in_channels, 1, kernel_size=1)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        # x: (B, C, H, W)
        # mask: (B, 1, H, W)
        mask = self.sigmoid(self.conv(x))
        return x * mask
