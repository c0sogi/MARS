The execution failed with a `_pickle.UnpicklingError` because PyTorch 2.6+ defaults `weights_only=True` in `torch.load`, which restricts the unpickling of non-tensor types like the NumPy scalars stored in the checkpoint's `scaler_means` and `scaler_stds`. To fix this, I will explicitly set `weights_only=False` in the `torch.load` calls within both `runfile.py` and `library/train.py`. This restores the ability to load the locally generated checkpoint containing trusted NumPy data types. Cite debug_lesson_2.
