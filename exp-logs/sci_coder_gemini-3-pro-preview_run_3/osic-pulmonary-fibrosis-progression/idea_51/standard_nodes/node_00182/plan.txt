Implementation Strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Override `Config.EPOCHS` to 20 and `Config.T_MAX` to 20 to ensure the training completes within the time limit while maintaining scheduler synchronization. Set random seeds for reproducibility.
2.  **Data Loading**: Call `get_dataloaders(load_cached_data=True)` to load training, validation, and test data. Retrieve global FVC statistics for model initialization and inverse transformation.
3.  **Model Initialization**: Instantiate the `ARLRNet` model using the calculated global standard deviation. Move the model to the GPU.
4.  **Training**: Initialize the `Trainer` and execute the `fit()` method to train the model. The trainer handles the training loop, validation per epoch, and saving the best model checkpoint.
5.  **Validation & Metric Calculation**: Load the best model checkpoint. Perform inference on the validation set in evaluation mode. Inverse transform the predictions (scale back to ml) and calculate the final Laplace Log Likelihood metric. Print this metric with full precision.
6.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute and print the correlation between the error magnitude and key clinical features (Weeks, Base_FVC, Age, Percent) to identify error sources.
7.  **Submission Generation**: Compare the final validation metric against the threshold (-6.573619738753321). If the metric is higher, perform inference on the test set, apply the inverse transform, clip the confidence values at 70ml, and save the results to `./submission/submission.csv`.
