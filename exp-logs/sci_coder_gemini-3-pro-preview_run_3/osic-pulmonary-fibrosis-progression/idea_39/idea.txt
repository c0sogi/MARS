Based on the comprehensive analysis of the accumulated lessons, I propose the **Context-Injected Over-Parameterized Dual-Stream Network (CI-OP-DS Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Linear Capacity** **Cite solution_lesson_node_00060**, **Context Visibility** **Cite solution_lesson_node_00139**, and **Loss Optimization** **Cite solution_lesson_node_00138**. It explicitly rejects the use of stochastic regularization on residuals **Cite solution_lesson_node_00126** and clipped loss functions **Cite solution_lesson_node_00138** which caused previous iterations to fail.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology.

*   **Stream A: Over-Parameterized Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the baseline disease trajectory ($FVC(t) \approx Base + Rate \times t$). Unlike a single linear layer (which creates optimization bottlenecks), this MLP provides sufficient capacity to robustly map the identity and linear trends into the latent space **Cite solution_lesson_node_00060**.

*   **Stream B: Context-Injected Visual Residual (The Correction):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency, avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** Unfreeze top two stages; keep bottom frozen **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Context Injection (Structural Innovation):** We **concatenate** the image features with the **Raw Baseline FVC** and **Relative Time** *before* they enter the stream's MLP. This corrects the failure of previous models where the deep branch was blinded to the patient's initial severity, forcing it to learn generic rather than patient-specific corrections **Cite solution_lesson_node_00139**, **Cite solution_lesson_node_00035**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **No Regularization:** We explicitly **exclude Dropout**. Since this stream learns a weak residual correction to the strong clinical anchor, stochastic regularization drowns out the gradient signal **Cite solution_lesson_node_00126**.

*   **Latent Fusion & Shared Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm **Cite solution_lesson_node_00052**.
    *   **Head:** A shared Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Rationale:** A shared head ensures uncertainty estimation maintains a direct, low-complexity pathway from the clinical priors **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features are mapped to the active range of the network **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00124**, **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) **Cite solution_lesson_node_00103**.
    *   **Normalization:** Target `FVC` is Z-score standardized **Cite solution_lesson_node_00001**. Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Smooth Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   **Correction:** We explicitly include the $\sqrt{2}$ constants **Cite solution_lesson_node_00066** but **remove all clipping/thresholding** (e.g., `min`, `clamp`) from the loss calculation. This prevents gradient vanishing on outliers, allowing the model to learn from large errors **Cite solution_lesson_node_00138**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$ for each test `Patient_Week`.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via CI-OP-DS Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
