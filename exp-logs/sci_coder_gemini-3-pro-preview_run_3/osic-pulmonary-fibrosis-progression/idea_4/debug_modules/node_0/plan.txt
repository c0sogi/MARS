3.  **Image Processing Verification**: Load the training metadata to retrieve a valid patient ID. Use `process_patient` from `library.image_processing` to process the patient's CT scans and verify the output tensor shape and data type.
4.  **Dataset Verification**: Instantiate `LungFVCDataset` in debug mode. Fetch a single sample to verify the dictionary structure, tensor shapes (images, metadata, linear features), and data types.
5.  **Model Architecture Verification**: Instantiate the `DualPathTransformer`. specific dummy tensors matching the expected input shapes. Perform a forward pass and assert that the output shapes for FVC prediction and confidence (sigma) are correct and that sigma is positive.
6.  **Training Loop Verification**: Instantiate the `Trainer` class. Execute the `fit()` method for a single epoch. Verify that the training completes without error and that a model checkpoint (`best_model.pth`) is successfully saved to the configured directory.
