I will implement the `runfile.py` script to orchestrate the training, validation, failure analysis, and submission process for the BPCDS-Net model.

The strategy is as follows:
1.  **Setup & Initialization**: Set random seeds and detect the computing device. Initialize the `Config` and logging.
2.  **Data Loading**: Use the provided `get_dataloaders` function to load preprocessed training, validation, and test data. This leverages the caching mechanism implemented in `preprocessing.py`.
3.  **Model & Optimization**: Instantiate the `BPCDSNet` model. Configure the `AdamW` optimizer with differential learning rates (lower for the backbone, higher for the heads) and the `CosineAnnealingLR` scheduler. Use the `LaplaceNLLLoss`.
4.  **Training Loop**: Execute the training for `Config.EPOCHS`. In each epoch, run training and validation phases. Track the best validation metric (Laplace Log Likelihood) and save the best model checkpoint.
5.  **Failure Analysis**: After training, load the best model and perform inference on the validation set. Calculate the absolute errors and compute correlations between the error magnitude and input features (e.g., Baseline FVC, Age, Weeks) to identify systematic weaknesses.
6.  **Submission Generation**: If the best validation metric exceeds the specified threshold, generate the submission file. This involves:
    *   Parsing `sample_submission.csv` to identify target weeks for each test patient.
    *   Constructing input batches for the test patients using their static data (Image, Baseline FVC, etc.) and varying the `Relative_Time` feature.
    *   Running inference, applying the inverse transformation to predictions, and clipping the confidence values.
    *   Saving the results to `submission.csv`.
