To address the critical issue of target magnitude mismatch identified in the failure analysis, I will implement **Target Scaling** as recommended in Lesson `solution_lesson_node_00001`. The previous model failed to converge because it was initialized to predict values near 0, while the target FVC values are in the range of 2000-3000 ml. By standardizing the target variable (mean ~2650, std ~800), the default neural network initialization will be much closer to the target distribution, facilitating effective learning.

Here is the implementation strategy:
1.  **Configuration**: Update `library/config.py` to include `TARGET_MEAN` and `TARGET_STD` constants derived from EDA, and increase `EPOCHS` to 50 to ensure convergence.
2.  **Dataset**: Modify `library/data.py` to scale the target FVC values using the defined constants during data loading.
3.  **Training & Evaluation**: Update `library/train.py` to unscale the model predictions (both FVC and Confidence) back to the original milliliter units before calculating the competition metric and generating outputs.
4.  **Inference**: Update `library/inference.py` to unscale predictions during the test phase.
5.  **Execution Control**: Update `runfile.py` to unscale values for failure analysis and enforce the conditional submission generation based on the validation metric threshold.
