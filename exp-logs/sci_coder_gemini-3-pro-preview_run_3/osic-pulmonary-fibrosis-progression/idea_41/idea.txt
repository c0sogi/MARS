Based on the comprehensive analysis of the accumulated lessons, I propose the **Projected-Context Dual-Stream Network (PCDS-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Dimensionality Balance** **Cite solution_lesson_node_00146**, **Context Visibility** **Cite solution_lesson_node_00139**, and **Linear Capacity** **Cite solution_lesson_node_00060**. It explicitly rejects the use of explicit shortcuts **Cite solution_lesson_node_00085** and zero-initialization on latent streams **Cite solution_lesson_node_00118**, which caused previous iterations to fail.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology designed to balance robust clinical priors with deep visual residuals.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for fine-grained texture analysis (e.g., reticulation), avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of heavier models like V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Bottleneck Projection (Structural Innovation):** The high-dimensional backbone output (1408-dim) is immediately projected to **64 dimensions** via a learnable Linear layer. This prevents the high-dimensional image noise from statistically dominating the low-dimensional clinical features during fusion **Cite solution_lesson_node_00146**, **Cite solution_lesson_node_00065**.

*   **Stream A: Over-Parameterized Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prioritize primitive features and avoid proxy leakage **Cite solution_lesson_node_00098**, **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory". We use an MLP to ensure the network has sufficient capacity to robustly map the identity and linear trends into the latent space without optimization bottlenecks **Cite solution_lesson_node_00060**.

*   **Stream B: Context-Injected Visual Interaction (The Correction):**
    *   **Input:** Concatenation of [Image Projection (64-dim), `Baseline FVC`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`].
    *   **Context Injection:** We explicitly provide the clinical context to the visual stream. This corrects the failure of previous models where the deep branch was blinded to the patient's initial severity, forcing it to learn generic rather than patient-specific corrections **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Regularization:** We rely on the **Bottleneck Projection** and **Early Stopping** for regularization, explicitly excluding Dropout to preserve the weak residual signal **Cite solution_lesson_node_00126**.

*   **Latent Fusion & Shared Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm **Cite solution_lesson_node_00052**.
    *   **Head:** A shared Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We explicitly **exclude** any "Time-Shortcut" (concatenating `|t|` at the head). By forcing the time dependency to flow through the deep streams, we prevent premature convergence to simple heuristics **Cite solution_lesson_node_00085**. We use a shared head to ensure uncertainty estimation maintains a direct connection to the clinical priors **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features are mapped to the active range of the network **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00124**, **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) instead of One-Hot to preserve order and reduce sparsity **Cite solution_lesson_node_00103**.
    *   **Normalization:** Target `FVC` is Z-score standardized **Cite solution_lesson_node_00001**. Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   **Correction:** We explicitly include the $\sqrt{2}$ constants **Cite solution_lesson_node_00066** but **remove all clipping/thresholding** from the loss calculation to prevent gradient vanishing on outliers **Cite solution_lesson_node_00138**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$ for each test `Patient_Week`.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via PCDS-Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
