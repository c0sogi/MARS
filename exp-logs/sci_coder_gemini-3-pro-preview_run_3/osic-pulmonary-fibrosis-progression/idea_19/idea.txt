Based on the comprehensive analysis of the accumulated lessons, I propose the **Metric-Aligned Clinical-Residual Fusion Network (MACR-Net)**.

This solution synthesizes the successful **Dual-Stream** architecture of Idea 13 with the critical corrections identified in the failures of Ideas 14-18. It explicitly addresses the **Loss Mismatch** (Lesson 066), **Capacity Overload** (Lesson 065), **Proxy Feature Leakage** (Lesson 069), and **Backbone Underfitting** (Lesson 071) by strictly adhering to a calibrated, over-parameterized residual topology.

### 1. Model
The architecture is a hybrid CNN-MLP that predicts lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$ using a **Latent Residual Summation** strategy.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We retain the B2 variant to ensure sufficient capacity for texture analysis, avoiding the underfitting observed with B0 **Cite solution_lesson_node_00071** and the overfitting of V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting **Cite solution_lesson_node_00065**.

*   **Stream A: The Clinical Anchor (Over-Parameterized Residual):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`. **Crucially, we exclude `Percent`** to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory". Unlike a simple linear layer (which can bottleneck optimization), this MLP projects the strong clinical priors into the latent space with sufficient capacity to robustly model the identity mapping and linear decay **Cite solution_lesson_node_00060**.

*   **Stream B: The Visual Interaction Stream:**
    *   **Input:** Concatenation of [Image Projection, `Baseline FVC`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`].
    *   **Architecture:** A shared MLP (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream captures non-linear cross-modal interactions (e.g., "Fibrosis $\times$ Time") **Cite solution_lesson_node_00032**.

*   **Latent Fusion & Metric-Aligned Head:**
    *   **Fusion:** $H_{final} = H_{clin} + H_{vis}$. This summation enforces a residual learning paradigm where the visual stream corrects the robust clinical anchor **Cite solution_lesson_node_00052**.
    *   **Head:** A single Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We use a shared head to ensure uncertainty estimation maintains a direct connection to the strong clinical priors **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Content-Adaptive Slice Selection:** For each patient, select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin for uncertainty growth **Cite solution_lesson_node_00036**.
    *   **Target Standardization:** The target `FVC` is **Z-score standardized** during training to resolve the magnitude gap **Cite solution_lesson_node_00001**.
    *   **Input Normalization:** `Baseline FVC` and `Age` are standardized but passed as **raw scalars** (no Batch Norm) to preserve absolute magnitude signals **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   **Correction:** We explicitly include the $\sqrt{2}$ constants found in the competition metric. This corrects the systematic underestimation of uncertainty (by approx 30%) observed when using standard NLL **Cite solution_lesson_node_00066**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Duration:** **50 Epochs**. This extended duration is mandatory to allow the uncertainty estimation to calibrate **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through the MACR-Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
