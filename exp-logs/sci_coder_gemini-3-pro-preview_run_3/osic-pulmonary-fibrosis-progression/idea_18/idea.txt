Based on the systematic analysis of the previous experiments and the derived lessons, I propose the **Cascaded Latent-Residual Network (CLR-Net)**.

This solution represents a structural evolution of the **Dual-Stream Point-Wise Residual** (Idea 13) and the **Residual-Interaction** (Idea 17) approaches. It synthesizes the robust "Dual-Stream" topology **Cite solution_lesson_node_00052** with the "Conditional Interaction" logic of Idea 17, while explicitly correcting the **Loss Mismatch** **Cite solution_lesson_node_00066** and **Capacity Overload** **Cite solution_lesson_node_00065** that caused the latter to fail.

### 1. Model
The architecture is a hybrid CNN-MLP that predicts lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$ using a **Cascaded Residual** topology constrained to a low-dimensional latent space.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We retain the B2 variant as the optimal balance between texture recognition and parameter efficiency, avoiding the overfitting risks of heavier backbones like V2-S or Noisy Student variants **Cite solution_lesson_node_00054**, **Cite solution_lesson_node_00065**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting **Cite solution_lesson_node_00065**.

*   **Stream A: The Clinical Anchor (Over-Parameterized Trajectory):**
    *   **Input:** `Baseline FVC`, `Percent`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 64) -> ReLU -> Linear(64 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory" (Baseline + Decay). We use an MLP to ensure the network has sufficient capacity to robustly map the identity and linear trends into the latent space **Cite solution_lesson_node_00060**.
    *   **Output:** Clinical Latent Vector ($H_{clin}$, 64-dim).

*   **Stream B: The Conditional Visual Stream (Cascaded Input):**
    *   **Input:** Concatenation of [Image Projection (64-dim), $H_{clin}$ (64-dim)].
    *   **Innovation:** We cascade the *processed* latent vector from Stream A into Stream B. This forces the visual stream to learn "Given this expected clinical state, what is the visual correction?" This enables cross-modal interaction **Cite solution_lesson_node_00032** without the noise of raw inputs drowning out the signal **Cite solution_lesson_node_00023**.
    *   **Architecture:** An MLP (`Linear(128 -> 64) -> ReLU -> Linear(64 -> 64)`).
    *   **Output:** Residual Latent Vector ($H_{resid}$).

*   **Residual Fusion & Metric-Aligned Head:**
    *   **Aggregation:** $H_{final} = H_{clin} + H_{resid}$. This summation enforces a residual learning paradigm **Cite solution_lesson_node_00052**.
    *   **Head:** A single Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We use a shared head to ensure uncertainty estimation maintains a direct connection to the strong clinical priors **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Content-Adaptive Slice Selection:** For each patient, select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin for uncertainty growth **Cite solution_lesson_node_00036**.
    *   **Target Standardization:** The target `FVC` is **Z-score standardized** during training to resolve the magnitude gap **Cite solution_lesson_node_00001**, **Cite solution_lesson_node_00006**.
    *   **Input Normalization:** `Baseline FVC`, `Percent`, and `Age` are standardized but passed as **raw scalars** (no Batch Norm) to preserve absolute magnitude signals **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   **Correction:** We explicitly include the $\sqrt{2}$ constants found in the competition metric. Previous attempts failed because they optimized standard NLL, which underestimates the required standard deviation by a factor of $\sqrt{2}$ **Cite solution_lesson_node_00066**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Duration:** **50 Epochs**. This extended duration is mandatory to allow the uncertainty estimation to calibrate **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through the CLR-Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
