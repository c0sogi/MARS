This script demonstrates the end-to-end usage of the provided library modules for the lung function decline prediction task. It validates the data loading pipeline, model architecture, loss calculation, and training loop execution.

To ensure rapid execution and resource optimization, the script:
1.  Overrides global `Config` settings to use a tiny subset of the data (20 samples) and runs for only 1 epoch.
2.  Sets up a dedicated working directory for this demonstration to keep outputs isolated.
3.  Validates the shapes of data batches and model outputs using assertions.
4.  Verifies the custom metric calculation with a known manual example.
5.  Executes a short training run to confirm the pipeline functions correctly without errors.
