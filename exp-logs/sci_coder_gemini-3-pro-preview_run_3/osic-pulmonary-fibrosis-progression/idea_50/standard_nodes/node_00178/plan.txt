Here is the implementation strategy for `runfile.py`:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the computation device (GPU/CPU). Override the default `NUM_EPOCHS` in `Config` to a smaller value (20) to satisfy the "fast baseline" requirement while ensuring sufficient convergence.

2.  **Data Loading**: Utilize the `get_dataloaders` function from the `library.data` module. We will enable `load_cached_data=True` to leverage pre-processed image tensors, significantly speeding up the pipeline.

3.  **Model Initialization**: Instantiate the `CRDSNet` model from `library.model`. Define the optimizer (AdamW) with differential learning rates for the backbone and the head, and initialize the Cosine Annealing scheduler and the custom `MetricAlignedLaplaceLoss`.

4.  **Training Loop**: Execute a training loop for the defined number of epochs. Inside the loop, use `train_one_epoch` for training and `evaluate` for validation (imported from `library.train`). Implement early stopping based on the validation metric (Laplace Log Likelihood) and save the best model checkpoint.

5.  **Final Evaluation**: After training, load the best model checkpoint. Run a full evaluation on the validation set to obtain the `Final Validation Metric` and print it with full precision.

6.  **Failure Analysis**: Perform a specific inference pass on the validation set to collect predictions, targets, and input features. Calculate the absolute prediction error (`|True FVC - Predicted FVC|`) and compute Pearson correlations between this error and key input features (Baseline FVC, Age, Percent, etc.) to identify sources of systematic failure.

7.  **Submission Generation**: Check if the final validation metric exceeds the specified threshold (`-6.573619738753321`). If successful, generate predictions for the test set using `generate_submission` and save them to `./submission/submission.csv`.
