Based on the comprehensive analysis of the accumulated lessons, I propose the **Constrained-Residual Dual-Stream Network (CRDS-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream Point-Wise Residual** topology **Cite solution_lesson_node_00052** with critical corrections for **Input Isolation** **Cite solution_lesson_node_00177**, **Metric Alignment** **Cite solution_lesson_node_00164**, and **Target Normalization** **Cite solution_lesson_node_00155**. It explicitly resolves the "Signal Dilution" failure identified in **Cite solution_lesson_node_00177** by strictly isolating the autoregressive signal, and it corrects the "Phantom Gain" optimization failure **Cite solution_lesson_node_00164** by enforcing metric constraints within the standardized optimization space.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Output-Space Summation** topology designed to enforce a strong inductive bias for autoregressive forecasting.

*   **Stream A: Constrained Linear Residual (The Autoregressive Anchor):**
    *   **Input Restriction:** This stream receives **only** `Baseline FVC` and `Relative Time` ($t_{rel}$). We explicitly **exclude** static metadata (Age, Sex, Smoking) from this specific branch.
    *   **Architecture:** A single **Learnable Linear Layer** (no activation, no bias) mapping these 2 inputs directly to the output space ($\mu_{linear}, \sigma_{linear}$).
    *   **Purpose:** This enforces the inductive bias that the primary prediction is a linear function of the baseline and time ($FVC(t) \approx \alpha \cdot Base + \beta \cdot t$). By isolating these inputs, we prevent the optimization from diluting this strong signal with weaker static features **Cite solution_lesson_node_00177**.

*   **Stream B: Deep Interaction Residual (The Correction):**
    *   **Image Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency **Cite solution_lesson_node_00071**.
    *   **Fine-Tuning:** Unfreeze the top two convolutional stages; keep lower layers frozen **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer.
    *   **Bottleneck Projection:** Project the high-dimensional output to **64 dimensions** via a Linear layer to prevent statistical dominance **Cite solution_lesson_node_00146**.
    *   **Context Injection:** Concatenate the **Projected Image** with **All Clinical Scalars** (Baseline FVC, Time, Age, Sex, Smoking). This ensures the deep branch can learn complex interactions (e.g., "Smokers with fibrosis pattern X decline faster") **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Regularization:** We explicitly **exclude Dropout**. Since this stream learns a weak residual to the strong linear anchor, stochastic regularization drowns out the gradient signal **Cite solution_lesson_node_00126**.

*   **Constraint-Aware Fusion:**
    *   **Mean:** $\mu_{scaled} = \mu_{linear} + \mu_{deep}$.
    *   **Uncertainty (Structural Innovation):**
        *   Calculate the standardized floor: $\epsilon_{std} = 70 / \sigma_{global\_target}$.
        *   $\sigma_{scaled} = \text{Softplus}(\sigma_{linear} + \sigma_{deep}) + \epsilon_{std}$.
    *   **Rationale:** By enforcing the metric's 70ml floor *architecturally* within the standardized space, we align the optimization landscape with the evaluation metric. This prevents the model from optimizing "phantom gains" in the clipped region, resolving the divergence between validation loss and metric score **Cite solution_lesson_node_00164**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` **Cite solution_lesson_node_00103**.
    *   **Target Normalization (Crucial Correction):** Normalize targets using **Global Statistics** (mean/std of all visits in training), not baseline statistics. This prevents covariate shift caused by the declining trend of the disease **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood (Standardized)**.
    *   Formula: $L = \frac{\sqrt{2} |y_{scaled} - \mu_{scaled}|}{\sigma_{scaled}} + \ln(\sqrt{2} \sigma_{scaled})$.
    *   We optimize in the standardized space to avoid gradient instability **Cite solution_lesson_node_00165** while explicitly including the $\sqrt{2}$ constants to correct systematic uncertainty underestimation **Cite solution_lesson_node_00066**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly maintain a batch size of **32 or higher** **Cite solution_lesson_node_00094**.
    *   **No Auxiliary Loss:** We train only on the final output to avoid conflicting objectives **Cite solution_lesson_node_00159**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$ for each test `Patient_Week`.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via CRDS-Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{global} + \mu_{global}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
