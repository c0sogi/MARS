The implementation strategy involves creating a self-contained Python script that leverages the provided library modules (`config`, `utils`, `data`, `model`, `train`) to demonstrate the end-to-end pipeline for the Pulmonary Fibrosis Progression task.

To ensure speed and efficiency, the script will:
1.  **Override Configuration**: Modify `Config` parameters to use a temporary working directory, reduce the number of epochs to 1, and set a small batch size.
2.  **Debug Data Loading**: Use the `debug=True` flag in `get_dataloaders` to load only a tiny subset of the training/validation data, significantly reducing image processing time.
3.  **Validate Components**:
    *   **Data**: Assert correct shapes for image tensors and tabular features.
    *   **Model**: Perform a forward pass with the `RaliNet` model and assert output dimensions.
    *   **Metric**: Manually verify the custom metric calculation against a known value.
    *   **Training**: Run a single training epoch and validation step.
    *   **Submission**: Generate predictions and verify the output CSV format and constraints (e.g., confidence clipping).
4.  **Reproducibility**: Set random seeds at the start.

The script is designed to be robust, failing explicitly with `AssertionError` if any component behaves unexpectedly.
