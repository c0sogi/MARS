Based on the comprehensive analysis of the accumulated lessons, I propose the **Residual-Augmented Latent Interaction Network (RALI-Net)**.

This solution represents a structural evolution of the best-performing **Dual-Stream Point-Wise Residual** approach (Idea 13). It directly addresses the bottleneck identified in **Cite solution_lesson_node_00060**, where the "Wide" linear stream was found to be too simple to capture the full robustness of the clinical priors. By upgrading this stream to an **Over-Parameterized Clinical MLP**, we ensure the strong baseline signals are preserved and processed with sufficient capacity, while maintaining the non-linear cross-modal interactions via a parallel visual stream.

### 1. Model
The architecture is a hybrid CNN-MLP that predicts lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$ using a **Latent Residual Fusion** strategy.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We retain the B2 variant as the optimal balance between texture recognition and parameter efficiency **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated vector (3 slices) is projected to 128 dimensions via a learnable Linear layer **Cite solution_lesson_node_00008**.

*   **Stream A: Over-Parameterized Clinical Residual (The Evolution):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`.
    *   **Architecture:** A dedicated MLP (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 128)`).
    *   **Purpose:** Unlike Idea 13 (which used a single linear layer), this stream is **over-parameterized** to project the strong clinical priors into a high-dimensional latent space. This prevents the optimization bottleneck where a minimal layer struggles to learn the identity mapping and complex clinical trends simultaneously **Cite solution_lesson_node_00060**. It explicitly models the "Clinical Trajectory" independent of imaging.

*   **Stream B: Visual Interaction Stream:**
    *   **Input:** Concatenation of [Image Projection, `Baseline FVC`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`].
    *   **Architecture:** A shared MLP (`Linear(Input -> 256) -> ReLU -> Linear(256 -> 128)`).
    *   **Purpose:** This stream captures the **non-linear cross-modal interactions** (e.g., "Fibrosis pattern X accelerates decline in older smokers") **Cite solution_lesson_node_00032**.

*   **Latent Fusion & Head:**
    *   **Fusion:** The outputs of Stream A and Stream B are **Summed** in the 128-dimensional latent space.
        *   $Latent_{Fused} = Latent_{Clinical} + Latent_{Visual}$.
        *   This forces the Visual stream to learn a *residual correction* to the robust Clinical trajectory **Cite solution_lesson_node_00052**.
    *   **Head:** A single Linear layer projects $Latent_{Fused}$ to $\mu$ and $\sigma$.
    *   **Constraint:** This shared path ensures uncertainty estimation has direct access to the stable clinical features via the summation, preventing the instability observed when heads are decoupled **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Content-Adaptive Slice Selection:** For each patient, select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to maintain the physical origin **Cite solution_lesson_node_00036**.
    *   **Target Standardization:** The target `FVC` is **Z-score standardized** during training to resolve the magnitude gap **Cite solution_lesson_node_00001**, **Cite solution_lesson_node_00006**.
    *   **Input Normalization:** `Baseline FVC` and `Age` are standardized but passed as **raw scalars** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** Modified Laplace Log Likelihood ($L = \frac{|y - \mu|}{\sigma} + \ln(\sigma)$).
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. Do **not** enforce the metric's 70ml clip in the architecture to allow natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Duration:** **50 Epochs**. This extended duration is mandatory to allow the uncertainty estimation to calibrate **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via the latent fusion network.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file.
