The implementation strategy involves orchestrating the training and evaluation of the EADS-Net model using the provided library components while adhering to the specific constraints of the task.

1.  **Configuration & Setup**: We will override the default epoch count to 25 to ensure the "fast baseline" requirement is met while still allowing convergence. We will set the random seed for reproducibility.
2.  **Data Loading**: We utilize `get_dataloaders` to fetch the training, validation, and test loaders. This handles caching and preprocessing automatically.
3.  **Model Initialization**: The `EADSNet` is instantiated and moved to the GPU.
4.  **Training Loop**: We implement the training loop explicitly (rather than using `library.train.run_training`) to have fine-grained control over logging and to integrate the specific validation logic. We use the differential learning rate strategy defined in the library. We save the best model checkpoint based on the Laplace Log Likelihood metric.
5.  **Validation & Failure Analysis**:
    *   After training, we load the best model.
    *   We run inference on the full validation set to compute the final metric.
    *   We extract predictions and true targets to compute absolute errors.
    *   We calculate the Pearson correlation between these errors and key features (Age, Baseline FVC, Weeks, Percent) to identify error sources.
6.  **Submission**: We check if the final validation metric exceeds the threshold (-6.573619738753321). If successful, we generate predictions for the test set (predicting all required weeks per patient), apply the necessary inverse transformations and confidence clipping, and save the `submission.csv`.
