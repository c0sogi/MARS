The following script demonstrates the usage of the provided library files for the lung function decline prediction task. It performs the following steps:

1.  **Environment Setup**: Configures a temporary execution environment by creating a subset of the metadata and sample submission files to ensure the demonstration runs quickly.
2.  **Utility Verification**: Validates the `TargetScaler` and `LaplaceLogLikelihood` metric logic with assertions.
3.  **Data Pipeline Verification**: Initialized the data loaders using the subsetted data, verifying the shape and content of the batches produced.
4.  **Model Verification**: Instantiates the `EADSNet` model and performs a forward pass to verify output shapes and value constraints (e.g., positive uncertainty).
5.  **Training Integration**: Executes a shortened training run (1 epoch) using the `run_training` function logic, verifying that the model trains, evaluates, and generates a valid submission file.
