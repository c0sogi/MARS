The following script demonstrates the usage of the provided ZIMAR-Net library components. It performs the following steps:

1.  **Configuration Override**: Adjusts global settings (epochs, batch size, directories) to ensure the demonstration runs quickly and isolates its outputs in a demo directory.
2.  **Utility Verification**: Validates the logic of the `InverseScaler` and `LaplaceMetric` classes using synthetic data and manual assertions.
3.  **Data Pipeline Verification**: Initializes data loaders in debug mode, verifying that batches contain the correctly shaped tensors for images, clinical vectors, and targets.
4.  **Model Architecture Verification**: Instantiates the `ZIMARNet` model, performs a forward pass with dummy data to check output shapes, and verifies the zero-initialization of the visual stream.
5.  **Training Loop Demonstration**: Runs a truncated training session (1 epoch) using the `Trainer` class to demonstrate the fitting process and checkpoint saving.
6.  **Inference Demonstration**: Generates a submission file using the trained model and verifies the output format.
