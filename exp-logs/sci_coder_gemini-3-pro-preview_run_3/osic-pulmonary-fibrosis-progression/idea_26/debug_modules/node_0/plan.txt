### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed using `library.utils.seed_everything` to ensure reproducibility. Verify the compute device (CPU/GPU).
2.  **Data Pipeline Verification**:
    *   Initialize the `OSICDataset` and `DataLoader` via `library.data.get_dataloaders`.
    *   Fetch a single batch to verify the data structure, shapes, and types of the image tensors, tabular features, and targets.
    *   Validate that the image dimensions match the configuration (`260x260`) and that tabular features have the expected dimension (6).
3.  **Model Architecture Verification**:
    *   Instantiate the `GCRNet` model from `library.model`.
    *   Perform a forward pass using the fetched batch.
    *   Assert that the output shape is `(Batch_Size, 2)` corresponding to `FVC` and `Confidence`.
    *   Verify that the predicted confidence values (Sigma) are positive.
4.  **Loss and Metric Verification**:
    *   Instantiate `LaplaceLogLikelihoodLoss` and `MetricMonitor`.
    *   Compute the loss on the model outputs and verify it is a finite scalar.
    *   Update the metric monitor and retrieve average scores to ensure the calculation logic holds.
5.  **Training Loop Demonstration (Speed Optimized)**:
    *   Instead of running the full 50 epochs defined in `run_training`, manually construct a small `Subset` of the training data (e.g., 4 samples).
    *   Create a temporary `DataLoader` for this subset.
    *   Run `library.train.train_one_epoch` for a single iteration to demonstrate the training step without the computational overhead.
    *   Run `library.train.evaluate` on the same small subset to demonstrate validation.
6.  **Inference and Submission Demonstration**:
    *   Save the current model state as a checkpoint to the expected location (`working/idea_26/checkpoints/best_model.pth`).
    *   Execute `library.predict.generate_submission`. This function loads the checkpoint and generates predictions for the test set.
    *   Verify that the `submission.csv` file is created and contains the expected columns (`Patient_Week`, `FVC`, `Confidence`).
