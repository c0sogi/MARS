Based on the comprehensive analysis of the accumulated lessons, I propose the **Supervised Bottleneck-Projected Dual-Stream Network (SB-PDS Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Dimensionality Balance** **Cite solution_lesson_node_00146**, **Context Visibility** **Cite solution_lesson_node_00139**, and **Regularization** **Cite solution_lesson_node_00132**. It explicitly resolves the optimization instability of previous iterations by enforcing a strict "Boosting" paradigm via **Auxiliary Supervision** and **Output-Space Zero-Initialization** **Cite solution_lesson_node_00118**.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Output-Space Summation** topology with **Deep Supervision**.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency **Cite solution_lesson_node_00071**, **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** Unfreeze top two stages; keep bottom frozen **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer.
    *   **Bottleneck Projection (Structural Innovation):** The high-dimensional backbone output (1408-dim) is immediately projected to **64 dimensions** via a Linear layer. This prevents the high-dimensional image noise from statistically dominating the fusion layer **Cite solution_lesson_node_00146**.

*   **Stream A: Supervised Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Base Mean ($\mu_{base}$) and Base Uncertainty ($\sigma_{base}$).
    *   **Purpose:** This stream learns the baseline disease trajectory. We use an MLP to ensure sufficient capacity to model the linear trends without optimization bottlenecks **Cite solution_lesson_node_00060**.
    *   **Auxiliary Supervision:** We apply the loss function directly to these outputs during training. This forces Stream A to become a robust standalone predictor, stabilizing the residual learning process.

*   **Stream B: Projected-Context Visual Residual (The Correction):**
    *   **Input:** Concatenation of [**Projected Image (64-dim)**, **Raw Clinical Scalars**].
    *   **Context Injection:** By providing raw scalars (Baseline FVC, Time) directly to this stream, we ensure the deep branch is conditioned on the patient's initial severity, allowing it to learn patient-specific residuals **Cite solution_lesson_node_00139**, **Cite solution_lesson_node_00035**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Dropout(p=0.2) -> Linear(128 -> 64) -> Dropout(p=0.2) -> Linear(64 -> 2)`).
    *   **Regularization:** We explicitly **include Dropout**. Since this stream learns a weak residual correction, regularization is mandatory to prevent overfitting to noise **Cite solution_lesson_node_00132**.
    *   **Zero-Initialization:** The final layer is initialized to **zero**. This ensures the model starts as the (supervised) Clinical Anchor **Cite solution_lesson_node_00118**.
    *   **Outputs:** Residuals $\delta_\mu, \delta_\sigma$.

*   **Probabilistic Output Fusion:**
    *   **Mean:** $\mu_{final} = \mu_{base} + \delta_\mu$.
    *   **Uncertainty:** $\sigma_{final} = \text{Softplus}(\sigma_{base} + \delta_\sigma) + \epsilon$.
    *   **Rationale:** Ensures a direct pathway for clinical priors **Cite solution_lesson_node_00055** without explicit shortcuts **Cite solution_lesson_node_00085**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select "Anchor" slice (Max Lung Area) and two boundary slices (50% area) **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. **No Z-score** **Cite solution_lesson_node_00036**.
    *   **Normalization:** Target `FVC` is Z-score standardized **Cite solution_lesson_node_00001**. Input scalars are standardized but passed **raw** (no Batch Norm) **Cite solution_lesson_node_00017**.

### 3. Training
*   **Loss Function:** **Multi-Task Metric-Aligned Laplace Log Likelihood**.
    *   $L_{metric} = \frac{\sqrt{2} |y - \hat{y}|}{\hat{\sigma}} + \ln(\sqrt{2} \hat{\sigma})$ **Cite solution_lesson_node_00066**.
    *   **No Clipping:** Do not clamp the loss during training **Cite solution_lesson_node_00138**.
    *   **Total Loss:** $L = L_{metric}(\text{Final}) + 0.5 \cdot L_{metric}(\text{Base})$.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$. Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via SB-PDS Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for submission **Cite solution_lesson_node_00014**.
