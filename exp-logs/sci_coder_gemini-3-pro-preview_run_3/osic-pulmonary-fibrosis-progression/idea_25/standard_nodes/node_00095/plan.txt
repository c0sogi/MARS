My implementation strategy focuses on adopting the **Dual-Stream Point-Wise Residual Network (DSPRNet)** architecture, which has historically yielded the best performance on this task.

1.  **Configuration**: I will increase the `BATCH_SIZE` from 16 to 32. As noted in **Lesson 00094**, small batch sizes on this dataset destabilize the optimization of Batch Normalization layers in the EfficientNet backbone, leading to premature convergence. I will also update the working directory.
2.  **Model Architecture**: I will replace the cascaded `CCVRNet` with `DSPRNet`.
    *   **Stream A (Linear Residual)**: A dedicated linear stream that processes only the dominant autoregressive features (Baseline FVC and Time). I will project these 2 features into the 64-dim latent space using a Linear layer. This "over-parameterization" prevents the bottlenecking of the strong linear signal, as advised in **Lesson 00060**.
    *   **Stream B (Deep Interaction)**: A parallel deep stream that concatenates the image embeddings with *all* tabular features to learn complex non-linear corrections.
    *   **Fusion**: The streams are summed in the latent space (`Linear + Deep`) before the final projection, allowing the model to learn `Prediction = LinearTrend + NonLinearCorrection` (Cite **Lesson 00052**).
3.  **Training**: I will update the training script to initialize `DSPRNet` and correctly assign the new sub-modules (`linear_stream`, `deep_stream`) to the optimizer.

    """
    Stream A: Over-Parameterized Clinical Anchor.
    Learns the expected clinical trajectory based on tabular data.
    """

    def __init__(self):
        super(ClinicalStreamA, self).__init__()
        # Inputs: Baseline_FVC, Baseline_Percent, Age, Sex, Smoking, Relative_Weeks
        input_dim = 6

        self.net = nn.Sequential(
            nn.Linear(input_dim, Config.CLINICAL_HIDDEN_DIM),  # 128
            nn.ReLU(),
            nn.Linear(Config.CLINICAL_HIDDEN_DIM, Config.LATENT_DIM),  # 64
        )

    def forward(self, x):
        return self.net(x)

class CCVRNet(nn.Module):
    """
    Cascaded Clinical-Visual Residual Network.
    """

    def __init__(self):
        super(CCVRNet, self).__init__()
        self.visual_branch = VisualBranch()
        self.stream_a = ClinicalStreamA()
        self.stream_b = VisualStreamB()

        # Shared Head: Projects H_final to mu and sigma
        self.head = nn.Linear(Config.LATENT_DIM, 2)

    def forward(self, image, tabular):
        """
        Args:
            image: Tensor (Batch, 3, H, W)
            tabular: Tensor (Batch, 6)
        Returns:
            mu: Predicted FVC (scaled)
            sigma: Predicted Uncertainty (scaled)
        """
        # 1. Get Visual Embedding (E_img)
        img_embed = self.visual_branch(image)  # (B, 64)

        # 2. Get Clinical Anchor Embedding (H_clin) - Stream A
        clin_embed = self.stream_a(tabular)  # (B, 64)

        # 3. Get Visual Interaction Embedding (H_inter) - Stream B
        # Cascade: Condition visual processing on clinical state
        combined_input = torch.cat([img_embed, clin_embed], dim=1)  # (B, 128)
        inter_embed = self.stream_b(combined_input)  # (B, 64)

        # H_final = StreamA + StreamB
        h_final = clin_embed + inter_embed  # (B, 64)

        # 5. Prediction Head
        out = self.head(h_final)  # (B, 2)

        mu = out[:, 0]
        raw_sigma = out[:, 1]

        # Uncertainty Constraint
        # Apply softplus to ensure positivity, add epsilon for stability
        sigma = F.softplus(raw_sigma) + 1e-6

        return mu, sigma

class LinearStream(nn.Module):
    """
    Stream A: Linear Residual Stream.
    Processes dominant autoregressive features (Baseline FVC, Time).
    Over-parameterized to latent dimension to avoid bottlenecks (Cite solution_lesson_node_00060).
    """

    def __init__(self):
        super(LinearStream, self).__init__()
        # Inputs: Baseline_FVC_Scaled, Relative_Weeks_Scaled
        input_dim = 2
        # Project to latent dim directly (Linear mapping)
        self.net = nn.Linear(input_dim, Config.LATENT_DIM)

    def forward(self, x):
        return self.net(x)


class DeepStream(nn.Module):
    """
    Stream B: Deep Interaction Stream.
    Fuses Image Embeddings with all Tabular features to learn non-linear corrections.
    """

    def __init__(self):
        super(DeepStream, self).__init__()
        # Input: Image Projection (64) + All Tabular (6)
        input_dim = Config.IMG_EMBED_DIM + 6

        self.net = nn.Sequential(
            nn.Linear(input_dim, Config.FUSION_HIDDEN_DIM),  # 128
            nn.ReLU(),
            nn.Linear(Config.FUSION_HIDDEN_DIM, Config.LATENT_DIM),  # 64
        )

    def forward(self, img_embed, tabular):
        combined = torch.cat([img_embed, tabular], dim=1)
        return self.net(combined)

    Dual-Stream Point-Wise Residual Network (DSPRNet).
    Implements architecture from solution_lesson_node_00052.
    """

        self.visual_branch = VisualBranch()
        self.linear_stream = LinearStream()
        self.deep_stream = DeepStream()

        self.head = nn.Linear(Config.LATENT_DIM, 2)

        img_embed = self.visual_branch(image)  # (B, 64)

        linear_input = tabular[:, [0, 5]]

        raw_sigma = out[:, 1]

        # Apply softplus to ensure positivity, add epsilon for stability
        sigma = F.softplus(raw_sigma) + 1e-6

        return mu, sigma
