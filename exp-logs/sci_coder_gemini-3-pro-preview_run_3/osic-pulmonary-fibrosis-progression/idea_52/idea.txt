Based on the comprehensive analysis of the accumulated lessons, I propose the **Affine-Isolated Latent-Residual Network (AILR-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Input Isolation** **Cite solution_lesson_node_00177**, **Affine Capacity** **Cite solution_lesson_node_00180**, **Visual Embedding Capacity** **Cite solution_lesson_node_00183**, and **Metric Alignment** **Cite solution_lesson_node_00164**. It explicitly resolves the conflict between signal preservation and capacity by implementing a restricted-input, over-parameterized anchor fused in a sufficiently wide latent space.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology.

*   **Stream A: Affine-Isolated Clinical Anchor (The Foundation):**
    *   **Input Restriction:** This stream receives **only** `Baseline FVC` and `Relative Time` ($t_{rel}$). We explicitly **exclude** static metadata (Age, Sex, Smoking) from this branch to strictly enforce the autoregressive inductive bias ($y_t \approx f(y_0, t)$) and prevent signal dilution **Cite solution_lesson_node_00177**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(2 -> 128) -> ReLU -> Linear(128 -> 128)`).
    *   **Affine Capacity:** We strictly ensure `bias=True` in all layers to allow the model to learn global intercepts/offsets **Cite solution_lesson_node_00180**.
    *   **Purpose:** Unlike a simple linear layer (which creates optimization bottlenecks), this MLP projects the restricted inputs into a high-dimensional latent space, ensuring sufficient capacity to robustly model the identity mapping and linear decay **Cite solution_lesson_node_00060**.

*   **Stream B: Context-Aware Visual Residual (The Correction):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency **Cite solution_lesson_node_00071**.
    *   **Fine-Tuning:** Unfreeze top two stages; keep bottom frozen **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer.
    *   **Context Injection:** Concatenate the image features with **All Raw Clinical Scalars** (`Baseline FVC`, `Time`, `Age`, `Sex`, `SmokingStatus`). This ensures the deep branch is conditioned on the full patient context, allowing it to learn complex, patient-specific residuals **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 256) -> ReLU -> Linear(256 -> 128)`).
    *   **Dimensionality:** We maintain a latent dimension of **128** (matching Stream A). We reject aggressive compression (e.g., to 64) to preserve the variance required for the residual signal **Cite solution_lesson_node_00183**.
    *   **Regularization:** We explicitly **exclude Dropout**. Since this stream learns a weak residual correction to the strong anchor, stochastic regularization drowns out the gradient signal **Cite solution_lesson_node_00126**.

*   **Latent Fusion & Constraint-Aware Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm in the latent space **Cite solution_lesson_node_00052**.
    *   **Head:** A shared Linear layer projects $H_{final}$ to $\mu_{scaled}$ and $\sigma_{raw}$. We use a shared head to ensure uncertainty estimation maintains a direct connection to the clinical priors **Cite solution_lesson_node_00055**.
    *   **Structural Innovation (Metric Constraint):** We enforce the metric's 70ml floor *architecturally* within the standardized space.
        *   Calculate $\epsilon_{std} = 70 / \sigma_{global\_target}$.
        *   $\sigma_{scaled} = \text{Softplus}(\sigma_{raw}) + \epsilon_{std}$.
        *   This prevents the model from predicting uncertainties below the metric's threshold, resolving the divergence between validation loss and metric score **Cite solution_lesson_node_00164**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select "Anchor" slice (Max Lung Area) and two boundary slices (50% area) **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. **No Z-score** to preserve physical origin **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** **Ordinal Encoding** for `SmokingStatus` **Cite solution_lesson_node_00103**.
    *   **Target Normalization:** Normalize targets using **Global Statistics** (all visits), not baseline statistics **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) **Cite solution_lesson_node_00017**.
    *   **Exclusions:** Explicitly exclude `Percent` to avoid proxy leakage **Cite solution_lesson_node_00069**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood (Standardized)**.
    *   $L = \frac{\sqrt{2} |y_{scaled} - \mu_{scaled}|}{\sigma_{scaled}} + \ln(\sqrt{2} \sigma_{scaled})$.
    *   We optimize in the standardized space to avoid gradient instability **Cite solution_lesson_node_00165** while explicitly including the $\sqrt{2}$ constants **Cite solution_lesson_node_00066** and avoiding arbitrary clipping **Cite solution_lesson_node_00138**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.
    *   **No Auxiliary Loss:** We train only on the final output to avoid conflicting objectives **Cite solution_lesson_node_00159**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$. Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via AILR-Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{global} + \mu_{global}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for submission **Cite solution_lesson_node_00014**.
