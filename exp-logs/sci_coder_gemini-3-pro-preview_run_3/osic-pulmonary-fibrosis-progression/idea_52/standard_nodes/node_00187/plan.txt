I will optimize the AILR-Net architecture by introducing a bottleneck projection layer for the image features before fusion. Currently, the high-dimensional image embeddings (1408 dim) are concatenated directly with the low-dimensional tabular features (5 dim), which can cause the optimizer to ignore the clinical signal (Cite solution_lesson_node_00146). I will project the image features to 128 dimensions using a Linear-ReLU block before concatenation. This maintains sufficient capacity for visual residuals (Cite solution_lesson_node_00183) while balancing the modalities. Additionally, I will extend the training duration to 25 epochs in the runfile to allow the regularized model sufficient time to converge.
