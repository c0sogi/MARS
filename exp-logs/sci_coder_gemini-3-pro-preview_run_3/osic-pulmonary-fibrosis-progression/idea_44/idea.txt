Based on the comprehensive analysis of the accumulated lessons, I propose the **Global-Normed Projected-Context Residual Network (GPCR-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Target Normalization** **Cite solution_lesson_node_00155**, **Dimensionality Balance** **Cite solution_lesson_node_00146**, and **Regularization** **Cite solution_lesson_node_00126**. It explicitly resolves the failure of Idea 43 by correcting the normalization statistics and removing the destabilizing Dropout/Zero-Initialization combination, while retaining the robust **Auxiliary Supervision** strategy.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology with **Deep Supervision**.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for texture analysis (e.g., reticulation), avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of heavier models like V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Bottleneck Projection:** The high-dimensional backbone output (1408-dim) is immediately projected to **64 dimensions** via a learnable Linear layer. This prevents the high-dimensional image noise from statistically dominating the fusion layer **Cite solution_lesson_node_00146**.

*   **Stream A: Supervised Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the baseline disease trajectory ($FVC(t) \approx Base + Rate \times t$). We use an MLP to ensure sufficient capacity to model the linear trends without optimization bottlenecks **Cite solution_lesson_node_00060**.
    *   **Auxiliary Head:** A dedicated Linear layer projects the output of this stream to auxiliary predictions $\mu_{aux}, \sigma_{aux}$. These are trained against the ground truth to force Stream A to be a robust standalone predictor.

*   **Stream B: Context-Injected Visual Residual (The Correction):**
    *   **Input:** Concatenation of [**Projected Image (64-dim)**, **Raw Clinical Scalars**].
    *   **Context Injection:** By providing raw scalars (Baseline FVC, Time) directly to this stream, we ensure the deep branch is conditioned on the patient's initial severity, allowing it to learn patient-specific residuals rather than generic corrections **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Regularization:** We explicitly **exclude Dropout**. Since this stream learns a weak residual correction to the strong clinical anchor, stochastic regularization drowns out the gradient signal. We rely on the **Bottleneck Projection** and **Early Stopping** for regularization **Cite solution_lesson_node_00126**.
    *   **Initialization:** We use **Standard Random Initialization**. We reject Zero-Initialization because the parallel Stream A is a learnable projection (not an identity), making zero-init unstable **Cite solution_lesson_node_00118**.

*   **Latent Fusion & Shared Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm **Cite solution_lesson_node_00052**.
    *   **Head:** A shared Linear layer projects $H_{final}$ to $\mu, \sigma$.
    *   **Constraint:** We use a shared head to ensure uncertainty estimation maintains a direct, low-complexity pathway from the clinical priors **Cite solution_lesson_node_00055**, avoiding explicit time-shortcuts **Cite solution_lesson_node_00085**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) **Cite solution_lesson_node_00124**, **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) **Cite solution_lesson_node_00103**.
    *   **Target Normalization (Crucial Correction):** We calculate the mean and standard deviation of the **Entire Training Target Distribution** (all visits) and use these to Z-score normalize the target `FVC`. We explicitly reject using baseline-only statistics, which introduces a covariate shift in longitudinal data **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Multi-Task Metric-Aligned Laplace Log Likelihood**.
    *   **Primary Loss:** $L_{main} = \frac{\sqrt{2} |y - \mu|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   **Auxiliary Loss:** $L_{aux}$ (same formula applied to Stream A outputs).
    *   **Total Loss:** $L = L_{main} + 0.5 \cdot L_{aux}$.
    *   **Metric Alignment:** Explicitly includes $\sqrt{2}$ constants **Cite solution_lesson_node_00066** and avoids arbitrary clipping **Cite solution_lesson_node_00138**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. No hard clipping in architecture **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$ for each test `Patient_Week`.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via GPCR-Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{global\_target} + \mu_{global\_target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global\_target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
