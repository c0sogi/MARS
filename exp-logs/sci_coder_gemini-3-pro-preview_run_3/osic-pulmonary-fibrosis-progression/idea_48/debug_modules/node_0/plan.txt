Implementation Strategy:
1.  **Environment Setup**: Initialize the random seed and override the `Config` class attributes to enable debug mode (`DEBUG=True`), reduce epochs to 1, and redirect output paths to a temporary working directory. This ensures the script runs quickly and doesn't interfere with existing runs.
2.  **Data Pipeline Verification**: Call `get_dataloaders` to retrieve training and validation loaders. Fetch a single batch to verify the shapes and data types of the image tensors, tabular features, and target values against expected dimensions.
3.  **Model Architecture Verification**: Instantiate the `CASDSNet` model and move it to the appropriate device (CPU/GPU). Perform a forward pass with the fetched batch to ensure the model outputs mean (`mu`) and confidence (`sigma`) tensors of the correct shape and that `sigma` satisfies the positivity constraint.
4.  **Loss & Metric Verification**: Compute the custom `LLLLoss` on the model outputs. Verify the loss is a valid scalar. Perform the inverse transformation on predictions and calculate the competition metric (`calculate_metric`) to ensure the scoring logic functions correctly.
5.  **Training Loop Simulation**: Run a minimal training loop (1 epoch) using `train_epoch` and `val_epoch` to demonstrate the optimization process and log the results. Save the model state to a checkpoint.
6.  **Inference & Submission**: Invoke `generate_submission` to process the test set (subset in debug mode) and generate a `submission.csv`. Verify the file's existence and structure.
