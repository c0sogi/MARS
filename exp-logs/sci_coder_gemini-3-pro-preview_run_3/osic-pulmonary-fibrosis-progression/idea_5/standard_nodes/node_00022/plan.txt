Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and ensure reproducibility with `seed_everything(Config.SEED)`.
2.  **Data Loading**: Load the training and validation metadata from the `./metadata` directory. Use `get_dataloaders` to create PyTorch DataLoaders with `load_cached_data=True` to leverage preprocessed image tensors.
3.  **Model Initialization**: Instantiate the `WideAndDeepNet` model, `AdamW` optimizer, and `CosineAnnealingLR` scheduler using hyperparameters defined in `Config`. Move the model to the GPU.
4.  **Training Loop**:
    *   Iterate for `Config.EPOCHS` (35 epochs).
    *   Perform training steps using `train_epoch`.
    *   Perform validation using `validate` to monitor performance.
    *   Save the model checkpoint whenever the validation score improves.
5.  **Evaluation & Failure Analysis**:
    *   Load the best saved model state.
    *   Run a custom inference loop on the validation set to extract detailed predictions ($\mu$, $\sigma$) and ground truth values.
    *   Compute the **Final Validation Metric** using the competition metric function.
    *   Calculate absolute errors ($|y_{true} - y_{pred}|$) and correlate them with metadata features (Weeks, Age, Sex, SmokingStatus, Percent) to identify error sources.
6.  **Conditional Submission**:
    *   Check if the Final Validation Metric exceeds the threshold `-6.6997912217`.
    *   If passed, load test metadata, expand it using `prepare_submission_df`, and run inference using the best model.
    *   Apply the inverse transformation (Z-score un-normalization) and clip confidence values.
    *   Save the results to `./submission/submission.csv`.
