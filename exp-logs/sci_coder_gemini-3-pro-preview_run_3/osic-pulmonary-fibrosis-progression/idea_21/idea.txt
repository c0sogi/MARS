Based on the comprehensive analysis of the accumulated lessons, particularly the success of the Dual-Stream architecture (**Cite solution_lesson_node_00052**) and the identified bottlenecks regarding linear capacity (**Cite solution_lesson_node_00060**) and uncertainty modeling (**Cite solution_lesson_node_00055**), I propose the **Robust Clinical-Residual Fusion Network (RCRF-Net)**.

This solution introduces a structural innovation by replacing the simple linear residual connection with an **Over-Parameterized Clinical Stream** and augmenting the uncertainty head with a **Time-Shortcut**. This ensures the model preserves strong clinical priors without optimization bottlenecks while explicitly modeling the physical degradation of confidence over time.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Dual-Stream Latent Summation** topology.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for texture analysis, avoiding the underfitting of B0 (**Cite solution_lesson_node_00071**) and the overfitting of heavier models (**Cite solution_lesson_node_00054**).
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection (**Cite solution_lesson_node_00027**).
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals (**Cite solution_lesson_node_00025**).
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting (**Cite solution_lesson_node_00065**).

*   **Stream A: Over-Parameterized Clinical Anchor:**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`. We explicitly **exclude** `Percent` to prevent proxy leakage (**Cite solution_lesson_node_00069**).
    *   **Architecture:** An **MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Innovation:** Unlike previous iterations that used a single linear layer, this stream is **over-parameterized**. This ensures the network has sufficient capacity to robustly map the identity and linear trends into the latent space, avoiding the optimization bottleneck of minimal layers (**Cite solution_lesson_node_00060**).

*   **Stream B: Visual Interaction Stream:**
    *   **Input:** Concatenation of [Image Projection, `Baseline FVC`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`].
    *   **Architecture:** An **MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream captures complex non-linear cross-modal interactions (e.g., "Fibrosis $\times$ Time") (**Cite solution_lesson_node_00032**).

*   **Latent Fusion & Time-Shortcut Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm where the visual stream corrects the robust clinical anchor (**Cite solution_lesson_node_00052**).
    *   **Mean Head:** A Linear layer projects $H_{final}$ to $\mu$.
    *   **Uncertainty Head (Structural Innovation):** A Linear layer projects the concatenation of $[H_{final}, |t_{rel}|]$ to $\sigma$.
    *   **Rationale:** By explicitly injecting the **absolute magnitude of relative time** into the uncertainty head, we provide a low-complexity pathway for the model to learn the "Uncertainty Cone" (confidence degrading with distance from baseline), ensuring physical consistency and faster calibration (**Cite solution_lesson_node_00036**, **Cite solution_lesson_node_00055**).

### 2. Data
*   **Preprocessing:**
    *   **Content-Adaptive Slice Selection:** For each patient, select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency (**Cite solution_lesson_node_00015**).
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline (**Cite solution_lesson_node_00036**).
    *   **Target Standardization:** The target `FVC` is **Z-score standardized** during training (**Cite solution_lesson_node_00001**).
    *   **Input Normalization:** `Baseline FVC` and `Age` are standardized but passed as **raw scalars** (no Batch Norm) to preserve absolute magnitude signals (**Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**).

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   We explicitly include the $\sqrt{2}$ constants to correct the systematic underestimation of uncertainty observed with standard NLL (**Cite solution_lesson_node_00066**).
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow (**Cite solution_lesson_node_00014**).
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs (**Cite solution_lesson_node_00027**).
    *   **Duration:** **50 Epochs** to allow uncertainty calibration (**Cite solution_lesson_node_00011**).

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through RCRF-Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) (**Cite solution_lesson_node_00006**).
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file (**Cite solution_lesson_node_00014**).
