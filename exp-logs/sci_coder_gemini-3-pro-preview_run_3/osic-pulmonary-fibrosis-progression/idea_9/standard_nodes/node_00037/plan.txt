Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup and Configuration**: Initialize the environment using `Config.setup()` to create directories and set random seeds. Override `Config.EPOCHS` to 30 to ensure the training completes quickly while allowing sufficient convergence for a baseline.
2.  **Data Loading**: Use `get_dataloaders` to retrieve the training, validation, and test data loaders.
3.  **Training**: Instantiate the `Trainer` class and execute the `fit` method to train the OCP-Net model.
4.  **Model Restoration**: Load the best checkpoint saved during training to ensure evaluation and analysis are performed on the optimal model state.
5.  **Validation**: Run the `validate` method on the hold-out validation set to compute the final Laplace Log Likelihood score. Print this metric with full precision.
6.  **Failure Analysis**:
    *   Perform inference on the validation set to gather predictions, ground truth, and input features.
    *   Calculate the absolute error for each sample.
    *   Compute and print the Pearson correlation between the error magnitude and key features (Age, Sex, Smoking Status, Baseline FVC, Weeks) to identify sources of systematic error.
7.  **Submission**: Check if the validation metric exceeds the threshold (-6.57744688338769). If successful, generate the submission file using `trainer.generate_submission`.
