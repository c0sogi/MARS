This script demonstrates the usage of the provided library files for the lung function decline prediction task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to create a lightweight "demo" environment (reduced epochs, batch size, and temporary directories) to ensure fast execution.
2.  **Data Pipeline Verification**: Instantiates data loaders using `library.data.get_dataloaders`, fetches a single batch, and verifies the tensor shapes and data types of images, tabular features, and targets.
3.  **Model Architecture Verification**: Instantiates the `OCPNet` model from `library.model`, performs a forward pass with the sample batch, and asserts that the output shapes (mean and uncertainty) are correct and valid.
4.  **Metric Verification**: Tests the `laplace_log_likelihood` function from `library.utils` against a manually calculated value to ensure metric correctness.
5.  **Training Loop Demonstration**: Initializes the `Trainer` from `library.train` and runs a minimal training session (1 epoch) using the `fit` method.
6.  **Inference and Submission**: Generates a submission file using the `generate_submission` method and verifies the output file format and content.
