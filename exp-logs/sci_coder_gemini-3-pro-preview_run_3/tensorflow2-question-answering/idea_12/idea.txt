### Model
The proposed solution is a **2D Interaction Convolutional Ranker** and a **1D U-Net Reader**. This architecture approaches the ranking problem as an image recognition task over a similarity matrix and treats the reading problem as a sequence segmentation task using an encoder-decoder architecture with skip connections.

1.  **Long Answer Ranker (2D Interaction Convolutional Network):**
    *   **Input:** Accepts the Question and a Candidate Long Answer (paragraph) as separate inputs.
    *   **Embedding:** Maps tokens to pre-trained static word embeddings (e.g., GloVe).
    *   **Interaction Image:** Computes the outer product (or pairwise similarity) between the Question embeddings and the Candidate embeddings. This results in a **2D Interaction Matrix** (an "image") where the axes represent the question and candidate sequence positions, and pixel intensity represents the similarity between words.
    *   **Encoder:** The interaction matrix is processed by a stack of **2D Convolutional** layers followed by **2D Max-Pooling**. The convolutional filters learn to recognize geometric matching patterns, such as diagonal lines (indicating consecutive phrase matching) or rectangular blocks (indicating term clusters), which are strong signals of relevance.
    *   **Scoring:** The output of the final pooling layer is flattened and passed through a Multi-Layer Perceptron (MLP) to predict a relevance probability.

2.  **Short Answer Reader (1D U-Net):**
    *   **Input:** Concatenates the Question and the Top-Ranked Candidate Paragraph into a single sequence.
    *   **Architecture:** Adapts the **U-Net** architecture (commonly used for image segmentation) for 1D text sequences.
    *   **Contraction Path (Encoder):** A series of convolutional blocks followed by max-pooling layers. This progressively reduces the sequence length while increasing the feature depth, capturing high-level semantic context.
    *   **Expansion Path (Decoder):** A series of upsampling layers (e.g., transposed convolutions) followed by standard convolutions. This restores the sequence to its original length.
    *   **Skip Connections:** Features from the Contraction path are concatenated with the corresponding layers in the Expansion path. This preserves fine-grained localization information (exact token positions) that is usually lost during pooling, which is critical for precise span extraction.
    *   **Output:** The final layer is a 1x1 convolution that projects the features to logits, predicting the start and end probabilities for each token.

### Data
*   **Preprocessing:**
    *   **Segmentation:** The raw `document_text` is parsed to extract candidate paragraphs using top-level HTML tags (e.g., `<P>`, `<Table>`, `<Ul>`).
    *   **Tokenization:** Text is tokenized by splitting on whitespace. A vocabulary is built from the training corpus, and tokens are mapped to indices corresponding to the pre-trained embedding matrix.
*   **Dataset Construction:**
    *   **Ranker Data:** Training samples are created as pairs. Positive pairs consist of the Question and the ground-truth paragraph. Negative pairs are selected by sampling paragraphs from the same document that do not contain the answer.
    *   **Reader Data:** Only positive paragraphs containing valid short answers are used. The start and end token indices are adjusted to be relative to the beginning of the concatenated sequence.

### Training
*   **Strategy:** The Ranker and Reader are trained as independent models to minimize computational resource requirements and allow for parallel training.
*   **Ranker Optimization:** Trained using **Binary Cross-Entropy Loss**. The model learns to classify whether the interaction pattern between a Question and Paragraph indicates a match (1) or a non-match (0).
*   **Reader Optimization:** Trained using **Categorical Cross-Entropy Loss** applied independently to the start and end token predictions.
*   **Optimizer:** The **Adam** optimizer is used for both models with standard learning rate scheduling.

### Evaluation
1.  **Candidate Generation:** The test document is segmented into candidate paragraphs.
2.  **Ranking:** The 2D Interaction Convolutional Ranker generates an interaction image for the Question and each candidate, processes it, and outputs a relevance score.
3.  **Selection:** The candidate with the highest relevance score is selected as the predicted Long Answer.
4.  **Extraction:** The selected paragraph is concatenated with the Question and passed to the 1D U-Net Reader. The U-Net outputs probability distributions for the start and end tokens.
5.  **Inference:** The valid span (`start <= end`) with the highest joint probability is identified. A global confidence score is computed; if it falls below a tuned threshold, the system predicts "Null", otherwise it outputs the predicted Long Answer indices and Short Answer text.
