### Model
The proposed solution is a **Recurrent Siamese Ranker and Conditional LSTM Reader**. This architecture utilizes Recurrent Neural Networks (RNNs) to capture sequential dependencies and long-range context, which are often missed by averaging or convolutional approaches, while remaining significantly lighter than full Transformer models.

1.  **Long Answer Ranker (Siamese Bi-LSTM):**
    *   **Input:** Accepts the Question and a Candidate Long Answer (paragraph) as separate inputs.
    *   **Embedding:** Maps tokens to pre-trained static word embeddings (e.g., GloVe).
    *   **Encoder:** Both inputs are processed by a shared **Bi-Directional LSTM** layer. This processes the text sequentially in both directions to generate context-aware hidden states for every token.
    *   **Aggregation:** A **Max-Over-Time Pooling** operation is applied to the sequence of hidden states. This selects the most salient features from the entire sequence, resulting in a single fixed-size vector representation for the Question and the Candidate.
    *   **Scoring:** The relevance score is calculated using the **Cosine Similarity** between the Question vector and the Candidate vector.

2.  **Short Answer Reader (Conditional LSTM):**
    *   **Input:** The Question and the Top-Ranked Candidate Paragraph.
    *   **Query Encoding:** The Question is encoded using a Bi-LSTM, and the final hidden states (forward and backward) are concatenated to form a fixed "Question Vector".
    *   **Context Conditioning:** The "Question Vector" is replicated and concatenated to the embedding of *every* token in the Candidate Paragraph. This explicitly conditions the paragraph representation on the question at the input level.
    *   **Sequence Modeling:** The combined embeddings are passed through a separate Bi-Directional LSTM layer to generate a sequence of context-aware hidden states for the paragraph.
    *   **Output:** Two independent linear classifiers (Dense layers) project the LSTM outputs to logits, predicting the probability of each token being the `start` and `end` of the answer span.

### Data
*   **Preprocessing:** The `document_text` is parsed to extract text within top-level HTML tags (e.g., `<P>`, `<Table>`), creating a list of candidate paragraphs. HTML tags are removed, and text is tokenized by whitespace.
*   **Vocabulary:** A vocabulary is built from the training corpus, filtering rare words. Tokens are mapped to indices corresponding to the pre-trained embedding matrix.
*   **Ranker Dataset:** Training pairs are generated. Positive pairs consist of the Question and the paragraph containing the ground-truth annotation. Negative pairs are formed by sampling paragraphs from the same document that do not contain the answer.
*   **Reader Dataset:** Only positive paragraphs (those containing a Short Answer) are used. The start and end token indices of the short answer are adjusted to be relative to the specific paragraph's start.

### Training
*   **Strategy:** The Ranker and Reader are trained as separate models to modularize the pipeline and reduce computational resource requirements.
*   **Ranker Optimization:** Trained using **Contrastive Loss**. The model learns to minimize the distance (maximize cosine similarity) for positive pairs and maximize the distance for negative pairs, pushing relevant paragraphs closer to the question in the vector space.
*   **Reader Optimization:** Trained using **Sparse Categorical Cross-Entropy Loss**. The model minimizes the error for predicting the correct start and end tokens independently.
*   **Optimizer:** The Adam optimizer is used for both models with gradient clipping to prevent exploding gradients, a common issue in RNNs.

### Evaluation
1.  **Candidate Generation:** The test document is segmented into candidate paragraphs.
2.  **Ranking:** The Siamese Bi-LSTM Ranker encodes the Question and all Candidates into vectors and computes cosine similarity scores.
3.  **Selection:** The candidate with the highest similarity score is selected as the predicted Long Answer.
4.  **Extraction:** The Conditional LSTM Reader processes the selected paragraph (conditioned on the Question vector) to output probability distributions for start and end indices.
5.  **Inference:** The span with the highest joint probability (Start Prob $\times$ End Prob) is selected. If the Ranker's similarity score is below a calibrated threshold, the system predicts "Null"; otherwise, it returns the predicted Long and Short answers.
