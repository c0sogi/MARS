This script demonstrates the end-to-end pipeline of the Question Answering system using the provided library. It performs the following steps:

1.  **Configuration**: Patches the `Config` class to use a temporary working directory and small dataset subsets for rapid execution.
2.  **Preprocessing**: Generates a vocabulary and embedding matrix from the training data subset.
3.  **Data Loading**: Creates PyTorch datasets and dataloaders for both the Ranker and Reader models, verifying data integrity.
4.  **Model Initialization**: Instantiates the `HistogramRanker` and `QRNNReader` models and verifies their forward passes with dummy batches.
5.  **Training**: Runs a single epoch of training for both models to demonstrate the training loop.
6.  **Inference**: Runs the inference pipeline on a subset of the test data and generates a submission file.
