Implementation strategy:
1.  **Setup**: Initialize random seeds and device configuration for reproducibility and GPU usage.
2.  **Training**: Utilize the `Trainer` class from `library.trainer` to train both the Ranker and Reader models. The `Config` class already defines efficient batch sizes and sample limits to ensure fast execution within the time constraints.
3.  **Validation**: Implement a custom `validate_and_analyze` function. This function will:
    *   Load the validation metadata and a subset of the raw data.
    *   Simulate the full inference pipeline (Ranking -> Selection -> Reading) on the validation set.
    *   Compute the Micro F1 score by comparing predictions against ground truth annotations (handling both Long and Short answers).
    *   Print the `Final Validation Metric`.
4.  **Failure Analysis**: Within the validation loop, collect metadata (question length, document length, model confidence scores) and the computed error (1 - F1). Calculate and print the Pearson correlation between these features and the error to identify failure modes.
5.  **Submission**: Use the `InferencePipeline` class from `library.inference` to generate predictions for the test set and save them to `submission.csv`.
6.  **Optimization**: Use `torch.no_grad()` for inference steps and process data in chunks to manage memory usage effectively.
