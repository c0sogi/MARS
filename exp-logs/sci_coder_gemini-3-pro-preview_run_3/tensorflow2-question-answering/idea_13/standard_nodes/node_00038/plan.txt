Implementation strategy:
1.  **Configuration Override**: Modify `Config` parameters to ensure the training runs quickly (limit epochs to 3, sample size to 20,000) and efficiently (batch size 128).
2.  **Training**: Initialize the `ModelTrainer` and execute the training pipeline. This involves building the vocabulary, creating embedding matrices, and training both the Ranker (DIPN) and Reader (QIRN) models using the provided data loaders.
3.  **Validation & Metric**:
    *   Initialize the `PredictionPipeline` and load the trained models.
    *   Run inference on the validation set using the pipeline's `run_inference` method pointing to the validation metadata.
    *   Iterate through the validation metadata to extract ground truth annotations directly from the source JSONL files.
    *   Compute the Micro F1 score by comparing predictions against ground truth for both long and short answers.
    *   Print the final validation metric.
4.  **Failure Analysis**:
    *   Calculate the error magnitude (1.0 - F1 score) for each validation example.
    *   Extract input features (question length, document length) during the ground truth extraction phase.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify failure modes.
5.  **Submission**:
    *   Run the prediction pipeline on the test set.
    *   Generate the `submission.csv` file using the pipeline's submission generation method.
