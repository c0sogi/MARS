Implementation strategy:
1.  **Configuration Override**: Modify `Config` parameters to ensure the script runs quickly (limit training samples, reduce epochs) while maintaining enough capacity to learn a baseline.
2.  **Training**: Instantiate the `Trainer` class from `library.trainer` and execute the training loop. This produces trained model weights saved in the cache directory.
3.  **Validation & Metric Calculation**:
    *   Load the validation metadata and the ground truth annotations.
    *   Construct an `InferenceDataset` using the validation metadata to simulate the prediction pipeline.
    *   Run inference on the validation set using the trained models.
    *   Compare predictions against ground truth to calculate True Positives (TP), False Positives (FP), and False Negatives (FN) for both long and short answers.
    *   Compute and print the global Micro F1 score.
4.  **Failure Analysis**:
    *   During the validation loop, collect metadata (question length, document complexity) and error status for each sample.
    *   Compute the correlation between these input features and the error occurrence to identify weak points.
5.  **Submission**:
    *   Instantiate the `NQPipeline` class from `library.inference`.
    *   Execute `generate_predictions()` to process the test set and save the `submission.csv` file.
