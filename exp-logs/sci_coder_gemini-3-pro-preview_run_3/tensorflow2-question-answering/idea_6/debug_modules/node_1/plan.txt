The issue is that the `parse_html` function in `library/utils.py` uses a restricted set of HTML tags that does not include inline formatting tags like `<B>` and `<I>`. This causes the test case in `runfile.py` to fail because the parser does not strip the `<B>` tags from the input string. To fix this, I will define a comprehensive `HTML_TAGS` set globally in `library/utils.py` (including `<B>` and `<I>`) and use it in `parse_html`. I will also refactor `library/data_loader.py` and `library/evaluate.py` to import this global `HTML_TAGS` constant instead of redefining it locally, ensuring consistency and adhering to the DRY principle.
