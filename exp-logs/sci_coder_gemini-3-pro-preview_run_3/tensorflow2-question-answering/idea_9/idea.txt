### Model
The proposed solution is a **Decomposable Attention Ranker** and a **Gated Convolutional Reader**. This architecture focuses on computational efficiency by using lightweight alignment mechanisms for ranking and parallelizable gated convolutions for extraction, avoiding the sequential bottlenecks of RNNs and the heavy compute of Transformers.

1.  **Long Answer Ranker (Decomposable Attention Network):**
    *   **Input:** Accepts the Question and a Candidate Long Answer (paragraph) as separate inputs.
    *   **Embedding:** Maps tokens to pre-trained static word embeddings (e.g., GloVe) to represent semantic meaning.
    *   **Attend (Alignment):** Instead of encoding each sequence into a single vector immediately, the model computes a soft alignment matrix between every token in the Question and every token in the Candidate. This allows the model to align related words (e.g., "who" with person names) efficiently.
    *   **Compare:** The aligned representations are compared using a simple Feed-Forward Network (FFN). This step determines the local similarity between aligned sub-phrases.
    *   **Aggregate:** The results of the comparison are summed to produce a single aggregate vector, which is passed through a final FFN to output a relevance probability. This "Attend-Compare-Aggregate" structure captures structural matching without complex encoders.

2.  **Short Answer Reader (Gated Convolutional Network):**
    *   **Input:** Concatenates the Question and the Top-Ranked Candidate Paragraph into a single sequence.
    *   **Encoder:** The sequence is processed by a stack of **Gated Convolutional Layers**. Each layer consists of a standard 1D convolution followed by a **Gated Linear Unit (GLU)** activation. The gating mechanism allows the network to control the flow of information, effectively selecting relevant features (like answer candidates) and suppressing noise (like irrelevant clauses) without the computational overhead of recurrent gates.
    *   **Output:** Two independent linear layers project the final gated features to logits, predicting the probability of each token being the `start` and `end` of the answer span.

### Data
*   **Preprocessing:**
    *   **Segmentation:** The raw `document_text` is parsed to extract discrete candidate paragraphs based on top-level HTML tags (e.g., `<P>`, `<Table>`, `<Ul>`).
    *   **Tokenization:** Text is tokenized by splitting on whitespace. A vocabulary is built from the training corpus, and tokens are mapped to indices corresponding to the pre-trained embedding matrix.
*   **Dataset Construction:**
    *   **Ranker Data:** Training samples are created as pairs. Positive pairs consist of the Question and the ground-truth paragraph. Negative pairs are generated by sampling paragraphs from the same document that do not contain the answer, ensuring a balanced distribution.
    *   **Reader Data:** Only positive paragraphs containing valid short answers are used. The start and end token indices are adjusted to be relative to the beginning of the concatenated sequence (Question + Paragraph).

### Training
*   **Strategy:** The Ranker and Reader are trained as independent models to maintain modularity and reduce peak memory usage.
*   **Ranker Optimization:** The model is trained using **Binary Cross-Entropy Loss**. The objective is to correctly classify whether a Question-Paragraph pair is a match (1) or a non-match (0).
*   **Reader Optimization:** The model is trained using **Categorical Cross-Entropy Loss** applied independently to the start and end token predictions.
*   **Optimizer:** The **Adam** optimizer is used for both models to ensure fast convergence. Gradient clipping is applied to stabilize training.

### Evaluation
1.  **Candidate Generation:** The test document is segmented into candidate paragraphs.
2.  **Ranking:** The Decomposable Attention Ranker processes the Question against all candidates to generate a relevance probability for each.
3.  **Selection:** The candidate with the highest probability is selected as the predicted Long Answer.
4.  **Extraction:** The Gated Convolutional Reader processes the selected paragraph (concatenated with the question) to generate probability distributions for start and end indices.
5.  **Inference:** The valid span (`start <= end`) with the highest joint probability is selected. A global confidence score is computed (Ranker Score $\times$ Reader Span Score). If this confidence is below a tuned threshold, the system predicts "Null"; otherwise, it outputs the predicted Long Answer indices and Short Answer text.
