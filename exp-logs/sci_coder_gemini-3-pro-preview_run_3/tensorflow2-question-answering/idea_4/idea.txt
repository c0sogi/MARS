### Model
The proposed solution is a **Transformer-Lite Ranker and Separable Convolutional Reader**. This architecture synthesizes the efficiency of depth-wise separable convolutions (from Model 4) with the global context capabilities of self-attention, avoiding the recurrence of RNNs and the computational cost of full-scale Transformers.

1.  **Long Answer Ranker (Siamese Self-Attention):**
    *   **Input:** Accepts the Question and a Candidate Long Answer (paragraph) as separate inputs.
    *   **Embedding:** Maps tokens to pre-trained static word embeddings (e.g., GloVe) combined with learnable positional encodings to retain sequence order information.
    *   **Encoder:** Both inputs are processed by a shared, single-layer **Transformer Encoder Block**. This consists of a Multi-Head Self-Attention mechanism to capture global word-to-word dependencies, followed by a lightweight Feed-Forward Network.
    *   **Aggregation:** A **Global Max Pooling** operation is applied to the sequence of encoded vectors to extract the most prominent features, resulting in a single dense vector for the Question and one for the Candidate.
    *   **Scoring:** The relevance score is calculated using the **Dot Product** between the two vectors.

2.  **Short Answer Reader (Separable ConvNet):**
    *   **Input:** Concatenates the Question and the Top-Ranked Candidate Paragraph into a single sequence.
    *   **Encoder:** The sequence is passed through a stack of **Depthwise Separable Convolution** blocks. Each block performs a spatial convolution independently over each channel (depthwise), followed by a 1x1 convolution (pointwise) to mix channels. This structure captures local n-gram context with significantly fewer parameters and computations than standard CNNs.
    *   **Output:** Two independent dense layers project the final convolutional features to logits, predicting the start and end token indices of the short answer.

### Data
*   **Candidate Generation:** The raw document text is parsed to identify top-level HTML tags (e.g., `<P>`, `<Table>`, `<Ul>`), splitting the document into discrete candidate paragraphs.
*   **Tokenization:** Text is tokenized by splitting on whitespace. Tokens are mapped to indices in a vocabulary derived from the pre-trained embeddings.
*   **Ranker Dataset:** Training pairs are constructed. Positive pairs consist of the Question and the ground-truth paragraph. Negative pairs are selected using **Hard Negative Mining** (e.g., paragraphs with high TF-IDF overlap with the question but no answer) to force the model to learn semantic relevance rather than just lexical matching.
*   **Reader Dataset:** Only positive paragraphs containing a valid short answer are used. The start and end indices are adjusted to be relative to the beginning of the concatenated sequence.

### Training
*   **Strategy:** The Ranker and Reader are trained independently to maintain modularity and reduce memory usage.
*   **Ranker Optimization:** Trained using **Hinge Loss** (Margin Ranking Loss). The model learns to score the positive candidate higher than a negative candidate by a fixed margin.
*   **Reader Optimization:** Trained using **Categorical Cross-Entropy Loss** for the start and end positions.
*   **Optimizer:** The AdamW optimizer is used for both models to provide weight decay and stable convergence.

### Evaluation
1.  **Preprocessing:** The test document is segmented into candidate paragraphs.
2.  **Ranking:** The Siamese Self-Attention Ranker encodes the Question and all Candidates, computing a similarity score for each.
3.  **Selection:** The candidate with the highest similarity score is selected as the predicted Long Answer.
4.  **Extraction:** The Separable ConvNet Reader processes the selected candidate (concatenated with the question) to predict start and end probabilities.
5.  **Inference:** The valid span (`start <= end`) with the highest joint probability is chosen. A global confidence score is calculated; if it falls below a tuned threshold, the system predicts "Null", otherwise it outputs the Long Answer indices and Short Answer text.
