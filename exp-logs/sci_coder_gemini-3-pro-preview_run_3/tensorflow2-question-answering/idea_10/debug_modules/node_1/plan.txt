The issue is a race condition between directory initialization and cleanup in the main execution script. The `Config.ensure_directories()` method is called at the module level when `runfile.py` loads, creating the necessary working directories. However, the `if __name__ == "__main__":` block subsequently deletes these directories using `shutil.rmtree` to ensure a clean state, but fails to recreate them before the data processing functions attempt to save files. This results in an `OSError` because the target directory for `vocab.parquet` no longer exists. The fix is to explicitly call `Config.ensure_directories()` immediately after the cleanup step to restore the directory structure.
