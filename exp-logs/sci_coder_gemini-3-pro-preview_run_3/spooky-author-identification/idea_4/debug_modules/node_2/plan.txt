The issue stems from Python's behavior of evaluating default arguments at function definition time (import time) rather than at call time. In `library/data_manager.py`, the function `load_raw_data` is defined with `debug_size=Config.DEBUG_SAMPLE_SIZE`. This binds `debug_size` to the initial value of `100` when the module is imported. Although `runfile.py` updates `Config.DEBUG_SAMPLE_SIZE` to `60` at runtime, calls to `load_raw_data` that rely on the default argument (like the one inside `run_statistical_pipeline`) continue to use the stale value of `100`. This causes a mismatch in dataset sizes between the main script (60 samples) and the statistical pipeline (100 samples), triggering the `AssertionError`.

To fix this, I will modify `load_raw_data` to set the default value of `debug_size` to `None` and assign it the current value of `Config.DEBUG_SAMPLE_SIZE` inside the function body. This ensures the updated configuration value is retrieved at runtime (Cite debug_lesson_2).
