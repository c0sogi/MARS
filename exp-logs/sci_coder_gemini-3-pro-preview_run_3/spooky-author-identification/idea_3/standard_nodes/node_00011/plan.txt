5.  **Validation & Failure Analysis**:
    *   I will generate final predictions on the hold-out `val_df`.
    *   I will calculate and print the `Final Validation Metric` (Log Loss).
    *   I will perform failure analysis by calculating the correlation between the error magnitude (negative log probability of the true class) and the text length (`log_char_len`), printing the result.
6.  **Submission**: If the validation metric is below the specified threshold, I will generate predictions for the test set using the trained ensemble and save them to `submission.csv`.
