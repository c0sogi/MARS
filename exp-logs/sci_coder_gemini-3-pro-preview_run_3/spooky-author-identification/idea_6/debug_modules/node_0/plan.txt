This script demonstrates the end-to-end pipeline for the Author Identification task using the provided library modules. It covers configuration setup, feature extraction (TF-IDF and Stylometric), statistical modeling (Logistic Regression), Masked Language Modeling (MLM) adaptation, Neural Network training (Transformer with custom head), and Ensemble optimization.

To ensure the demonstration runs quickly within the time limit, the script overrides specific `Config` parameters to enable `DEBUG` mode (using a small data subset), reduces the number of epochs, and minimizes cross-validation folds. It includes assertions at each stage to verify the correctness of data shapes and pipeline logic.
