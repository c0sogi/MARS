# Proposed Strategy: Semi-Supervised Hybrid Ensemble with Explicit Stylometric Augmentation

## Model
The proposed solution evolves the "Heterogeneous Hybrid Ensemble" (Idea 5) by introducing a **Semi-Supervised Self-Training Pipeline** and augmenting the statistical branch with **Explicit Stylometric Features**.

1.  **Neural Branch (The Context Experts):**
    *   Retain the **DeBERTa-v3-base** and **RoBERTa-base** backbones to ensure error orthogonality **Cite {solution_lesson_node_00008}**.
    *   Utilize the **Multi-Layer Concatenation Head** (extracting `[CLS]` tokens from the last 4 layers) to preserve hierarchical stylistic features (morphology $\to$ syntax $\to$ semantics) **Cite {solution_lesson_node_00019}**.
    *   Apply **Adversarial Weight Perturbation (AWP)** during training to flatten the loss landscape and improve generalization.

2.  **Statistical Branch (The Augmented Stylometrist):**
    *   **Sparse Features:** Retain the **TF-IDF pipeline** with **Word N-grams (1-2)** and **Character N-grams (3-5)** to capture vocabulary and orthography **Cite {solution_lesson_node_00002}**.
    *   **Dense Features (Structural Innovation):** Augment the sparse matrix with a vector of **Explicit Stylometric Meta-Features**. Based on the finding that error correlates with text length **Cite {solution_lesson_node_00002}**, we will explicitly model:
        *   Sentence Length (Character and Word counts).
        *   Punctuation Density (Frequency of `;`, `:`, `,`, `?`, `!`, `-`).
        *   Lexical Diversity (Type-Token Ratio).
        *   Average Word Length.
    *   **Classifier:** These dense features will be scaled and concatenated with the sparse TF-IDF features, feeding into the weighted **Logistic Regression / Multinomial Naive Bayes** ensemble **Cite {solution_lesson_node_00003}**.

## Data
1.  **Domain-Adaptive Pre-training (DAPT):**
    *   Perform **Masked Language Modeling (MLM)** on the concatenated Train and Test corpora using both Transformer backbones. This adapts the models to the 19th-century literary domain **Cite {solution_lesson_node_00017}**.
2.  **Pseudo-Labeling (Self-Training):**
    *   This strategy introduces a **Two-Stage Pipeline**.
    *   **Stage 1 Data:** The original labeled training set.
    *   **Stage 2 Data:** The original training set augmented with high-confidence predictions from the Test set. Test samples where the Stage 1 ensemble predicts a probability $> 0.95$ will be added to the training pool with their predicted labels (Hard Pseudo-Labeling).

## Training
1.  **Stage 1 (Teacher Training):**
    *   Train the Neural and Statistical models using **Stratified K-Fold Cross-Validation (k=5)**.
    *   Generate **Out-Of-Fold (OOF)** predictions and Test predictions.
    *   Optimize the ensemble weights ($w_{stat}, w_{deberta}, w_{roberta}$) on the OOF predictions **Cite {solution_lesson_node_00014}**.
2.  **Pseudo-Label Generation:**
    *   Apply the optimized Stage 1 ensemble to the Test set.
    *   Filter samples with max probability $> 0.95$ and merge them into the training folds.
3.  **Stage 2 (Student Retraining):**
    *   Retrain all branches (Neural and Statistical) on the augmented dataset.
    *   **Crucial:** Use the *original* non-augmented validation folds to monitor performance and prevent concept drift.
    *   Re-optimize the ensemble weights on the original validation set.

## Evaluation
1.  **Inference:**
    *   Pass the test data through the Stage 2 (Retrained) models.
    *   Average the predictions across the 5 folds for each branch (Bagging).
2.  **Blending:**
    *   Combine the bagged predictions using the Stage 2 optimized weights.
    *   Apply numerical stability clipping ($max(min(p, 1-10^{-15}), 10^{-15})$).
