# Hybrid Transformer-Statistical Ensemble Strategy

## Model
The proposed solution implements a **Hybrid Neural-Statistical Ensemble** that combines the deep contextual understanding of modern Large Language Models with the robust surface-level stylometry of linear models.

1.  **Deep Learning Branch (Structural Innovation):**
    *   Utilize a **Pre-trained Transformer** backbone (specifically `microsoft/deberta-v3-base` or `roberta-base`) fine-tuned for sequence classification. Unlike the previous Bag-of-Words approaches, this architecture employs self-attention mechanisms to capture complex syntactic structures, semantic context, and long-range dependencies. This directly addresses the weakness identified in previous iterations where performance degraded on shorter texts, as Transformers can extract richer signals from limited tokens compared to sparse n-gram matches.
2.  **Statistical Branch (Strategic Retention):**
    *   Retain the highly effective **TF-IDF (Word + Character N-gram) pipeline** feeding into a **Logistic Regression and Multinomial Naive Bayes** weighted ensemble.
    *   This component preserves the explicit modeling of sub-word morphological features (character n-grams) which were found to be critical for authorship attribution **Cite {solution_lesson_node_00002}**.
    *   It also maintains the stability benefits of combining discriminative (LR) and generative (NB) models **Cite {solution_lesson_node_00003}**.
3.  **Ensemble Aggregation:**
    *   The final predictions will be generated via a **Weighted Soft Voting** mechanism, combining the probability distributions from the Transformer branch and the Statistical branch.

## Data
1.  **Preprocessing:**
    *   **Transformer Branch:** Raw text will be processed using the specific **Tokenizer** associated with the pre-trained model (e.g., DeBERTaTokenizer). Special care will be taken to preserve casing and punctuation, as these are vital stylometric signals.
    *   **Statistical Branch:** Text will be vectorized using `TfidfVectorizer` with `sublinear_tf` scaling. The feature set will consist of a concatenation of **Word N-grams** (1-2) and **Character N-grams** (3-5) to capture vocabulary and orthography respectively **Cite {solution_lesson_node_00002}**.
2.  **Splitting:**
    *   The provided stratified validation split (from the metadata) will be used to monitor the Transformer's fine-tuning and to optimize the ensemble weights.

## Training
1.  **Transformer Fine-Tuning:**
    *   The model will be trained using **Categorical Cross-Entropy Loss** with the **AdamW** optimizer.
    *   A linear learning rate scheduler with warmup will be employed to prevent early divergence.
    *   **Early Stopping** based on validation Log Loss will be used to prevent overfitting.
2.  **Statistical Model Fitting:**
    *   The Logistic Regression and Naive Bayes models will be refitted on the training data using the hyperparameters established in previous successful iterations **Cite {solution_lesson_node_00003}**.
3.  **Ensemble Optimization:**
    *   After training both branches, the optimal blending weights (e.g., $w \cdot P_{transformer} + (1-w) \cdot P_{statistical}$) will be determined by minimizing Log Loss on the validation set.

## Evaluation
1.  **Inference:**
    *   Generate probability distributions for the test set using both the fine-tuned Transformer and the Statistical ensemble.
2.  **Calibration & Formatting:**
    *   Apply the learned ensemble weights to combine the predictions.
    *   Apply the required numerical stability clipping ($max(min(p, 1-10^{-15}), 10^{-15})$) to the final probabilities before generating the submission CSV.
