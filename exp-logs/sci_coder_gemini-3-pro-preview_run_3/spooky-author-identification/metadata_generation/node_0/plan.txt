The implementation strategy involves the following steps:
1.  **Setup and Loading**: Define the input (`./input`) and output (`./metadata`) directories. Load the raw `train.csv` and `test.csv` files using pandas.
2.  **Data Splitting**: Use `sklearn.model_selection.train_test_split` to create a validation set from the training data. The split will use a fixed random state (42), a test size of 20%, and stratified sampling based on the 'author' column to ensure class distribution is preserved.
3.  **Metadata Generation**: Save the split datasets (train, validation) and the original test dataset to the `./metadata` directory as CSV files. These files will serve as the metadata, containing IDs, text, and labels (for train/val).
4.  **Validation and Verification**:
    *   Reload the generated metadata files to verify integrity.
    *   Print summary statistics including shapes and class distributions.
    *   Programmatically assert that the split ratio is approximately 80:20.
    *   Programmatically assert that the class distribution in the validation set matches the training set (verifying stratification).
    *   Since the dataset consists of inline text rather than references to external files, the file path resolution check will be explicitly skipped with a log message.
