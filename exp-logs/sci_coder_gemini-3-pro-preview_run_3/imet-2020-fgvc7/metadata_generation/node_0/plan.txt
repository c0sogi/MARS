The following script generates the required metadata for the artwork classification task.

**Implementation Strategy:**
1.  **Setup & Data Loading**: The script defines the input and output directories and loads the `train.csv` and `sample_submission.csv` files.
2.  **Data Preparation**: It parses the `attribute_ids` column in the training data into lists of labels. To satisfy the requirement for stratified sampling in a multi-label classification task, it uses `MultiLabelBinarizer` to convert these lists into a sparse binary matrix suitable for stratification.
3.  **Stratified Split**: The script utilizes `iterative_train_test_split` from the `skmultilearn` library. This algorithm is designed to split multi-label data while maintaining the distribution of all labels across the training and validation sets. It targets an 80:20 split ratio.
4.  **Metadata Generation**:
    *   It creates `train.csv` and `val.csv` metadata files containing the `id`, `attribute_ids`, and the relative `file_path` (constructed as `train/{id}.png`).
    *   It creates a `test.csv` metadata file using IDs from `sample_submission.csv` and constructing paths as `test/{id}.png`.
5.  **Verification**:
    *   **File Existence**: It checks a random sample of 1000 paths from each dataset to ensure the files exist in the `./input` directory.
    *   **Split Ratio**: It asserts that the validation set size is approximately 20% of the total training data.
    *   **Stratification**: It verifies that the distribution of the most frequent labels is consistent between the training and validation sets.
