The implementation strategy focuses on efficiency and robustness given the large number of images and the time constraints.

1.  **Setup and Loading**: We will load the `metadata/train.csv` file to identify the training set. We will use a fixed random seed for reproducibility.
2.  **Target Analysis**: We will parse the multi-label `attribute_ids` string into lists. We will calculate the distribution of label frequencies, identifying the most and least common attributes to assess class imbalance. We will also analyze the "label cardinality" (number of labels per image).
3.  **Image Analysis (Sampling Strategy)**: Processing 96,000+ images for pixel-level statistics is computationally expensive. We will randomly sample 5,000 images to estimate global statistics (dimensions, channels, pixel mean/std). This provides a statistically significant approximation well within the runtime limit. We will use `concurrent.futures` to parallelize image reading and processing across the available 12 vCPUs.
4.  **Relationship Analysis**: We will examine if there are correlations between image metadata (width, height, file size) and the target variable (specifically, the number of labels per image).
5.  **Reporting**: The results will be printed in the specified format, strictly adhering to the "no progress bars" and "silent execution" rules.
