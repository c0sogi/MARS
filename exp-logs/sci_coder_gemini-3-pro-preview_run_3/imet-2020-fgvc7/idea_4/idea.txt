Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Ensemble of Heterogeneous Architectures** as the optimized strategy. This approach moves beyond monolithic model reliance to a multi-backbone system that leverages distinct inductive biases to capture the complex, high-cardinality label space.

# Model
I propose a structural evolution to a **Two-Model Ensemble** comprising:
1.  **Model A (Texture Specialist): ResNet101d**. We will retain this architecture as it proved highly effective in the previous best solution. Its "Deep Stem" modification (3x3 convolution stack) preserves low-level spatial information crucial for identifying artistic textures and fine details (Cite solution_lesson_node_00014).
2.  **Model B (Context Specialist): ConvNeXt-Base**. We will re-introduce this modern architecture but correct the implementation flaws from previous attempts. ConvNeXt utilizes large kernels (7x7) and Transformer-inspired design patterns to capture broader global context and semantic hierarchies, complementing the local feature focus of the ResNet.
    *   *Correction:* Unlike the failed experiment in Lesson 8, we will **not** subsample the dataset to fit this model. The A100 GPU has sufficient memory to train this heavier backbone if batch sizes are managed correctly (Cite solution_lesson_node_00008).

Both models will utilize a standard classification head (Global Average Pooling followed by a Linear projection) mapping to the 3,474 classes.

# Data
*   **Dataset Coverage:** We will strictly utilize the **full training dataset (96,118 images)** for both models. We explicitly reject any strategy that reduces data volume to accommodate model complexity, as coverage of the long tail is the primary performance driver (Cite solution_lesson_node_00008).
*   **Resolution:** Input images will be resized to **352x352 pixels**. This resolution was empirically found to offer a superior trade-off between detail preservation and computational throughput compared to 320x320 (Cite solution_lesson_node_00014).
*   **Preprocessing:** Standard normalization and lightweight Random Horizontal Flip augmentation will be applied to maximize throughput.

# Training
Both models will be trained independently using the following optimized protocol:
*   **Loss Function:** We will employ **Asymmetric Loss (ASL)**. This addresses the extreme sparsity of the target vectors by down-weighting easy negatives (Cite solution_lesson_node_00011). Crucially, we will implement **explicit float32 casting** for the logits and targets within the loss function to prevent the numerical instability and `NaN` divergence observed with mixed-precision training (Cite solution_lesson_node_00013).
*   **Optimizer & Schedule:**
    *   **Optimizer:** AdamW with Automatic Mixed Precision (AMP).
    *   **Scheduler:** OneCycleLR with a maximum learning rate of **1e-3**. We will maintain this aggressive learning rate to ensure convergence of the classification heads (Cite solution_lesson_node_00010).
    *   **Duration:** Each model will be trained for **12 epochs**. This duration allows sufficient time for the loss to stabilize and the F1 metric to mature, avoiding the "metric-loss divergence" pitfalls of shorter runs (Cite solution_lesson_node_00012).

# Evaluation
*   **Test Time Augmentation (TTA):** For every test image, we will generate predictions using both the original and a horizontally flipped view (Cite solution_lesson_node_00004).
*   **Ensemble Aggregation:** The TTA-averaged probability vectors from Model A (ResNet101d) and Model B (ConvNeXt-Base) will be averaged together. This ensemble approach mitigates the non-deterministic variance inherent in single-model training (Cite solution_lesson_node_00016).
*   **Threshold Calibration:** We will perform a linear search on the validation set using the *ensembled* probabilities to find the optimal decision threshold that maximizes the Micro-F1 score, and apply this calibrated threshold to the final test predictions (Cite solution_lesson_node_00001).
