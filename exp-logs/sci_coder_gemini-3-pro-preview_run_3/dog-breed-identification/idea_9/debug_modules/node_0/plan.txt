5.  **Training Loop Execution**: Execute `train_loop` for a single fold on the small debug dataset. This verifies the integration of the engine, model, and data loaders, and generates checkpoint files.
6.  **Weight Averaging**: Use the generated checkpoints to demonstrate `average_checkpoints`, producing a final model file.
7.  **Inference Pipeline**: Execute `run_inference` to generate predictions using the trained model. Validate the structure and dimensions of the output submission file.
8.  **Cleanup**: (Implicit) The script uses a specific demo directory which isolates outputs.
