The execution failure is caused by an API incompatibility with `albumentations==2.0.8`. The installed version of the library has standardized image resizing transforms (like `RandomResizedCrop`, `CenterCrop`, and `Resize`) to use a single `size` argument (a tuple of `(height, width)`) instead of separate `height` and `width` arguments. The original code uses the deprecated 1.x syntax, triggering a Pydantic validation error (`InitSchema size Field required`).

To fix this, I will update `library/dataset.py` to replace the separate `height` and `width` arguments with the `size` tuple argument for `RandomResizedCrop`, `CenterCrop`, and `Resize`.
