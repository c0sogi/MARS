Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and `seed_everything()`. To strictly adhere to the "fast baseline" and time limit constraints (2 hours), I will dynamically modify `Config.FINE_TUNE_EPOCHS` to 4 (down from 30) and `Config.WARMUP_EPOCHS` to 1. This ensures the 5-fold training completes in approximately 40 minutes.
2.  **Data Preparation (5-Fold Split)**: Load the provided `train.csv` metadata. Since the library expects specific CSV paths, I will use `StratifiedKFold` to split the training data into 5 folds. For each fold iteration, I will save temporary `train_fold_x.csv` and `val_fold_x.csv` files and monkey-patch `Config.TRAIN_CSV` and `Config.VAL_CSV` to point to these subsets. This allows me to use the provided `get_dataloaders` and `train_fold` functions without modification.
3.  **Training Loop**: Iterate through the 5 folds. For each fold, instantiate a new `ConvNeXt-Small` model and train it using `train_fold`. This saves the best model checkpoint for each fold to the working directory.
4.  **Validation & Metric**: After training, I will perform inference on the official hold-out validation set (`metadata/val.csv`). I will load all 5 trained models, generate predictions using Test-Time Augmentation (TTA), average the probabilities (Ensemble), and compute the `Multi Class Log Loss`. The result will be printed as `Final Validation Metric: <value>`.
5.  **Failure Analysis**: I will calculate the Cross-Entropy loss for each sample in the validation set. Then, I will extract metadata (file size, width, height, aspect ratio) for these images and calculate the Pearson correlation between the loss and these features to identify potential biases or error sources.
6.  **Submission**: I will compare the calculated validation metric against the threshold (0.14004325100369866). If the model performs well enough, I will trigger the `run_inference()` function to generate predictions for the test set and save `submission.csv`.
