# Proposed Solution: ConvNeXt-Tiny with Test-Time Augmentation

## Model
We will transition from the ResNet-50 architecture to **ConvNeXt-Tiny**.
*   **Architecture:** ConvNeXt is a modern convolutional architecture that modernizes the standard ResNet design by incorporating design choices from Vision Transformers (e.g., larger 7x7 kernels, inverted bottleneck layers, and fewer activation functions). This architecture typically provides superior feature extraction and generalization for fine-grained classification tasks compared to standard ResNets, while remaining computationally efficient.
*   **Head:** The pre-trained classification head will be replaced with a single linear layer mapping the backbone's output features to the 120 dog breed classes.
*   **Initialization:** The backbone will be initialized with ImageNet-1k pre-trained weights.

## Data
*   **Training Preprocessing:** We will apply **Random Resized Crops** (224x224) and **Random Horizontal Flips**. We will explicitly **exclude Label Smoothing** from the target generation process to avoid penalizing the model for high-confidence predictions, which is detrimental to the Log Loss metric (Cite solution_lesson_node_00003).
*   **Validation/Test Preprocessing:** Images will be resized to 256x256, followed by a **Center Crop** to 224x224 and normalization.

## Training
We will employ a rigorous training pipeline designed to maximize stability and metric alignment:
*   **Loss Function:** We will use standard **Cross-Entropy Loss** with hard targets. This ensures the model is optimized directly for the evaluation metric (Log Loss) without the artificial confidence penalties introduced by smoothing techniques (Cite solution_lesson_node_00003).
*   **Strategy:** We will strictly adhere to the **Two-Phase Transfer Learning** strategy (Cite solution_lesson_node_00001):
    1.  **Warm-up:** Freeze the ConvNeXt backbone and train only the new head for 1 epoch using a higher learning rate (e.g., 1e-3) to align the random weights.
    2.  **Fine-tuning:** Unfreeze the entire network and train for additional epochs with a reduced learning rate (e.g., 1e-5) to refine features.
*   **Metric Tracking:** We will ensure the validation loop calculates Log Loss against the hard ground-truth labels, completely decoupled from any training-time regularization, to prevent misleading performance signals (Cite solution_lesson_node_00002).

## Evaluation
To further minimize Log Loss and improve prediction stability, we will implement **Test-Time Augmentation (TTA)** during the inference phase.
*   **Procedure:** Instead of a single prediction per test image, the model will generate predictions for multiple views of the image (e.g., the original center crop plus a horizontally flipped version).
*   **Aggregation:** The probability vectors from these views will be averaged to produce the final prediction. This technique structurally reduces the variance of the predictions and penalizes over-confident outliers, directly improving the Log Loss score.
