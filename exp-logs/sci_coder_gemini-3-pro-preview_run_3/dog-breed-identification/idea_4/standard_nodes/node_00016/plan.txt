The issue is that the training process encountered a `CUDA out of memory` error because the batch sizes defined in the configuration were too large for the actual available GPU memory (approx. 16GB), which is less than the expected 40GB A100. To resolve this, I will reduce the batch sizes for Phase 2 and Phase 3 in `library/config.py`. Additionally, I will implement Automatic Mixed Precision (AMP) in `library/engine.py` using `torch.cuda.amp.autocast` and `GradScaler` to further reduce memory usage and improve training efficiency.

def predict_tta(model, dataloader, device):
    """
    Performs inference with Test-Time Augmentation (Horizontal Flip).

    Args:
        model: PyTorch model.
        dataloader: Test dataloader (returns image, id).
        device: Device to predict on.

    Returns:
        tuple: (list of ids, numpy array of predictions)
    """

    all_preds = []
    all_ids = []

    with torch.no_grad():
        for images, ids in dataloader:
            images = images.to(device, non_blocking=True)

            # 1. Forward pass with original images
            outputs_orig = model(images)
            probs_orig = torch.softmax(outputs_orig, dim=1)

            avg_probs = (probs_orig + probs_flipped) / 2.0
