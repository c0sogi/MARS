### Implementation Strategy

1.  **Configuration Override**: Modify the `Config` class attributes at runtime to establish a "fast baseline." This involves reducing the number of training epochs (e.g., to 5) and ensuring the device is set to GPU.
2.  **Data Loading**: Utilize `library.dataset.get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test sets.
3.  **Model Construction**: Build the ConvNeXt-Base model using `library.model.build_model`.
4.  **Training Pipeline**: Implement the two-phase training strategy manually to adhere to the fast baseline constraints:
    *   **Warm-up**: Freeze the backbone and train only the classifier head for 1 epoch.
    *   **Fine-tuning**: Unfreeze the entire model and train for the reduced number of epochs using a Cosine Annealing scheduler.
    *   **Checkpointing**: Save the model with the best validation loss.
5.  **Validation & Metrics**: Load the best saved model and evaluate it on the full validation set to compute the final Multi Class Log Loss. Print this metric with full precision.
6.  **Failure Analysis**:
    *   Compute the Cross-Entropy Loss for each sample in the validation set.
    *   Extract metadata features (width, height, aspect ratio, file size) for each validation image.
    *   Calculate and print the Pearson correlation between the error magnitude (loss) and these input features to identify potential biases.
7.  **Conditional Submission**: Compare the final validation metric against the threshold (`0.14004325100369866`). If the model performs better (lower loss), generate predictions using Test-Time Augmentation (TTA) via `library.predict.inference_with_tta` and save the submission file.
