Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `utils`. Set random seeds for reproducibility.
2.  **Training Loop**: Implement a loop iterating through the 5 Stratified K-Folds. For each fold, invoke `run_fold_training` from `library.train`. To ensure the "fast baseline" requirement is met while retaining high performance, I will override the default 30 epochs to 20 epochs, which is sufficient for convergence on an A100 GPU without exceeding the time limit.
3.  **OOF Validation & Metric Calculation**:
    *   After training, iterate through each fold again to perform inference on the validation set (Out-Of-Fold predictions).
    *   Collect predictions, true labels, and simultaneously extract metadata (file size, dimensions) using `PIL` (lazy loading) for efficiency.
    *   Compute the global **Multi Class Log Loss** on the concatenated predictions.
    *   Print the metric in the required format.
4.  **Failure Analysis**:
    *   Calculate per-sample loss (Cross Entropy).
    *   Compute Pearson correlations between the loss and image properties (width, height, aspect ratio, file size) to identify systematic failures.
    *   Print the correlations.
5.  **Submission**:
    *   Compare the calculated validation metric against the threshold (`0.14004325100369866`).
    *   If the model performs well enough, call `generate_ensemble_submission` from `library.inference` to create the final `submission.csv`.
