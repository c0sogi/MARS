The solution implements a robust heterogeneous ensemble pipeline orchestrated via `runfile.py`.

### Strategy Outline
1.  **Configuration Override**: To adhere to the "fast baseline" constraint while ensuring convergence, the epoch count is optimized to 15, and the batch size is increased to 64 to fully utilize the A100 GPU.
2.  **Data Loading**: The script utilizes the provided `get_dataloaders` function, leveraging cached metadata for efficiency.
3.  **Heterogeneous Training Loop**:
    - Iterates through the two specified architectures: **ConvNeXt-Small** (local features) and **Swin-Small** (global features).
    - Implements **Layer-Wise Learning Rate Decay (LLRD)** to preserve pre-trained feature hierarchies.
    - Utilizes **Cosine Annealing** for scheduler optimization.
    - Saves the best checkpoint based on validation loss.
4.  **Post-Hoc Calibration**:
    - After training, the best model for each architecture is loaded.
    - A **Temperature Scaler** is fitted on the validation logits to align confidence scores with the Log Loss metric.
5.  **Ensemble & Evaluation**:
    - Validation probabilities from both calibrated models are averaged.
    - The final **Multi-Class Log Loss** is computed on the hold-out validation set.
6.  **Failure Analysis**:
    - Systematically analyzes prediction errors by calculating the correlation between sample-wise Log Loss and input metadata (File Size and Aspect Ratio) to identify potential biases.
7.  **Conditional Submission**:
    - If the validation metric meets the strict threshold (< 0.14004), the script proceeds to inference.
    - **Test-Time Augmentation (TTA)** is applied (averaging predictions from original and horizontally flipped images).
    - Final predictions are generated, formatted, and saved to `./submission/submission.csv`.
