Based on the lessons learned, I propose the following optimized strategy. The core structural innovation is the transition from a single-model training loop to a **Stratified K-Fold Cross-Validation Ensemble Pipeline**. This directly addresses the data scarcity and metric variance issues identified in previous experiments while maximizing the performance of the optimal architecture found so far.

# Proposed Solution: Stratified K-Fold Ensemble with ConvNeXt-Small and Model EMA

## Model
We will utilize the **ConvNeXt-Small** architecture.
*   **Architecture Choice:** We retain **ConvNeXt-Small** as it proved to be the optimal balance between capacity and generalization. It significantly outperformed the "Tiny" variant (Cite solution_lesson_node_00009) but avoided the overfitting and efficiency issues observed with "Base" and "Large" variants on this dataset size (Cite solution_lesson_node_00013, Cite solution_lesson_node_00016).
*   **Structural Enhancement (EMA):** We will implement **Model Exponential Moving Average (EMA)**. During training, we will maintain a shadow copy of the model weights that updates as a moving average of the trained weights. This technique often yields a flatter solution in the weight space, improving calibration and Log Loss performance on unseen data.

## Data
We will enforce a strict augmentation pipeline that prioritizes geometric diversity.
*   **Preprocessing Pipeline:** The pipeline will consist of **`RandomResizedCrop`** followed by **`RandomHorizontalFlip`** and finally **`RandAugment`**.
    *   We explicitly retain `RandomResizedCrop` to prevent the overfitting observed when using static resizing (Cite solution_lesson_node_00012).
    *   We ensure `RandomHorizontalFlip` is applied *before* `RandAugment` to guarantee the model learns basic spatial symmetries, which `RandAugment` alone does not provide (Cite solution_lesson_node_00014).
*   **Resolution:** We will fix the input resolution to **224x224**. Higher resolutions (e.g., 384x384) previously failed because the necessary reduction in batch size destabilized training (Cite solution_lesson_node_00016).
*   **Target Formatting:** We will strictly use **Hard Labels** (0 or 1) and avoid Label Smoothing. This ensures the training objective is perfectly aligned with the Multi-Class Log Loss evaluation metric (Cite solution_lesson_node_00003).

## Training
We will adopt a **5-Fold Stratified Cross-Validation** strategy.
*   **Procedure:** Instead of a single train/validation split, we will divide the dataset into 5 stratified folds. We will train 5 independent ConvNeXt-Small models, where each model trains on 4 folds (80%) and validates on the remaining fold (20%). This ensures that 100% of the training data is eventually used to learn features, mitigating the limitations of the small dataset size (Cite solution_lesson_node_00013).
*   **Schedule:** Each fold will use a **Cosine Annealing** scheduler with `T_max=30` epochs. This extended decay horizon allows the optimizer to find better minima compared to shorter schedules (Cite solution_lesson_node_00007).
*   **Phases:** We will maintain the **Two-Phase Transfer Learning** strategy: freeze the backbone for 1 epoch to align the head, then unfreeze the entire network for the remaining epochs (Cite solution_lesson_node_00001).
*   **Loss:** We will use standard **Cross-Entropy Loss** for both training and validation to prevent metric decoupling (Cite solution_lesson_node_00002).

## Evaluation
*   **Ensemble Inference:** For the test set, we will generate predictions using all 5 trained models. The final probability for each image will be the arithmetic mean of the 5 outputs. This averaging significantly reduces prediction variance and improves Log Loss.
*   **Test-Time Augmentation (TTA):** For each of the 5 models, we will predict on both the original image and a horizontally flipped version, averaging the results before the ensemble aggregation.
