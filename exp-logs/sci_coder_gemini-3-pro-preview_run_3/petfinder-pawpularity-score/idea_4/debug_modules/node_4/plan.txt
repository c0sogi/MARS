The error `TypeError: got an unexpected keyword argument 'squared'` arises because the installed version of `scikit-learn` (1.7.2) has removed the `squared` parameter from `mean_squared_error`, which was deprecated in version 1.4. To fix this targeted API incompatibility (Cite debug_lesson_4), I will modify `library/utils.py` to calculate the standard Mean Squared Error and then manually compute the square root using `np.sqrt` to derive the Root Mean Squared Error.
