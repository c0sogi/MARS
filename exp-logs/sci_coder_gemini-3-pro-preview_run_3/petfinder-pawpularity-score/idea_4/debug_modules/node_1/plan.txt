The issue stems from a breaking change in `albumentations` version 2.0+, where transforms like `RandomResizedCrop` and `Resize` now require a single `size` argument (a tuple of `(height, width)`) instead of separate `height` and `width` arguments. The current implementation uses the deprecated signature, causing a `ValidationError`. To fix this, I will update the instantiation of these transforms in `library/data.py` to use the `size` parameter, ensuring compatibility with the installed library version.
