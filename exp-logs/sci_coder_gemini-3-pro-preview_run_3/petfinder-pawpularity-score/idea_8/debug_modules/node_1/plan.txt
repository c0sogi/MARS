The issue is that the `FeatureExtractor._process_loader` method assumes the input tensor always has 5 dimensions `(Batch, TTA_Crops, Channels, Height, Width)` corresponding to TTA-enabled data. However, the validation and test datasets are instantiated with `tta=False`, resulting in 4-dimensional tensors `(Batch, Channels, Height, Width)`, which causes a `ValueError` during unpacking. To fix this, I will implement a conditional check on the tensor dimensions: if the input is 5D, it unpacks `t` (crops) and flattens the batch; if it is 4D, it sets `t=1` and uses the tensor as is. This ensures the method handles both TTA and non-TTA batches correctly.
