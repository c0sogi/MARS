The following implementation strategy outlines the execution flow for the `runfile.py` script:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility using the provided `library.utils` and `library.config`.
2.  **Feature Extraction**: Utilize the `library.feature_extractor.extract_features` function to generate or load cached embeddings (MobileNetV2 features) and metadata for the training, validation, and test datasets. This leverages the GPU if available and avoids redundant computation.
3.  **Model Training**: Instantiate the `RidgeRegressor` from `library.regressor` and fit it on the training features (concatenated image embeddings and binary metadata). This provides a fast, deterministic solution suitable for a baseline.
4.  **Validation & Metrics**: Generate predictions on the validation set. Compute the Root Mean Squared Error (RMSE) using `library.utils.compute_rmse` and print it in the specific format required (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute and print the correlation between these errors and the binary metadata features (e.g., 'Blur', 'Occlusion') to identify which characteristics lead to higher prediction errors.
6.  **Submission**: Generate predictions for the test set and save the results to the specified submission path using `library.utils.save_submission`.
