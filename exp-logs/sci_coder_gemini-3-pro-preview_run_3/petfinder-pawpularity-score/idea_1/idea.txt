To establish a highly efficient and reliable baseline, I propose a **Linear Probing** approach using a lightweight, pre-trained Convolutional Neural Network (CNN) coupled with a closed-form regression solver. This method prioritizes speed and reproducibility by avoiding the stochastic nature and computational cost of training neural networks via backpropagation or tuning complex tree ensembles.

### Model
The architecture consists of two distinct stages:
1.  **Feature Extractor (Backbone):** Utilize **MobileNetV2**, a lightweight CNN pre-trained on ImageNet. The network is completely **frozen** (no gradient updates). We remove the final classification layer and use the output of the Global Average Pooling layer, resulting in a compact 1,280-dimensional feature vector for each image.
2.  **Regressor (Head):** The 1,280 image features are concatenated with the 12 binary metadata features to form a single input vector of size 1,292. These vectors are fed into a **Ridge Regression** model (Linear Least Squares with L2 regularization). Unlike the Multi-Layer Perceptrons (MLPs) or Support Vector Machines (SVMs) used in other approaches, this model learns a simple linear mapping between the features and the Pawpularity score.

### Data
*   **Preprocessing:** Images are resized to a standard resolution of 224x224 pixels and normalized using the standard ImageNet mean and standard deviation. No data augmentation (e.g., flipping, rotation) is applied, ensuring a deterministic pipeline.
*   **Metadata:** The 12 binary columns (e.g., Focus, Eyes, Face) are cast to floating-point values and concatenated directly with the image features.
*   **Feature Caching:** To maximize efficiency, the image features for the entire dataset are extracted in a single pass and stored in memory, treating the problem as a standard tabular regression task thereafter.

### Training
The training process differs significantly from standard deep learning loops:
1.  **Extraction:** Pass the entire training set through the frozen MobileNetV2 to generate the feature matrix $X_{img}$.
2.  **Assembly:** Construct the full training matrix $X_{train}$ by horizontally stacking $X_{img}$ and the metadata matrix $X_{meta}$.
3.  **Solving:** Instead of using iterative optimizers like SGD or Adam, fit the Ridge Regression model using a linear algebra solver (e.g., Cholesky decomposition or Singular Value Decomposition). This computes the optimal weights $w$ analytically by minimizing the squared error with L2 regularization. This step typically completes in seconds.

### Evaluation
For the test set, the process is identical to the extraction phase:
1.  Resize and normalize test images.
2.  Pass images through the frozen MobileNetV2 to extract features.
3.  Concatenate with test metadata.
4.  Compute the dot product of the combined features and the learned weights $w$ to obtain the raw prediction.
5.  **Post-processing:** Clip the final predictions to the valid range of the dataset (1.0 to 100.0) to ensure physical plausibility before saving to the submission file.
