The issue is caused by the `drop_last=True` parameter in the training `DataLoader` configuration within `library/data_loader.py`. In the debug setup, the dataset size is 50 and the batch size is 8. Since 50 is not perfectly divisible by 8 ($50 = 6 \times 8 + 2$), the loader drops the last 2 samples, resulting in only 48 extracted features. This triggers the `AssertionError` in `runfile.py` which expects the number of extracted features to exactly match the input subset size. To fix this, I will set `drop_last=False` to ensure all data samples are processed during feature extraction.
