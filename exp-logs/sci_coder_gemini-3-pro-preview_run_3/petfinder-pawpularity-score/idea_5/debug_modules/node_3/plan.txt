The issue is that Python evaluates default argument values at definition time, not at runtime. In `library/data_loader.py`, the function `get_dataloaders` is defined with `debug=Config.DEBUG`. Since `Config.DEBUG` is `False` when the module is imported, the default value is frozen as `False`. Even though `runfile.py` sets `Config.DEBUG = True` at runtime, calls to `get_dataloaders()` (without arguments) inside `FeatureExtractor` still use the stale default `False`, causing the full dataset to be loaded instead of the debug subset. This leads to a shape mismatch assertion failure.

To fix this, I will modify `get_dataloaders` to use `None` as the default value and resolve `Config.DEBUG` dynamically inside the function body. This ensures the runtime value of the configuration is used, as per **Cite debug_lesson_8**.
