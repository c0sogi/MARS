Based on the lessons learned, particularly the importance of capturing "composition and layout" (Cite solution_lesson_node_00002) and the success of "Independent Component Compression" (Cite solution_lesson_node_00022), I propose a **Spatially-Aware Quad-Stream Ensemble with Pyramid Pooling**.

This strategy evolves the previous "Global Average Pooling" approach by introducing **Spatial Pyramid Pooling (SPP)**. While previous solutions effectively captured *what* is in the image (semantics/texture), they discarded *where* it is located. Since "Pawpularity" is influenced by photographic composition (e.g., rule of thirds, centering, subject focus), retaining spatial structure via SPP allows the model to differentiate between a pet centered in the frame versus one obscured in a corner, without the cost of object detection.

### Model

The architecture consists of a **Spatially-Aware Feature Extractor** feeding into a **Compressed Stacking Ensemble**:

1.  **Quad-Stream Backbones (Frozen)**:
    We retain the four high-performing backbones identified in previous experiments (Cite solution_lesson_node_00025) to capture orthogonal signals:
    *   **Swin Transformer Large**: Global composition.
    *   **EfficientNetV2 Large**: Local texture and quality.
    *   **DINOv2 Large**: Geometric correspondence (Self-Supervised).
    *   **CLIP Vision Model (Large)**: Semantic/Affective "vibe" (Language-Contrastive).
    *   All backbones are **frozen** to prevent overfitting (Cite solution_lesson_node_00014).

2.  **Spatial Pyramid Pooling (SPP)**:
    Instead of performing Global Average Pooling (GAP) which collapses the feature map to a single $1 \times 1 \times C$ vector, we implement a 2-level SPP for each backbone:
    *   **Level 0**: Global Average Pooling ($1 \times 1$ grid).
    *   **Level 1**: Quadrant Average Pooling ($2 \times 2$ grid).
    *   The outputs are flattened and concatenated, resulting in a feature vector $5 \times$ larger than the standard GAP output. This explicitly encodes the spatial distribution of features (e.g., "fur texture in the center" vs. "clutter in the top-left").

3.  **Independent Component Compression**:
    To manage the dimensionality explosion caused by SPP (potentially >20,000 dimensions), we apply **Principal Component Analysis (PCA)** independently to the concatenated SPP vector of *each* backbone (Cite solution_lesson_node_00022).
    *   We retain 95% of the variance per backbone. This compresses the spatial information into the most salient "Eigen-Layouts" and balances the contribution of each stream.

4.  **Stacking Ensemble Head**:
    We employ the optimized heterogeneous stacking configuration:
    *   **Level 1 Base Learners**:
        *   **Support Vector Regression (SVR)**: RBF Kernel, $C=20$ (Cite solution_lesson_node_00026).
        *   **LightGBM**: Gradient Boosting.
        *   **ExtraTrees Regressor**: Randomized trees with **no feature subsampling** (i.e., `max_features=None`) to ensure all PCA components are considered (Cite solution_lesson_node_00027).
    *   **Level 2 Meta-Learner**: Linear Regression to aggregate predictions.

### Data

1.  **Preprocessing**:
    *   Images are resized to **224x224** and normalized.
    *   **Test-Time Augmentation (TTA)**: We apply Horizontal Flipping. The SPP features are extracted for both the original and flipped images, and their PCA-transformed representations are averaged (Cite solution_lesson_node_00007).
    *   **Caching**: Feature cache filenames will include a hash of the configuration (including "SPP" and backbone names) to prevent stale cache loading (Cite solution_lesson_node_00007).

2.  **Metadata Integration**:
    *   The 12 binary metadata features are concatenated with the compressed image features.
    *   **Scaling**: Metadata features are scaled by a factor of **10.0** to ensuring they exert meaningful influence on the SVR's distance-based kernel (Cite solution_lesson_node_00025).

### Training

1.  **Feature Extraction & Compression**:
    *   Pass the entire dataset through the frozen backbones.
    *   Extract feature maps/tokens and perform SPP (1x1 + 2x2).
    *   Fit four separate PCA transformers (one per backbone) on the training set SPP vectors and transform the entire dataset.
2.  **Ensemble Training (Cross-Validation)**:
    *   Perform **5-Fold Cross-Validation**.
    *   Train Level 1 models (SVR, LightGBM, ExtraTrees) on the training folds and generate Out-of-Fold (OOF) predictions.
    *   Train the Level 2 Linear Meta-Learner on the OOF predictions to minimize RMSE.
3.  **Final Retraining**:
    *   Retrain all PCA transformers, Level 1 models, and the Level 2 learner on the full training set.

### Evaluation

1.  **Inference**:
    *   Process test images through the frozen backbones using TTA.
    *   Apply SPP to generate spatial feature vectors.
    *   Project vectors using the learned PCA transformers.
    *   Concatenate with scaled metadata.
2.  **Prediction**:
    *   Generate predictions from the retrained Level 1 models.
    *   Aggregate using the Level 2 Meta-Learner.
    *   Clip final predictions to the range [1, 100].
