The following script generates metadata for the Pet Pawpularity Prediction task. It reads the raw `train.csv` and `test.csv` files, constructs relative file paths for the images, and creates a stratified 80:20 train-validation split based on the `Pawpularity` score (using binning for the continuous target). Finally, it performs rigorous validation checks on the generated metadata, including file existence verification and statistical checks on the split distribution.
