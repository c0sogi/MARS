Based on the empirical findings and lessons learned, I propose a **Stacked Hybrid-Feature Ensemble with Test-Time Augmentation**. This strategy evolves the previous successful dual-backbone approach by introducing a diverse stacking architecture to better model the subjective target and robustifying the data pipeline.

# Model
The architecture retains the **Dual-Backbone Feature Extractor** (Swin Transformer + EfficientNetV2) which successfully combined global composition and local detail (Cite solution_lesson_node_00005). However, instead of relying on a single regression head, we will implement a **Two-Level Stacking Ensemble**:
1.  **Level 1 (Base Learners):** We will train three distinct regressors on the frozen features to leverage different inductive biases:
    *   **Support Vector Regression (SVR)** with RBF kernel: To capture non-linear, distance-based similarities (Cite solution_lesson_node_00005). We will apply PCA dimensionality reduction specifically for this branch to improve training speed.
    *   **Gradient Boosting Regressor (LightGBM)**: To capture complex feature interactions and decision trees that SVR might miss, offering a robust alternative to deep MLP heads which were prone to overfitting (Cite solution_lesson_node_00003).
    *   **Ridge Regression**: To provide a stable, low-variance linear baseline (Cite solution_lesson_node_00002).
2.  **Level 2 (Meta-Learner):** A simple **Linear Regression** (or Ridge) model will take the predictions from the Level 1 models as input to generate the final score. This allows the model to dynamically weight the "distance-based" and "tree-based" signals.

# Data
1.  **Test-Time Augmentation (TTA):** We will implement the TTA strategy that was previously attempted but failed due to caching issues. During feature extraction, we will process both the original image and a horizontally flipped version, averaging their embeddings to enforce invariance and reduce variance (Cite solution_lesson_node_00007).
2.  **Robust Caching:** To prevent the "silent failure" of stale caches, we will implement **configuration-aware caching**. The cache filenames will include a hash of the configuration (e.g., including backbones used and TTA status) to ensure that changing the pipeline logic forces a re-computation of features (Cite solution_lesson_node_00007).
3.  **Preprocessing:** Images remain resized to 224x224 and normalized. Metadata is concatenated with the averaged image embeddings.

# Training
We will employ a **K-Fold Cross-Validation** scheme (e.g., 5 folds) to train the stack:
1.  **Feature Extraction:** Run the frozen backbones with TTA on the entire dataset once and cache the results. This avoids the high cost of end-to-end fine-tuning (Cite solution_lesson_node_00004).
2.  **Level 1 Training:** For each fold, train SVR, LightGBM, and Ridge on the training split and generate predictions for the validation split (Out-of-Fold predictions).
3.  **Level 2 Training:** Train the meta-learner on the collected Out-of-Fold predictions to minimize RMSE.
4.  **Final Retraining:** Retrain all Level 1 models on the full training set for final inference.

# Evaluation
For the test set, we apply the same TTA-enabled feature extraction. The extracted features are fed into the retrained Level 1 models to produce base predictions, which are then aggregated by the Level 2 meta-learner. Final predictions are clipped to the valid range [1, 100].
