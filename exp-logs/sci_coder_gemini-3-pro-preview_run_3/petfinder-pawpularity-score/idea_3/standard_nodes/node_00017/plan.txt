To improve the model's performance, I will implement a strategy focused on increasing feature diversity and replacing the weakest component of the ensemble.

1.  **Augment Feature Space**: I will add `convnext_tiny` to the feature extractor backbones. This introduces a modern ConvNet architecture to complement the existing Swin Transformer and EfficientNetV2, enriching the semantic embeddings with diverse visual representations (Cite Lesson 00005).
2.  **Maximize SVR Signal**: I will increase the `SVR_PCA_COMPONENTS` from 0.95 to 0.99. Since the Support Vector Regressor is the strongest contributor to the ensemble (Cite Lesson 00012), retaining more variance from the high-dimensional embeddings allows it to capture subtler patterns.
3.  **Replace Weak Learner**: I will replace the `Ridge` regression model (which had a negligible coefficient of ~0.005) with an `MLPRegressor`. While MLPs can overfit on frozen features in isolation (Cite Lesson 00003), within a heterogeneous stacking ensemble (Cite Lesson 00011), a properly regularized MLP provides a valuable non-linear inductive bias distinct from the SVR and LightGBM.
