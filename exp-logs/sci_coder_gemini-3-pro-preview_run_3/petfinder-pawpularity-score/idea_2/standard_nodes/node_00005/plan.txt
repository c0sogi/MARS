The implementation strategy follows the standard machine learning workflow:
1.  **Setup**: Initialize the environment with a fixed random seed for reproducibility.
2.  **Data Preparation**: utilize the provided `data_loader` to create PyTorch DataLoaders and the `feature_extractor` to generate (or load cached) feature matrices for training, validation, and testing. This leverages the pre-trained Swin Transformer and EfficientNet backbones.
3.  **Model Training**: Train the Support Vector Regressor (SVR) using the `svr_model` module. The module handles hyperparameter tuning via GridSearchCV internally.
4.  **Validation**: Evaluate the trained model on the hold-out validation set to compute the Root Mean Squared Error (RMSE).
5.  **Failure Analysis**: Compute the absolute errors of the predictions and calculate their Pearson correlation with the interpretable metadata features (e.g., Blur, Face, Occlusion) to identify sources of systematic error.
6.  **Submission**: If the validation RMSE meets the specified threshold, generate predictions for the test set and save the submission file.
